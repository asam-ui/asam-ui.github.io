把主题带入项目

使用公共主题 API 覆盖语义变量，其余配置沿用默认值。

theme.ts 
import { applyAsamTheme, createAsamTheme }
  from '@asam-ui/ui/tokens';

applyAsamTheme(
  createAsamTheme({ color: { primary: '#2D6BD6' } })
);

通过目标元素可将主题限定在局部容器。挂到 body 的弹出层仍继承全局变量。
