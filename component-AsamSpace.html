间距容器 AsamSpace

统一一组相邻内容的间距、方向与换行。

使用场景 ​

统一一组相邻内容的间距、方向与换行。

子项尺寸约束 ​

Space 会按子项内容自动计算尺寸。Slider 等依赖父容器宽度或高度的子项，需要明确的容器尺寸或受约束的布局，否则自动尺寸可能无法满足其计算条件。应先为这类子项提供可确定的宽高，再组合间距；下列受约束的滑块示例仍可使用。

使用约定 ​

direction、alignment、wrap、fill、fillRatio、spacer 和 size 按公开参数组合。size 表示间距，可以使用数值、横纵数组或真实间距别名；不能把控件密度 big 当作本入口的间距别名。default 插槽放相邻内容。

控制间距的大小 ​

通过调整 size 的值来控制间距的大小

你可以使用内置的尺寸 small、default、large 来设置大小，这些尺寸分别对应 8px、12px、16px。 默认的间距大小为 small，也就是 8px。

您也可以通过自定义的 size 来控制大小，参见下一个部分。

控制间距的大小

展开源码
许可
vue

	<AsamSpace direction="vertical" alignment="start" :size="30">
		<AsamRadioGroup
			:model-value="size"
			@update:model-value="
				(value) => {
					if (value === 'small' || value === 'default' || value === 'large') size = value;

			<AsamRadioItem value="default">默认</AsamRadioItem>
