基础输入与操作

按钮 AsamButton

触发操作，提供语义颜色、形态、图标和交互反馈。

使用场景 ​

用于提交、确认、返回等离散操作。通过 type 选择颜色，通过 plain、text、link 等属性选择形态。省略 type 时依次继承按钮组和已配置的 provider 类型；未配置时使用 secondary。

语义颜色与点击 ​

按钮点击更新本地计数。禁用和加载中的按钮不会发出业务点击事件。

语义颜色与点击

展开源码
vue
<template>
	<div class="example">
		<div class="row">
			<AsamButton @click="count++"> 默认操作 </AsamButton>
			<AsamButton type="primary" @click="count++"> 主要操作 </AsamButton>
			<AsamButton type="gradient"> 渐变操作 </AsamButton>
			<AsamButton type="accent"> 强调操作 </AsamButton>
			<AsamButton type="success"> 成功 </AsamButton>
			<AsamButton type="warning"> 提醒 </AsamButton>
			<AsamButton type="danger"> 危险 </AsamButton>
			<AsamButton type="info"> 信息 </AsamButton>
			<AsamButton disabled @click="count++"> 禁用 </AsamButton>
		</div>
		<output>点击次数：{{ count }}</output>
	</div>
</template>

图标与自定义加载 ​

图标从 ASAM 图标包导入，可直接传组件，也可先注册到当前 Vue app 再将组件名字符串传给 icon。icon 插槽覆盖 icon 属性，loading 插槽覆盖 loadingIcon 属性。图标尺寸和位置由 iconSize、iconPosition 控制；已注册的字符串组件名会实际渲染对应图标。加载时以加载图标或 loading 插槽替换普通 icon（包括右侧 icon 和 icon 插槽），加载结束后恢复普通图标。

原生提交与实例状态 ​

nativeType 区分 button、submit、reset；click 事件携带 MouseEvent。实例返回当前解析后的 size、type、disabled 等状态。

原生提交与实例状态

展开源码
vue
<template>
	<div class="example">
		<form @submit.prevent="submitted++" @reset="submitted = 0">
			<div class="row">
				<AsamButton ref="button" native-type="submit" type="primary"> 提交表单 </AsamButton>
				<AsamButton native-type="reset"> 重置表单 </AsamButton>
				<AsamButton @click="inspect"> 读取状态 </AsamButton>
			</div>
		</form>
		<output>提交次数：{{ submitted }}；{{ state }}</output>
	</div>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamButtonNativeExample' });
import { ref } from 'vue';
import { AsamButton } from '@asam-ui/ui';
import type { AsamButtonExpose } from '@asam-ui/ui';
const button = ref<AsamButtonExpose>();
const submitted = ref(0);
const state = ref('');
function inspect() {
	state.value = button.value
		? [button.value.size, button.value.type, button.value.disabled].join(' / ')
		: '';
}
</script>

ASAM 扩展与迁移 ​

ASAM 扩展包括 gradient、secondary、accent、ghost、text 颜色、block、图标位置及尺寸、pressAnimation。旧 variant 属性与 AsamButtonVariant 类型已经删除：改用 type / AsamButtonType，形态用 plain、text、link。四档尺寸用 size，不要将形态名当作尺寸。

全局类型与覆盖优先级 ​

类型按显式 type、按钮组 type、ConfigProvider.button.type、secondary 默认的顺序解析。全局 type 响应动态更新；未配置全局类型时独立按钮仍使用 ASAM secondary。按钮组与显式 gradient/accent 等 ASAM 扩展样式保持自己的优先级，不需要每个按钮重复设置 type。

API 阅读方式 ​

secondary 是 ASAM 默认颜色，底层按钮映射为 type="default"；公开实例的 type 仍返回 ASAM 解析后的颜色。autoInsertSpace、双汉字判断、点击禁用及表单 reset 保留原生按钮行为；default slot 直接传递给原生按钮。shouldAddSpace 读取原生实例的实时状态。图标位置、尺寸及按压反馈属于 ASAM 视觉扩展；加载时由原生 loading 插槽替换普通图标。

下方 API 来自当前公开类型与运行默认值。默认值标为“未知 / 未声明”时，不代表 false、空值或未支持。省略 size 保留祖先上下文继承。省略 disabled 保留表单禁用继承；加载与禁用状态阻止点击。
