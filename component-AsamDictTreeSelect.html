在树选择器上管理字典选项、重载和请求取消。

字典树选择器 ​

在树选择器上管理字典选项、重载和请求取消。

基础用法 ​

示例通过本地 provider 获取字典，支持模型更新、暂停与重载。所有请求都留在演示内部。

数据来源与覆盖 ​

dictType 与 dataSource 只选一种；dataSource 使用 defineAsamDictSource 创建，不能再传 dictValueType。短来源的 dictValueType 可将字典值转换为 string、number 或 boolean。应用通过 provideAsamData 注入 dict.get，演示在独立子应用中使用本地字典，切换语言或离开时卸载。

单选值模式使用标量或 null；对象模式使用规范化 AsamOption。多选的数组与分隔字符串模式由 multiple、valueMode、multipleValueMode 联合约束；对象模式不能使用字符串存储。切换值策略时同时调整模型类型。

层级来源一次返回完整树；children 通过字段映射规范化。数据层不开放 lazy/load 或 props.lazy/props.lazyLoad，不能从基础页的节点懒加载示例推导本组件支持。值模型保留 ASAM 标量/对象策略，不开放 native 值模式。

生命周期、事件与实例 ​

active=false 暂停请求并保留上次成功数据；reload({ force: true }) 请求新数据，cancel() 取消当前请求。success 返回规范化选项数组，error 返回 AsamDataError；旧成功数据更新失败时组件显示过期状态。reload 的 status 为 success、error 或 cancelled；不能把取消当作成功。

immediate 控制初始化是否请求，active 控制请求是否启用。初始化和默认值以本页自动 API 的原始来源为准。

插槽与基础能力 ​

default 插槽保留对应级联或树节点的 data/node 与可选 option；tag、label 等以对应基础入口和本页公开 slots 为准。

本站继承关系 ​

  • 树选择器：适用的基础展示、交互与公开 API。

本页数据来源、模型、事件和实例的覆盖规则优先；本站链接不扩大本组件公开契约。尺寸使用基础组件的 ASAM 尺寸规则，示例使用 default。

字典刷新与示例 Provider ​

强制重载会先调用 provider.dict.refresh，再重新读取字典。示例 provider 同时提供 get 和 refresh，并检查请求取消信号；使用固定字典数据，不连接真实后端。宿主接入时应在 refresh 中实现实际缓存更新。

完整树与对象多选 ​

示例一次返回完整组织树，使用 multiple 与 valueMode=object 保存规范化对象及 raw 成员；禁用成员不能勾选。展示节点、header/footer、过滤、清空、原生 getCheckedNodes、刷新失败的旧数据保留与取消慢请求。读取节点时只保存数量，避免序列化级联节点的循环引用。演示使用独立 Vue 应用安装 provider，卸载时释放应用。 不包含节点懒加载。

示例逐次保存 update:modelValue、change、success 和 error 的载荷快照：模型与成功结果保留规范化对象及原始 raw 树；失败记录错误种类和消息。default 读取规范化 option.raw 与原生 data.label，header/footer 直接展示内容。取消请求不会伪造一次成功事件，失败刷新不清空调用方模型。

<template>

<script lang="ts" setup>
defineOptions({ name: 'AsamDictTreeSelectCompleteTreeChild' });
import { inject, ref } from 'vue';
import { AsamDictTreeSelect } from '@asam-ui/ui';
import type {
	AsamTreeSelectDataEmits,
	AsamValue,
	AsamDataError,
	AsamDictTreeSelectExpose,
	AsamOption
} from '@asam-ui/ui';
import type { Member, DemoState } from './provider.js';
const state = inject<DemoState>('complete-tree-demo');
if (!state) throw new Error('演示 provider 尚未安装');
const { active, failure, slow } = state;
const value = ref<readonly AsamOption<string, Member>[]>([]);
const control = ref<AsamDictTreeSelectExpose<string, Member>>();
const result = ref('');
const successes = ref(0);
const error = ref('');
const checkedCount = ref(0);
type DataEmits = AsamTreeSelectDataEmits<AsamValue, object>;
const events = ref<readonly { readonly name: string; readonly payload: unknown }[]>([]);
function recordEvent(name: string, payload: unknown) {
	const snapshot: unknown = JSON.parse(JSON.stringify(payload));
	events.value = [...events.value, { name, payload: snapshot }];
}
function onModelUpdate(payload: DataEmits['update:modelValue'][0]) {
	recordEvent('update:modelValue', payload);
}
function onModelChange(payload: DataEmits['change'][0]) {
	recordEvent('change', payload);
}
function onSuccess(payload: DataEmits['success'][0]) {
	recordEvent('success', payload);
	successes.value++;
	error.value = '';
}
function onError(payload: AsamDataError) {
	recordEvent('error', { kind: payload.kind, message: payload.message });
	error.value = payload.message;
}
async function reload() {
	result.value = (await control.value?.reload({ force: true }))?.status ?? 'cancelled';
}
async function cancelSlow() {
	slow.value = true;
	const pending = control.value?.reload({ force: true });
	setTimeout(() => control.value?.cancel(), 30);
	result.value = (await pending)?.status ?? 'cancelled';
	slow.value = false;
}
function inspect() {
	checkedCount.value = control.value?.getCheckedNodes(false)?.length ?? 0;
}
</script>

数据入口的原生事件边界 ​

TreeSelect 使用原生 visible-change、remove-tag、popup-scroll 和 end-reached 名称；末端事件保留原生滚动方向类型（top/bottom/left/right），不能把 popup-scroll 改名。Tree 节点事件保留其参数；remove-tag 和节点原生载荷可包含基础层的类型键（例如数字值 1 对应 number:1），不能把它等同于规范化的 modelValue/change 值。数据包装增加 success/error，模型事件沿用本文的值/对象模式。

层级展示与勾选策略 ​

完整示例使用原始字符串数组模型；数据来源一次提供完整树，保留禁用节点，并通过 default 插槽读取节点 data/node 和规范化 option.raw。折叠标签显示实际提示，自定义 tag 通过原生 deleteTag 回调删除，remove-tag 原样转发基础组件的原生事件载荷；模型仍保留原始标量值。禁用后不能删除或勾选。checkStrictly 控制父节点是否独立选择，读取公开勾选实例只序列化键，避免节点循环引用。原生实例和原生节点事件使用节点键，取 default 插槽的 data.value 或 getCheckedKeys 返回值；业务值取 v-model 或 option.value，不能直接把业务模型值当作原生实例键。showCheckbox、checkOnClickNode 和 renderAfterExpand 保持 TreeSelect 公开语义，宽度通过 popperStyle.minWidth 设置。勾选接口来自 Tree，标签和弹层来自 Select；不从本例推导节点懒加载支持。

点击 default 插槽内的“记住父节点键”保存原生 data.value，再使用 setChecked(key, true, deep) 的第三个参数。checkStrictly=true 时，deep=false 仅勾选父节点；deep=true 勾选两个可用子节点，禁用子节点保持未选，因此父节点在 getHalfCheckedKeys 中半选。模型业务值从 option.value 或 v-model 取得；AsamOption 没有公开 key 字段。原生实例读写使用插槽提供的节点键，示例先检查其为 string/number。

checkStrictly=false 时，勾选父节点会按原生规则传播到可用子节点；checkStrictly=true 时父节点独立选择。两个模式保留原始业务值模型，原生实例仍使用节点键。deep 参数决定实例操作是否递归，不能用它替代整个控件的 checkStrictly 配置。

局部请求错误插槽 ​

可选 error 插槽仅在当前请求错误存在时调用，接收只读 { error, stale, retry }。 error 与本实例 error 事件中的 AsamDataError 为同一对象，保留 cause、kind、 message 与 notified；渲染插槽不会再次通知 provider。stale 表示保留的数据已过期。

retry() 不接收参数，直接返回现有 reload({ force: true }) 的 Promise，结果为 AsamReloadResult<readonly AsamOption<V, I>[]> 的 success、error 或 cancelled 分支。 重试遵守 active、当前来源、取消和卸载规则，不改写模型。字典强刷沿用 provider 的 refresh 后 get；缺少 refresh 仍是原配置错误。

提供该插槽时，自有内容替换整个默认局部错误区；返回空内容也表示主动替换。 未提供时继续显示原错误文字、过期提示和默认重试按钮。无 error 的单独 stale 状态 不调用此插槽；empty、loading 和其他基础插槽继续使用原作用域。

以下完整 TS/JS 示例先制造失败，再等待插槽 retry 的返回结果；成功后可再次制造 更新失败，观察旧结果与模型保留。每次挂载使用独立子 app 和本地 provider。
