消息服务 AsamMessage

显示短暂的全局操作反馈，并返回可关闭的句柄。

使用场景 ​

显示短暂的全局操作反馈，并返回可关闭的句柄。

类型、分组与手动关闭 ​

消息保持显示以便观察，结束按钮关闭本示例持有的所有句柄。

类型、分组与手动关闭

展开源码
vue
<template>
	<div class="actions">
		<AsamButton type="success" native-type="button" @click="success">成功消息</AsamButton>
		<AsamButton type="info" native-type="button" @click="grouped">分组信息</AsamButton>
		<AsamButton type="default" native-type="button" @click="closeOwned"
			>关闭本例消息</AsamButton
		>
	</div>
	<p role="status">已创建 {{ count }} 次</p>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamMessageBasicDemo' });
import { ref, onBeforeUnmount } from 'vue';
import { AsamButton, AsamMessage } from '@asam-ui/ui';
import type { AsamMessageHandler } from '@asam-ui/ui';
const handles: AsamMessageHandler[] = [];
const count = ref(0);
const success = () => {
	handles.push(AsamMessage.success({ message: '草稿保存成功', duration: 0, showClose: true }));
	count.value++;
};
const grouped = () => {
	handles.push(
		AsamMessage({ message: '重复提示合并', grouping: true, duration: 0, showClose: true })
	);
	count.value++;
};
const closeOwned = () => {
	handles.splice(0).forEach((handle) => handle.close());
};
onBeforeUnmount(closeOwned);
</script>

.actions {

	align-items: center;
}

.panel {
	padding: var(--asam-space-lg);
	border: 1px solid var(--asam-color-border);
	border-radius: var(--asam-radius-control);
}
</style>

使用约定 ​

调用 AsamMessage(params, appContext?)；字符串、VNode/渲染函数或选项对象均按公开参数类型使用。primary/success/warning/info/error 为快捷调用，返回 handler.close()。duration=0 持续显示，showClose 提供关闭按钮，grouping 与 repeatNum 管理重复消息，placement/offset/zIndex 配置位置。closeAll 和 closeAllByPlacement 属全局操作；卸载仅关闭本示例自己的句柄。ASAM 保留应用上下文注册和品牌样式，无 size 参数。

完整用法 ​

以下用法使用本库公开入口。每个示例提供完整 TS/JS SFC，参数、事件、插槽和实例类型见本页 API。服务实例由创建方负责关闭；HTML 内容仅用于调用方已知的可信字符串。

import { AsamButton, AsamMessage, type AsamMessageHandler } from '@asam-ui/ui';

import { onBeforeUnmount } from 'vue';

import { h } from 'vue';

const open = () => {
	trackAsamMessage(AsamMessage('这是一条消息。'));
};

const openVn = () => {
	trackAsamMessage(
		AsamMessage({
			message: h('p', { style: 'line-height: 1; font-size: 14px' }, [
				h('span', null, '消息内容可以使用 '),
				h('i', { style: 'color: teal' }, 'VNode')
			])
		})
	);
};

const ownedAsamMessage = new Set<AsamMessageHandler>();
let mountedAsamMessage = true;
const trackAsamMessage = (handle: AsamMessageHandler) => {
	if (mountedAsamMessage) ownedAsamMessage.add(handle);
	else handle.close();
	return handle;
};
onBeforeUnmount(() => {
	mountedAsamMessage = false;
	for (const handle of ownedAsamMessage) handle.close();
	ownedAsamMessage.clear();
});
</script>

组合职责与生命周期 ​

字符串、VNode、内容函数或 options 都返回独立 close 句柄。primary/success/warning/info/error 保留快捷调用和 AppContext。grouping 合并相同内容，placement/offset/appendTo 与 zIndex 决定叠放；duration=0 持续显示，由创建方关闭。customClass 支持字符串、数组及对象并保留 ASAM 品牌类。closeAll/closeAllByPlacement 影响相应范围的全部消息，示例用各自句柄清理，避免关闭别人的消息。
