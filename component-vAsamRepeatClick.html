指令

连续点击指令 vAsamRepeatClick

按住主要鼠标按钮时重复执行回调。

使用场景 ​

按住主要鼠标按钮时重复执行回调。

延迟重复与数量上限 ​

按住增加按钮观察重复，松开停止；单次点击也生效。

延迟重复与数量上限

展开源码
vue
<template>
	<div class="actions">
		<button v-asam-repeat-click="options" type="button">按住增加（最多20）</button>
		<button type="button" @click="count = 0">重置计数</button>
	</div>
	<p role="status">数量 {{ count }}</p>
</template>

<script lang="ts" setup>
defineOptions({ name: 'vAsamRepeatClickBasicDemo' });
import { ref } from 'vue';
import { vAsamRepeatClick } from '@asam-ui/ui';
import type { AsamRepeatClickOptions } from '@asam-ui/ui';
const count = ref(0);
const options: AsamRepeatClickOptions = {
	delay: 400,
	interval: 120,
	handler: () => {
		count.value = Math.min(count.value + 1, 20);
	}
};
</script>

使用约定 ​

绑定函数使用默认节奏，或传入 { handler, delay, interval } 明确控制首次等待与重复间隔。鼠标抬起停止重复，目标卸载执行指令清理。业务回调自行检查范围或忙碌状态，本例限制数量上限。

组合职责与生命周期 ​

SFC 命名 vAsamRepeatClick 后消费业务回调。仅主鼠标按键长按重复执行，mouseup 结束重复，短点击仍调用一次；更新替换回调，卸载释放定时器和监听。绑定函数或 { handler, delay, interval } 可指定重复间隔和启动延迟，不增加组件 size 或业务计数状态。
