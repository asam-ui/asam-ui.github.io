表单操作区 AsamFormActions

统一排列保存与取消动作，提供加载、禁用、对齐与原生提交语义。

使用场景 ​

统一排列保存与取消动作，提供加载、禁用、对齐与原生提交语义。默认按钮来自 ASAM Button。

保存、取消与加载 ​

save/cancel 携带 MouseEvent。saving 表示提交中并阻止取消，disabled 禁止两个按钮；应用在请求结束后恢复 saving。

保存、取消与加载

展开源码
vue
<template>
	<div class="example">
		<AsamFormActions
			v-bind="{
				...{ saving: saving, disabled: disabled },
				...{ align: 'start', 'save-text': '确认保存', 'cancel-text': '返回' }
			}"
			@save="save"
			@cancel="event = 'cancel'"
		/>
		<AsamCheckboxItem v-model="disabled"> 禁止操作 </AsamCheckboxItem>
		<output>{{ event }}；saving：{{ saving }}</output>
	</div>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamFormActionsBasicExample' });
import { ref } from 'vue';
import { AsamFormActions, AsamCheckboxItem } from '@asam-ui/ui';
const saving = ref(false);
const disabled = ref(false);
const event = ref('尚未操作');
async function save() {
	saving.value = true;
	try {
		await new Promise((resolve) => setTimeout(resolve, 250));
		event.value = 'save';
	} finally {
		saving.value = false;
	}
}
</script>

附加操作与完整替换 ​

leading 放左侧内容；save/cancel 只替换默认按钮文字。default 完全替换按钮区，此时应用自行绑定事件、禁用和加载。

附加操作与完整替换

ASAM 扩展与迁移 ​

ASAM 操作区通过组上下文向默认按钮提供四档 size。submitNativeType 默认为 button；设为 submit 时放在真实表单内监听表单 submit，避免 save 再次提交。组件没有公开 expose。

API 阅读方式 ​

下方 Props、Events、Slots、Exposes 按当前实际公开类型与运行默认值生成。组合属性按分支生效，不能任意混搭值模式。标为“未知 / 未声明”的默认值不代表 false 或空值。源码区域提供对应语言的独立 Demo.vue，可直接复制或下载；本地辅助组件、数据和素材已内联到当前文件。
