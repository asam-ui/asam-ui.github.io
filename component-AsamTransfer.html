选择与表单

穿梭框 AsamTransfer

用于在两个列表之间移动静态选项，模型表示右侧已选值。

使用场景 ​

用于在两个列表之间移动静态选项，模型表示右侧已选值。规范化模式消费 options；native 使用原始 data。

移动、检索与方向事件 ​

change 依次给出最新值、移动方向和移动值。filterable 启用两侧检索，titles/buttonTexts 定义标题及动作文本。

移动、检索与方向事件

展开源码
vue
<template>
	<div class="example">
		<AsamTransfer
			ref="control"
			v-bind="{
				...{ filterable: true },
				...{
					options: options,
					titles: ['待选', '已选'],
					'button-texts': ['移除', '加入']
				}
			}"
			v-model="value"
			@change="(v, direction, moved) => (event = JSON.stringify({ v, direction, moved }))"
		>
			<template #default="{ data }">
				{{ data?.label }}
			</template>
			<template #left-footer> 请选择左侧项目 </template>
			<template #right-footer> 右侧为当前模型 </template>
		</AsamTransfer>
		<AsamButton type="default" @click="control?.clearQuery('left')"> 清空左侧检索 </AsamButton>
		<output>值：{{ value }}；{{ event }}</output>
	</div>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamTransferBasicExample' });
import { ref } from 'vue';
import { AsamTransfer, AsamButton } from '@asam-ui/ui';
import type { AsamTransferExpose } from '@asam-ui/ui';
const control = ref<AsamTransferExpose>();
const options = [
	{ label: '设计', value: 'design', raw: { code: 'design' } },
	{ label: '开发', value: 'dev', raw: { code: 'dev' } },
	{ label: '停用', value: 'off', disabled: true, raw: { code: 'off' } }
];
const value = ref<string[]>(['design']);
const event = ref('尚未移动');
</script>

字符串与对象存储 ​

穿梭框始终多选，无需 multiple 属性。字符串模式使用 separator；对象模式保存规范化选项数组，targetOrder 控制右侧排列。

字符串与对象存储

		<AsamTransfer v-model="objects" :options="options" value-mode="object" />

原始数据映射 ​

valueMode=native 配合 data 与 props 映射原始 key、label 和 disabled；模型使用原始键数组。

原始数据映射

展开源码
vue
<template>
	<div class="example">
		<div class="row">
			<AsamButton type="default" @click="reset('original')">按来源顺序</AsamButton>
			<AsamButton type="default" @click="reset('push')">新增项放末尾</AsamButton>
			<AsamButton type="default" @click="reset('unshift')">新增项放开头</AsamButton>
		</div>
		<AsamTransfer
			v-model="value"
			v-bind="{
				'value-mode': 'native',
				data: data,
				targetOrder: order,
				buttonTexts: ['移出', '移入'],
				props: { key: 'id', label: 'name', disabled: 'locked' }
			}"
			@change="recordMove"
		/>
		<output>原始键：{{ value }}</output>
		<output>排列：{{ order }}；移动：{{ lastMove }}</output>
	</div>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamTransferNativeExample' });
import { ref } from 'vue';
import { AsamButton, AsamTransfer } from '@asam-ui/ui';
const value = ref<number[]>([2]);
const order = ref<'original' | 'push' | 'unshift'>('original');
const lastMove = ref('');
function reset(next: 'original' | 'push' | 'unshift') {
	order.value = next;
	value.value = [2];
	lastMove.value = '';
}
function recordMove(_value: unknown, direction: string, keys: readonly unknown[]) {
	lastMove.value = `${direction}:${keys.join(',')}`;
}
const data = [
	{ id: 1, name: '设计', locked: false },
	{ id: 2, name: '开发', locked: false },
	{ id: 3, name: '停用', locked: true }
];
</script>

四档尺寸与上下文继承 ​

四个实例分别显式使用 large、big、default、small。下面省略 size 的实例随 ConfigProvider 响应切换；显式 size 覆盖祖先。面板本身没有 size 契约的入口不附加虚构尺寸属性。

四档尺寸与上下文继承

展开源码
vue
<template>
	<div class="example">
		<div class="density-grid">
			<section data-density="large">
				<strong> large </strong>
				<AsamTransfer size="large" :options="options" :model-value="['design']" />
			</section>
			<section data-density="big">
				<strong> big </strong>
				<AsamTransfer size="big" :options="options" :model-value="['design']" />

ASAM 扩展与迁移 ​

四档 density 通过 ConfigProvider/表单继承。ASAM value/object 与 array/string 遵守同一存储规则；native 保留原始 data 行为。公开 expose 为 clearQuery、leftPanel、rightPanel，footer/empty 插槽按左右侧提供。

虚拟滚动与边界项 ​

API 阅读方式 ​

高级模式默认左右标题为“未选择 / 已选择”，按钮文本为空，targetOrder 为 push；native 模式采用底层依赖的标题与 targetOrder 默认值。显式 titles 和 buttonTexts 会覆盖默认值。original 按来源 data/options 顺序排列右侧，push 将新增项接在现有右侧之后，unshift 将新增项放在现有右侧之前；三者都保留原始键及所选值模式。

下方 Props、Events、Slots、Exposes 按当前实际公开类型与运行默认值生成。组合属性按分支生效，不能任意混搭值模式。标为“未知 / 未声明”的默认值不代表 false 或空值。源码区域提供对应语言的独立 Demo.vue，可直接复制或下载；本地辅助组件、数据和素材已内联到当前文件。

原生与高级入口 ​

valueMode="native" 直接委托原生穿梭框，保留省略的 titles、buttonTexts、targetOrder、modelValue 与原生默认值。原生 default 插槽仅接收 { option }；高级 value/object 路径仍提供 { option, data }。left-check-change / right-check-change 保留第二实参（包含 undefined），change 保留值、方向、移动值的原顺序。clearQuery 保留原生返回值，leftPanel/rightPanel 读取 live 引用。原生入口不增加独立 disabled 协议；高级入口的 disabled、对象/字符串模型和表单校验属于 ASAM 组合。虚拟列表高度与移动后的缓存时序直接遵循原生，不再修补 VNode 或内部 setup。
