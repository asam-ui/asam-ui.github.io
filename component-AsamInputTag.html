基础输入与操作

标签输入 AsamInputTag

将自由输入转换为字符串标签，支持上限、分隔、拖动与折叠。

使用场景 ​

适合关键词、标签等自由文本集合。v-model 使用 string[] 或 undefined；按 trigger 指定的按键或 delimiter 分隔符生成标签。

新增、删除与数量上限 ​

默认按 Enter 添加标签。max 限制数量，clearable 提供整体清空；事件分别记录添加和删除的内容。

新增、删除与数量上限

展开源码
vue
<template>
	<div class="example">
		<AsamInputTag
			v-model="tags"
			v-bind="{ class: 'field', 'aria-label': '项目标签' }"
			placeholder="输入后按 Enter"
			:max="5"
			clearable
			@add-tag="event = '新增：' + String($event)"
			@remove-tag="(value, index) => (event = '删除：' + value + '，索引 ' + index)"
		/>
		<output>标签：{{ tags?.join('、') }}；{{ event }}</output>
	</div>
</template>

import { ref } from 'vue';
import { AsamInputTag } from '@asam-ui/ui';
const tags = ref<string[] | undefined>(['设计', '开发']);
const event = ref('尚未操作');
</script>

分隔、拖动与折叠 ​

逗号生成标签；saveOnBlur 保存失焦时尚未提交的文字。拖动改变顺序，折叠只改变显示。

分隔、拖动与折叠

		<AsamInputTag
			v-model="tags"
			v-bind="{ class: 'field', 'aria-label': '可排序标签' }"
			delimiter=","
			draggable
			save-on-blur
			collapse-tags
			collapse-tags-tooltip
			:max-collapse-tags="2"
			tag-type="success"
			tag-effect="plain"
			@drag-tag="(oldIndex, newIndex) => (order = oldIndex + ' → ' + newIndex)"
		/>
		<output>顺序：{{ tags?.join('、') }}；拖动：{{ order }}</output>

四档密度与继承 ​

large / big / default / small 分别为四档密度。显式 size 覆盖继承；省略 size 时按组件、组、表单、ConfigProvider 到 default 解析。通过切换 provider 验证继承响应。

四档密度与继承

展开源码
vue
<template>
	<div class="example">
		<div class="row">
			<AsamInputTag
				size="large"
				v-bind="{ class: 'field', 'aria-label': 'large尺寸' }"
				:model-value="['ASAM']"
			/>
			<AsamInputTag
				size="big"
				v-bind="{ class: 'field', 'aria-label': 'big尺寸' }"
				:model-value="['ASAM']"
			/>
			<AsamInputTag
				size="default"
				v-bind="{ class: 'field', 'aria-label': 'default尺寸' }"
				:model-value="['ASAM']"

			<AsamInputTag
				size="small"
				v-bind="{ class: 'field', 'aria-label': 'small尺寸' }"
				:model-value="['ASAM']"
			/>
		</div>

				<AsamInputTag

			</div>
		</AsamConfigProvider>

trigger 选择 Enter 或 Space，saveOnBlur 控制失焦保存。max 限制标签数，draggable 允许重排并提供 oldIndex/newIndex/value。collapseTags 配合 maxCollapseTags 折叠，collapseTagsTooltip 通过悬停展示其余标签。clearIcon 配置清空标记；tagType/tagEffect/effect 配置标签及提示样式。只读保留显示，禁用阻止编辑；自定义 tag/prefix/suffix 见已有插槽示例。
