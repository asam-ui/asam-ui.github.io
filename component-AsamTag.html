标签 AsamTag

显示状态、分类或可关闭的短文本。

使用场景 ​

显示状态、分类或可关闭的短文本。

基础用法与状态 ​

下列示例只使用本入口的实际公开能力。

基础用法与状态

展开源码
vue
<template>
	<div class="flow">
		<AsamTag v-for="size in sizes" :key="size" v-bind="{ size, type: 'success' }">
			<span>{{ size }} 草稿</span>
		</AsamTag>
		<AsamTag v-if="visible" closable @close="visible = false">可移除标签</AsamTag>
		<AsamButton type="primary" v-else native-type="button" @click="visible = true"
			>恢复标签</AsamButton
		>
	</div>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamTagBasicDemo' });
import { ref } from 'vue';
import { AsamButton, AsamTag } from '@asam-ui/ui';
const visible = ref(true);
import type { AsamControlSize } from '@asam-ui/ui';
const sizes: AsamControlSize[] = ['large', 'big', 'default', 'small'];
</script>

<style scoped>
.flow {
	display: flex;
	flex-wrap: wrap;
	gap: var(--asam-space-md);
	align-items: center;
}
</style>

使用约定 ​

type、effect、round、hit、color、closable 和 disableTransitions 设置呈现；close 只发出关闭意图，宿主负责从数据或视图移除。default 插槽放文本，click 反馈真实点击。ASAM size 支持 large/big/default/small 并继承上下文。

可移除标签 ​

设置 closable 属性可以定义一个标签是否可移除。它接受一个 Boolean。默认的标签移除时会附带渐变动画。如果不想使用，可以设置 disable-transitions 属性，它接受一个 Boolean，true 为关闭。当 Tag 被移除时会触发 close 事件。

动态编辑标签 ​

动态编辑标签可以通过点击标签关闭按钮后触发的 close 事件来实现。

动态编辑标签

展开源码

完整示例许可 · 下载完整源码与许可

vue
<!--
SPDX-License-Identifier: MIT
Complete attribution and permission: LICENSE-f75284197908c909e814ff4cfb537557e04896d63b9edd8df332f6f6dbde5d7d.txt
Included in the source bundle; notice resource: /licenses/source-notices/f75284197908c909e814ff4cfb537557e04896d63b9edd8df332f6f6dbde5d7d.txt
-->
<template>
	<div class="flex gap-2">
		<AsamTag
			v-for="tag in dynamicTags"
			:key="tag"
			closable
			:disable-transitions="false"
			@close="handleClose(tag)"
		>
			{{ tag }}
		</AsamTag>
		<AsamInput
			v-if="inputVisible"
			ref="InputRef"
			:model-value="inputValue"
			class="w-20"
			size="small"
			v-bind="domEnterAttrs(handleInputConfirm)"
			@update:model-value="
				(value) => {
					if (typeof value === 'string') inputValue = value;
				}
			"
			@blur="handleInputConfirm"
		/>
		<!-- prettier-ignore -->
		<AsamButton type="primary"
			v-else
			class="button-new-tag"
			size="small"
			@click="showInput"
		>
			+ 新建标签
		</AsamButton>
	</div>
</template>

<script lang="ts" setup>
import type { HTMLAttributes } from 'vue';
defineOptions({ name: 'AsamTagCapEditableDemo' });
import { AsamTag, AsamInput, AsamButton } from '@asam-ui/ui';

import { nextTick, ref } from 'vue';

import type { AsamInputExpose } from '@asam-ui/ui';

const inputValue = ref('');
const dynamicTags = ref(['标签一', '标签二', '标签三']);
const inputVisible = ref(false);
const InputRef = ref<AsamInputExpose>();

const handleClose = (tag: string) => {
	dynamicTags.value.splice(dynamicTags.value.indexOf(tag), 1);
};

const showInput = () => {
	inputVisible.value = true;
	nextTick(() => {
		InputRef.value!.input!.focus();
	});
};

const handleInputConfirm = () => {
	if (inputValue.value) {
		dynamicTags.value.push(inputValue.value);
	}
	inputVisible.value = false;
	inputValue.value = '';
};

const domEnterAttrs = (handler: () => void): Pick<HTMLAttributes, 'class' | 'onKeyup'> => ({
	class: 'ui032-enter-input',
	onKeyup: (event) => {
		if (event.key === 'Enter') handler();
	}
});
</script>
