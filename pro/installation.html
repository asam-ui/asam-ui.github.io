ASAM UI PRO

快速开始

在已有 Vue 工程中完成安装、导入样式并显示第一个 Pro 组件。版本配对与迁移规则见版本与迁移。

1. 安装 UI 和 Pro

从 npm 安装 UI 2.0.1 和 Pro 2.0.1。Pro 声明了对该 UI 版本的精确 peer 依赖。

配套 UI 使用 Tiptap 3.31.3。新建 pnpm 11 锁文件前，在工程的 pnpm-workspace.yaml 合并下列约束，保证 Vue 适配器的两个可选扩展和它使用的 core、pm 版本一致。已下载的完整工程已包含该配置。

yaml
overrides:
  '@tiptap/vue-3@3.31.3>@tiptap/extension-bubble-menu': 3.31.3
  '@tiptap/vue-3@3.31.3>@tiptap/extension-floating-menu': 3.31.3
sh
pnpm add @asam-ui/ui@2.0.1 @asam-ui/pro@2.0.1 vue@3.5.34 element-plus@2.14.7

此版本需要 Vue >=3.5.34 <3.6.0 和 Element Plus 2.14.7。已有项目只补齐缺少的依赖。

2. 导入样式

在 main.ts 中按顺序导入 npm 包提供的样式：

ts
import 'element-plus/dist/index.css';
import '@asam-ui/ui/style.css';
import '@asam-ui/pro/style.css';

如果宿主已加载 Element Plus 样式，保留一处导入并放在 ASAM 样式之前。使用组件 resolver 时，避免重复导入样式。

3. 显示第一个组件

将以下内容放入 App.vue，由工程现有入口挂载：

vue
<template>
	<AsamApplicationProvider>
		<AsamDisplayCard title="第一个 Pro 页面">开始组织页面内容。</AsamDisplayCard>
	</AsamApplicationProvider>
</template>

<script setup lang="ts">
import { AsamApplicationProvider, AsamDisplayCard } from '@asam-ui/pro/components';
</script>

4. 启动检查

运行目标工程已有的开发脚本；若脚本名为 dev：

sh
pnpm run dev

打开终端给出的本地地址，确认显示“第一个 Pro 页面”和卡片内容。再运行工程已有的类型检查与构建脚本。

需要数据读取、权限或编辑保存时，按对应组件说明注入应用服务。生命周期、会话与持久化的完整约定见应用能力。

按需配置

分类、叶子导入与暗色样式

同一个 Pro 包按高级组件、应用能力和页面模板组织。公开类型统一在 AI 的类型字典中按 UI、Pro 页签查阅。可复用能力通过公开分类与叶子入口接入；完整工程模板和示例另外提供可修改源码与可运行 ZIP。

在应用根部提供配置、权限与数据服务。导航、会话、偏好和请求分别从 @asam-ui/pro/application/navigation、security、preferences、transport 导入；组合式能力从 @asam-ui/pro/application/composables 或其能力叶子导入。完整脚手架和页面工程继续按源码包说明运行。

ts
import { Application, Components, Templates } from '@asam-ui/pro';
import type { Types } from '@asam-ui/pro';
import { useToggle } from '@asam-ui/pro/application/composables/use-toggle';
const [opened, toggle] = Application.composables.useToggle(false);

Types 仅存在于类型空间。分类补全和精确导入共享实现；纯 Hook 优先叶子导入。根分类访问可能带来更广的依赖解析，不能承诺与叶子相同的树摇结果。

其他组件按需具名导入，例如：

ts
import { AsamApplicationProvider, AsamEditorForm } from '@asam-ui/pro/components';

需要暗色模式时，补充 Element Plus 的暗色变量，并按应用能力接入主题偏好：

ts
import 'element-plus/theme-chalk/dark/css-vars.css';
自动导入配置

保留现有 Vite 插件配置，在需要时合并以下适配：

ts
import Components from 'unplugin-vue-components/vite';
import AutoImport from 'unplugin-auto-import/vite';
import { AsamUIResolver } from '@asam-ui/ui/resolver';
import { AsamProResolver, asamProAutoImports } from '@asam-ui/pro/resolver';
const plugins = [
	Components({ resolvers: [AsamUIResolver(), AsamProResolver()] }),
	AutoImport({
		imports: asamProAutoImports({
			include: ['Application', 'useToggle', { name: 'useClickAway', as: 'useOutside' }],
			types: ['UseCountDownOptions']
		})
	})
];

按能力可选用 abilities: ['preferences', 'composables/use-toggle']，支持名称白名单、别名和排除。组件 resolver 只匹配真实公开组件并引入公共样式；函数默认按叶子导入，类型只生成 type-only 声明。手动导入与自动导入可以混用。可选插件须在消费工程正常安装，不默认把全库符号注入全局。

选择入口

  • 高级组件：组件用法、API 与真实示例。
  • 应用能力：导航、会话、偏好、请求与脚手架。
  • 页面模板：完整页面、同源代码与独立预览。
  • 统一语言与国际化：同 UI scope、资源、原生语言与已有错误展示。
  • 类型字典：实际包出口与声明。
  • AI 接入：配方、版本配对与具名迁移方法。

示例使用本地数据与合成服务。接入真实业务后，检查实际类型、构建、交互、权限与错误恢复。
