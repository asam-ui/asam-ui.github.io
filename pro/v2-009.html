<template>
	<section class="component-project" data-demo-host>
		<label
			>演示场景<AsamSelect
				:model-value="selected"
				aria-label="演示场景"
				@update:model-value="selectScenario"
				><AsamOption
					v-for="option in options"
					:key="option.value"
					:value="option.value"
					:label="option.label" /></AsamSelect></label
		><AsamConfigProvider :button="{ type: 'primary' }"
			><AsamApplicationProvider
				><component :is="current" :key="selected" /></AsamApplicationProvider
		></AsamConfigProvider>
	</section>
</template>
<script lang="ts" setup>
import { computed, defineAsyncComponent, shallowRef } from 'vue';
import { AsamSelect, AsamOption, AsamConfigProvider } from '@asam-ui/ui';
import { AsamApplicationProvider } from '@asam-ui/pro/components';
const options = [
	{ value: 'basic/ts', label: '文本与数值字段 (TS)' },
	{ value: 'basic/js', label: '文本与数值字段 (JS)' },
	{ value: 'detail/ts', label: '只读与禁用 (TS)' },
	{ value: 'detail/js', label: '只读与禁用 (JS)' }
] as const;
const scenarios = {
	'basic/ts': defineAsyncComponent(() => import('./examples/basic/ts/Demo.vue')),
	'basic/js': defineAsyncComponent(() => import('./examples/basic/js/Demo.vue')),
	'detail/ts': defineAsyncComponent(() => import('./examples/detail/ts/Demo.vue')),
	'detail/js': defineAsyncComponent(() => import('./examples/detail/js/Demo.vue'))
};
const selected = shallowRef<keyof typeof scenarios>('basic/ts');
function selectScenario(value: unknown) {
	const option = options.find((option) => option.value === value);
	if (option) selected.value = option.value;
}
const current = computed(() => scenarios[selected.value]);
</script>

使用说明

从 @asam-ui/pro 使用文本字段工厂；验证码发送与校验服务由应用注入。

模型和公共字段协议

factory 模型 清空 query 空值 detail/readonly
createAsamPasswordField string / null / 缺失 '' 不输出 非空固定六个圆点，DOM不含原密码
createAsamTagField 非空、唯一 string 的数组 / 缺失 新数组 [] 不输出 字符串以顿号连接
createAsamMentionField string / null / 缺失 '' 不输出 完整文本
createAsamCaptchaField string / null / 缺失 '' 不输出 验证码文本，无发送按钮

数字0、布尔、对象不自动转字符串；字符串"0"保留。submit保留显式null/空字符串/空数组，缺失跳过。 标签输入交互去除空字符串并按原顺序去重，大小写敏感，不trim；外部无效重复模型直接报错。 候选value是非空唯一字符串，不以label作为身份。标签允许自由输入，候选作为快捷按钮；禁用候选不可选择。 提及的options来自应用提供的同步响应式getter，选择、过滤、键盘、焦点由现有AsamMention/EP公开能力承担。 异步候选由应用维护加载结果并通过getter提供；不内置账号搜索请求。

factory共同选项：key、label、defaultValue、modes。默认值仅在create初始化应用并独立复制。 三模式通过AsamField、createAsamFieldSchema复用既有Form规则、隐藏/禁用/只读、白名单转换。 inputProps为对应ASAM公开类型中除modelValue/disabled/readonly外的选项；提及额外排除options，由candidates统一提供。 模式componentProps可配置公开控件属性与监听；模型、禁用、只读仍由字段外层裁定。 inputProps/modes的密码属性不改变详情掩码策略。密码submit是明文模型，应用负责安全传输和权限，不应输出到日志。

验证码服务与生命周期

必填target getter、service({ target, signal }): Promise，cooldownSeconds默认60，允许0..86400有限秒数。 resolve仅表示应用确认发送成功，reject回到可重试error；不把异常原文显示到DOM。 state为idle/sending/cooldown/error及remaining/error。发送中重复操作和冷却期操作返回false；成功返回true。 成功时按clock.now的绝对截止时间倒计时，后台节流后重新计算，不按tick次数计秒。 clock可注入now/schedule/clear，生产默认Date.now/setTimeout；测试可确定性推进。 now必须返回有限毫秒值；schedule必须异步且仅调用一次callback，返回独立handle；clear必须幂等取消且不抛错。 非法now、时钟差值/截止值溢出、schedule抛错或同步回调使当前动作进入可重试error，不把非法时钟视为冷却已结束。 适配器若违反clear的清理契约，controller仍撤销状态所有权，但实际资源释放由适配器负责。 每个实际控件实例独立controller。target、禁用/只读变化、卸载会取消请求并清理定时器；输入模型在发送中改变使当前结果过期。 普通验证码输入不会中断已经成功的冷却。取消后的服务即使忽略signal且晚到，也不能改写当前实例状态。 重挂从idle开始，不跨实例或重挂共享限流；真正的限流、身份验证、权限与防滥用必须由应用/后端实现。 取消不能撤销已经在服务端发送的短信，signal必须由应用接入传输取消。

控件公开props：modelValue、disabled、readonly；其余AsamInput公开属性经componentProps透传。 events：update:modelValue、state-change(AsamCaptchaState)。slots透传AsamInput的公开slots。 expose：focus/send/cancel(AsamCaptchaExpose)。AsamField本身只提供既有focus/refresh；要观察状态用模式componentProps的onStateChange。 createAsamCaptchaController也可直接使用，提供state/send/reset/dispose；dispose后不可再次发送。 changed同步通知可重入reset/dispose或启动后继send。通知返回后旧动作重新核代次，不分配或覆盖后继资源。 sending通知抛错时不调用服务，清理请求并进入可重试error；其他通知抛错也使当前动作失败并清理。 error/idle终态通知异常被隔离，不递归通知或外抛。dispose先关闭发送入口再清理/通知，销毁通知不能发送新服务。 不传短信URL、账号模型或验证码给service，目标语义和验证由应用定义。

接入与迁移

根据密码、标签、提及或验证码需求选择工厂，再通过 defineAsamFields / createAsamFieldSchema 组合。工厂返回 custom 字段，不新增 kind 枚举。保持 value 的字符串类型，默认数组用工厂创建；异步建议与验证码服务由应用提供并响应 signal。

既有kind:text/textarea无需迁移；从手写密码custom字段迁移到createAsamPasswordField时，详情统一掩码。 旧逗号字符串标签在应用输入边界显式拆分并normalizeAsamTags，不能直接当数组；空null标签在应用显式转[]。 提及仍存完整文本，不输出选中账号ID数组。验证码旧全局倒计时需改为实例级服务/时钟，服务端限流保留。
