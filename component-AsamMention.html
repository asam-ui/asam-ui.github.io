基础输入与操作

提及输入 AsamMention

在文本中通过触发字符选择人员或主题。

使用场景 ​

用于评论、消息中的 @人员、#主题等提及，模型保存完整输入内容。 完整说明。

触发与选择 ​

输入 @ 后显示候选。select 同时返回选项与触发字符，search 返回检索片段与字符。

触发与选择

展开源码
vue
<template>
	<div class="example">
		<AsamMention
			v-model="value"
			v-bind="{ class: 'field', 'aria-label': '评论提及' }"
			:options="options"
			@select="(item, prefix) => (selected = prefix + item.label)"
			@search="(pattern, prefix) => (query = prefix + pattern)"
		/>
		<output>评论：{{ value }}；选择：{{ selected }}；检索：{{ query }}</output>
	</div>
</template>

多触发字符与自定义标签 ​

prefix 可使用一个字符或字符数组，每项必须恰好一个字符；split 也必须是单字符。label 插槽接收 item、index。

多触发字符与自定义标签

四档密度与继承 ​

large / big / default / small 分别为四档密度。显式 size 覆盖继承；省略 size 时按组件、组、表单、ConfigProvider 到 default 解析。通过切换 provider 验证继承响应。

四档密度与继承

展开源码
vue
<template>
	<div class="example">
		<div class="row">
			<AsamMention
				size="large"
				v-bind="{ class: 'field', 'aria-label': 'large尺寸' }"
				model-value="@team"
				:options="[{ value: 'team', label: '协作组' }]"
			/>
			<AsamMention
				size="big"
				v-bind="{ class: 'field', 'aria-label': 'big尺寸' }"
				model-value="@team"
				:options="[{ value: 'team', label: '协作组' }]"
			/>
			<AsamMention
				size="default"
				v-bind="{ class: 'field', 'aria-label': 'default尺寸' }"
				model-value="@team"
				:options="[{ value: 'team', label: '协作组' }]"
			/>
			<AsamMention
				size="small"
				v-bind="{ class: 'field', 'aria-label': 'small尺寸' }"
				model-value="@team"
				:options="[{ value: 'team', label: '协作组' }]"
			/>
		</div>
		<AsamConfigProvider :size="density">
			<div class="example">
				<AsamMention
					v-bind="{ class: 'field', 'aria-label': '继承尺寸' }"
					model-value="@team"
					:options="[{ value: 'team', label: '协作组' }]"
				/>
				<div class="row">
					<AsamButton type="default" @click="density = 'small'"> 继承 small </AsamButton>
					<AsamButton type="default" @click="density = 'big'"> 继承 big </AsamButton>
				</div>

用法与契约补充说明 ​

使用场景 ​

用于评论、消息中的 @人员、#主题等提及，模型保存完整输入内容。modelValue 对齐原生 MentionProps 的字符串模型；update:modelValue 保留 string | number，Vue 的 number 修饰符可能让监听器收到数字。options 描述 value、label、disabled 等信息；扩展字段通过泛型保留。

完整继承输入组合 ​

min/max/step、formatter/parser、modelModifiers 与 textarea 参数原样交给 底层输入。trim/number/lazy 的实际更新和整项删除由原生处理；ASAM 不转换 modelValue、不保存独立草稿、不安排失焦后备提交，也不自行调度 change/blur 表单校验。直接 v-model.number 将数字写回字符串 prop 时，可能出现与原生相同的类型警告。建议保留文本模型，在应用或高级数据层处理业务数值；更新事件不能因此静默丢弃数字。旧 string | number 的 prop 用法迁移为字符串，数字输入 type=number 也使用文本模型。

实际单行装饰槽与嵌套输入实例 ​

通过公开 mention.input 调用 focus、blur、select、clear；多行回填后调用 resizeTextarea 重新测量。输出实际 input/textarea/ref、textareaStyle、autosize、passwordVisible 和 isComposing 状态，展示本入口的嵌套 InputInstance 路由。tooltip 与 dropdownVisible 继续按本页公开类型及现有多行/事件示例使用。

原生委托与事件记录 ​

下方完整 TS/JS 示例记录模型及事件顺序，并可切换禁用、只读和自动校验状态。省略的基础参数使用原生 defaults；显式 undefined/null/false 原样传入，合法值范围见 API。四档 size 是 ASAM 的视觉桥接；Password 额外固定 type=password，并在省略 showPassword 时启用显隐入口。

更多参数与事件说明 ​

完整继承输入事件 ​

除提及自己的 search、select、whole-remove，所有输入事件均由实际 input/textarea 承接：update:modelValue 为 string | number；input 为字符串；change 为字符串及可选原生 Event； clear 为可选 MouseEvent；focus/blur 为 FocusEvent；mouseenter/mouseleave 为 MouseEvent；keydown 为 KeyboardEvent 或浏览器自动填充触发的 Event； compositionstart/update/end 为 CompositionEvent。显式公开的监听器逐项转发， 每次原生触发只通知一次，不同时在外层 DOM 再挂同名监听器。
