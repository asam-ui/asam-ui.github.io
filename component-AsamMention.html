基础输入与操作

提及输入 AsamMention

在文本中通过触发字符选择人员或主题。

使用场景 ​

用于评论、消息中的 @人员、#主题等提及，模型保存完整输入内容。modelValue 对齐原生 MentionProps 的字符串模型；update:modelValue 保留 string | number，Vue 的 number 修饰符可能让监听器收到数字。options 描述 value、label、disabled 等信息；扩展字段通过泛型保留。

触发与选择 ​

输入 @ 后显示候选。select 同时返回选项与触发字符，search 返回检索片段与字符。

触发与选择

展开源码
vue

	<div class="example">
		<AsamMention
			v-model="value"
			v-bind="{ class: 'field', 'aria-label': '评论提及' }"
			:options="options"
			@select="(item, prefix) => (selected = prefix + item.label)"
			@search="(pattern, prefix) => (query = prefix + pattern)"
		/>
		<output>评论：{{ value }}；选择：{{ selected }}；检索：{{ query }}</output>
	</div>
</template>

多触发字符与自定义标签 ​

prefix 可使用一个字符或字符数组，每项必须恰好一个字符；split 也必须是单字符。label 插槽接收 item、index。

多触发字符与自定义标签

四档密度与继承 ​

large / big / default / small 分别为四档密度。显式 size 覆盖继承；省略 size 时按组件、组、表单、ConfigProvider 到 default 解析。通过切换 provider 验证继承响应。

四档密度与继承

展开源码
vue
<template>
	<div class="example">
		<div class="row">
			<AsamMention
				size="large"
				v-bind="{ class: 'field', 'aria-label': 'large尺寸' }"
				model-value="@team"
				:options="[{ value: 'team', label: '协作组' }]"
			/>
			<AsamMention
				size="big"
				v-bind="{ class: 'field', 'aria-label': 'big尺寸' }"
				model-value="@team"
				:options="[{ value: 'team', label: '协作组' }]"
			/>
			<AsamMention
				size="default"
				v-bind="{ class: 'field', 'aria-label': 'default尺寸' }"
				model-value="@team"
				:options="[{ value: 'team', label: '协作组' }]"
			/>
			<AsamMention
				size="small"
				v-bind="{ class: 'field', 'aria-label': 'small尺寸' }"
				model-value="@team"
				:options="[{ value: 'team', label: '协作组' }]"
			/>
		</div>
		<AsamConfigProvider :size="density">
			<div class="example">
				<AsamMention
					v-bind="{ class: 'field', 'aria-label': '继承尺寸' }"
					model-value="@team"
					:options="[{ value: 'team', label: '协作组' }]"
				/>
				<div class="row">
					<AsamButton @click="density = 'small'"> 继承 small </AsamButton>

				</div>
			</div>
		</AsamConfigProvider>
		<output>Provider：{{ density }}</output>
	</div>
</template>

完整继承输入事件 ​

除提及自己的 search、select、whole-remove，所有输入事件均由实际 input/textarea 承接：update:modelValue 为 string | number；input 为字符串；change 为字符串及可选原生 Event； clear 为可选 MouseEvent；focus/blur 为 FocusEvent；mouseenter/mouseleave 为 MouseEvent；keydown 为 KeyboardEvent 或浏览器自动填充触发的 Event； compositionstart/update/end 为 CompositionEvent。显式公开的监听器逐项转发， 每次原生触发只通知一次，不同时在外层 DOM 再挂同名监听器。

API 阅读方式 ​

下方 API 来自当前公开类型与运行默认值。默认值标为“未知 / 未声明”时，不代表 false、空值或未支持。省略 size 保留祖先上下文继承。省略 disabled 保留表单禁用继承；validateEvent 控制校验事件，不用 disabled 代替。

完整继承输入组合 ​
