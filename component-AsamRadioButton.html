选择与表单

按钮单选项 AsamRadioButton

通过 value 定义单项身份，default 插槽定义显示内容；放入对应 Group 统一维护选择。

组件关系 ​

请放入 单选组 使用，模型由组管理。希望通过 options 自动生成按钮时使用 单选集合 的 type="button"。

使用场景 ​

通过 value 定义单项身份，default 插槽定义显示内容；放入对应 Group 统一维护选择。 与自动消费 options 的 Radio 集合入口分开。

组合与双向绑定 ​

单项使用 value；label 用于显示或可访问说明，不依赖旧 label 充当选择值。禁用项无法更改。

组合与双向绑定

展开源码
vue
<template>
	<div class="example">
		<AsamRadioGroup v-model="value">
			<AsamRadioButton value="design"> 设计 </AsamRadioButton>
			<AsamRadioButton value="dev"> 开发 </AsamRadioButton>
			<AsamRadioButton value="off" disabled> 停用 </AsamRadioButton>
		</AsamRadioGroup>
		<output>选择：{{ value }}</output>
	</div>
</template>

禁用与组内覆盖 ​

组 disabled 控制组内选择，子项显式 size 可覆盖组内继承。按钮项的 fill/textColor 由 Group 配置。

禁用与组内覆盖

展开源码
vue
<template>
	<div class="example">
		<AsamRadioGroup v-model="value" size="big" :disabled="disabled">
			<AsamRadioButton value="design"> 继承 big </AsamRadioButton>
			<AsamRadioButton value="dev" size="small"> 覆盖 small </AsamRadioButton>
		</AsamRadioGroup>
		<AsamButton type="default" @click="disabled = !disabled"> 切换组禁用 </AsamButton>
		<output>选中：{{ value }}；组禁用：{{ disabled }}</output>
	</div>
</template>

四档尺寸与上下文继承 ​

四个实例分别显式使用 large、big、default、small。下面省略 size 的实例随 ConfigProvider 响应切换；显式 size 覆盖祖先。面板本身没有 size 契约的入口不附加虚构尺寸属性。

四档尺寸与上下文继承

展开源码
vue

				</AsamRadioGroup>
			</section>
			<section data-density="big">
				<strong> big </strong>
				<AsamRadioGroup v-model="value" size="big">
					<AsamRadioButton value="design"> 设计 </AsamRadioButton>
					<AsamRadioButton value="dev"> 开发 </AsamRadioButton>
					<AsamRadioButton value="off" disabled> 停用 </AsamRadioButton>
				</AsamRadioGroup>
			</section>
			<section data-density="default">
				<strong> default </strong>
				<AsamRadioGroup v-model="value" size="default">
					<AsamRadioButton value="design"> 设计 </AsamRadioButton>

ASAM 扩展与迁移 ​

ASAM 扩展为四档 size 和组内上下文继承。default 插槽只负责展示。Item、Button、Group 不提供实例方法，不能调用集合或输入组件的 focus。事件及当前可用属性以下方实际公开类型为准。

API 阅读方式 ​

下方 Props、Events、Slots、Exposes 按当前实际公开类型与运行默认值生成。组合属性按分支生效，不能任意混搭值模式。标为“未知 / 未声明”的默认值不代表 false 或空值。源码区域提供对应语言的独立 Demo.vue，可直接复制或下载；本地辅助组件、数据和素材已内联到当前文件。
