富文本编辑器 AsamEditor

使用结构化文档的富文本编辑、只读展示与资源插入。

富文本编辑器 ​

AsamEditor 使用结构化文档作为 v-model，提供编辑工具栏、只读显示和有限的实例方法。不要将 HTML 字符串传给模型。

编辑与实例方法 ​

示例将初始文档拆为独立文件，并携带一份本地 SVG 图片。编辑后可观察 change 次数；按钮分别调用聚焦、失焦、清空、插入图片和读取 HTML，页面同时展示当前结构化模型。

编辑与实例方法

展开源码
vue
<template>
	<div class="demo-controls">
		<AsamButton type="primary" @click="editor?.focus()">聚焦</AsamButton>
		<AsamButton type="primary" @click="editor?.blur()">失焦</AsamButton>
		<AsamButton type="primary" @click="editor?.clear()">清空</AsamButton>
		<AsamButton type="primary" @click="insertImage">插入本地图片</AsamButton>
		<AsamButton type="primary" @click="readHTML">读取 HTML</AsamButton>
		<AsamButton type="primary" @click="reset">恢复初始文档</AsamButton>
	</div>
	<!-- prettier-ignore -->
	<AsamEditor
		ref="editor"
		v-model="document"
		placeholder="填写排产说明"
		@change="changes++"
	/>
	<p>
		<output>change 次数：{{ changes }}；插图结果：{{ imageResult }}</output>
	</p>
	<pre class="demo-output">{{ html || '点击读取 HTML' }}</pre>
	<AsamCollapse
		><AsamCollapseItem name="auxiliary-content">
			<template #title><span>当前结构化文档</span></template>
			<pre class="demo-output">{{ JSON.stringify(document, null, 2) }}</pre>
		</AsamCollapseItem></AsamCollapse
	>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamEditorBasicExample' });
import { ref } from 'vue';
import { AsamCollapse, AsamCollapseItem, AsamButton, AsamEditor } from '@asam-ui/ui';
import type { AsamEditorDocument, AsamEditorExpose } from '@asam-ui/ui';
import { createDocument } from './document.js';
import badge from './badge.svg?url&no-inline';
const editor = ref<AsamEditorExpose>();
const document = ref<AsamEditorDocument>(createDocument());
const changes = ref(0);
const imageResult = ref('尚未插入');
const html = ref('');
function insertImage(): void {
	imageResult.value = String(
		editor.value?.insertImage({
			src: new URL(badge, window.location.href).pathname,
			alt: '本地示例图片',
			title: 'ASAM Demo'
		}) ?? false
	);
}
function readHTML(): void {
	html.value = editor.value?.getHTML() ?? '';
}
function reset(): void {
	document.value = createDocument();
	html.value = '';
	imageResult.value = '尚未插入';
}
</script>

modelValue 的根节点为 { type: 'doc', content: [...] }，内容数组非空；空文档可使用一个空 paragraph。编辑产生 update:modelValue 和 change，两者传入结构化文档。外部替换模型时组件更新内容并重建撤销历史，不应依赖旧文档的 undo 恢复已替换数据。

只读与禁用 ​

editable 默认开启，disabled 默认关闭。任一条件使编辑不可用时隐藏工具栏，clear 不修改内容，insertImage 返回 false；getHTML 仍可读取展示内容。示例在只读与禁用之间切换，并展示拒绝插图的返回值。

placeholder 默认是“请输入内容”，在空文档中显示提示。工具栏支持段落、1–3 级标题、引用、列表、代码块、分隔线、常用行内标记、撤销重做和链接。

占位提示响应后续 placeholder 变化，不需要重新聚焦；该更新不改写文档、不触发模型或 change 回声，也不清除撤销历史。

安全链接、资源插入与外部替换 ​

下面同时展示 HTTP(S)/mailto 链接、非法资源被拒绝、只读/禁用切换和外部 JSON 替换。链接工具栏支持选区添加和移除，不把任意字符串作为 HTML 注入。外部替换不发 change 回声，并重建历史；新文档不能通过 undo 恢复旧文档。所有编辑操作仍受 editable/disabled 限制。

链接、图片安全与外部 JSON 替换

展开源码
vue
<template>
	<div class="example">
		<AsamEditor
			ref="editor"
			v-model="document"
			:editable="editable"
			:disabled="disabled"
			@change="changes++"
		/>
		<div class="controls">
			<AsamCheckboxItem v-model="editable"> 可编辑</AsamCheckboxItem>
			<AsamCheckboxItem v-model="disabled"> 禁用</AsamCheckboxItem>
			<AsamButton type="primary" @click="insertLocal">插入站内图片</AsamButton>
			<AsamButton type="primary" @click="insert('javascript:alert(1)')"
				>尝试非法图片</AsamButton
			>
			<AsamButton type="primary" @click="replace">外部替换 JSON</AsamButton>
			<AsamButton type="primary" @click="editor?.clear()">清空文档</AsamButton>
			<AsamButton type="primary" @click="html = editor?.getHTML() ?? ''"
				>读取序列化</AsamButton
			>
		</div>
		<output>插图：{{ inserted }}；change：{{ changes }}</output>
		<pre>{{ html }}</pre>
		<pre>{{ JSON.stringify(document, null, 2) }}</pre>
	</div>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamEditorSecurityExample' });
import { ref } from 'vue';
import { AsamCheckboxItem, AsamEditor, AsamButton } from '@asam-ui/ui';
import type { AsamEditorDocument, AsamEditorExpose } from '@asam-ui/ui';
import image from './image.svg?url&no-inline';
const editor = ref<AsamEditorExpose>();
const editable = ref(true);
const disabled = ref(false);
const inserted = ref('尚未插图');
const changes = ref(0);
const html = ref('');
const document = ref<AsamEditorDocument>({
	type: 'doc',
	content: [
		{
			type: 'paragraph',
			content: [
				{
					type: 'text',
					text: '安全链接',
					marks: [{ type: 'link', attrs: { href: 'https://example.com' } }]
				},

初始化与外部替换会验证结构化文档。非法根、字段、节点、标记、嵌套、heading level 或资源地址被拒绝；这不是只检查 JSON 是否可解析。粘贴内容的图片会剥离；Tiptap 序列化输出会去除内部默认属性后再验证。服务器持久化结构化模型，getHTML 用于当前显示的序列化，不扩大为任意 HTML 编辑接口。

文档与资源边界 ​

节点支持 paragraph、heading、blockquote、bulletList、orderedList、listItem、codeBlock、horizontalRule、image，以及文本块中的 text、hardBreak。heading 的 level 为 1、2 或 3；列表包含以 paragraph 开始的 listItem；引用和列表不能为空。标记支持 bold、italic、strike、code、underline、link，link 的 attrs 只包含 href。运行时会拒绝未知字段、非法嵌套或资源地址；类型中的通用字符串字段不代表任意节点名都受支持。

图片资源由调用方提供 src 和可选 alt、title；允许 HTTP(S) 或以单个 / 开头的站内绝对路径，拒绝 data、blob、协议相对地址、凭据和控制字符。insertImage 在资源非法或不可编辑时返回 false。粘贴 HTML 中的图片被移除，不负责上传、文件选择或后端存储。

链接只接受 HTTP(S) 或有效 mailto 地址。getHTML 返回当前序列化内容，持久化建议保留结构化模型；宿主对其他来源 HTML 的处理仍由宿主负责。公开方法仅为 focus、blur、clear、insertImage、getHTML，不暴露底层编辑器实例，也没有公开内容插槽。

可调用的公开辅助出口 ​

EMPTY_EDITOR_DOCUMENT 是共享的 AsamEditorDocument 对象，形状为 { type: 'doc', content: [{ type: 'paragraph' }] }。类型字段只读；创建独立模型时可用 structuredClone，不直接改写共享常量。

isSafeImageUrl(value: string): boolean 判定 HTTP(S) 无凭据地址或单个 / 开头的站内路径。isSafeLinkUrl(value: string): boolean 判定 HTTP(S) 无凭据地址或 mailto 路径包含 @ 的地址；它不保证邮箱有效或可送达。两者拒绝首尾空白、控制字符、反斜杠及不允许的协议，返回布尔值，不创建资源、不发送请求、不替调用方改写地址。

validateEditorDocument(value: unknown): asserts value is AsamEditorDocument 验证上述完整文档语法。合法输入正常返回，并使 TypeScript 在后续代码中收窄类型；非法输入抛 TypeError，消息以 AsamEditor 开头。它只验证，不改写输入，不返回修复后的文档。JSON.parse 的语法错误应另行处理。
