富文本编辑器 ​

AsamEditor 使用结构化文档作为 v-model，提供编辑工具栏、只读显示和有限的实例方法。不要将 HTML 字符串传给模型。

编辑与实例方法 ​

下载示例将初始文档内联为完整单文件，并使用可编辑的公开 HTTPS 图片地址。编辑后可观察 change 次数；按钮分别调用聚焦、失焦、清空、插入图片和读取 HTML，页面同时展示当前结构化模型。

用法与契约补充说明 ​

编辑与实例方法 ​

modelValue 的根节点为 { type: 'doc', content: [...] }，内容数组非空；空文档可使用一个空 paragraph。编辑产生 update:modelValue 和 change，两者传入结构化文档。外部替换模型时组件更新内容并重建撤销历史，不应依赖旧文档的 undo 恢复已替换数据。

可调用的公开辅助出口 ​

isSafeImageUrl(value: string): boolean 判定 HTTP(S) 无凭据地址或单个 / 开头的站内路径。isSafeLinkUrl(value: string): boolean 判定 HTTP(S) 无凭据地址或 mailto 路径包含 @ 的地址；它不保证邮箱有效或可送达。两者拒绝首尾空白、控制字符、反斜杠及不允许的协议，返回布尔值，不创建资源、不发送请求、不替调用方改写地址。

可调用的公开辅助出口 ​

validateEditorDocument(value: unknown): asserts value is AsamEditorDocument 验证上述完整文档语法。合法输入正常返回，并使 TypeScript 在后续代码中收窄类型；非法输入抛 TypeError，消息以 AsamEditor 开头。它只验证，不改写输入，不返回修复后的文档。JSON.parse 的语法错误应另行处理。

下载示例的图片来源 ​

编辑器的图片模型只接收可访问的 HTTP(S) 或站内根路径，不接受内联 data/blob。两个插图示例默认使用公开的 HTTPS 图片，按钮明确标为“插入示例图片”，地址可改为消费项目已托管的资源。默认图片需要网络；单个 Demo.vue 不提供文件上传、资源托管或新的根路径接口。其他允许 data URL 的图片显示组件仍可使用内联 SVG。此说明不改变编辑器的公开安全规则。
