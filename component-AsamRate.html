选择与表单

评分 AsamRate

用于评分输入与只读评分展示，模型为数字。

使用场景 ​

用于评分输入与只读评分展示，模型为数字。allowHalf 支持半星，texts/colors 与阈值配置表达评分语义。

半星、文字与只读 ​

change 携带提交分数。disabled 显示评分，showScore/scoreTemplate 展示数值。

半星、文字与只读

展开源码
vue
<template>
	<div class="example">
		<AsamRate
			ref="control"
			v-bind="{ 'allow-half': true, 'show-text': true }"
			v-model="value"
			:texts="['很差', '较差', '一般', '满意', '很好']"
			@change="event = $event"
		/>
		<AsamRate
			:model-value="value"
			v-bind="{ disabled: true, 'show-score': true, 'score-template': '{value} 分' }"
		/>
		<AsamButton @click="control?.focus()"> 聚焦评分 </AsamButton>
		<output>评分：{{ value }}；事件：{{ event }}</output>
	</div>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamRateBasicExample' });
import { ref } from 'vue';
import { AsamRate, AsamButton } from '@asam-ui/ui';
import type { AsamRateExpose } from '@asam-ui/ui';
const control = ref<AsamRateExpose>();
const value = ref(3.5);
const event = ref(0);
</script>

ASAM 扩展与迁移 ​

ASAM 四档 size 调整评分交互区与图标密度。没有内容插槽；实例公开 focus、setCurrentValue 与 resetCurrentValue。展示文字与颜色通过公开属性配置，不使用私有实例字段。

评分预览与恢复 ​

setCurrentValue 设置当前预览，resetCurrentValue 回到已提交模型；预览不提交 v-model。 低分与高分阈值决定 colors / icons 的分档，空图标、禁用空图标及颜色可独立配置。 allowHalf 保留半星选择，clearable 可再次点击同一分值清零；showText 与 showScore 分别 显示文字和 scoreTemplate 中的值，disabled 只读模式仍显示真实评分。 评分容器及图标支持主题变量，focus 是 ASAM 补充的键盘入口。

公开评分预览、恢复与聚焦

展开源码
vue
<template>
	<div class="example">
		<AsamRate
			ref="control"
			v-model="rating"
			show-text
			:texts="['很差', '较差', '一般', '满意', '很好']"
			:low-threshold="2"
			:high-threshold="4"
			clearable
			aria-label="公开评分预览"
		/>
		<div class="actions">
			<AsamButton @click="control?.setCurrentValue(4)">预览 4 星</AsamButton>
			<AsamButton @click="control?.resetCurrentValue()">结束预览</AsamButton>
			<AsamButton @click="control?.focus()">聚焦评分</AsamButton>
		</div>
		<output>已提交评分：{{ rating }}；预览不会修改模型</output>
	</div>
</template>

import { AsamRate, AsamButton } from '@asam-ui/ui';
import type { AsamRateExpose } from '@asam-ui/ui';

const rating = ref(3);
defineOptions({ name: 'AsamRateInstanceDemo' });
</script>
