使用场景 ​

按需展开相关说明，减少初始页面长度。

基础用法与状态 ​

下列示例只使用本入口的实际公开能力。

基础用法与状态

展开源码
vue
<template>
	<AsamCollapse
		:model-value="active"
		@update:model-value="
			(value) => {
				if (Array.isArray(value) && value.every((name) => typeof name === 'string'))
					active = value;
			}
		"
	>
		<AsamCollapseItem title="基础说明" name="intro">
			<p>本地说明内容。</p>
		</AsamCollapseItem>
		<AsamCollapseItem name="detail">
			<template #title>补充说明</template>
			<p>可展开的补充内容。</p>
		</AsamCollapseItem>
		<AsamCollapseItem title="禁用项" name="locked" disabled />
	</AsamCollapse>
	<p role="status">展开项：{{ active.join(', ') }}</p>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamCollapseBasicDemo' });
import { ref } from 'vue';
import { AsamCollapse, AsamCollapseItem } from '@asam-ui/ui';
const active = ref<string[]>(['intro']);
</script>

使用约定 ​

v-model 管理 activeNames，accordion 控制单项展开；change 反馈当前值。普通模式使用名称数组，单项模式按公开类型配置。default 插槽放 CollapseItem，宿主管理展开状态。
