显示已经计算好的百分比或进行中的状态。

使用场景 ​

显示已经计算好的百分比或进行中的状态。

基础用法与状态 ​

下列示例只使用本入口的实际公开能力。

		<AsamProgress type="circle" :percentage="value" :width="100" />

使用约定 ​

percentage 使用 0～100；支持线形、环形、仪表盘及文字、颜色配置。 完整说明。

完整使用场景 ​

直线进度条 ​

Progress 组件设置 percentage 属性即可，表示进度条对应的百分比。该属性必填，并且必须在 0-100 的范围内。你可以通过设置 format 来自定义文字显示的格式。

直线进度条

展开源码
许可

	<div class="demo-progress">
		<AsamProgress :percentage="50" />

		<AsamProgress :percentage="100" status="success" />
		<AsamProgress :percentage="100" status="warning" />
		<AsamProgress :percentage="50" status="exception" />
	</div>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamProgressCapLinearProgressBarDemo' });

自定义进度条的颜色 ​

可以通过 color 属性来设置进度条的颜色。该属性可以接受十六进制颜色值，函数和数组。

自定义进度条的颜色

展开源码
许可
vue
<!-- 此演示还使用 @asam-ui/icons-vue，请按官网对应指南配置这些公开依赖。 -->
<template>
	<div class="demo-progress">
		<AsamProgress :percentage="percentage" :color="customColor" />

		<AsamProgress :percentage="percentage" :color="customColorMethod" />

		<AsamProgress :percentage="percentage" :color="customColors" />
		<AsamProgress :percentage="percentage" :color="customColors" />
		<div>
			<AsamButtonGroup>
				<AsamButton type="default" :icon="Minus" @click="decrease" />
				<AsamButton type="default" :icon="Plus" @click="increase" />
			</AsamButtonGroup>
		</div>
	</div>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamProgressCapCustomColorDemo' });
import { AsamProgress, AsamButtonGroup, AsamButton } from '@asam-ui/ui';

import { ref } from 'vue';
import { Minus, Plus } from '@asam-ui/icons-vue';

const percentage = ref(20);
const customColor = ref('#409eff');

const customColors = [
	{ color: '#f56c6c', percentage: 20 },
	{ color: '#e6a23c', percentage: 40 },
	{ color: '#5cb87a', percentage: 60 },
	{ color: '#1989fa', percentage: 80 },
	{ color: '#6f7ad3', percentage: 100 }
];

const customColorMethod = (percentage: number) => {
	if (percentage < 30) {
		return '#909399';
	}
	if (percentage < 70) {
		return '#e6a23c';
	}
	return '#67c23a';
};
const increase = () => {
	percentage.value += 10;
	if (percentage.value > 100) {
		percentage.value = 100;
	}
};
const decrease = () => {
	percentage.value -= 10;
	if (percentage.value < 0) {
		percentage.value = 0;
	}
};
</script>
