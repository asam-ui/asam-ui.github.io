在触发元素附近展示补充信息和少量操作。

使用场景 ​

在触发元素附近展示补充信息和少量操作。

面板操作后关闭 ​

操作按钮通过插槽公开的 hide 关闭面板。

面板操作后关闭

展开源码
vue
<template>
	<AsamPopover title="草稿操作" :width="240" trigger="click">
		<template #reference>
			<AsamButton type="default" native-type="button">打开气泡面板</AsamButton>
		</template>
		<template #default="{ hide }">
			<p class="example-paragraph">需要确认的补充信息。</p>
			<AsamButton
			 type="default"
				native-type="button"
				@click="
					count++;
					hide();
				"
			>
				完成并关闭
			</AsamButton>
		</template>
	</AsamPopover>
	<p class="example-paragraph" role="status">完成 {{ count }} 次</p>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamPopoverBasicDemo' });
import { ref } from 'vue';
import { AsamButton, AsamPopover } from '@asam-ui/ui';
const count = ref(0);
</script>

	margin-block: 16px;
	line-height: 1.8;
	overflow-wrap: anywhere;
}
</style>

用法与契约补充说明 ​

数组组合触发 ​

trigger 接受单个 hover/click/focus/contextmenu，也接受这些值组成的数组。以下示例初始使用 ['hover', 'click']，可取消一项观察仅悬停或仅点击的数组触发；全部取消后空数组不启用自动触发。多个触发方式的排队、延迟和关闭行为遵循原生契约，混合悬停与点击时请先移出锚点再观察关闭。

使用约定 ​

默认触发为 hover；需要点击时显式设置 trigger="click"。reference 插槽提供触发元素，default 插槽接收 hide 以完成操作后关闭。visible 省略时采用非受控触发，v-model:visible 用于受控状态。title/content/width、placement、showAfter/hideAfter、teleported/appendTo、persistent、virtualTriggering/virtualRef 均按公开类型使用。hide 与 popperRef 是公开方法/句柄；无独立控件 size。

组合职责与生命周期 ​

reference 或 virtualRef 提供触发目标，default 提供复杂内容，content 用于简单文字。trigger 支持 hover/click/focus/contextmenu 单值及其数组组合，visible/v-model:visible 提供受控状态，disabled 禁用触发。showAfter/hideAfter、enterable、persistent、teleported 与 appendTo 决定交互和生命周期；placement/width/offset/showArrow/popperStyle/popperClass 控制定位与外观。公开 hide 和 popperRef 可与独立指令协作。

原生事件与插槽 ​

仅转发 update:visible、before-enter、before-leave、after-enter、after-leave，保留每次原生发射及其顺序。旧合成 show/hide 事件迁移为 after-enter/after-leave。default 插槽中的 hide 是原生函数；受控 visible 的显隐仍由调用方按原生契约维护。组件不额外截获 Esc、不去重事件或恢复焦点。
