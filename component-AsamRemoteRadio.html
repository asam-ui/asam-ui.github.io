远端单选框组 AsamRemoteRadio

在单选框组上管理异步选项、重载和请求取消。

远端单选框组 ​

在单选框组上管理异步选项、重载和请求取消。

基础用法 ​

示例通过本地 Promise 函数加载选项，支持模型更新、暂停与重载。所有请求都留在演示内部。

基础场景的原始值模型保持 ready/running，单选更新会替换上一项；对象模式则保留规范化选项及来源raw。两种存储语义由 valueMode 明确选择，单选不接收集合存储策略。

本地数据与生命周期

展开源码
vue
<template>
	<section class="data-demo">
		<!-- prettier-ignore -->
		<AsamCheckboxItem v-model="active">启用请求</AsamCheckboxItem>
		<AsamRemoteRadio
			ref="control"
			v-model="value"
			:data-source="dataSource"
			:active="active"
			size="default"
			@error="error = $event.message"
			@success="error = ''"
		>
			<template #option="{ option }">{{ option.label }}</template>
		</AsamRemoteRadio>
		<div class="demo-actions">
			<AsamButton type="default" native-type="button" :disabled="!active" @click="reload"
				>强制重载</AsamButton
			>
			<AsamButton type="default" native-type="button" @click="control?.cancel()"
				>取消请求</AsamButton
			>
		</div>
		<p role="status">{{ result }} {{ error }}</p>
		<pre>{{ value }}</pre>
	</section>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamRemoteRadioValuesDemo' });
import { ref } from 'vue';
import { AsamCheckboxItem, AsamButton, AsamRemoteRadio, defineAsamOptions } from '@asam-ui/ui';
import type { AsamAsyncChoiceExpose, AsamApiRequest } from '@asam-ui/ui';
interface Item {
	label: string;
	value: string;
	children?: readonly Item[];
}
interface Query {
	text: string;
}
const value = ref<string | null>(null);
const active = ref(true);
const control = ref<AsamAsyncChoiceExpose<string, Item>>();
const error = ref('');
const result = ref('');
const items: readonly Item[] = [
	{ label: '准备', value: 'ready' },
	{ label: '进行', value: 'running' }
];
const api: AsamApiRequest<Query, readonly Item[]> = async (params, context) => {
	context.signal.throwIfAborted();
	return items.filter((item) => item.label.includes(params.text));
};
const factory = defineAsamOptions<string, Item>();
const dataSource = factory.api({
	api,
	params: { text: '' },
	transform: (response) => response,
	fieldNames: { label: 'label', value: 'value' }
});
async function reload() {
	const response = await control.value?.reload({ force: true });
	result.value = response?.status ?? 'cancelled';
}
</script>

数据来源与覆盖 ​

dataSource、api + params、request 三种来源只选一种。 完整说明。

单选值模式的模型为标量或 null；valueMode=object 时使用规范化 AsamOption。单选框组由组件入口确定单选职责，没有 multiple 或 multipleValueMode 配置。

生命周期、事件与实例 ​

active=false 暂停请求并保留上次成功数据；reload({ force: true }) 请求新数据，cancel() 取消当前请求。 完整说明。

immediate 控制初始化是否请求，active 控制请求是否启用。初始化和默认值以本页自动 API 的原始来源为准。

插槽与基础能力 ​

option 插槽接收 { option }，option.raw 保留原始对象；default 插槽沿用基础选项布局。实例仅增加数据重载与取消，不声明基础选择器的 focus/blur。

本站继承关系 ​

  • 单选框组：适用的基础展示、交互与公开 API。

本页数据来源、模型、事件和实例的覆盖规则优先；本站链接不扩大本组件公开契约。尺寸使用基础组件的 ASAM 尺寸规则，示例使用 default。

连续按钮与对象模型 ​

type="button" 将选项排列为连续拼接的按钮；尺寸为 large / big / default / small。 完整说明。

四个公开事件在完整示例的事件记录中可检查：update:modelValue 与 change 保留具体单项/集合模型，success 保留规范化选项及来源 raw，error 保留错误种类和消息。失败恢复和取消继续保留调用方模型；取消不伪装为 error。

option 插槽保留具体规范化项和 option.raw.id；default 插槽无 scope 参数，可替换选项布局。完整示例可切换自定义默认内容并恢复来源选项；默认内容替代选项布局，切换本身不修改模型，恢复后仍保留原始实体。

<template>
	<section class="data-demo demo-layout-1">
		<!-- prettier-ignore -->
		<AsamCheckboxItem v-model="customDefault">自定义默认布局</AsamCheckboxItem>
		<label for="AsamRemoteRadio-size">尺寸</label>
		<AsamSelect id="AsamRemoteRadio-size" v-model="size">
			<AsamOption :label="'small'" :value="'small'">small</AsamOption>
			<AsamOption :label="'default'" :value="'default'">default</AsamOption>
			<AsamOption :label="'big'" :value="'big'">big</AsamOption>
			<AsamOption :label="'large'" :value="'large'">large</AsamOption>
		</AsamSelect>
		<!-- prettier-ignore -->
		<AsamCheckboxItem v-model="active">启用请求</AsamCheckboxItem>
		<!-- prettier-ignore -->
		<AsamCheckboxItem v-model="failing">模拟失败</AsamCheckboxItem>
		<AsamRemoteRadio
			ref="control"
			v-model="value"
			:data-source="dataSource"
			:active="active"
			:size="size"
			type="button"
			value-mode="object"
			@update:model-value="events.push({ name: 'update:modelValue', payload: $event })"
			@change="recordChange"
			@error="recordError"
			@success="recordSuccess"
		>
			<template v-if="customDefault" #default>
				<div class="choice-default" data-testid="choice-default">
					自定义默认内容；取消切换后恢复来源选项。
				</div>
			</template>
			<template #option="{ option }">
				<span data-testid="choice-option" :data-raw-id="option.raw.id">{{
					option.label
				}}</span>
			</template>
		</AsamRemoteRadio>
		<AsamButton type="default" native-type="button" :disabled="!active" @click="reload"
			>强制重载</AsamButton
		>
		<AsamButton type="default" native-type="button" @click="cancel">取消慢请求</AsamButton>
		<p role="status">{{ result }} {{ error }}</p>
		<pre>模型：{{ JSON.stringify(value) }}</pre>
		<pre>变更：{{ JSON.stringify(changes) }}</pre>
		<pre data-testid="choice-events">{{ JSON.stringify(events) }}</pre>
	</section>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamRemoteRadioButtons' });
import { ref } from 'vue';
import {
	AsamCheckboxItem,
	AsamSelect,
	AsamOption,
	AsamButton,
	AsamRemoteRadio,
	defineAsamOptions
} from '@asam-ui/ui';
import type {
	AsamAsyncChoiceExpose,
	AsamValue,
	AsamDataError,
	AsamRadioDataEmits,
	AsamApiRequest
} from '@asam-ui/ui';
interface Item {
	id: number;
	label: string;
	value: number;
	disabled?: boolean;
}
type Model = AsamOption<number, Item> | null;
type Change = AsamRadioDataEmits<AsamValue, Item>['change'][0];
type Size = 'large' | 'big' | 'default' | 'small';
const size = ref<Size>('default');
const value = ref<Model>(null);
const changes = ref<Change[]>([]);
const active = ref(true);
const customDefault = ref(false);
const control = ref<AsamAsyncChoiceExpose<number, Item>>();
const error = ref('');
const events = ref<{ name: string; payload: unknown }[]>([]);
function recordChange(value: Change) {
	changes.value.push(value);
	events.value.push({ name: 'change', payload: value });
}
function recordError(value: AsamDataError) {
	error.value = value.message;
	events.value.push({ name: 'error', payload: { kind: value.kind, message: value.message } });
}
function recordSuccess(options: readonly AsamOption<AsamValue, Item>[]) {
	error.value = '';
	events.value.push({ name: 'success', payload: options });
}
const result = ref('');
const failing = ref(false);
const slow = ref(false);
const api: AsamApiRequest<Record<string, never>, readonly Item[]> = async (_params, context) => {
	if (slow.value) await new Promise((done) => setTimeout(done, 300));
	context.signal.throwIfAborted();
	if (failing.value) throw new Error('演示加载失败');
	return [
		{ id: 0, label: '准备', value: 0 },
		{ id: 2, label: '进行', value: 2 },
		{ id: 3, label: '完成', value: 3 },
		{ id: 4, label: '停用', value: 4, disabled: true }
	];
};
const dataSource = defineAsamOptions<number, Item>().api({
	api,
	params: {},
	transform: (rows) => rows,
	fieldNames: { label: 'label', value: 'value', disabled: 'disabled' }
});
async function reload() {
	result.value = (await control.value?.reload({ force: true }))?.status ?? 'cancelled';
}
async function cancel() {
	slow.value = true;
	const pending = control.value?.reload({ force: true });

局部请求错误插槽 ​

可选 error 插槽仅在当前请求错误存在时调用，接收只读 { error, stale, retry }。 完整说明。

retry 不接收参数，返回强制 reload 的 Promise，并遵守取消和卸载规则。 完整说明。

提供该插槽时，自有内容替换整个默认局部错误区；返回空内容也表示主动替换。 未提供时继续显示原错误文字、过期提示和默认重试按钮。无 error 的单独 stale 状态 不调用此插槽；empty、loading 和其他基础插槽继续使用原作用域。

用法与契约补充说明 ​

数据来源与覆盖 ​

dataSource、api + params、request 三种来源只选一种。dataSource 必须由 defineAsamOptions 创建，使用该来源时映射、转换和缓存配置写在工厂内，不再重复传短来源属性。自定义字段映射同时提供同步 transform；API 返回 Promise，并检查 context.signal。

生命周期、事件与实例 ​

active=false 暂停请求并保留上次成功数据；reload({ force: true }) 请求新数据，cancel() 取消当前请求。success 返回规范化选项数组，error 返回 AsamDataError；旧成功数据更新失败时组件显示过期状态。reload 的 status 为 success、error 或 cancelled；不能把取消当作成功。

连续按钮与对象模型 ​

type="button" 将选项排列为连续拼接的按钮；尺寸为 large / big / default / small。完整示例保留数字值 0 和 option.raw，演示停用选项、加载失败后保留模型、恢复与取消慢请求。对象由组件规范化，调用方不手工拼接标签。Radio 只承担单选；不接收 Checkbox 的 min/max 或 tag。

局部请求错误插槽 ​

可选 error 插槽仅在当前请求错误存在时调用，接收只读 { error, stale, retry }。 error 与本实例 error 事件中的 AsamDataError 为同一对象，保留 cause、kind、 message 与 notified；渲染插槽不会再次通知 provider。stale 表示保留的数据已过期。

更多参数与事件说明 ​

局部请求错误插槽 ​

retry() 不接收参数，直接返回现有 reload({ force: true }) 的 Promise，结果为 AsamReloadResult<readonly AsamOption<V, I>[]> 的 success、error 或 cancelled 分支。 重试遵守 active、当前来源、取消和卸载规则，不改写模型。
