下拉操作 AsamDropdown

将次要操作收纳在可触发的菜单中。

使用场景 ​

将次要操作收纳在可触发的菜单中。

组合菜单、图标与公开方法 ​

显式菜单容器与项目共同运行，支持鼠标和键盘选择。

组合菜单、图标与公开方法

展开源码
vue
<!-- 此演示还使用 @asam-ui/icons-vue，请按官网对应指南配置这些公开依赖。 -->
<template>
	<div class="actions">
		<AsamDropdown ref="menu" v-bind="{ trigger: 'click', wrapMenu: false }" @command="select">
			<AsamButton type="default" native-type="button">打开操作菜单</AsamButton>
			<template #dropdown>
				<AsamDropdownMenu>
					<AsamDropdownItem command="edit" :icon="Edit">编辑</AsamDropdownItem>
					<AsamDropdownItem command="archive" divided>归档</AsamDropdownItem>
					<AsamDropdownItem command="remove" disabled>删除（不可用）</AsamDropdownItem>
				</AsamDropdownMenu>
			</template>
		</AsamDropdown>
		<AsamButton type="default" native-type="button" @click="menu?.open()"
			>通过方法打开</AsamButton
		>
		<AsamButton type="default" native-type="button" @click="menu?.close()"
			>通过方法关闭</AsamButton
		>
	</div>
	<p role="status">当前命令：{{ command }}</p>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamDropdownBasicDemo' });
import { ref, shallowRef } from 'vue';
import { AsamButton, AsamDropdown, AsamDropdownMenu, AsamDropdownItem } from '@asam-ui/ui';
import type { AsamDropdownExpose } from '@asam-ui/ui';
import { Edit } from '@asam-ui/icons-vue';
const menu = shallowRef<AsamDropdownExpose>();
const command = ref('未选择');
const select = (value: string | number | object) => {
	command.value = String(value);
};
</script>

使用约定 ​

默认 wrapMenu=false 原样透传 dropdown 插槽。直接提供 AsamDropdownItem 时显式设置 wrapMenu=true；传入 AsamDropdownMenu 时保持 false。command 保留命令、项目实例和触发事件。支持 click/hover/contextmenu、splitButton、禁用、显隐延时、位置和浮层配置；open/close 是 ASAM 便捷方法，handleOpen/handleClose 等公开方法仍按 API 使用。 控件密度支持 large/big/default/small；省略时遵循最近 group、Form、ConfigProvider 的顺序，显式 prop 优先。

完整用法 ​

以下用法使用本库公开入口。每个示例提供完整 TS/JS SFC，参数、事件、插槽和实例类型见本页 API。服务实例由创建方负责关闭；HTML 内容仅用于调用方已知的可信字符串。

组合职责与生命周期 ​

默认 dropdown 插槽提供原生菜单容器；显式 wrapMenu=true 时自动建立菜单容器，手动使用 AsamDropdownMenu 时设 wrapMenu=false，避免嵌套菜单。splitButton 的左按钮触发 click，右触发器展开菜单；trigger、triggerKeys、loop 和 tabindex 管理鼠标与键盘入口。command 保留 command、item 与 Event 三个参数，visible-change 通知显隐。hideOnClick 决定选择后关闭，disabled 不执行命令。handleOpen/handleClose 是实时实例方法。virtualTriggering 配合 virtualRef 使用外部或坐标触发器，placement/offset/popperOptions 控制定位，teleported/appendTo 控制挂载。size 使用 large/big/default/small 四档控件密度。

官方示例默认值适配 ​

AsamDropdown 的默认 trigger 为原生 hover；需要点击时显式设置 trigger="click"。悬停分支须显式设置 trigger="hover"；点击和右键分支分别使用 click、contextmenu。本页定位示例显式使用 bottom 或各个方向；组件默认 placement 为原生 bottom。显式使用 AsamDropdownMenu 时设置 wrapMenu=false。

局部与全局挂载 ​

切换公开挂载参数后，再打开浮层观察内容位于当前组件附近或挂载到 body。 开关显示当前模式，两个模式均可操作；关闭后可以再次切换。
