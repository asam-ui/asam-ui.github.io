选择与表单

时间选择器 AsamTimePicker

通过输入框与弹层编辑时间。

使用场景 ​

通过输入框与弹层编辑时间。 未设置 valueFormat 时保持原生 Date 模型；需要字符串或时间戳时显式配置 valueFormat。format 控制展示，valueFormat 控制模型文本或时间戳。

原生默认模型 ​

未设置行为属性时由原生控件解析默认值。以下完整 SFC 对照显式 undefined、null 和空字符串；输出保留原始模型类型，不把清空值统一为 null。固定原生版本的非法输入诊断与兼容限制仍按原生处理。

原生默认模型

展开源码
vue
<template>
	<section class="native-values-example">
		<p>使用原生模型和默认值；日期/时间未传 valueFormat，选择后保持 Date。</p>
		<AsamTimePicker v-model="value" clearable @update:model-value="updates++" />
		<AsamButton type="default" native-type="button" @click="value = undefined"
			>显式 undefined</AsamButton
		>
		<AsamButton type="default" native-type="button" @click="value = null">显式 null</AsamButton>
		<AsamButton type="default" native-type="button" @click="value = ''"
			>显式空字符串</AsamButton
		>
		<output>{{ summary }}；更新次数 {{ updates }}</output>
	</section>
</template>

<script lang="ts" setup>
import { computed, ref } from 'vue';
import { AsamButton, AsamTimePicker } from '@asam-ui/ui';
import type { AsamTimeValue } from '@asam-ui/ui';
defineOptions({ name: 'AsamTimePickerNativeValuesExample' });
const value = ref<AsamTimeValue>();
const updates = ref(0);
const summary = computed(() =>
	value.value === undefined
		? 'undefined'
		: value.value instanceof Date
			? 'Date ' + value.value.toISOString()
			: JSON.stringify(value.value)
);
</script>

ASAM 扩展与迁移 ​

disabledHours、disabledMinutes、disabledSeconds 可随状态动态变化，范围回调会收到 start/end 的 role 以及比较端点。arrowControl 使用上下控制箭头。清空、change、update:modelValue 与 keydown 直接转发原生事件及其所有参数、顺序，不追加事件或去重。日期禁用 disabledDate 的完整日期选择场景由 DatePicker/Panel 承接，纯时间旋钮不增加日期选择行为。

ASAM 四档 size 与表单、ConfigProvider 继承一致。空模型支持 null，展示 format 不改变存储；日期字符大小写按 valueFormat 规则配置。 validateEvent 控制表单校验触发；teleported 决定弹层挂载位置。 单点日期时间使用 DatePicker type=datetime；两个独立日期时间端点使用 DateTimeRangePicker。

API 阅读方式 ​

固定官方文档中的 deprecated label 与源码有冲突：实际原生 props 使用 ariaLabel，不声明 label。迁移到 aria-label（TS 对象属性为 ariaLabel），文本会落在真实 input 的 aria-label 上；下方基础示例可直接验证。ASAM 不增加一个无原生承接的 label 接口。

下方 Props、Events、Slots、Exposes 按当前实际公开类型与运行默认值生成。组合属性按分支生效，不能任意混搭值模式。标为“未知 / 未声明”的默认值不代表 false 或空值。源码区域提供对应语言的独立 Demo.vue，可直接复制或下载；本地辅助组件、数据和素材已内联到当前文件。
