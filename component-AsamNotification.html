通知服务 AsamNotification

在页面角落展示带标题的通知，适用于较完整的结果说明。

使用场景 ​

在页面角落展示带标题的通知，适用于较完整的结果说明。

通知位置与关闭句柄 ​

创建右下角通知，支持通知自身关闭按钮和本例关闭操作。

通知位置与关闭句柄

展开源码
vue
<template>
	<div class="actions">
		<AsamButton type="success" native-type="button" @click="notify">显示通知</AsamButton>
		<AsamButton type="default" native-type="button" @click="closeOwned"
			>关闭本例通知</AsamButton
		>
	</div>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamNotificationBasicDemo' });
import { onBeforeUnmount } from 'vue';
import { AsamButton, AsamNotification } from '@asam-ui/ui';
import type { AsamNotificationHandle } from '@asam-ui/ui';
const handles: AsamNotificationHandle[] = [];
const notify = () => {
	handles.push(
		AsamNotification.success({
			title: '处理完成',
			message: '共处理 3 条本地记录。',
			position: 'bottom-right',
			duration: 0,
			showClose: true
		})
	);
};
const closeOwned = () => {
	handles.splice(0).forEach((handle) => handle.close());
};
onBeforeUnmount(closeOwned);
</script>

}

}
</style>

	<div class="flex flex-wrap demo-gap">
		<AsamButton type="default" class="!ml-0" plain @click="open1"> 自动关闭 </AsamButton>
		<AsamButton type="default" class="!ml-0" plain @click="open2"> 不自动关闭 </AsamButton>

<script lang="ts" setup>
import { AsamButton, AsamNotification, type AsamNotificationHandle } from '@asam-ui/ui';

import { onBeforeUnmount } from 'vue';

import { h } from 'vue';

const open1 = () => {
	trackAsamNotification(
		AsamNotification({
			title: '标题',
			message: h('i', { style: 'color: teal' }, '这是一条提醒。')
		})
	);
};

const open2 = () => {
	trackAsamNotification(
		AsamNotification({
			title: '提示',
			message: '这条消息不会自动关闭。',
			duration: 0
		})
	);
};

const ownedAsamNotification = new Set<AsamNotificationHandle>();
let mountedAsamNotification = true;
const trackAsamNotification = (handle: AsamNotificationHandle) => {
	if (mountedAsamNotification) ownedAsamNotification.add(handle);
	else handle.close();
	return handle;
};
onBeforeUnmount(() => {
	mountedAsamNotification = false;
	for (const handle of ownedAsamNotification) handle.close();
	ownedAsamNotification.clear();
});
</script>

用法与契约补充说明 ​

使用约定 ​

AsamNotification(options, appContext?) 与 success/warning/info/error 快捷调用返回 handle.close()。title/message、duration、showClose、position、offset、zIndex、onClick/onClose 配置内容、位置与交互。duration=0 保持显示，closeAll 为全局关闭。ASAM 传递应用上下文并添加品牌样式类。无四档 size；卸载关闭自身实例。

组合职责与生命周期 ​

progress=true 显示倒计时进度条，对象可定制颜色、strokeWidth 等 AsamNotificationProgress 参数；percentage/type/duration/indeterminate/width 由通知自身管理，不接受外部赋值。pauseOnHover 默认暂停倒计时与进度，false 时持续计时；duration=0 持续显示，不自动结束。字符串或 VNode 快捷参数、options.message 内容函数均保留原语义。四角 position、offset、zIndex 和 updateOffsets 管理叠放；onClick/onClose 保留回调。创建方保存 close 句柄，在卸载时逐个清理自己的通知。customClass 接受 Vue 类值。
