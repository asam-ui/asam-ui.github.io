水印 AsamWatermark

在一个内容区域上重复显示说明文字或图形。

使用场景 ​

在一个内容区域上重复显示说明文字或图形。

基础用法与状态 ​

下列示例只使用本入口的实际公开能力。

基础用法与状态

展开源码
vue
<template>
	<AsamWatermark :content="['ASAM', '本地示例']">
		<div class="watermark-content">用于展示水印的本地内容区域。</div>
	</AsamWatermark>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamWatermarkBasicDemo' });
import { AsamWatermark } from '@asam-ui/ui';
</script>

<style scoped>
.watermark-content {
	height: 240px;
	padding: var(--asam-space-lg);
}
</style>

使用约定 ​

content 使用文字或文字数组，image 可提供图像；font、rotate、width/height、gap/offset 与 zIndex 控制水印排布。default 插槽放被覆盖内容，必须为容器建立实际尺寸。本例明确设置 ASAM 文字；水印不执行访问控制。
