统计值 AsamStatistic

把已经获得的数值与单位清晰地展示。

使用场景 ​

把已经获得的数值与单位清晰地展示。

基础用法与状态 ​

下列示例只使用本入口的实际公开能力。

基础用法与状态

展开源码
vue
<template>
	<AsamStatistic
		v-bind="{ title: '本地示例数量', value: 12345.67, precision: 2, suffix: '条' }"
	/>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamStatisticBasicDemo' });
import { AsamStatistic } from '@asam-ui/ui';
</script>

使用约定 ​

value、precision、decimalSeparator/groupSeparator 或 formatter 控制显示；title/prefix/suffix 的属性或插槽组织说明和单位，valueStyle 定制数值样式。组件不获取或汇总业务数据，没有控件密度 size。

完整使用场景 ​

基础用法 ​

用于突出某个或某组数字时，如统计数值、金额、排名等，数值和标题前后都可以加icon、单位等元素。可以使用 vueuse 实现数值的变化动效

基础用法

展开源码
许可

<!-- 此演示还使用 @asam-ui/icons-vue，请按官网对应指南配置这些公开依赖。 -->
<template>
	<AsamRow :gutter="16">
		<AsamCol :xs="24" :sm="12" :md="6" class="text-center mb-4">
			<AsamStatistic title="日活跃用户" :value="268500" />
		</AsamCol>

						男女比例
						<AsamIcon style="margin-left: 4px" :size="12">
							<Male />
						</AsamIcon>
					</div>
				</template>
				<template #suffix>/100</template>
			</AsamStatistic>
		</AsamCol>
		<AsamCol :xs="24" :sm="12" :md="6" class="text-center mb-4">
			<AsamStatistic title="交易总数" :value="outputValue" />
		</AsamCol>
		<AsamCol :xs="24" :sm="12" :md="6" class="text-center mb-4">
			<AsamStatistic title="反馈数量" :value="562">
				<template #suffix>
					<AsamIcon style="vertical-align: -0.125em">
						<ChatLineRound />
					</AsamIcon>
				</template>
			</AsamStatistic>
		</AsamCol>
	</AsamRow>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamStatisticCapBasicDemo' });
import { AsamRow, AsamCol, AsamStatistic, AsamIcon } from '@asam-ui/ui';

import { ref } from 'vue';
import { onMounted, onBeforeUnmount } from 'vue';
import { ChatLineRound, Male } from '@asam-ui/icons-vue';

const outputValue = ref(0);
let frame = 0;
onMounted(() => {
	const start = performance.now();
	const animate = (now: number) => {
		const progress = Math.min((now - start) / 1500, 1);
		outputValue.value = Math.round(172000 * progress);
		if (progress < 1) frame = requestAnimationFrame(animate);
	};
	frame = requestAnimationFrame(animate);
});
onBeforeUnmount(() => cancelAnimationFrame(frame));
</script>
