架构与边界 ​

ASAM UI 基于 Vue 3 和 Element Plus，提供统一样式的基础控件、通用复合组件与数据驱动能力。 页面把数据、接口函数、列定义和事件处理传入组件，组件负责通用展示、交互与数据装配。

组件如何分层 ​

层次 职责 阅读入口
设计系统 tokens、主题变量、基础样式与动效约定 主题
基础控件 输入、选择、日期时间等通用交互 组件目录
复合组件 表单布局、卡片、表格与分页 组件目录
数据驱动 远程选项、字典、分页请求、表单依赖 数据驱动
容器与反馈 弹框、抽屉、浮层与下拉菜单 组件目录

层次描述组件职责。实际可用能力以当前版本的官网组件正文、公开类型和完整可运行示例为准。 目录链接、API 表头或一次挂载不能证明某个具体功能已经实现。

包与宿主 ​

@asam-ui/ui 提供通用组件、tokens 和数据运行时。核心包不引用业务仓库别名、业务模型、 store 或具体 API。@asam-ui/ui-yudao 是可选的芋道 adapter，以 provider 注入方式复用 宿主的请求与字典能力。

业务宿主负责路由、权限、身份凭据、具体接口和业务流程。容器里的提交动作、失败提示与 页面状态仍由宿主按接口约定处理。接入步骤见安装与消费。

文档分工 ​

官网独立承载组件正文、API、可运行示例与源码面板。每个重要使用方式由对应组件页说明， TS 与 JS 变体均展示实际运行的完整 SFC；包含辅助脚本或样式时按文件展示、逐文件复制。 语言切换会重新挂载对应变体，状态重置。安装、provider 和主题指南复用同源文档。 Storybook 仅用于本机与内网开发验证。

API 的可导入类型视图保留联合分支、泛型约束和 events、slots、expose 的 payload。 嵌套参数的可读视图区分 ASAM 声明、上游声明和数据 / provider 协议；说明未声明时明确标识。 固定上游文档默认与注释默认供理解用，实际运行默认优先采用源码或安装包。 显式 undefined、条件表达式、实例工厂和未知默认值各自保留，工厂不会在文档抽取时执行。

同名正文与演示共用一条目录阅读路径；不同层级和重复标题各有唯一锚点。 目录、API JSON 与示例 JSON 引用同一次构建的公开入口、正文和原始示例文件。
