选择与表单

级联面板 AsamCascaderPanel

常驻显示级联菜单，用于不需要输入框与弹层的层级选择。

使用场景 ​

常驻显示级联菜单，用于不需要输入框与弹层的层级选择。面板使用原始 options 与 props 字段映射，模型默认保存完整路径。

路径与节点插槽 ​

default 收到 node/data。change 更新选择路径；getCheckedNodes 读取选中节点，clearCheckedNodes 清空内部勾选。

路径与节点插槽

展开源码
vue
<template>
	<div class="example">
		<AsamCascaderPanel ref="panel" v-model="value" :options="options">
			<template #default="{ data }">
				{{ data.label }}
			</template>
			<template #empty> 暂无节点 </template>
		</AsamCascaderPanel>
		<div class="row">
			<AsamButton type="default" @click="inspect"> 读取选中节点 </AsamButton>
			<AsamButton type="default" @click="clear"> 清空 </AsamButton>
		</div>
		<output>路径：{{ value }}；节点：{{ selected }}</output>
	</div>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamCascaderPanelBasicExample' });
import { ref } from 'vue';
import { AsamCascaderPanel, AsamButton } from '@asam-ui/ui';
import type { AsamCascaderPanelExpose, AsamCascaderPanelProps } from '@asam-ui/ui';
const panel = ref<AsamCascaderPanelExpose>();
const value = ref<AsamCascaderPanelProps['modelValue']>([]);
const options = [
	{
		value: 'team',
		label: '团队',
		children: [
			{ value: 'design', label: '设计' },
			{ value: 'dev', label: '开发' }
		]
	}
];
const selected = ref('');
function inspect() {
	selected.value = JSON.stringify(panel.value?.getCheckedNodes(true).map((node) => node.value));
}
function clear() {
	panel.value?.clearCheckedNodes();
	value.value = [];
}
</script>

多选与非叶节点 ​

props.multiple 开启多选，checkStrictly 允许选择任意层级，emitPath=false 返回节点值。与 ASAM Cascader 的规范化 valueMode 区分。

ASAM 扩展与迁移 ​

面板没有公开 size 属性，不声称支持输入控件的四档密度；外围选择输入与四档弹层密度见 Cascader。lazy/lazyLoad 由原始 props 控制，resolve 结果必须符合当前节点字段映射。

面板始终使用原生级联模型，TS 父模型使用 ref<AsamCascaderPanelProps['modelValue']>，初始路径数组与多选配置不缩窄原生模型的声明范围。

API 阅读方式 ​

下方 Props、Events、Slots、Exposes 按当前实际公开类型与运行默认值生成。组合属性按分支生效，不能任意混搭值模式。标为“未知 / 未声明”的默认值不代表 false 或空值。源码区域提供对应语言的独立 Demo.vue，可直接复制或下载；本地辅助组件、数据和素材已内联到当前文件。

原生协议完整 API ​

面板直接使用原生 options、props、modelValue；不提供标准化 value/object 转换，也不提供 Select 输入壳。 完整说明。

属性 ​

名称 说明 类型 默认值
model-value / v-model 选中项绑定值 string/number/arraystring[] | number[] | any —
options 选项的数据源， value 和 label 可以通过 CascaderProps 自定义. arrayAsamCascaderOption[] —
props 配置选项, 请参阅下面 CascaderProps 表。 objectCascaderProps —
virtual-scroll 是否为大数据启用虚拟滚动 boolean false
item-size 虚拟滚动的节点高度 (px) number 34
height 虚拟滚动的菜单高度 (px) number 204

事件 ​

名称 说明 类型
change 当绑定值变化时触发的事件 Function(value: AsamCascaderNativeProps['modelValue'] | undefined) => void
update:modelValue 当绑定值变化时触发的事件 Function(value: AsamCascaderNativeProps['modelValue'] | undefined) => void
expand-change 当展开节点发生变化时触发 Function(value: AsamCascaderNode['pathValues']) => void
close 面板的关闭事件，提供给 Cascader 以便做更好的判断。 Function() => void

插槽 ​

名称 说明 类型
default 下级节点的自定义内容，它们分别是当前节点对象和节点数据。 object{ node: any, data: any }
empty 没有数据时面板的内容。 —

实例方法与状态 ​

名称 说明 类型

级联配置类型（CascaderProps） ​

属性 说明 类型 默认值

用法与契约补充说明 ​

原生协议完整 API ​

面板直接使用原生 options、props、modelValue；不提供标准化 value/object 转换，也不提供 Select 输入壳。默认 emitPath=true，multiple/checkStrictly/lazy 的语义与 Cascader native 一致。virtualScroll=true 时 height 限定窗口高度，itemSize 必须与实际行高一致；筛选、折叠标签与输入宽度由带输入壳的 Cascader 承接。
