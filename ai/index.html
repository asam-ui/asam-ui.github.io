AIAI 接入Skill 安装Agent 接入组件资料可选 MCP

让 Agent 帮你接入 ASAM UI ​

在现有 Vue 项目执行一条命令（Node.js >=22.20）：

sh
npx skills@1.7.2 add https://asam-ui.github.io/downloads/asam-ui-usage.tgz --skill asam-ui-usage

选择 Agent，再提出下面的请求。Skill 接入组件；文档 MCP 可选， 独立 @asam-ui/mcp@0.1.0-alpha.1 已在 npmjs 发布，可由宿主通过 npx 启动， 不是安装 Skill 或组件的前置条件。

四个入口 ​

入口 你会获得什么
Skill 安装 一条 npx 命令安装完整消费 Skill
Agent 接入 识别项目、选择导入方式、生成示例并检查结果
组件资料 同版本组件、公开类型与数据 provider 的资料入口
文档 MCP 已发布的独立文档查询服务、固定 npx 版本与最小宿主配置

从一个明确的请求开始 ​

text
使用 $asam-ui-usage，在当前 Vue 项目接入 ASAM UI。
先识别包管理器和已有配置，接入 npmjs 上的 @asam-ui/ui@0.1.0-alpha.1。
沿用项目的导入方式，添加独立的按钮示例，保留现有页面和 provider。
按实际包的公开类型选择四档控件尺寸，需要图标时使用 @asam-ui/icons-vue@0.1.0-alpha.1。
给出文件差异，执行 typecheck/build，并说明检查结果。

Skill 负责消费组件。核心、图标与芋道适配包的 0.1.0-alpha.1 已在 npmjs 发布； 沿用工程现有包管理器安装固定版本。离线 tarball 保留在高级入口。 维护组件库源码、Story 和 tokens 使用仓库内部维护 Skill。
