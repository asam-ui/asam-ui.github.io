安装消费 Skill ​

asam-ui-usage 可独立安装到业务项目，不需要克隆整个组件库，也不会替换你的 AGENTS 或应用配置。

一条命令安装 ​

在业务项目目录执行（Node.js >=22.20）：

sh
pnpm dlx skills@1.7.2 add https://asam-ui.github.io/downloads/asam-ui-usage.tgz --skill asam-ui-usage

按提示选择 Agent。使用 pnpm dlx，无需全局安装 skills；Skill 不会自动安装组件包。 已用 Codex 干净项目验证完整安装。无人值守可追加 --agent codex --copy --yes。 安装后让 Agent 使用 $asam-ui-usage，添加一个按钮示例并运行项目检查。

标准消费入口为 SKILL.md，引用资料与脚本随同目录分发。 维护方只公开消费 Skill，不包含私有主仓协作规则、业务源码或凭据。 命令使用现有公开归档；它与组件 npm 包分别交付。

高级：离线安装、来源哈希与维护流程

下载与核对 ​

下载本次网站构建随附的 Skill 分发包，并查看 SHA256 与来源清单。这是当前构建的真实文件；本地预览可下载，不表示远端或 npm 已发布。Skill 与组件包分开交付，安装 Skill 不会自动安装组件依赖。

在独立目录解压，先核对压缩包 SHA256 与交付清单一致：

sh
tar -xzf asam-ui-usage.tgz
node install.mjs --target /absolute/path/to/your-project

Windows PowerShell 可用 Get-FileHash ./asam-ui-usage.tgz -Algorithm SHA256；其他 shell 可用对应 SHA256 工具。路径包含空格时用引号包裹。安装脚本需要 Node.js 22.19 或兼容版本。

查看差异后安装 ​

默认只输出待复制文件，并按分发包内 manifest.json 校验每个 Skill 文件的 SHA256。确认是目标项目后执行：

sh
node install.mjs --target /absolute/path/to/your-project --apply

文件位于项目 .agents/skills/asam-ui-usage/。同内容重复执行返回 unchanged；若已有 Skill 内容不同，脚本停止并指出冲突，保留原内容，供 Agent 比较后合并。其他 Skill、AGENTS、锁文件和应用配置不会被安装器修改。

让支持项目 Skill 的 Agent 在下一轮读取该目录，或明确提供 SKILL.md 路径。需要全局安装时使用宿主自身安装方式，不将本脚本的项目目录参数当作全局路径。

从源码交付与正式分发 ​

维护方先构建固定组件包，再执行 node tools/skills/build-usage.mjs，在 tools/skills/dist/ 得到归档与哈希清单。分发包包含安装器、项目识别与产物检查脚本，以及从真实 exports、声明文件哈希、root/full/resolver 读取的契约快照；缺失构建出口时生成失败。可通过重复 --package <已构建或解包目录> 参数加入同批核心、图标和适配包；传入包必须包含核心包。消费者只需收到分发包和固定产品 tarball，不需要克隆仓库。

快照中的 full 检查使用注册记录器，记录组件、指令、全局属性与根导出身份；嵌套插件请求不会执行。它不替代实际 Vue 初始化、服务调用、指令 hooks 或组件交互验证。Skill 提交、产品包提交、网站 API/SFC 来源分别记录，旧快照不能证明新候选已经配对。

正式分发时先固定源码提交并构建，校验文件和下载链接，再按已授权流程上传站点或发布渠道。未推送的分支不能作为公众安装入口；首次 npm 发布和站点写入沿各自授权执行。消费端始终核对来源与版本，完整流程见 Agent 接入。
