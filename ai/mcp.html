文档查询 MCP ​

@asam-ui/mcp 是可选的 stdio 文档服务，提供基础组件目录、公开 API、完整 TS/JS 示例和接入指南。它与 Skill 可以分别使用，也不要求启动 Storybook。

本页配置固定为 @asam-ui/mcp@1.0.1，内置 UI 1.0.0 文档快照。Pro 组件配方和本地专家工具见 Pro 开发与迁移，不要将两套资料的版本与能力混用。

开始前确保 Node.js >=22.19.0 和 pnpm 可用。

通用 JSON 配置 ​

支持 mcpServers 的宿主可使用以下配置；合并到现有对象并保留其他服务。

json
{
	"mcpServers": {
		"asam-ui": {
			"command": "pnpm",
			"args": ["dlx", "@asam-ui/mcp@1.0.1"]
		}
	}
}

Windows 找不到 pnpm 时，将 command 改为 pnpm.cmd。

Codex ​

在 ~/.codex/config.toml 或项目 .codex/config.toml 添加：

toml
[mcp_servers.asam_ui]
command = "pnpm"
args = ["dlx", "@asam-ui/mcp@1.0.1"]
startup_timeout_sec = 60

重新加载宿主后确认服务可用，配置格式见 Codex MCP 文档。

VS Code ​

在项目 .vscode/mcp.json 添加：

json
{
	"servers": {
		"asam-ui": {
			"type": "stdio",
			"command": "pnpm",
			"args": ["dlx", "@asam-ui/mcp@1.0.1"]
		}
	}
}

在 MCP 服务列表启动服务。VS Code 使用 servers，与通用配置中的 mcpServers 不同；配置示例遵循 VS Code 官方格式，在实际宿主中确认工具发现与查询结果。

验证一次查询 ​

让 Agent 查找 AsamButton 的 size 类型，再读取 basic 的 TS 示例：

  1. list_components：查询 Button，得到精确公开名称。
  2. get_component_api：component 为 AsamButton、section 为 props、member 为 size。
  3. get_component_example：component 为 AsamButton、demo 为 basic、language 为 ts。

返回的组件版本应为 1.0.0。API 支持分页；示例不传 demo 时会列出可选项，选定后返回完整文件与适用许可。get_guide 可读取 installation、provider、theme、skill。

版本与使用范围 ​

服务读取安装包内的固定资料，不追随官网更新。更换文档版本时使用对应的固定 MCP 版本，并核对项目实际组件包的公开类型。请求版本不匹配、未知组件或非法参数会返回错误；资料缺失或损坏时，启动诊断写入 stderr。
