文档查询 MCP ​

@asam-ui/mcp 是独立 stdio 文档服务，提供组件目录、公开 API、完整 TS/JS SFC 和接入指南。 不需要克隆私有主仓、启动 Storybook 或访问内网。MCP 与 Skill 可分别使用。

@asam-ui/mcp@0.1.0-alpha.1 已在 npmjs 发布。 使用下面的固定版本配置，无须下载本地 tarball 或先安装 pnpm。

最小配置 ​

Node.js >=22.19。在 Codex 的 ~/.codex/config.toml 或项目 .codex/config.toml 添加：

toml
[mcp_servers.asam_ui]
command = "npx"
args = ["-y", "@asam-ui/mcp@0.1.0-alpha.1"]
startup_timeout_sec = 60

重新加载宿主后查看 ASAM 的四个文档工具。Windows 找不到 npx 时改为 npx.cmd。 配置格式见 Codex MCP 文档。

其他宿主：VS Code

在项目 .vscode/mcp.json 添加：

json
{
	"servers": {
		"asam-ui": {
			"type": "stdio",
			"command": "npx",
			"args": ["-y", "@asam-ui/mcp@0.1.0-alpha.1"]
		}
	}
}

在 VS Code MCP 服务列表启动并信任服务。Windows 找不到 npx 时使用 npx.cmd。 其他宿主按自己的格式使用相同 command/args；VS Code 的 servers 与一些宿主的 mcpServers 格式不同。VS Code 配置说明。

验证一次查询 ​

让 Agent：“用 ASAM 文档工具查 AsamButton 的 size 类型，再取 basic 的 TS 示例， 确认返回组件版本 0.1.0-alpha.1”。工具顺序：

  1. list_components：查询 Button，得到精确公开名称。
  2. get_component_api：component 为 AsamButton、section 为 props、member 为 size。
  3. get_component_example：component 为 AsamButton、demo 为 basic、language 为 ts。

返回组件版本、文档 sourceSha 和快照哈希；API 与示例应同源。 API 支持分页；示例不传 demo 时列出可用示例，选择后返回完整文件及适用许可。 get_guide 提供 installation、provider、theme、skill。

配对与更新 ​

本已发布版本配对组件 0.1.0-alpha.1，产品来源 4110356ba3d9cb669de5c4d9d22ab72f7d1d6a4a， 官网资料来源 abb44e4d0431ffaad22c5c09aa3a761c13c406e1。包内 data/manifest.json 记录公开输入 URL、SHA256 与压缩快照哈希。运行时读取包内固定资料，不追随网站最新内容。 更新时安装新的固定 MCP 版本；工具参数 version 与资料不符会明确报错。

未知组件、示例、版本或非法参数返回错误。资料缺失/损坏时启动失败，诊断写 stderr。 没有 MCP 时直接读 组件资料 与安装包声明即可。

资料来源、离线使用与宿主验证范围

常规接入使用本页固定 npm 版本，tarball 仅用于离线消费与维护。 服务只查询公开资料，不提供业务数据、消费源码读取或代码写入工具。

已覆盖固定 tarball 的 npx 启动，以及 Codex 原生 app-server MCP 层的工具发现、API 和 完整 TS/JS 示例查询。模型自主调用流程仍因网络超时未完成；当前验证环境的 VS Code 没有 Copilot 扩展，未完成真实发现/查询。以上 VS Code 配置依据宿主官方格式，未作为已测宿主声明。 已发表版本的下载字节与固定版本快照一致；工具返回的数据仍需结合消费项目的类型检查、 构建和真实渲染结果使用。

本 MCP 使用完整许可与自有资料/SFC 使用附录。 第三方内容及原组件包仍保留各自许可。
