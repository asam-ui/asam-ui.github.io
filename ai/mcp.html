文档查询 MCP ​

@asam-ui/mcp 是独立 stdio 文档服务，提供组件目录、公开 API、完整 TS/JS SFC 和接入指南。 不需要克隆私有主仓、启动 Storybook 或访问内网。MCP 与 Skill 可分别使用。

@asam-ui/mcp@1.0.0 固定版本配置如下。 使用下面的固定版本配置，通过 pnpm dlx 启动，无须下载本地 tarball。

最小配置 ​

通用 JSON 配置 ​

支持 mcpServers 的宿主可使用以下 stdio 配置：

json
{
	"mcpServers": {
		"asam-ui": {
			"command": "pnpm",
			"args": ["dlx", "@asam-ui/mcp@1.0.0"]
		}
	}
}

Windows 找不到 pnpm 时使用 pnpm.cmd。将配置合并到宿主现有的 mcpServers，保留其他服务。

Codex ​

Node.js >=22.19.0。在 Codex 的 ~/.codex/config.toml 或项目 .codex/config.toml 添加：

toml
[mcp_servers.asam_ui]
command = "pnpm"
args = ["dlx", "@asam-ui/mcp@1.0.0"]
startup_timeout_sec = 60

重新加载宿主后查看 ASAM 的四个文档工具。Windows 找不到 pnpm 时改为 pnpm.cmd。 配置格式见 Codex MCP 文档。

其他宿主：VS Code

在项目 .vscode/mcp.json 添加：

json
{
	"servers": {
		"asam-ui": {
			"type": "stdio",
			"command": "pnpm",
			"args": ["dlx", "@asam-ui/mcp@1.0.0"]
		}
	}
}

在 VS Code MCP 服务列表启动并信任服务。Windows 找不到 pnpm 时使用 pnpm.cmd。 其他宿主按自己的格式使用相同 command/args；VS Code 的 servers 与一些宿主的 mcpServers 格式不同。VS Code 配置说明。

验证一次查询 ​

让 Agent：“用 ASAM 文档工具查 AsamButton 的 size 类型，再取 basic 的 TS 示例， 确认返回组件版本 1.0.0”。工具顺序：

  1. list_components：查询 Button，得到精确公开名称。
  2. get_component_api：component 为 AsamButton、section 为 props、member 为 size。
  3. get_component_example：component 为 AsamButton、demo 为 basic、language 为 ts。

返回组件版本、文档 sourceSha 和快照哈希；API 与示例应同源。 API 支持分页；示例不传 demo 时列出可用示例，选择后返回完整文件及适用许可。 get_guide 提供 installation、provider、theme、skill。

资料来源、离线使用与宿主验证范围

常规接入使用本页固定 npm 版本，tarball 仅用于离线消费与维护。 服务只查询公开资料，不提供业务数据、消费源码读取或代码写入工具。

安装后按本页步骤查询并核对返回的组件版本、来源与快照哈希；宿主配置不等于实际查询已通过。返回的数据仍需结合消费项目的类型检查、构建和真实渲染结果使用。

本 MCP 使用完整许可与自有资料/SFC 使用附录。 第三方内容及原组件包仍保留各自许可。
