AIAI 接入Skill 安装Agent 接入组件资料可选 MCP

可选 MCP ​

MCP 可帮助 Agent 查找组件文档和示例，但不是安装或使用 ASAM UI 的前置条件。

已有工具时 ​

核对当前宿主实际提供的工具、访问权限和文档版本，再读取相关组件资料。返回的信息需要与安装包类型核对，不把旧版本文档当作当前契约。

MCP 仅用于本机/内网已有服务的可选检索。公网官网独立提供完整组件文档、API 与同源 SFC，不包含 Storybook；不能把公网 Storybook 地址作为接入前提。

没有工具时 ​

直接使用 组件资料、已安装的声明文件与同版本示例，继续安装、配置和验证。不要为一次组件接入新增 MCP 服务，也不要猜测工具名、地址或认证信息。

数据边界 ​

组件文档查询不需要业务凭据或真实数据。连接新服务或发送业务源码需遵守消费项目原有授权；此 Skill 不授予外发权限。工具返回成功不代替 typecheck、build 或真实渲染验证。
