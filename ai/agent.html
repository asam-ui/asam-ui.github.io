Agent 接入流程 ​

让 Agent 按当前项目的结构工作，不需要先把项目整理成统一模板。

识别现有工程 ​

读取项目规则、package.json、workspace 与锁文件，核对 Vue/Vite、包管理器和现有检查脚本。多份锁文件或版本冲突需要先确定使用者；保留已有 router、store、插件、样式、provider 和未提交修改。

选择导入方式 ​

方式 适用情况 指南
手动导入 明确控制每个组件引用，适合先接入一个页面 手动导入
自动 resolver 项目已使用 Vite 组件自动导入，按模板生成引用与样式 自动导入
全量注册 使用独立 full 入口统一注册已导出组件 全量注册

同一组件采用一种方式；样式和 provider 初始化各保留一处。根插件只负责 runtime/theme；全量注册使用独立 @asam-ui/ui/full，以交付包实际 exports 为准。

安装与验证 ​

使用交付的固定组件 tarball 与哈希，并按真实 peer 范围补齐兼容依赖。没有 npm 首发时仍可完成本地安装。先显示具体差异，再在已有授权内执行；不会替换整个 Vite 配置或入口文件。

新增独立示例，在你指定的位置接入；执行原有 typecheck/build，再检查示例渲染、样式与交互。第二次执行先检查已安装依赖、注册、样式和 provider，满足时不重复插入。

更新到本批契约 ​

先核对目标包的实际导出与声明，再迁移已确认删除的 Button variant 到 type、Input 的 password/textarea 职责到专用组件；保留其他业务属性、模型和事件。四档控件尺寸为 large、big、default、small，适用组件继承组件组、Form 与 ConfigProvider 的尺寸。Icon、Avatar、Drawer、Space 等独立尺寸语义按各自类型使用，不能批量替换为 big。

图标从同批独立 @asam-ui/icons-vue 精确产物导入。UI 的全量注册和 resolver 不负责注册图标，三条 UI 导入路径都按图标包的实际根/子路径声明显式导入。公共尺寸类型已存在并不表示每个组件已接入四档；未导出的候选或未完成能力不能提前使用。

第二次执行还应确认 import 别名、CSS 覆盖顺序、锁文件与 provider 参数没有重复或变化。Skill 安装器返回 unchanged 只证明 Skill 文件幂等；业务接入另需比较实际配置、依赖图和示例。

你应收到的结果 ​

  • Skill 与组件包来源、版本和 SHA256。
  • 实际修改文件及用途，保留的项目逻辑。
  • 运行命令、结果、既有诊断与新增诊断。
  • 未完成项及原因；不把生成代码或构建通过当成所有交互已验证。
