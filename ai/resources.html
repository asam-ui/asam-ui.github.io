组件资料 ​

公开 API 来自真实公开类型、JSDoc 与 SFC；演示运行与源码面板读取同一原生 SFC 的 TS/JS、多文件输入。不另行维护一份 AI 专用 props 表。版本不一致时，以实际安装包为准。

文档与类型 ​

  • 组件目录：组件示例、源码与公开 API。
  • 安装与消费：三种导入、样式与兼容约束。
  • 数据 provider：请求、字典和宿主注入边界。
  • 联合类型与透传契约：组合类型及完整定义。
  • 主题与 CSS variables：主题覆盖和样式。
  • 内容来源清单：构建版本、来源文件与哈希。
  • 组件资料索引 JSON：从现有组件目录与包元数据生成的入口，不包含虚构 API。
  • 公开 API JSON：真实符号定义、成员、服务签名与可追溯源码哈希；未知默认值为 null。
  • 同源示例 JSON：每个 TS/JS 变体的完整可见源码与 SHA256，以及原件哈希和许可映射。
  • 示例许可归属：受支持原件的完整归属、许可、原始头部和逐文件哈希。

API 成员的 provenance 标识 ASAM、上游声明或数据 / provider 协议。details 保留嵌套字段、 枚举和 payload 的原声明事实；publicDisplayType / publicPayloadSignatures 由同一严格公开 类型投影生成，供可见页面展示。嵌套回调用真实公开成员路径及 Parameters / ReturnType 保留私有参数身份；多重重载逐条展示。不能公开命名的细节为 null，沿真实公开类型视图继续读取， 不将私有名直接换成虚构导出。definition 保留可导入的严格公开类型投影。大型平台类型或 递归引用有明确的展开边界，读取完整类型时继续使用 definition 和实际安装包声明。 固定上游文档摘录带版本、提交、源文件行号和散列，只补充对应上游声明的说明，不覆盖 ASAM 自有属性或 provider 约定，也不将文档默认当作实测默认。 documentation 记录文档默认和适用条件；sourceDefault 记录固定源码中的字面量、工厂或 函数值表达式，工厂不执行。实际默认值未知时 default 仍为 null。

源码面板、复制、AI 资料和下载使用同一份完整实现。精确识别的独立许可头部移入完整许可 资源，源码保留 SPDX 和随包许可文件指针；原始文件和头部不改写。下载的源码包包含所有 文件和各自完整许可。普通注释、模板、字符串和实际代码仍执行同一公开依赖检查。

离线消费项目可从 node_modules/@asam-ui/ui/package.json 的 exports 开始，阅读 dist/index.d.ts 及其组件、数据声明。不依赖组件库的本地目录、维护工具或业务接口。

版本对齐 ​

Skill 包中的契约快照仅描述它的构建批次。接入前再次读取实际安装包，尤其核对 ./full、./global 与 ./resolver。同版本不同候选通过产品 tarball SHA256、声明/入口哈希区分；Skill 源码提交与产品提交分别记录。

聚合 API、示例与内容来源清单的 sourceSha 应匹配同次网站构建，并核对组件公开入口、相关/继承链接及示例文件哈希。源码中尚未导出的入口、没有运行示例的页面或缺少成员的类型不能算作完整支持。官网的构建提交标签不等同于 npm 发布版本；文档能访问也不表示对应组件包已经公开发布。

没有 sourceSha 的资料保留实际构建来源字段，不补造标签。有限声明验证、旧聚合和部分 TS/JS 示例分别说明覆盖范围，不能代替新固定包的整库配对。依赖声明路径用于溯源，不保证是可打开的公网源码链接；消费者优先读取安装包的公开声明。

组件、服务和指令分别核对。组件 resolver 不负责服务调用或指令注册；full 的注册检查也不证明服务交互、指令 hooks、真实 Vue 初始化或四档视觉。具体结果随固定交付批次记录。
