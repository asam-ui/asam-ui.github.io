WorkBuddy 开发专家 ​

ASAM UI 以本地自定义专家的形式接入 WorkBuddy，使用当前账号登记的专家和资料查询工具。

安装命令和配套版本以快速接入为准。点击截图可在新标签页查看大图。

1. 为当前账号安装专家 ​

先打开 WorkBuddy 并登录一次，再完全退出应用，包括系统托盘。运行专家安装器，选择 WorkBuddy 和安装。检测到多个账号时，选择你接下来要使用的账号。安装完成后，重新打开 WorkBuddy。

2. 从「我的专家」打开 ​

进入 专家·技能·连接器 → 专家 → 我的专家，在我创建的里打开 ASAM UI 开发专家，点击召唤。WorkBuddy 专家中心说明

在 MCP 服务管理中可展开 asam-ui，核对服务开关和 agent_discover、agent_read 等工具。

在已安装技能中确认 asam-ui-development 已启用，打开详情可查看插件提供的技能。

3. 发起第一次查询 ​

在专家会话中选好目标 Vue 项目。也可以在任务输入框键入 /asam，从技能建议中选择 asam-ui-development。若宿主提示连接 asam-ui，核对来源后按提示确认。

发送以下请求，完成后查看实际工具记录。

text
使用 ASAM UI 开发专家查询“按钮”的用法。先用 agent_discover 查找，再用 agent_read 读取配方。告诉我资料版本和一个使用示例，不修改项目文件。

若专家已出现但工具无法调用，核对当前账号并使用原安装入口的检查。安装和检查说明
