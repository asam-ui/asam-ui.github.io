管理数据模型迁移 ​

适用于已明确的 Directory 账号 DTO 到 Catalog 模型。完整复制管理页面及导航、安全相对依赖，使用实际配对 UI/Pro 安装包。

显式映射 ​

directoryUser.from 返回带类型化 id 的 Row。先取出 id，再把其余完整 Edit 交给 catalogUser.to，最后将原 id 放入 Catalog.key：

ts
const { id, ...edit } = directoryUser.from(directoryDTO);
const catalogDTO = { key: id, ...catalogUser.to(edit) };

这是管理源码中的 codec 使用片段。保留数字 0 与字符串 0、角色集合、context、note 和 version；不要把 Row.id 混入严格 Edit，也不修改原 DTO。

接入完整页面 ​

同时修改初始格式和实际服务选择，避免界面选择 Catalog 而服务仍读取 Directory。保留查询、新建、编辑、详情和授权边界。

检查完整 DTO 相等、版本约束、未知角色与禁用候选、真实保存结果和错误恢复。结构合法的 JSON 仍可能发生业务身份丢失，需要对关键值做明确断言。
