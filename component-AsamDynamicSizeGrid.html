虚拟滚动

动态尺寸虚拟网格 AsamDynamicSizeGrid

在有限视窗内渲染可见行列单元格。

使用场景 ​

在有限视窗内渲染可见行列单元格。

契约与组合 ​

这是虚拟网格基础入口，只渲染可见范围与 cache 缓冲。提供固定 height / width 和 totalRow / totalColumn，默认插槽的 style 必须放在真实项目根节点上，否则绝对位置与尺寸计算无法生效。插槽提供 rowIndex / columnIndex / style / data。

rowHeight / columnWidth 是尺寸函数；estimatedRowHeight / estimatedColumnWidth 用于尚未测算范围。 完整说明。

通过 scrollTo 与 scrollToItem 定位网格，支持双方向滚动。 完整说明。

这些低层入口没有表格列注册或独立选择模型，也没有额外四档 size；行列尺寸由宿主决定，颜色、间距和字体来自 ASAM tokens。

perfMode 默认值与 forceUpdate 行为保持原生。固定版本在 perfMode=true 时，reset 方法可能保留活跃样式缓存中的旧尺寸；此入口不增加缓存修复。示例保留公开 reset 调用，供观察同输入原生行为；需要完整重建视窗时可由宿主改变组件 key，宿主数据不受影响。

用法与契约补充说明 ​

契约与组合 ​

rowHeight / columnWidth 是尺寸函数；estimatedRowHeight / estimatedColumnWidth 用于尚未测算范围。函数结果改变后可调用公开 resetAfter({rowIndex,columnIndex}, true)，或 resetAfterRowIndex / resetAfterColumnIndex 重置单个方向。三个方法以及 scrollTo / scrollToItem 直接来自原生实例，保留全部参数、this、返回值和 live 状态；ASAM 不清理样式缓存、不重放滚动请求、不接管原生卸载。

更多参数与事件说明 ​

契约与组合 ​

scrollTo({scrollLeft,scrollTop}) / scrollToItem(rowIndex,columnIndex,alignment) 支持公开定位；alignment 可以为 start / center / end / auto / smart（以本入口类型为准）。direction 支持 ltr / rtl，网格同时支持两方向滚动。scrollbarAlwaysOn 控制持续显示；useIsScrolling 决定插槽是否读取滚动中状态。远端定位时，固定 2.14.7 可能先写入滚动位置，再更新估算总长度，浏览器可能按旧长度钳制；同输入原生也有这一限制，ASAM 不补写第二次滚动。
