Color Picker Panel ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Keep the palette visible in the page layout for direct color editing. The panel renders inline without a trigger or popper.

Format, transparency, and presets ​

Use showAlpha to enable transparency, colorFormat to set the output format, and predefine to offer preset colors. The model holds a color string or null.

Instance methods and disabled state ​

The panel exposes color, inputRef, and update. Call update to resynchronize the color. Use the footer slot for additional content. The panel has no public size prop.

ASAM extensions and migration ​

The inline panel uses the native color contract and offers a footer slot. Use the Color Picker trigger for ASAM's four control sizes.

Border, hue styles, and disabled state ​

The border is visible by default. Use border: false when embedding the panel in an existing container. disabled blocks all color editing. hueSliderClass and hueSliderStyle style the hue slider without affecting the color format. The example keeps transparency with showAlpha and hex8. Use the footer slot for extra content while the panel manages input and color synchronization.

Reading the API ​

The generated props, events, slots, and exposed members reflect the current public types and runtime defaults. Use each property combination with its applicable mode. “Unknown / Not declared” means no default is documented by the runtime. The source panel provides a standalone Demo.vue for each language. Its local helpers, data, and assets are included for copying or downloading.
