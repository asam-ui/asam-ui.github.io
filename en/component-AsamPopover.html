Popover ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Show additional information and a small number of actions next to a trigger.

Dismiss the popover after an action ​

The action button calls the slot's hide function to dismiss the popover.

Example: basic

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<AsamPopover title="草稿操作" :width="240" trigger="click">
		<template #reference>
			<AsamButton type="default" native-type="button">打开气泡面板</AsamButton>
		</template>
		<template #default="{ hide }">
			<p class="example-paragraph">需要确认的补充信息。</p>
			<AsamButton
				type="primary"
				native-type="button"
				@click="
					count++;
					hide();
				"
			>
				完成并关闭
			</AsamButton>
		</template>
	</AsamPopover>
	<p class="example-paragraph" role="status">完成 {{ count }} 次</p>
</template>

Combining triggers in an array ​

trigger accepts hover, click, focus, or contextmenu, or an array of those values. See how to combine triggers.

Additional usage and API details ​

Combining triggers in an array ​

trigger accepts hover, click, focus, or contextmenu, or an array of those values. This example starts with ['hover', 'click']. Clear one option to try a single trigger in the array, or clear both to disable automatic activation. Multiple triggers follow native queueing, delay, and closing behavior. When mixing hover and click, move the pointer away from the trigger before testing dismissal.

Usage conventions ​

The default trigger is hover. Set trigger="click" to open on click. Supply the trigger through reference and call hide from default after an action. Omit visible for uncontrolled activation, or use v-model:visible to control it. See the public types for title, content, width, placement, showAfter, hideAfter, teleported, appendTo, persistent, virtualTriggering, and virtualRef. The instance exposes hide and popperRef. Popover has no separate control-size prop.

Composition and lifecycle ​

reference or virtualRef supplies the trigger target. Use default for rich content and content for plain text. trigger accepts hover, click, focus, or contextmenu individually or in an array. Use visible or v-model:visible for controlled state and disabled to disable activation. showAfter, hideAfter, enterable, persistent, teleported, and appendTo govern interaction and lifecycle. placement, width, offset, showArrow, popperStyle, and popperClass govern positioning and appearance. Use the public hide method and popperRef with a separate directive if needed.

Native events and slots ​

update:visible, before-enter, before-leave, after-enter, and after-leave are forwarded in their original order. Migrate the old synthesized show and hide events to after-enter and after-leave. The default slot exposes the native hide function. When controlling visible, maintain the state in the caller. Escape handling, repeated events, and focus are left to the underlying component.
