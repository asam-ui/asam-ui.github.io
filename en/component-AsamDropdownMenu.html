Dropdown Menu ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Provide the menu structure, keyboard navigation, and focus management for a Dropdown.

Menu composition, icons, and public methods ​

An explicit menu and its items work together and support mouse and keyboard selection.

			通过方法打开
		</AsamButton>
		<AsamButton type="default" native-type="button" @click="menu?.close()">

</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamDropdownMenuBasicDemo' });
import { ref, shallowRef } from 'vue';
import { AsamButton, AsamDropdown, AsamDropdownMenu, AsamDropdownItem } from '@asam-ui/ui';
import type { AsamDropdownExpose } from '@asam-ui/ui';
import { Edit } from '@asam-ui/icons-vue';
const menu = shallowRef<AsamDropdownExpose>();
const command = ref('未选择');
const select = (value: string | number | object) => {
	command.value = String(value);
};
</script>

Usage conventions ​

Place the menu in the AsamDropdown dropdown slot and set wrapMenu to false on the parent. Put menu items in the default slot. onKeydown receives keyboard events. See the API for public methods such as handleFocus and handleKeydown. The menu inherits its density from the parent.

Composition responsibilities and lifecycle ​

The menu receives context from the parent AsamDropdown and holds AsamDropdownItem children. For explicit menu composition, set wrapMenu to false on the parent. The default slot holds the items. The parent controls density, keyboard looping, triggering, and closing. The menu has no separate application command or size.
