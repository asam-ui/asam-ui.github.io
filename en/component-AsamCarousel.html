Carousel ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Cycle through related content within one region of a page.

Basic usage and states ​

This example uses the component's public API.

Example: basic

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<AsamCarousel
		v-bind="{ height: '180px', autoplay: false, trigger: 'click', arrow: 'always' }"
		@change="index = $event"
	>
		<AsamCarouselItem v-for="item in 3" :key="item" :name="String(item)">
			<div class="slide">本地内容 {{ item }}</div>
		</AsamCarouselItem>
	</AsamCarousel>
	<p class="example-paragraph" role="status">当前索引：{{ index }}</p>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamCarouselBasicDemo' });

</script>

<style scoped>

	height: 100%;
	display: grid;
	place-items: center;

</style>

Usage guidelines ​

Configure the carousel with height, initialIndex, trigger, autoplay, interval, loop, direction, type, indicatorPosition, and arrow. The change event provides the current and previous indexes. The instance exposes methods to select a slide or move forward and backward. The first example disables autoplay so users can select slides with the arrows and indicators.
