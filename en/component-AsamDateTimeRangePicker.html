Date-time range picker ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

AsamDateTimeRangePicker uses two independent date-time inputs for the start and end.

Endpoints and the completed model ​

The model is a complete [start, end] pair or null. An initial partial selection stays inside the control. Clearing an endpoint clears the range and emits clear and change(null). Set startPlaceholder and endPlaceholder separately. valueFormat sets the storage format of both endpoints and defaults to YYYY-MM-DD HH:mm:ss.

vue
<template>
	<AsamDateTimeRangePicker
		v-model="range"
		start-placeholder="Start date and time"
		end-placeholder="End date and time"
	/>
</template>

<script setup lang="ts">
import { ref } from 'vue';
import { AsamDateTimeRangePicker } from '@asam-ui/ui';
import type { DateTimeRangeValue } from '@asam-ui/ui';

const range = ref<DateTimeRangeValue>(null);
</script>

Endpoint slots and instance controls ​

focus, blur, handleOpen, and handleClose accept start or end, defaulting to start. The date-cell and sidebar slots identify the endpoint. visible-change reports visibility and the endpoint.

Choose the right range control ​

Use AsamDatePicker with type="datetime" for one date-time or with type="datetimerange" and single-panel for a native single-panel range. The older AsamDateTimePicker name is compatible with the independent two-endpoint model.
