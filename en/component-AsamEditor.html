Rich Text Editor ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

AsamEditor uses a structured document for v-model and provides an editing toolbar, a read-only view, and a limited set of instance methods. Pass a structured document to the model. HTML strings are rejected.

Editing and instance methods ​

Use the Insert menu in the toolbar to insert links, images, attachments, and dividers. The buttons above the editor demonstrate how to insert images and attachments using instance methods, focus or blur the editor, clear its content, and read its HTML. Edit the document to see its current structure and the number of change events.

<script lang="ts" setup>
defineOptions({ name: 'AsamEditorBasicExample' });
import { ref } from 'vue';
import { AsamCollapse, AsamCollapseItem, AsamButton, AsamEditor, AsamInput } from '@asam-ui/ui';
import type { AsamEditorDocument, AsamEditorExpose } from '@asam-ui/ui';
import { createDocument } from './document.js';
// 默认图片来自公开 HTTPS 地址；本项目站内图片须由宿主托管，不支持 data/blob。
const imageUrl = ref('https://asam-ui.github.io/assets/favicon.svg');
const editor = ref<AsamEditorExpose>();
const document = ref<AsamEditorDocument>(createDocument());
const changes = ref(0);
const imageResult = ref('尚未插入');
const attachmentResult = ref('尚未插入');
const html = ref('');
function insertImage(): void {
	imageResult.value = String(
		editor.value?.insertImage({
			src: imageUrl.value,
			alt: 'ASAM 示例图片',
			title: 'ASAM 示例图片'
		}) ?? false
	);
}
function insertAttachment(): void {
	attachmentResult.value = String(
		editor.value?.insertAttachment({
			href: 'https://asam-ui.github.io/assets/favicon.svg',
			name: 'ASAM 示例附件'
		}) ?? false
	);
}
function readHTML(): void {
	html.value = editor.value?.getHTML() ?? '';
}
function reset(): void {
	document.value = createDocument();
	html.value = '';
	imageResult.value = '尚未插入';
	attachmentResult.value = '尚未插入';
}
</script>

Read-only and disabled states ​

editable defaults to true and disabled defaults to false. When either prop prevents editing, the toolbar is hidden, clear leaves the content unchanged, and insertImage and insertAttachment return false. getHTML can still read the displayed content. The example switches between read-only and disabled states and shows what the rejected image insertion returns.

When the document is empty, placeholder displays a hint. Its default text means “Please enter content.” The toolbar groups controls for history, paragraph styles, inline formatting, lists and blocks, and insertion. Use the Insert menu to add or remove links or to insert images and attachments. Click outside the menu or press Esc to close it.

Changes to placeholder take effect without refocusing the editor. Updating it preserves the document and undo history and emits neither a model update nor a change event.

Safe links, resource insertion, and external replacement ​

The example covers HTTP(S) and mailto links, rejected resources, read-only and disabled modes, and replacement with external JSON. Use the toolbar to add or remove links on the selection. Link input is handled as a URL, with arbitrary HTML injection disallowed. Replacing the model externally rebuilds the undo history without emitting change, so undo cannot restore the previous document. All editing operations respect editable and disabled.

defineOptions({ name: 'AsamEditorSecurityExample' });
import { ref } from 'vue';
import { AsamCheckboxItem, AsamEditor, AsamButton, AsamInput } from '@asam-ui/ui';
import type { AsamEditorDocument, AsamEditorExpose } from '@asam-ui/ui';
// Editor 图片只接收根路径或 HTTP(S) URL，内联 data/blob 会按公开契约被拒绝。
const imageUrl = ref('https://asam-ui.github.io/assets/favicon.svg');
const editor = ref<AsamEditorExpose>();
const editable = ref(true);
const disabled = ref(false);
const inserted = ref('尚未插图');
const changes = ref(0);
const html = ref('');
const document = ref<AsamEditorDocument>({
	type: 'doc',
	content: [
		{
			type: 'paragraph',
			content: [
				{
					type: 'text',
					text: '安全链接',
					marks: [{ type: 'link', attrs: { href: 'https://example.com' } }]
				},
				{ type: 'hardBreak' },
				{
					type: 'text',
					text: '邮件',
					marks: [{ type: 'link', attrs: { href: 'mailto:demo@example.com' } }]
				}
			]
		}
	]
});
function insert(src: string): void {
	inserted.value = String(editor.value?.insertImage({ src, alt: '示例图片' }));
}
function insertExample(): void {
	insert(imageUrl.value);
}
function replace(): void {
	document.value = {
		type: 'doc',
		content: [
			{
				type: 'heading',
				attrs: { level: 2 },
				content: [{ type: 'text', text: '外部新文档' }]
			},
			{ type: 'paragraph' }
		]
	};
}
</script>

The editor validates structured documents during initialization and external replacement. It validates the root, fields, nodes, marks, nesting, heading levels, and resource URLs in addition to JSON syntax. Pasting strips images. Internal default attributes are removed from the serialized Tiptap output before validation. Store the structured model on the server. Use getHTML to serialize the current view.

Document and resource constraints ​

The document supports text, headings, blockquotes, lists, code blocks, images, and common text marks. Full details.

For an image, supply src and optionally alt and title. Use an HTTP(S) URL or a site-root path beginning with a single /. The editor rejects data URLs, blob URLs, protocol-relative URLs, credentials, and control characters. insertImage returns false for an invalid resource or when editing is unavailable. Images in pasted HTML are removed. Insert attachments with insertAttachment({ href, name }). Supply an HTTP(S) URL and a nonempty filename. Attachments are stored as linked text.

Links accept only HTTP(S) URLs or valid mailto addresses. getHTML returns the current serialized content. Prefer the structured model for persistence. The host handles HTML from other sources. The public instance API consists of focus, blur, clear, insertImage, insertAttachment, and getHTML. The underlying editor instance is private. Pass a resourcePicker to open the host's resource picker from the toolbar's image and attachment actions. After selection or upload, call the instance methods with stable URLs. Use the insert slot to add other actions.

Usage and API notes ​

Editing and instance methods ​

The modelValue root is { type: 'doc', content: [...] }, and the content array must contain at least one node. Use a single empty paragraph for an empty document. Editing emits update:modelValue and change, both with the structured document. Replacing the model externally updates the content and rebuilds the undo history. Undo cannot recover the replaced document.

Public helpers ​

isSafeImageUrl(value: string): boolean checks for an HTTP(S) URL without credentials or a site-root path beginning with a single /. isSafeLinkUrl(value: string): boolean checks for an HTTP(S) URL without credentials or a mailto URL whose path contains @. It cannot confirm that a mailbox exists or that mail can be delivered. Both helpers reject leading and trailing whitespace, control characters, backslashes, and disallowed protocols. They return a boolean and leave resource creation, requests, and URL rewriting to the caller.

Public helpers ​

validateEditorDocument(value: unknown): asserts value is AsamEditorDocument validates the full document structure described above. It returns normally for a valid input and narrows its type in subsequent TypeScript code. An invalid input throws a TypeError whose message starts with AsamEditor. Validation leaves the input unchanged and returns no repaired document. Handle JSON.parse syntax errors separately.

Image sources in downloaded examples ​

The editor's image model accepts reachable HTTP(S) URLs and site-root paths only. Inline data and blob URLs are rejected. Both image insertion examples use a public HTTPS image by default and label their buttons “Insert example image.” You can replace the URL with an asset hosted by your project. The default image requires network access. A standalone Demo.vue provides no file upload, asset hosting, or new site-root endpoint. Image display components that accept data URLs can still use inline SVG. The editor's public security rules also apply to the downloaded example.

Additional props and events ​

Document and resource constraints ​

Supported nodes include paragraph, heading, blockquote, bulletList, orderedList, listItem, codeBlock, horizontalRule, and image, plus text and hardBreak within text blocks. A heading's level is 1, 2, or 3. Lists contain listItem nodes beginning with a paragraph. Blockquotes and lists must be nonempty. Supported marks include bold, italic, strike, code, underline, and link. The link mark accepts only href in attrs. The runtime rejects unknown fields, invalid nesting, and invalid resource URLs. Generic string fields in the types still accept only supported node names.
