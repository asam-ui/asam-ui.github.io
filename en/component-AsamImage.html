Usage guidelines ​

Use the public props to configure src, fit, lazy, scrollContainer, loading, previewSrcList, initialIndex, previewTeleported, and viewer options. See the full notes.

AsamImage includes a built-in preview. Use AsamImageViewer when you need to control the preview instance independently. Native img attributes, event arguments, and slot scopes are passed through. The underlying viewer handles zoom and closing.

Since 2.2.3, you can use the native image attribute loading="lazy" in place of lazy="true".

				'image/png': 'png',
				'image/jpeg': 'jpg',
				'image/webp': 'webp'

			const extension = extensions[blob.type.split(';')[0]] ?? 'bin';

			document.body.appendChild(link);
