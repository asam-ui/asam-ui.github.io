Dictionary Checkbox Group ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

Use dictionary options in a checkbox group with reload and cancellation.

Basic usage ​

The example reads a dictionary from a local provider and demonstrates model updates, pausing, and reloading. Requests run entirely within the demo.

The basic example shows independent models for a raw value array and a delimited string. The string uses valueMode="value" and can switch between the pipe and tilde separators. The demo clears the string before switching so the new separator never reinterprets the old encoding. Deselecting re-encodes the model with the current separator. The array and object groups are independent.

Data sources and overrides ​

Choose dictType or dataSource. Create a dataSource with defineAsamDictSource and configure the value type in that source. See the full notes.

A checkbox group stores an array or, with multipleValueMode="string", a delimited string using separator. valueMode="object" requires an array of normalized AsamOption objects. The group always supports multiple selections.

Lifecycle, events, and instance methods ​

active=false pauses requests and retains the last successful data. Use reload({ force: true }) for fresh data and cancel() to cancel the current request. See the full notes.

immediate controls the initial request, and active controls whether requests are enabled. See the generated API for the defaults and their sources.

Slots and base features ​

The option slot receives { option }. option.raw retains the source record. The default slot uses the base option layout contract. The data instance exposes reload and cancellation, and the group has no selector-style focus or blur methods.

Related base components ​

  • Checkbox Group provides the applicable display, interaction, and public API.

Use this page's rules for data sources, models, events, and exposed members, and refer to the linked base components for the features available here. Sizes follow the ASAM base components. Examples use default.

Dictionary refresh and the example provider ​

A forced reload calls provider.dict.refresh before reading the dictionary again. The example supplies both get and refresh and checks the request cancellation signal. It uses fixed local data. Implement cache updates in the host provider's refresh.

Connected buttons and the object model ​

type="button" lays out the options as connected buttons. Sizes are large, big, default, and small. See the full notes.

Inspect the four public events in the example log. update:modelValue and change preserve the applicable scalar or collection model, success preserves normalized options and their source raw, and error preserves error kind and message. The caller's model survives failure, recovery, and cancellation. A cancelled request emits no error.

The option slot keeps the normalized item and option.raw.id. The unscoped default slot replaces the options layout. Switch to custom default content and back to source options in the full example. Switching preserves the model and original entities.

<script lang="ts" setup>
defineOptions({ name: 'AsamDictCheckboxButtons' });
import { ref } from 'vue';
import LimitsContract from './LimitsContract.vue';
import PresentationContract from './PresentationContract.vue';
import ValidationContract from './ValidationContract.vue';
const showValidation = ref(false);
const showPresentation = ref(false);
const showLimits = ref(false);
import {
	AsamCheckboxItem,
	AsamSelect,
	AsamOption,
	AsamButton,
	AsamDictCheckbox
} from '@asam-ui/ui';
import type {
	AsamAsyncChoiceExpose,
	AsamValue,
	AsamDataError,
	AsamCheckboxDataEmits
} from '@asam-ui/ui';
interface Item {
	id: number;
	label: string;
	value: number;
	disabled?: boolean;
}
type Model = readonly AsamOption<number, Item>[];
type Change = AsamCheckboxDataEmits<AsamValue, Item>['change'][0];
type Size = 'large' | 'big' | 'default' | 'small';
import { failing, slow } from './provider.js';
const size = ref<Size>('default');
const value = ref<Model>([]);
const changes = ref<Change[]>([]);
const active = ref(true);
const customDefault = ref(false);
const control = ref<AsamAsyncChoiceExpose<number, Item>>();
const error = ref('');
const events = ref<{ name: string; payload: unknown }[]>([]);
function recordChange(value: Change) {
	changes.value.push(value);
	events.value.push({ name: 'change', payload: value });
}
function recordError(value: AsamDataError) {
	error.value = value.message;
	events.value.push({ name: 'error', payload: { kind: value.kind, message: value.message } });
}
function recordSuccess(options: readonly AsamOption<AsamValue, Item>[]) {
	error.value = '';
	events.value.push({ name: 'success', payload: options });
}
const result = ref('');
async function reload() {
	result.value = (await control.value?.reload({ force: true }))?.status ?? 'cancelled';
}
async function cancel() {
	slow.value = true;
	const pending = control.value?.reload({ force: true });
	setTimeout(() => control.value?.cancel(), 20);
	result.value = (await pending)?.status ?? 'cancelled';
	slow.value = false;
}
</script>

Local request error slot ​

The optional error slot runs only when the current request has an error. It receives a read-only { error, stale, retry } scope. See the full notes.

Call retry() without arguments. It returns the forced reload Promise and follows the same cancellation and unmount behavior. See the full notes.

Providing the slot replaces the default local error region, including when the slot renders empty content. With the slot omitted, the component displays its error message, stale-data hint, and retry button. The slot requires a current error. empty, loading, and other base slots keep their original scopes.

Additional usage notes ​

Data sources and overrides ​

Choose dictType or a dataSource created with defineAsamDictSource. Configure the source's value type in its factory. With the shorthand dictType source, dictValueType converts dictionary values to string, number, or boolean. The app injects dict.get through provideAsamData. The demo uses a local dictionary in a separate child app and unmounts it on a language change or navigation away.

Lifecycle, events, and instance methods ​

active=false pauses requests and retains the last successful data. Use reload({ force: true }) for fresh data and cancel() to cancel the current request. success emits a normalized option array. error emits an AsamDataError. A failed refresh marks the last successful data stale. Handle the reload result by its status of success, error, or cancelled.

Connected buttons and the object model ​

type="button" displays connected options in one of four sizes, large, big, default, or small. The full example preserves numeric 0 and option.raw. It shows disabled options, retention of the model after failure, recovery, and slow-request cancellation. The component supplies the normalized objects and their labels. Checkbox Group inherits native min and max selection limits. This example sets max=2, valueMode="object", and multipleValueMode="array". Delimited storage is available only in value mode.

Connected buttons and the object model ​

Selection limits. The connected-buttons example uses independent object, value-array, and delimited-string models. Set min to 0, 1, or 2 and max to 1, 2, or 3, or omit both props. Switch between ordinary checkboxes and connected buttons and disable the group. The options retain their source values and full raw records. Disabled source options stay unavailable. Limits affect further selections and preserve existing selections. The parent example's model and request controls are independent.

Connected buttons and the object model ​

Automatic validation. The connected-buttons example logs actual validation calls from a change rule on public AsamBaseForm and AsamFormItem for object, value-array, and delimited-string models. Omit validate-event for the enabled default, set it to false to pause automatic validation, and set it to true or omit it to restore validation. Switch between ordinary checkboxes and connected buttons. Change the model through selection or the external buttons. Pausing validation preserves existing errors. Restoring it by itself leaves the model unchanged.

Local request error slot ​

The optional error slot runs only while the current request has an error. It receives a read-only { error, stale, retry } scope. The error is the same AsamDataError emitted by that instance, including cause, kind, message, and notified. Rendering the slot leaves the provider's notification state unchanged. stale indicates that the retained data is outdated.

Additional props and events ​

Local request error slot ​

Call retry() with no arguments. It returns the Promise from reload({ force: true }) with the success, error, or cancelled branch of AsamReloadResult<readonly AsamOption<V, I>[]>. Retrying follows active, the current source, cancellation, and unmount, and preserves the model. A forced dictionary refresh runs refresh before get. Omitting refresh produces the existing configuration error.
