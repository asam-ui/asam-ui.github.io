Pagination ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Display page numbers and let the host manage the current page and the number of items per page.

Basic usage and state ​

This example uses the public Pagination API.

Example: basic

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<div class="demo-root-layout">
		<AsamPagination
			v-bind="{
				total: records.length,
				pageSizes: [10, 20, 50],
				layout: 'total, sizes, prev, pager, next',
				size
			}"
			v-model:current-page="page"
			v-model:page-size="pageSize"
		/>
		<label>
			<span>控件尺寸 size</span>
			<AsamSelect v-model="size">
				<AsamOption v-for="value in sizes" :key="value" :label="value" :value="value">
					{{ value }}
				</AsamOption>
			</AsamSelect>
		</label>
		<p class="example-paragraph" role="status">
			第 {{ page }} 页，每页 {{ pageSize }} 条，显示记录 {{ first }}–{{ last }}。
			{{ records[first - 1] }} 到 {{ records[last - 1] }}
		</p>
	</div>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamPaginationBasicDemo' });
import { computed, ref } from 'vue';
import { AsamSelect, AsamOption, AsamPagination } from '@asam-ui/ui';
import type { AsamControlSize } from '@asam-ui/ui';
const sizes: AsamControlSize[] = ['large', 'big', 'default', 'small'];
const size = ref<AsamControlSize>('default');
const page = ref(1);
const pageSize = ref(10);
const records = Array.from({ length: 95 }, (_, index) => `项目任务 ${index + 1}`);
const first = computed(() => (page.value - 1) * pageSize.value + 1);
const last = computed(() => Math.min(first.value + pageSize.value - 1, records.length));
</script>

	margin-block: 0;
}
.demo-root-layout :deep(.el-pagination) {
	flex-wrap: wrap;
	row-gap: var(--asam-space-xs);
}
</style>

<style scoped>
p:where(.example-paragraph) {
	margin-block: 16px;
	line-height: 1.8;
	overflow-wrap: anywhere;
}
</style>

Usage conventions ​

Bind v-model:current-page and v-model:page-size to manage state. Use total or pageCount, along with pageSizes, layout, disabled and background, to configure the display. Read the full explanation.

Complete usage scenarios ​

Basic usage ​

Set layout to a comma-separated list. The elements appear in the order given.

Element Purpose
prev Button for the previous page.
next Button for the next page.
pager List of page numbers.
jumper Input for jumping to a page.
total Total item count.
sizes Selector for the number of items per page.
-> Right-aligns every element that follows it.

Additional usage and contract notes ​

Usage conventions ​

Bind v-model:current-page and v-model:page-size to manage state. Use total or pageCount, along with pageSizes, layout, disabled and background, to configure the display. Listen to the public current-change, size-change and change events or the ASAM page-change and page-size-change events. size accepts large, big, default and small and inherits its value from context. Keep static values consistent with the bound models. The component updates pagination state, and the host handles data requests.

Additional controls ​

This complete example uses size-change and current-change to handle changes to the page size and current page. page-sizes accepts an array of integers for the page-size choices. For example, [100, 200, 300, 400] offers four choices of 100, 200, 300 or 400 items per page.
