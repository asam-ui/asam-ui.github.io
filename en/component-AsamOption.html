Option ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

Related components ​

Use this component as a child of AsamSelect, which handles selection. Use AsamOptionGroup to organize options.

When to use it ​

Place raw-value options in the Select default slot. value identifies the selected option, label is the text shown in the input, and the default slot can render richer menu content.

Grouping and display content ​

Set valueMode="native" on Select to use raw Option components. The default slot controls the menu display, and label keeps the selected text in the input concise.

Raw objects and unique keys ​

Select.valueKey identifies raw object values. ASAM’s valueMode="object" uses a normalized option model. The example keeps the full business objects in a separate data file.

Four sizes and context inheritance ​

The four examples set large, big, default, and small on Select. The example below them omits size so it updates with ConfigProvider. An explicit size takes precedence over an inherited size. The option components use the Select context.

Example: sizes

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<div class="example">
		<div class="density-grid">
			<section data-density="large">
				<strong>large</strong>
				<AsamSelect size="large" model-value="design" value-mode="native">
					<AsamOptionGroup label="团队">
						<AsamOption label="设计" value="design" />
						<AsamOption label="开发" value="dev" />
					</AsamOptionGroup>
				</AsamSelect>
			</section>
			<section data-density="big">
				<strong>big</strong>
				<AsamSelect size="big" model-value="design" value-mode="native">
					<AsamOptionGroup label="团队">
						<AsamOption label="设计" value="design" />
						<AsamOption label="开发" value="dev" />
					</AsamOptionGroup>
				</AsamSelect>
			</section>
			<section data-density="default">
				<strong>default</strong>
				<AsamSelect size="default" model-value="design" value-mode="native">
					<AsamOptionGroup label="团队">
						<AsamOption label="设计" value="design" />
						<AsamOption label="开发" value="dev" />
					</AsamOptionGroup>
				</AsamSelect>
			</section>
			<section data-density="small">
				<strong>small</strong>
				<AsamSelect size="small" model-value="design" value-mode="native">
					<AsamOptionGroup label="团队">
						<AsamOption label="设计" value="design" />
						<AsamOption label="开发" value="dev" />
					</AsamOptionGroup>
				</AsamSelect>
			</section>
		</div>
		<AsamConfigProvider :size="density">
			<section data-density="inherited">
				<AsamSelect model-value="design" value-mode="native">
					<AsamOptionGroup label="团队">
						<AsamOption label="设计" value="design" />
						<AsamOption label="开发" value="dev" />
					</AsamOptionGroup>
				</AsamSelect>
			</section>
		</AsamConfigProvider>
		<div class="row" role="group" aria-label="继承尺寸">
			<span>继承尺寸</span>
			<AsamButton type="default" @click="density = 'small'">small</AsamButton>
			<AsamButton type="default" @click="density = 'big'">big</AsamButton>
		</div>
		<output>配置提供器：{{ density }}</output>
	</div>
</template>

ASAM extensions and migration ​

Option and OptionGroup have no independent size prop. The parent Select sets the menu density through its four sizes and popover context. These components provide only the default slot and expose no events or instance methods. Listen to change on Select for selection changes.

Reading the API reference ​

The Props, Events, Slots, and Exposes sections use the current public types and runtime defaults. Props tied to a particular branch apply only to that branch. Use one compatible value mode at a time. “Unknown / Undeclared” marks an unspecified default, which may differ from false or an empty value. Copy or download a standalone Demo.vue in the source panel for either language. The file includes the local helper components, data, and assets.
