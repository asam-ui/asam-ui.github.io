Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

Use Config Provider to let users switch languages in your application.

Use the two props to configure internationalization.

		<AsamButton type="primary" class="ui032-mb-2" @click="toggle">切换语言</AsamButton>
		<br />

		<AsamConfigProvider :locale="locale">
			<div class="demo-provider-layout-1">
				<AsamTable :data="[]" class="ui032-mb-1" />

			</div>
		</AsamConfigProvider>

<script lang="ts" setup>
defineOptions({ name: 'AsamConfigProviderCapUsageDemo' });
import { AsamButton, AsamConfigProvider, AsamTable, AsamPagination } from '@asam-ui/ui';

import { computed, ref } from 'vue';
import { asamLocaleZhCn as zhCn } from '@asam-ui/ui';
import { asamLocaleEn as en } from '@asam-ui/ui';

const language = ref('zh-cn');
const locale = computed(() => (language.value === 'zh-cn' ? zhCn : en));

const toggle = () => {
	language.value = language.value === 'zh-cn' ? 'en' : 'zh-cn';
};
</script>

The complete example demonstrates states and interactions, with both TS and JS source.

AsamButton resolves its color type in this order. It uses an explicit type, then the nearest AsamButtonGroup's type, then configured button.type, and finally the standalone default secondary. Changing the provider type updates child buttons that have no explicit or group override.

<script lang="ts" setup>
defineOptions({ name: 'AsamConfigProviderCapDialogDemo' });
import { AsamSwitch, AsamButton, AsamConfigProvider, AsamDialog } from '@asam-ui/ui';

import { computed, nextTick, ref, shallowReactive } from 'vue';

import type { AsamButtonExpose, AsamConfigProviderProps } from '@asam-ui/ui';

type GlobalConfig = {
	alignCenter: boolean;
	draggable: boolean;
	overflow: boolean;
	transition?: NonNullable<AsamConfigProviderProps['dialog']>['transition'];
};

const config = shallowReactive<GlobalConfig>({
	alignCenter: false,
	draggable: false,
	overflow: false
});
const visible = ref(false);
const enableTransition = ref(false);
const isObjectTransition = ref(false);

const buttonRef = ref<AsamButtonExpose>();

const ANIMATION_DURATION = 300;

const globalConfig = computed<GlobalConfig>(() => {
	let transition: NonNullable<AsamConfigProviderProps['dialog']>['transition'] | undefined;
	if (enableTransition.value) {
		if (isObjectTransition.value) {
			transition = {
				css: false,
				onBeforeEnter(el) {
					nextTick(() => {
						if (buttonRef.value) {
							const buttonRect = buttonRef.value.ref!.getBoundingClientRect();
							const dialogEl = el.querySelector('.el-dialog') as HTMLElement;

							if (dialogEl) {
								const dialogRect = dialogEl.getBoundingClientRect();

								const offsetX =
									buttonRect.left +
									buttonRect.width / 2 -
									(dialogRect.left + dialogRect.width / 2);
								const offsetY =
									buttonRect.top +
									buttonRect.height / 2 -
									(dialogRect.top + dialogRect.height / 2);

								dialogEl.style.transform = `translate(${offsetX}px, ${offsetY}px) scale(0.3)`;
								dialogEl.style.opacity = '0';
							}
						}
					});
				},
				onEnter(el, done) {
					nextTick(() => {
						const dialogEl = el.querySelector('.el-dialog') as HTMLElement;
						if (dialogEl) {
							// force reflow
							void dialogEl.offsetHeight;

							dialogEl.style.transition = `all ${ANIMATION_DURATION}ms cubic-bezier(0.4, 0, 1, 1)`;
							dialogEl.style.transform = 'translate(0, 0) scale(1)';
							dialogEl.style.opacity = '1';

							// wait for animation to complete, then cleanup inline styles to avoid affecting drag
							setTimeout(() => {
								dialogEl.style.transition = '';
								dialogEl.style.transform = '';
								dialogEl.style.opacity = '';
								done();
							}, ANIMATION_DURATION);
						} else {
							done();
						}
					});
				},
				onLeave(el, done) {
					const dialogEl = el.querySelector('.el-dialog') as HTMLElement;
					if (dialogEl) {
						if (buttonRef.value) {
							const buttonRect = buttonRef.value.ref!.getBoundingClientRect();
							const dialogRect = dialogEl.getBoundingClientRect();

							const currentTransform = dialogEl.style.transform;
							let dragOffsetX = 0;
							let dragOffsetY = 0;

							// avoid draggable effect
							if (currentTransform) {
								const translateMatch = currentTransform.match(
									/translate\(([^,]+),\s*([^)]+)\)/
								);
								if (translateMatch) {
									dragOffsetX = Number.parseFloat(translateMatch[1]);
									dragOffsetY = Number.parseFloat(translateMatch[2]);
								}
							}

							const offsetX =
								buttonRect.left +
								buttonRect.width / 2 -
								(dialogRect.left + dialogRect.width / 2) +
								dragOffsetX;
							const offsetY =
								buttonRect.top +
								buttonRect.height / 2 -
								(dialogRect.top + dialogRect.height / 2) +
								dragOffsetY;

							dialogEl.style.transition = `all ${ANIMATION_DURATION}ms cubic-bezier(0.4, 0, 1, 1)`;
							dialogEl.style.transform = `translate(${offsetX}px, ${offsetY}px) scale(0.3)`;
							dialogEl.style.opacity = '0';

							// wait for animation to complete, then cleanup inline styles
							setTimeout(() => {
								dialogEl.style.transition = '';
								dialogEl.style.transform = '';
								dialogEl.style.opacity = '';
								done();
							}, ANIMATION_DURATION);
						} else {
							done();
						}
					} else {
						done();
					}
				}
			};
		} else {
			transition = 'dialog-bounce';
		}
	}
	return {
		alignCenter: config.alignCenter,
		draggable: config.draggable,
		overflow: config.overflow,
		transition
	};
});
</script>

Empty value configuration (2.7.0) ​

Supported components
  • Cascader (AsamCascader)
  • Color Picker (AsamColorPicker) ^(2.10.3)
  • Date Picker (AsamDatePicker)
  • Select (AsamSelect)
  • Virtualized Select (AsamSelectV2)
  • Time Picker (AsamTimePicker)
  • Time Select (AsamTimeSelect)
  • Tree Select (AsamTreeSelect)

Set empty-values to configure the values treated as empty. The default is ['', null, undefined]. To treat the empty string as a value, set [undefined, null].

Set value-on-clear to choose the value on clear. Components default to undefined, and date components default to null. To configure undefined explicitly, use () => undefined.

The native mode preserves the native clear value. The default value mode normalizes undefined to null for single selection. See the full notes.

Usage and contract notes ​

Usage conventions ​

size accepts large, big, default, and small. Omit it to retain the default density. Configuration changes are reactive. A child's explicit size takes precedence over the nearest group, Form, or ConfigProvider. See the public props for locale, namespace, zIndex, button, and message. The provider supplies context. The default slot receives the live configuration, with application requests and events handled by the host.

Configuration types and locale packs ​

ButtonConfigContext, CardConfigContext, LinkConfigContext, and TableConfigContext have public counterparts prefixed with AsamConfigProvider. The configuration tables and examples use these types directly. The language example imports asamLocaleEn and asamLocaleZhCn from the same package. Switch locale between them or pass another locale object that satisfies the prop type.

Additional props and events ​

Empty value configuration (2.7.0) ​

The second AsamSelectV2 in the example uses value-mode="native". It preserves the native undefined clear value after overriding the global configuration. The first AsamSelect still clears to the provider's configured null. AsamSelectV2's default value mode normalizes a cleared single selection from undefined to null. Choose native when you need the native clear value.
