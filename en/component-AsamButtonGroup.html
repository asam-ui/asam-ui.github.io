Button Group ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Group related actions or build segmented controls. Child buttons inherit the group's type and size when omitted, and explicit settings on a child take precedence. Groups can be nested, and changes to their props remain reactive.

Shared colors and explicit overrides ​

The buttons inherit primary and big. The last button explicitly uses danger and small.

Vertical layout ​

Use direction to choose a horizontal or vertical layout and place the buttons in the default slot. The group declares no events or instance methods of its own.

Four sizes and inheritance ​

The four density levels are large, big, default, and small. An explicit size takes precedence. When omitted, size resolves from the component, group, form, and ConfigProvider in that order, with default as the fallback.

Example: sizes

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<AsamSpace wrap>
		<AsamButtonGroup v-for="size in sizes" :key="size" type="primary" :size="size">
			<AsamButton>{{ size }}</AsamButton>
		</AsamButtonGroup>
	</AsamSpace>
</template>

<script lang="ts" setup>
import { AsamButton, AsamButtonGroup, AsamSpace } from '@asam-ui/ui';
import type { AsamControlSize } from '@asam-ui/ui';

const sizes: readonly AsamControlSize[] = ['large', 'big', 'default', 'small'];
</script>

ASAM extensions and migration ​

Buttons inherit the group's ASAM color and four-level size settings. Set the layout with direction and the group's color with type. The legacy Button variant cannot set the group's color. Listen to events and access instance state on individual buttons.

Reading the API reference ​

The API reference uses the current public types and runtime defaults. “Unknown / Undeclared” marks an unspecified default. The actual value may depend on context. Omitting size preserves inheritance from ancestors. The group declares props and a default slot only.
