Message ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Show brief global feedback after an action and get a handle that can dismiss it.

Types, grouping, and manual dismissal ​

Messages stay visible so you can inspect them. Use the example's close action to dismiss the instances it created.

Example: basic

Example source ZIPComplete project ZIP
vue
<template>
	<div class="actions">
		<AsamButton type="primary" native-type="button" @click="success">成功消息</AsamButton>
		<AsamButton type="default" native-type="button" @click="grouped">分组信息</AsamButton>
		<AsamButton type="default" native-type="button" @click="closeOwned">
			关闭本例消息
		</AsamButton>
	</div>
	<p class="example-paragraph" role="status">已创建 {{ count }} 次</p>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamMessageBasicDemo' });
import { ref, onBeforeUnmount } from 'vue';
import { AsamButton, AsamMessage } from '@asam-ui/ui';
import type { AsamMessageHandler } from '@asam-ui/ui';
const handles: AsamMessageHandler[] = [];
const count = ref(0);
const success = () => {
	handles.push(AsamMessage.success({ message: '草稿保存成功', duration: 0, showClose: true }));
	count.value++;
};
const grouped = () => {
	handles.push(
		AsamMessage({ message: '重复提示合并', grouping: true, duration: 0, showClose: true })
	);
	count.value++;
};
const closeOwned = () => {
	handles.splice(0).forEach((handle) => handle.close());
};
onBeforeUnmount(closeOwned);
</script>

Call AsamMessage(params, appContext?) with a string, VNode, render function, or options object. See the usage conventions.

These examples use the public ASAM UI entry points. Each includes a complete TypeScript and JavaScript SFC. See the API on this page for props, events, slots, and instance types. Close service instances that you create, and pass only trusted strings as HTML.

Example: ep2147-basic

vue
<template>
	<div class="flex flex-wrap demo-gap">
		<AsamButton type="primary" class="!ml-0" :plain="true" @click="open">显示消息</AsamButton>
		<AsamButton type="default" class="!ml-0" :plain="true" @click="openVn">
			VNode 内容
		</AsamButton>
	</div>
</template>

<script lang="ts" setup>
import { AsamButton, AsamMessage, type AsamMessageHandler } from '@asam-ui/ui';

import { onBeforeUnmount } from 'vue';

import { h } from 'vue';

const open = () => {
	trackAsamMessage(AsamMessage('这是一条消息。'));
};

const openVn = () => {
	trackAsamMessage(
		AsamMessage({
			message: h('p', { style: 'line-height: 1; font-size: 14px' }, [
				h('span', null, '消息内容可以使用 '),
				h('i', { style: 'color: teal' }, 'VNode')
			])
		})
	);
};

const ownedAsamMessage = new Set<AsamMessageHandler>();
let mountedAsamMessage = true;
const trackAsamMessage = (handle: AsamMessageHandler) => {
	if (mountedAsamMessage) ownedAsamMessage.add(handle);
	else handle.close();
	return handle;
};
onBeforeUnmount(() => {
	mountedAsamMessage = false;
	for (const handle of ownedAsamMessage) handle.close();
	ownedAsamMessage.clear();
});
</script>

Additional usage and API details ​

Usage conventions ​

Call AsamMessage(params, appContext?) with a string, VNode, render function, or options object. The primary, success, warning, info, and error shortcuts return a handle with close(). Set duration to 0 to keep the message visible and enable showClose to display a close button. Use grouping and repeatNum for repeated messages and placement, offset, and zIndex for positioning. closeAll and closeAllByPlacement act globally. On unmount, the example closes its own handles. ASAM supports app context registration and applies its styling. The service has no size option.

Composition and lifecycle ​

A string, VNode, content function, or options object returns a close handle. The primary, success, warning, info, and error shortcuts support AppContext. grouping combines identical messages. placement, offset, appendTo, and zIndex configure stacking. Messages with duration: 0 stay visible until the caller closes them. customClass accepts string, array, and object values and preserves the ASAM styling class. closeAll and closeAllByPlacement affect every message in their scope. This example uses individual handles to avoid dismissing messages created elsewhere.
