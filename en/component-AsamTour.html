Tour ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Guide users through a sequence of steps tied to elements on the page.

Steps with and without a target ​

The targets come from element refs in the current SFC, so the example does not depend on global page IDs.

Example: basic

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<AsamButton type="primary" native-type="button" @click="open = true">开始导览</AsamButton>
	<AsamButton type="default" ref="target" native-type="button">导览目标</AsamButton>
	<AsamTour v-model="open" v-model:current="current" @finish="finished++">
		<AsamTourStep :target="target?.ref" title="第一步" description="这里展示目标说明。" />
		<AsamTourStep title="完成导览">
			<template #header>下一步操作</template>
			<p class="example-paragraph">没有目标的步骤使用居中展示。</p>
		</AsamTourStep>
		<template #indicators="{ current: index, total }">{{ index + 1 }} / {{ total }}</template>
	</AsamTour>
	<p class="example-paragraph" role="status">
		当前步骤 {{ current + 1 }}；完成 {{ finished }} 次
	</p>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamTourBasicDemo' });
import { ref } from 'vue';
import { AsamButton, type AsamButtonExpose, AsamTour, AsamTourStep } from '@asam-ui/ui';
const open = ref(false);
const current = ref(0);
const finished = ref(0);
const target = ref<AsamButtonExpose>();
</script>

<style scoped>
p:where(.example-paragraph) {
	margin-block: 16px;
	line-height: 1.8;
	overflow-wrap: anywhere;
}
</style>

Example: semantic-colors

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<div class="colors">
		<AsamButton type="default" @click="start('default')">默认（default）</AsamButton>
		<AsamButton type="default" @click="start('primary')">主要（primary）</AsamButton>
	</div>
	<AsamTour v-model="open" :type="type">
		<AsamTourStep title="查看导览颜色" description="观察背景、文字和内建按钮。" />
	</AsamTour>
</template>

<script lang="ts" setup>
import { shallowRef } from 'vue';
import { AsamButton, AsamTour, AsamTourStep } from '@asam-ui/ui';
import type { AsamTourProps } from '@asam-ui/ui';

const open = shallowRef(false);
const type = shallowRef<NonNullable<AsamTourProps['type']>>('default');

function start(value: NonNullable<AsamTourProps['type']>) {
	type.value = value;
	open.value = true;
}
</script>

Usage conventions ​

modelValue controls visibility and current sets the step. change, finish, and close report progress. See the usage conventions.

Complete usage examples ​

These examples use the public ASAM UI entry points. Each includes a complete TypeScript and JavaScript SFC. See the API on this page for props, events, slots, and instance types. Close service instances that you create, and pass only trusted strings as HTML.

Composition and lifecycle ​

Place AsamTourStep directly in default or group steps in a Fragment that the tour can enumerate. See step composition.

current is a zero-based index. change reports a step change, finish fires when the last step completes, and close includes the current index. See lifecycle details.

Step composition and its limits ​

The fragment and the pure functional component each provide two steps. In the stateful wrapper example, total counts only the step declared directly in the tour, so the first completion ends the tour. To use stateful content, place AsamTourStep directly in the tour slot and render the content component inside that step.

Native steps and event payloads ​

The tour forwards the default slot unchanged and uses AsamTourStep as an alias of the underlying step component. Updates to modelValue and current and the change, close(current), and finish events are forwarded as emitted. indicators retains its current and total scope. The tour leaves the step nodes intact.

Local and global mounting ​

The switch changes the target container through appendTo. Target positioning and the mask still use the component's viewport behavior. Both modes are interactive, and you can switch after closing the tour.

Additional usage and API details ​

Usage conventions ​

modelValue controls visibility and current sets the step. change, finish, and close report progress. Use mask, gap, placement, showArrow, scrollIntoViewOptions, and targetAreaClickable for the mask and positioning. Use AsamTourStep for each step and follow the component's step composition rules. Use the indicators slot for custom progress. Tour has no control-size prop.

Composition and lifecycle ​

Place AsamTourStep directly in default or group steps in a recognized Fragment. A pure functional component without props or slots can return these steps. Keep that function independent of component instances and setup state. To include stateful content from an SFC or defineComponent, place it inside a directly declared step so the tour can enumerate the step. The tour does not recursively render or rewrite VNodes to find steps.

Composition and lifecycle ​

current is a zero-based index. change reports a step change, finish fires when the last step completes, and close includes the current index. target accepts a selector, an HTMLElement, or a function returning an element. Make sure dynamic targets are already mounted. scrollIntoViewOptions accepts a Boolean or a native scroll options object, and a step can override the parent setting. mask, gap, and targetAreaClickable control the mask and clickable region. A step without a target appears in the center. indicators receives current and total. Configure navigation buttons on individual steps. Closing or unmounting releases focus handling, the mask, and listeners.
