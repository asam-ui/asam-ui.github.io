Switch ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

Interactive examples, TypeScript and JavaScript source, and the generated API reference are included on this page.

When to use it ​

Toggle a setting between two states immediately. The default model is boolean; activeValue and inactiveValue can define string or numeric states. Use beforeChange to decide whether a change is allowed.

Binding, text and events ​

change and input carry the new value. loading and disabled prevent interaction. inlinePrompt places state text inside the track.

Asynchronous confirmation and action slots ​

Return a boolean to allow or reject a change synchronously, or Promise<boolean> for asynchronous confirmation. The application controls loading during the local delay. Rejection preserves the previous model; clear loading in finally. The example uses one permission toggle for both confirmation paths and shows the current state in the action slots.

Example: confirmation

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<div class="example">
		<AsamSwitch v-model="enabled" :loading="loading" :before-change="confirm">
			<template #active-action>✓</template>
			<template #inactive-action>×</template>
		</AsamSwitch>
		<AsamCheckboxItem v-model="allow">允许本次切换</AsamCheckboxItem>
		<AsamSwitch v-model="synchronous" :before-change="() => allow" aria-label="同步确认" />
		<output>值：{{ enabled }}；确认中：{{ loading }}；同步值：{{ synchronous }}</output>
	</div>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamSwitchConfirmationExample' });
import { ref } from 'vue';
import { AsamSwitch, AsamCheckboxItem } from '@asam-ui/ui';
const enabled = ref(false);
const synchronous = ref(false);
const allow = ref(true);
const loading = ref(false);
async function confirm() {
	loading.value = true;
	try {
		await new Promise((resolve) => setTimeout(resolve, 250));
		return allow.value;
	} finally {
		loading.value = false;
	}
}
</script>

Sizes and inheritance ​

The four examples explicitly use large, big, default and small. An instance without size responds to ConfigProvider changes; an explicit size overrides its ancestors. Do not add a size prop to a panel that has no such contract.

ASAM extensions and migration ​

The four densities control the track and interaction area. active / inactive provide state content, and active-action / inactive-action provide thumb content. The public instance exposes focus and the live boolean checked state. Map legacy business states explicitly with activeValue / inactiveValue; strings such as true and false are not guessed or converted.

Icons, numeric values and instance state ​

activeIcon / inactiveIcon customize track content; activeActionIcon / inactiveActionIcon customize the thumb. The corresponding content and action slots take precedence. inlinePrompt puts content inside the track. Active and inactive values may be strings, numbers or booleans; the model must use the same value set.

loading and disabled block interaction. beforeChange supports synchronous and Promise results. input, change and update:modelValue each preserve the actual new value. focus targets the native input; checked reflects the current boolean state.

Reading the API ​

The API is generated from current public types and runtime defaults. An unknown or undeclared default does not mean false or empty. Combined props apply to their documented branches; value modes cannot be mixed arbitrarily. The Chinese source panel provides standalone Demo.vue files with local helpers, data and assets inlined.

Replace the old label prop with ariaLabel (aria-label in templates). The removed activeColor, inactiveColor and borderColor props are replaced by CSS variables --el-switch-on-color, --el-switch-off-color and --el-switch-border-color. These can be set in an instance's style; activeValue / inactiveValue still determine its state.
