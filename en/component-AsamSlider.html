Slider ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

Interactive examples, TypeScript and JavaScript source, and the generated API reference are included on this page.

When to use it ​

Select a value or range within a continuous or discrete numeric interval. min / max define the interval and step defines the increment. A range model is a numeric array.

Input, steps and events ​

input fires during dragging; change fires when the operation is committed. showInput adds numeric input, and inputSize can independently select one of the four densities.

Sizes and inheritance ​

Four instances explicitly use large, big, default and small. An instance without size responds to ConfigProvider changes; an explicit size overrides its ancestors. Panels without a size contract do not acquire an extra size prop.

ASAM extensions and migration ​

ASAM adds four sizes for size and inputSize. When omitted, inputSize uses the slider's resolved size. vertical requires an explicit height and sufficient room for interaction. There are no content slots. The public instance exposes focus and onSliderClick.

Discrete steps, mark constraints and vertical mode ​

A numeric step and showStops create equally spaced stops. step="mark" restricts values to the numbers in marks, which must lie within the inclusive min/max interval. Vertical sliders require an explicit height; the up and down arrow keys adjust the value.

showTooltip, placement, formatTooltip, tooltipClass and persistent control the tooltip. Range mode preserves two ordered endpoints. The input field is only available in single-value mode.

Reading the API ​

Use ariaLabel (aria-label in templates) for the accessible name. The old label prop has been removed. In range mode, use rangeStartLabel and rangeEndLabel for the two endpoints.

props, Events, Slots and Exposes are generated from current public types and runtime defaults. Combined props apply by branch; an unknown or undeclared default does not mean false or empty. The Chinese source panel provides standalone Demo.vue files with local helpers, data and assets inlined.
