Loading ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Access the loading service and directive from one entry point, with optional app-wide registration.

Using the directive from the combined entry point ​

You can register the directive locally in an SFC without installing it across the app.

Example: basic

Example source ZIPComplete project ZIP
vue
<template>
	<div class="actions">
		<AsamButton type="primary" native-type="button" @click="loading = !loading">
			切换加载
		</AsamButton>
		<label>
			<span>提示文字</span>
			<AsamInput v-model="text" />
		</label>
		<AsamButton type="default" native-type="button" @click="mounted = !mounted">
			卸载/恢复区域
		</AsamButton>
	</div>
	<div
		v-if="mounted"
		v-asam-loading="loading"
		v-bind="{ 'element-loading-text': text, class: 'loading-target' }"
	>
		<p class="example-paragraph">局部内容区域</p>
	</div>
	<p class="example-paragraph" role="status">{{ loading ? '加载中' : '加载已结束' }}</p>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamLoadingBasicDemo' });
import { ref } from 'vue';
import { AsamInput, AsamButton, AsamLoading } from '@asam-ui/ui';
const vAsamLoading = AsamLoading.directive;
const loading = ref(false);
const text = ref('正在加载');
const mounted = ref(true);
</script>

}
</style>

Usage conventions ​

AsamLoading.service exposes the loading service, and AsamLoading.directive exposes the loading directive. Call app.use(AsamLoading) to register the asam-loading directive and $asamLoading. Use the combined entry point as an object.

Choosing local or fullscreen loading ​

  • Local loading and instance updates and fullscreen loading service. Call the service as a function and keep the returned handle so you can close it.
  • Local directive and dynamic text and fullscreen loading directive. Use the binding state to control visibility. The directive cleans up when its host unmounts.

See the service reference for options and the returned instance. See the directive reference for binding values, modifiers, and lifecycle. The combined entry point connects service, directive, and install.
