Infinite Scroll Directive ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Request more content as a scroll container approaches the end.

Contract and composition ​

Use the v-asam-infinite-scroll directive. In <script setup>, import AsamInfiniteScroll as vAsamInfiniteScroll, or register the directive through the plugin. Read the full explanation.

The scroll container can be the directive element itself or its nearest scrollable ancestor. Read the full explanation.

On unmount, the native directive removes the scroll listener and the observer that fills an undersized viewport. The upstream implementation determines what happens to pending throttled calls and to an unmount while mounted awaits nextTick. A queued callback can still run afterward. Read the full explanation.

<template>
	<AsamCheckboxItem v-model="paused">暂停追加</AsamCheckboxItem>
	<ul
		v-asam-infinite-scroll="load"
		:infinite-scroll-disabled="disabled"
		:infinite-scroll-distance="16"
		:infinite-scroll-immediate="false"
		class="scroll-list"
	>
		<li v-for="item in count" :key="item">记录 {{ item }}</li>
	</ul>
	<p class="example-paragraph" role="status">
		{{ loading ? '正在追加' : count >= 30 ? '已经到底' : '可继续滚动' }}
	</p>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamInfiniteScrollBasicDemo' });
import { ref, computed, onBeforeUnmount } from 'vue';
import { AsamCheckboxItem, AsamInfiniteScroll as vAsamInfiniteScroll } from '@asam-ui/ui';
const count = ref(12);
const paused = ref(false);
const loading = ref(false);
const disabled = computed(() => paused.value || loading.value || count.value >= 30);
let timer: ReturnType<typeof setTimeout> | undefined;
const load = () => {
	if (disabled.value) return;
	loading.value = true;
	timer = setTimeout(() => {
		count.value = Math.min(count.value + 6, 30);
		loading.value = false;
	}, 250);
};
onBeforeUnmount(() => clearTimeout(timer));
</script>

<script lang="ts" setup>
defineOptions({ name: 'AsamInfiniteScrollImmediateDemo' });
import { computed, onBeforeUnmount, ref } from 'vue';
import {
	AsamCheckboxItem,
	AsamButton,
	AsamInfiniteScroll as vAsamInfiniteScroll
} from '@asam-ui/ui';
const count = ref(0);
const calls = ref(0);
const paused = ref(false);
const loading = ref(false);
const secondary = ref(false);
const lastCallback = ref('尚未调用');

const disabled = computed(() => paused.value || loading.value || count.value >= 50);
let timer: ReturnType<typeof setTimeout> | undefined;
const generation = ref(0);
function loadCallback(): void {
	load(secondary.value ? '第二加载函数' : '第一加载函数');
}
function load(source: string): void {
	if (disabled.value) return;
	lastCallback.value = source;
	loading.value = true;
	calls.value++;
	const revision = generation.value;
	timer = setTimeout(() => {
		if (revision !== generation.value) return;
		count.value = Math.min(50, count.value + 5);
		loading.value = false;
	}, 100);
}
function reset(): void {
	generation.value++;
	clearTimeout(timer);
	count.value = 0;
	loading.value = false;
}
onBeforeUnmount(() => {
	generation.value++;
	clearTimeout(timer);
});
</script>

Instances, types, and boundaries ​

The public API and complete SFC examples use the same public entry. The TypeScript and JavaScript examples include all local dependencies. The TypeScript version also includes type constraints. The host handles remote requests and business data persistence.

Additional usage and contract notes ​

Contract and composition ​

Use v-asam-infinite-scroll with a loading function. Import AsamInfiniteScroll as vAsamInfiniteScroll in <script setup> or register it through the plugin. Set infinite-scroll-delay for the throttle interval and infinite-scroll-distance for the trigger distance. Use infinite-scroll-disabled to prevent appending while loading, during a pause, or on the last page. Set infinite-scroll-immediate to true to keep filling the viewport when content is too short, or false to wait for scrolling.

Contract and composition ​

The element or its nearest scrollable ancestor can serve as the scroll container. The mounted, updated, and unmounted hooks use the native 2.14.7 directive functions, which receive the callback and this unchanged. This version captures the loading function on mount and keeps it on update. To dispatch dynamically, bind a stable function that reads current state or remount with a new key. The complete example uses a stable function and shows loading, the last page, pause and resume, initial filling of an empty list, and a nested scrollable parent.

Contract and composition ​

The native directive removes the scroll listener and the initial fill observer on unmount. Pending throttled calls and unmounts while mounted awaits nextTick follow upstream behavior. Guard against duplicate requests and cancel host-owned requests or timers on unmount. Use a mounted flag if the host needs to disregard work that is no longer relevant. To clear and refill the list, remount with a new key to restore the initial fill observer and cancel the old request timer. The immediate setting fills the viewport initially. Recreating a released observer requires remounting. The native directive is deprecated in 2.14.7. This entry still delegates to it. See AsamScrollbar for an alternative composition.
