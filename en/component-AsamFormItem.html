Form Item ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Connect a form field with its label, validation message, and help text. prop identifies the field in the form model. Use help for guidance that is separate from validation.

Help, label, and error slots ​

The help slot takes precedence over the help prop. The label slot receives the label, and the error slot receives the actual error message. Retain its accessibility semantics when customizing the message.

Clearing and resetting one field ​

clearValidate clears that field's validation feedback. resetField restores its initial value. validateState and validateMessage expose live state.

Label association, groups, and custom errors ​

With one control, the label automatically points to the input ID. With several controls, the wrapper has group semantics. Give each control its own aria-label. See the full notes.

ASAM extensions and migration ​

ASAM adds the help prop and slot, plus four sizes. Listen to the control's change or input for edits and use form validation events for validation. Form Item emits no separate business events. Use labelWidth, labelPosition, required, and error as documented. Define required-field validation in rules.

Reading the API ​

The generated props, events, slots, and exposed members reflect the current public types and runtime defaults. Use each property combination with its applicable mode. “Unknown / Not declared” means no default is documented by the runtime. The source panel provides a standalone Demo.vue for each language. Its local helpers, data, and assets are included for copying or downloading.

Additional usage notes ​

Label association, groups, and custom errors ​

With one control, the label automatically points to the input ID. With several controls, the wrapper has group semantics, so give each control an accessible name with aria-label. Use for to explicitly associate a native input. labelPosition overrides the parent form. A numeric labelWidth of zero stays zero. required controls the visual indicator, and rules control validation.

Label association, groups, and custom errors ​

The default error message uses role="alert". Preserve this semantic when customizing the error slot. An external error updates the internal state and message. The message can be inserted after a delay and enter with a transition. showMessage controls visibility and inlineMessage controls placement. The label and error slots receive their respective text. The help slot overrides the prop and stays separate from validation.

Initial and dynamic state and external errors ​

The native component applies changes to validateStatus after mount. An initial success with no error therefore does not guarantee the success appearance on first render. The example shows the supplied prop and actual internal state separately. Select empty, error, validating, or success, remount, then change the live status separately.

Initial and dynamic state and external errors ​

A nonempty initial error sets the internal error state and message. After initialization, changing error or validateStatus, calling validate, clearing validation, and resetting can all change internal state. clearValidate clears internal state and the message while preserving the field value and external props. resetField restores the registered initial value and clears the state while preserving external props. An unchanged external value is reapplied only through a new prop change or validation action. The example disables automatic input validation so you can observe these operations separately. In tests, wait for the message to become visible before asserting against the DOM.

More parameters and events ​

Initial and dynamic state and external errors ​

Use validate(trigger, callback) with a callback or a Promise. clearValidate preserves the field value, resetField restores the field's baseline, and setInitialValue changes the baseline used for future resets. size, validateState, and validateMessage report live state. prop is required for validation and reset and supports nested array paths.
