Input ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Use AsamInput for single-line values such as names, email addresses, or search terms. Use Password for secrets, Textarea for multiple lines, and Number input for step controls.
