Date-time picker compatibility alias ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

AsamDateTimePicker is the compatibility name for AsamDateTimeRangePicker. Both exported names use two independent inputs and accept the same completed [start, end] or null model.

Migrate to the current name ​

Replace the import and template tag with AsamDateTimeRangePicker. Keep DateTimeRangeValue, the endpoint parameters, slots, and events. For a single date-time use AsamDatePicker with type="datetime".

API and running examples ​

See the date-time range guide and the original compatibility reference.
