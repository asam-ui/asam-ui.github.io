Input Tag ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Enter a collection of free-text keywords or tags. v-model accepts string[] or undefined. Enter the designated trigger key or a delimiter to create a tag.

Adding, removing, and limiting tags ​

Enter adds a tag by default. max limits the count, and clearable adds a control to clear all tags. The add and remove events report the affected tags.

Example: basic

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<div class="example">
		<AsamInputTag
			v-model="tags"
			v-bind="{ class: 'field', 'aria-label': '项目标签' }"
			placeholder="输入后按 Enter"
			:max="5"
			clearable
			@add-tag="event = '新增：' + String($event)"
			@remove-tag="(value, index) => (event = '删除：' + value + '，索引 ' + index)"
		/>
		<output>标签：{{ tags?.join('、') }}；{{ event }}</output>
	</div>
</template>

Separators, dragging, and collapsed display ​

A comma creates a tag in this example. saveOnBlur saves pending text on blur. Dragging changes the order. Collapsing changes only how tags are displayed.

Sizes and inheritance ​

ASAM offers large, big, default, and small. An explicit size overrides inheritance. If omitted, the nearest component, group, form, or ConfigProvider setting applies, with default as the fallback. Change the provider size to see inherited values update.

Example: sizes

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<div class="example">
		<div class="row density-row">
			<div v-for="size in sizes" :key="size" class="field density-field">
				<strong>{{ size }}</strong>
				<AsamInputTag
					:size="size"
					v-bind="{ class: 'field', 'aria-label': size + '尺寸' }"

ASAM extensions and migration ​

ASAM adds four sizes. Use Input Tag for free-text tags and Select to choose multiple values from a fixed list. When migrating from a single-line input, change the string model to an array. Handle both a string and a string array in add-tag.

Tag editing ​

Set trigger to Enter or Space, and use saveOnBlur to save pending text on blur. See the full notes.

The underlying component handles readonly and disabled. In native read-only mode, Backspace may still remove a tag and trigger model, change, and remove-tag events. ASAM forwards these events. Apply business restrictions when accepting updates in the parent model.

Reading the API ​

The API below reflects the current public types and runtime defaults. “Unknown / Not declared” means no default is documented by the runtime. Omit size to inherit the ancestor setting and disabled to inherit the form state. Use validateEvent to control validation events.

Form inheritance and validation across five inputs ​

This complete TS/JS example includes the single-line, password, multiline, autocomplete, and tag inputs. Each leaves disabled unset to inherit the form state. validateEvent controls automatic validation on change and blur per input. Toggling the disabled state preserves the model, and editing still works when automatic validation is off. Each of the five pages contains a self-contained copy of the example.

Additional usage notes ​

Tag editing ​

Set trigger to Enter or Space and use saveOnBlur to save on blur. max limits the count. draggable enables reordering and reports oldIndex, newIndex, and value. Use collapseTags with maxCollapseTags to collapse tags, and collapseTagsTooltip to show the remaining tags on hover. clearIcon sets the clear icon. tagType, tagEffect, and effect style tags and their tooltip. Read-only mode preserves the display and follows the native Backspace behavior described above. Disabled mode blocks editing. See the slots example to customize tag, prefix, and suffix.

Native delegation and event logging ​

The complete TS/JS example logs model updates and event order and lets you toggle disabled, read-only, and automatic validation states. Omitted base props use the native defaults. Explicit undefined, null, and false pass through when allowed by the API. ASAM supplies four visual sizes. Password fixes type to password and enables the visibility toggle when showPassword is omitted.
