Time Select ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Generate fixed-step time options between a start and an end for bookings or schedules. Selecting an option commits its formatted time string. Clearing returns the native valueOnClear result directly.

Native model defaults ​

The underlying control supplies defaults for omitted behavior props. This complete SFC compares explicit undefined, null, and an empty string. The output preserves the original model type and the native clear value. The pinned native version handles invalid-input diagnostics and compatibility limits.

ASAM extensions and migration ​

The pinned 2.14.7 component logs a diagnostic for unparseable or negative start and end values or an unparseable, negative, or zero step. It falls back to 09:00, 18:00, and 00:30, respectively, so option generation terminates. See the full notes.

When start exceeds end, includeEndTime: false produces an empty list. includeEndTime: true still appends end. See the full notes.

ASAM's four sizes inherit from the form and ConfigProvider. See the full notes.

Reading the API ​

The generated props, events, slots, and exposed members reflect the current public types and runtime defaults. Use each property combination with its applicable mode. “Unknown / Not declared” means no default is documented by the runtime. The source panel provides a standalone Demo.vue for each language. Its local helpers, data, and assets are included for copying or downloading.

The component delegates public props, events, slots, model updates, and exposed members to the native control. Omitted props and explicit undefined, null, or false retain native behavior. Native validation and evaluation rules govern when the factory runs.

In the pinned 2.14.7 version, some combinations of clear sentinels and formats can produce blank displays, formatting errors, or diagnostics. These follow native behavior. See the full notes.

Native defaults and adaptation ​

start, end, step, and format default to 09:00, 18:00, 00:30, and HH:mm. An omitted modelValue is undefined. See the full notes.

Local and global poppers ​

The basic example uses default global mounting. The local mounting example configures the popper container. Open the control and observe which container holds the popper. Mount location is independent of the value and request protocol.

Additional usage notes ​

ASAM extensions and migration ​

The pinned 2.14.7 component logs a diagnostic for unparseable or negative start and end values or an unparseable, negative, or zero step. It falls back to 09:00, 18:00, and 00:30, respectively. The native parser has no additional 24-hour or 60-minute limit. It parses and formats 25:70 internally as 25:70. A zero-step utility call yields 26:10, and a call with 00:30 yields 26:40. The component replaces zero steps before generating options, so utility behavior on zero steps differs from component behavior. The default HH:mm format displays and commits these values as 02:10 and 02:40. Likewise, 24:15 displays and commits as 00:15. Validate caller input if it needs to stay within clock limits.

ASAM extensions and migration ​

When start exceeds end, includeEndTime: false produces an empty list. includeEndTime: true still appends end. minTime and maxTime compare raw times and disable options equal to the limits, including an appended end option. format controls both option labels and committed strings. The parent owns any existing out-of-bounds value and decides how interdependent fields update. The internal Select handles teleported and validateEvent.

ASAM extensions and migration ​

ASAM sizes inherit through the form and ConfigProvider. Pass step as a time string, for example 00:30 for 30 minutes. validateEvent controls form validation, and teleported controls where the popper mounts. Use DatePicker with type="datetime" for a single date-time value and DateTimeRangePicker for two independent date-time endpoints.

Localization and advanced options ​

Date locale and control labels are configured separately. The example’s locale.ts and locale.js also register the Day.js zh-cn date locale. Weeks start on Monday in Chinese and on Sunday in English. The app must install dayjs explicitly and use the same instance as the components. Changing the provider dictionary alone leaves the first day of the week unchanged. Registering the date locale leaves the application’s global default language unchanged.

Native clear values and migration ​

In the pinned 2.14.7 version, some combinations of clear sentinels and formats can produce blank displays, formatting errors, or diagnostics. Use the application's data adapter when the business model needs nullable values. DateTimeRangePicker and DateTimePicker retain their explicit complete-value or null contracts. When migrating code that assumed string models, set valueFormat explicitly on pickers that use it, for example YYYY-MM-DD for dates or HH:mm:ss for times. Time Select stores the time text produced by its own format.

Native defaults and adaptation ​

start, end, step, and format default to 09:00, 18:00, 00:30, and HH:mm. An omitted modelValue is undefined. Other defaults follow the pinned native component. Explicit undefined, null, and false retain native meaning. size controls ASAM's four visual densities and branding. DatePicker, TimePicker, and TimeSelect delegate focus and blur directly to the native public instance, preserving the receiver and return value. DatePicker and TimePicker also delegate handleOpen and handleClose. These input methods apply to input components.
