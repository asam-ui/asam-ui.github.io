Collapse ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Let users open related sections when needed to keep the initial page short.

Basic usage and states ​

This example uses the component's public API.

Example: basic

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<AsamCollapse
		:model-value="active"
		@update:model-value="
			(value) => {
				if (Array.isArray(value) && value.every((name) => typeof name === 'string'))
					active = value;
			}

	>
		<AsamCollapseItem title="基础说明" name="intro">
			<p class="example-paragraph">本地说明内容。</p>

	</AsamCollapse>

</template>

Usage guidelines ​

Bind the active item names with v-model and enable accordion to allow only one item to open at a time. change reports the current value. In standard mode the model is an array of names. In accordion mode use the single value defined by the public type. Place AsamCollapseItem components in the default slot and manage expansion state in the parent.
