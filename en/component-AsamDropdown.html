Dropdown ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Put secondary actions in a menu that opens from a trigger.

Menu composition, icons, and public methods ​

The example uses an explicit menu container and items. Try selecting an item with the mouse or keyboard.

Example: basic

Example source ZIPComplete project ZIP
vue
<template>
	<div class="actions">
		<AsamDropdown ref="menu" v-bind="{ trigger: 'click', wrapMenu: false }" @command="select">
			<AsamButton type="primary" native-type="button">打开操作菜单</AsamButton>
			<template #dropdown>
				<AsamDropdownMenu>
					<AsamDropdownItem command="edit" :icon="Edit">编辑</AsamDropdownItem>
					<AsamDropdownItem command="archive" divided>归档</AsamDropdownItem>
					<AsamDropdownItem command="remove" disabled>删除（不可用）</AsamDropdownItem>
				</AsamDropdownMenu>
			</template>
		</AsamDropdown>
		<AsamButton type="default" native-type="button" @click="menu?.open()">
			通过方法打开
		</AsamButton>
		<AsamButton type="default" native-type="button" @click="menu?.close()">
			通过方法关闭
		</AsamButton>
	</div>
	<p class="example-paragraph" role="status">当前命令：{{ command }}</p>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamDropdownBasicDemo' });
import { ref, shallowRef } from 'vue';
import { AsamButton, AsamDropdown, AsamDropdownMenu, AsamDropdownItem } from '@asam-ui/ui';
import type { AsamDropdownExpose } from '@asam-ui/ui';
import { Edit } from '@asam-ui/icons-vue';
const menu = shallowRef<AsamDropdownExpose>();
const command = ref('未选择');
const select = (value: string | number | object) => {
	command.value = String(value);
};
</script>

Additional usage and API details ​

Usage conventions ​

wrapMenu defaults to false and passes the dropdown slot through unchanged. Enable it when supplying AsamDropdownItem directly. Leave it disabled when providing AsamDropdownMenu. command carries the command, item instance, and triggering event. The component supports hover, click, context menu, split buttons, disabling, visibility delays, placement, and popup configuration. open and close are ASAM shortcuts. See the API for handleOpen, handleClose, and other methods. The control sizes are large, big, default, and small. An explicit size takes precedence. Otherwise, size comes from the nearest group, then Form, then ConfigProvider.

Composition and lifecycle ​

By default, supply the menu container through dropdown. Enable wrapMenu for an automatic container and leave it disabled when supplying AsamDropdownMenu. In split-button mode, the left button emits click and the right trigger opens the menu. trigger, triggerKeys, loop, and tabindex control mouse and keyboard access. command passes the command, item, and Event, while visible-change reports visibility. hideOnClick controls dismissal after selection. A disabled item does not execute a command. handleOpen and handleClose operate on the live instance. Use virtualTriggering and virtualRef with an external element or coordinate-based trigger. placement, offset, and popperOptions position the popup, and teleported and appendTo determine where it mounts. size accepts large, big, default, and small.

Trigger defaults in the examples ​

AsamDropdown defaults to hover. The examples set hover, click, or contextmenu explicitly for each trigger. The placement examples set bottom or another direction explicitly, and the native default is bottom. When supplying AsamDropdownMenu, leave wrapMenu disabled.
