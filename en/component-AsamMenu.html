Usage conventions ​

Use the public props to configure mode, collapse, defaultActive, defaultOpeneds, uniqueOpened, router and the menu trigger. The select, open and close events report selection and expansion. Read the full explanation.

Horizontal menu height ​

In horizontal mode, override the default menu height with the native --el-menu-horizontal-height CSS variable. Add a custom class to AsamMenu and set the variable in the host’s local styles.

css
.menu-with-height.el-menu--horizontal {
	--el-menu-horizontal-height: 100px;
}

Pass class="menu-with-height" to the intended AsamMenu. The host controls this menu’s height through the CSS variable independently of the four control densities.

Use a horizontal menu for top-level navigation. Menus default to vertical mode. Set mode to horizontal for a top bar. Read the full explanation.

Additional usage and contract notes ​

Usage conventions ​

Use the public props to configure mode, collapse, defaultActive, defaultOpeneds, uniqueOpened, router and the menu trigger. The select, open and close events report selection and expansion. router mode requires a host router. The component instance exposes methods for opening and closing submenus and updating the active item. The example stores the selection locally. The host handles navigation after selection, and the layout determines each item’s width and height.

Top bar ​

Menus default to vertical mode. To use horizontal navigation, set mode to horizontal. Use AsamSubMenu for a second level. background-color, text-color and active-text-color set the menu background, regular text and active item text colors, respectively.
