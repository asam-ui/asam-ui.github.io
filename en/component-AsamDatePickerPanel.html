Date Picker Panel ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Edit dates in a panel that stays on the page. Without valueFormat, the model uses Date values. format controls display, and valueFormat controls the formatted string or timestamp stored in the model.

Native model defaults ​

The underlying control supplies defaults for omitted behavior props. This complete SFC compares explicit undefined, null, and an empty string. The output preserves the original model type and the native clear value. The pinned native version handles invalid-input diagnostics and compatibility limits.

ASAM extensions and migration ​

ASAM sizing follows form and ConfigProvider inheritance. See the full notes.

Reading the API ​

The generated props, events, slots, and exposed members reflect the current public types and runtime defaults. Use each property combination with its applicable mode. “Unknown / Not declared” means no default is documented by the runtime. The source panel provides a standalone Demo.vue for each language. Its local helpers, data, and assets are included for copying or downloading.

Switch between Chinese and English through ConfigProvider. This example uses the public types to configure advanced options. The size, model, native range, and two-independent-endpoint contracts apply to their respective modes.

Date locale and control labels are configured separately. The example’s locale.ts and locale.js also register the Day.js zh-cn date locale. Weeks start on Monday in Chinese and on Sunday in English. See the full notes.

Existing dates in the pinned version may keep the previous locale. The example changes the component key to remount it and update the date locale. For a popup input, this closes the popper. Reopen it to see the new locale. The parent retains the full model value.

Additional usage notes ​

ASAM extensions and migration ​

The panel supports quarter, quarters, quarterrange, and singlePanel for native ranges including datetimerange. teleported applies to input poppers. Use border for the panel border and disabled to block selection. When changing type, reset incompatible model values. Enable showFooter and showConfirm explicitly when multiple selection needs a confirmation step. Both default to false.

ASAM extensions and migration ​

ASAM sizes inherit through the form and ConfigProvider. The native panel receives null, undefined, and an empty string unchanged. If a value leads to a native warning or exception, choose a supported model value. Omit the model to use the native default. The display format leaves storage unchanged. Follow the case-sensitive date tokens of valueFormat for model strings. This inline panel has no exposed input methods. For a single date-time input, use DatePicker with type="datetime". For two independent date-time endpoints, use DateTimeRangePicker.

Localization and advanced options ​

Date locale and control labels are configured separately. The example’s locale.ts and locale.js also register the Day.js zh-cn date locale. Weeks start on Monday in Chinese and on Sunday in English. The app must install dayjs explicitly and use the same instance as the components. Changing the provider dictionary alone leaves the first day of the week unchanged. Registering the date locale leaves the application’s global default language unchanged.

Native defaults and adaptation ​

type defaults to date, modelValue to an empty string, and border to true. Without valueFormat, selected values are Date objects. showFooter and showConfirm default to false. Other behavior defaults follow the pinned native component. Explicit undefined, null, and false keep native semantics. size controls ASAM's four visual densities and branding. DatePicker, TimePicker, and TimeSelect delegate focus and blur directly to the native public instance, preserving the receiver and return value. DatePicker and TimePicker also delegate handleOpen and handleClose. These input methods apply to input components.
