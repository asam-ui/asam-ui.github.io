Input OTP ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it and what to store ​

Use separate cells for a one-time code. v-model updates always emit a string and preserve leading zeros. A number can initialize the input but cannot preserve leading zeros. The default length is six. Use AsamPassword for passwords and AsamInput for ordinary single-line text.

Typing advances to the next cell, and the arrow keys move focus. Backspace clears the current cell and moves to the previous one. Delete clears the current cell. Paste and autofill validate characters individually and truncate to the configured length. finish fires when an edit fills all cells. change fires when focus leaves the group and the value has changed. Moving between cells does not repeat the group's focus and blur events.

Length and external updates ​

length changes the number of cells. Reducing it truncates the model. Parent updates synchronize the cells. Store codes such as 0123 as strings.

Sizes and inheritance ​

large, big, default, and small correspond to control heights of 40, 36, 32, and 28 px. An explicit size takes precedence. Omit it to inherit from the group, form, or provider, with default as the fallback. The native size for big resolves to default, while the ASAM appearance retains the big density.
