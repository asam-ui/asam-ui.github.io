Cascader Panel ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Keep a hierarchical menu visible for selection within the page. The panel uses native options and the field mappings in props. The model stores full paths by default.

Paths and node slots ​

The default slot receives node and data. change reports the selected path. Call getCheckedNodes to read checked nodes and clearCheckedNodes to clear the internal selection.

Example: basic

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<div class="example">
		<AsamCascaderPanel ref="panel" v-model="value" :options="options">
			<template #default="{ data }">
				{{ data.label }}
			</template>
			<template #empty>暂无节点</template>
		</AsamCascaderPanel>
		<div class="row">
			<AsamButton type="primary" @click="inspect">读取选中节点</AsamButton>
			<AsamButton type="default" @click="clear">清空</AsamButton>
		</div>
		<output>路径：{{ value }}；节点：{{ selected }}</output>
	</div>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamCascaderPanelBasicExample' });
import { ref } from 'vue';
import { AsamCascaderPanel, AsamButton } from '@asam-ui/ui';
import type { AsamCascaderPanelExpose, AsamCascaderPanelProps } from '@asam-ui/ui';
const panel = ref<AsamCascaderPanelExpose>();
const value = ref<AsamCascaderPanelProps['modelValue']>([]);
const options = [
	{
		value: 'team',
		label: '团队',
		children: [
			{ value: 'design', label: '设计' },
			{ value: 'dev', label: '开发' }
		]
	}
];
const selected = ref('');
function inspect() {
	selected.value = JSON.stringify(panel.value?.getCheckedNodes(true).map((node) => node.value));
}
function clear() {
	panel.value?.clearCheckedNodes();
	value.value = [];
}
</script>

ASAM extensions and migration ​

Use Cascader when you need an input and a popper with ASAM's four sizes. The inline panel has no public size prop. Native props.lazy and props.lazyLoad control lazy loading. The nodes passed to resolve must follow the current field mappings.

The panel uses the native cascader model. In TypeScript, declare the parent model as ref<AsamCascaderPanelProps['modelValue']> to preserve the full public model type when initializing a path array or enabling multiple selection.

Reading the API ​

The generated props, events, slots, and exposed members reflect the current public types and runtime defaults. Use each property combination with its applicable mode. “Unknown / Not declared” means no default is documented by the runtime. The source panel provides a standalone Demo.vue for each language. Its local helpers, data, and assets are included for copying or downloading.

This example uses the public native contract of AsamCascaderPanel. The full TS/JS SFC includes its actions, data structures, and callbacks.

Native panel API ​

The panel uses native options, props, and modelValue directly. For normalized value or object conversion and a Select-style input, use Cascader. See the full notes.

Props ​

Name Description Type Default
model-value / v-model Bound selection value AsamCascaderPanelProps['modelValue'] —
options Available options. Remap value and label fields with CascaderProps. AsamCascaderOption[] —
props Configuration for the options and selection behavior CascaderProps —
virtual-scroll Enable virtual scrolling for large lists boolean false
item-size Node height in the virtual list, in pixels number 34
height Menu height for the virtual list, in pixels number 204

Events ​

Name Description Type
change Fires when the bound value changes (value: AsamCascaderNativeProps['modelValue'] | undefined) => void
update:modelValue Updates the bound model (value: AsamCascaderNativeProps['modelValue'] | undefined) => void
expand-change Fires when the expanded node changes (value: AsamCascaderNode['pathValues']) => void
close Notifies Cascader that the panel requested closing () => void

Slots ​

Name Description Type
default Custom node content. Receives the current node object and its data. { node: CascaderNode, data: CascaderOption }
empty Content shown when the panel has no data —

Instance methods and state ​

Name Description Type
getCheckedNodes Returns checked nodes. Set leafOnly to true to return only leaves. It defaults to false. (leafOnly: boolean) => AsamCascaderNode[]
clearCheckedNodes Clears checked nodes () => void

CascaderProps ​

Prop Description Type Default
expandTrigger How to open a submenu 'click' | 'hover' 'click'
multiple Enable multiple selection boolean false
checkStrictly Select parent and child nodes independently boolean false
emitPath Return the full path of values. Set to false to return the selected node value alone. boolean true
lazy Load child nodes through lazyLoad boolean false
lazyLoad Load child data when lazy is enabled. Call reject if loading fails. (node: Node, resolve: Resolve, reject: () => void) => void —
value Option field used as the value string 'value'
label Option field used as the label string 'label'
children Option field containing child options string 'children'
disabled Option field indicating whether the option is disabled string 'disabled'
leaf Option field indicating whether the node is a leaf string 'leaf'
hoverThreshold Sensitivity threshold for expanding menus on hover number 500
checkOnClickNode Toggle selection when clicking a node boolean false
checkOnClickLeaf Toggle selection when clicking a leaf node boolean true
showPrefix Show the radio or checkbox prefix boolean true

Additional usage notes ​

Native panel API ​

The panel uses native options, props, and modelValue. emitPath defaults to true. The native Cascader rules also govern multiple, checkStrictly, and lazy. When virtualScroll is on, height sets the viewport and itemSize must match the actual row height. Use the Cascader input for filtering, collapsed tags, input width controls, and normalized value or object conversion.
