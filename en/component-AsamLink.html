Link ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Provide a text link or a clickable text action.

Semantic colors ​

type defaults to default and accepts default, primary, success, warning, danger and info.

Usage conventions ​

Use href and target to set the destination. Use type, underline, disabled, icon and the default and icon slots to control presentation. The click event receives a MouseEvent. The host application can explicitly cancel its default behavior. ASAM’s size accepts large, big, default and small. The icon’s graphic size is independent of this setting.

Validate link destinations ​

href is passed directly to the native <a> element. The host application is responsible for URL validation. Read the full explanation.

Complete TypeScript version

ts
function sanitizeUrl(url: string): string {
	const allowedProtocols = ['http:', 'https:'];
	try {
		const parsed = new URL(url, window.location.origin);
		return allowedProtocols.includes(parsed.protocol) ? parsed.href : '#';
	} catch {
		return '#';
	}
}

Complete JavaScript version

js
function sanitizeUrl(url) {
	const allowedProtocols = ['http:', 'https:'];
	try {
		const parsed = new URL(url, window.location.origin);
		return allowedProtocols.includes(parsed.protocol) ? parsed.href : '#';
	} catch {
		return '#';
	}
}

These browser functions demonstrate protocol validation. Apply your application’s rules for HTTP and HTTPS domains, redirect destinations and authorization before trusting a URL.

Underline ​

Use underline to control when a link shows an underline. The Boolean values are scheduled for removal in 3.0.0.

Starting with 2.9.9, use 'always' | 'hover' | 'never'. The examples use these values. If you are maintaining code from before 2.9.9, these are the equivalent legacy forms.

vue
<template>
	<!-- Before 2.9.9. Use 'hover' from 2.9.9. Boolean form removed in 3.0.0. -->
	<AsamLink underline>Link</AsamLink>
	<!-- Before 2.9.9. Use 'never' from 2.9.9. Boolean form removed in 3.0.0. -->
	<AsamLink :underline="false">Link</AsamLink>
</template>

Additional usage and contract notes ​

Validate link destinations ​

href is passed directly to the native <a> element. Validate externally supplied destinations before passing them in to prevent protocols such as javascript: and disallowed redirects. The functions above accept HTTP, HTTPS and relative paths resolved against the current page’s origin. They return # if parsing fails or the protocol is outside the allowlist. Pass the value returned by sanitizeUrl(rawUrl) to AsamLink.
