Usage guidelines ​

Use description, image, and imageSize to customize the empty state. Override the image and description with their named slots and place actions in the default slot. imageSize sets the graphic size. The host controls when to display the empty state and handles data requests and recovery actions.

Additional usage and API notes ​

Custom illustration colors ​

Use style to override these variables on the component root. The default SVG reads colors 1 through 9. Color 0 is a reserved variable in this version. Reference it as var(--el-empty-fill-color-0) in a custom image slot to use it. This example compares the default illustration with a custom one that uses color 0. It uses the existing variable names directly. Images passed by URL retain their original colors.
