Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Display a calculated percentage or indicate work in progress.

Usage guidelines ​

Set percentage to a value from 0 to 100. Progress supports line, circle, and dashboard displays with configurable text and colors. See the full notes.

Complete examples ​

	if (percentage.value < 0) {
		percentage.value = 0;

};

	{ color: '#f56c6c', percentage: 20 },
	{ color: '#e6a23c', percentage: 40 },

Usage guidelines ​

Set percentage from 0 to 100 and choose line, circle, or dashboard through type. Use status, color, format, showText, textInside, and strokeWidth to control the presentation. Use indeterminate or stripedFlow to show ongoing work. The width prop controls the geometry of the circular display. The host runs the task and handles cancellation.
