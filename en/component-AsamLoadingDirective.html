Loading Directive ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Bind a loading mask to an element and dismiss it when the state changes or the element unmounts.

State, dynamic text, and cleanup ​

Toggle the mask, change its message, and unmount the target to check cleanup.

Example: basic

<template>
	<div class="actions">

			<span>提示文字</span>

Usage conventions ​

The binding accepts a boolean or a loading options object. Read the full explanation.

Composition and lifecycle ​

Bind false or true to control visibility. An options object can supply text, background, spinner, svg, svgViewBox, customClass, and target settings. Visual settings such as the message update according to native rules. Read the full explanation.

The native unmounted hook handles cleanup using the native state and close behavior.

Fullscreen loading with automatic dismissal ​

Use fullscreen to cover the viewport and lock to prevent scrolling. The directive dismisses the mask when the binding becomes false or the host unmounts.

Example: fullscreen

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<AsamButton v-asam-loading.fullscreen.lock="loading" type="primary" @click="start">
		显示全屏指令加载
	</AsamButton>
	<p class="example-paragraph">指令绑定状态决定显隐，1.5 秒后自动结束。</p>
</template>

<script lang="ts" setup>
import { ref, onBeforeUnmount } from 'vue';
import { AsamButton, vAsamLoading } from '@asam-ui/ui';
const loading = ref(false);
let timer: ReturnType<typeof setTimeout> | undefined;
const start = () => {
	clearTimeout(timer);
	loading.value = true;
	timer = setTimeout(() => {
		loading.value = false;
	}, 1500);
};
onBeforeUnmount(() => clearTimeout(timer));
</script>

Additional usage and contract notes ​

Usage conventions ​

The binding accepts a boolean or a loading options object. The fullscreen, body, and lock modifiers select fullscreen coverage, mount the mask to body, and lock scrolling, respectively. Supply the message and visual settings through object options or native attributes such as element-loading-text. Text follows the native updated behavior. The native directive closes the mask when the binding is false or the host unmounts. Use the loading service for beforeClose, closed, other service options, and the returned instance. Migrate legacy asam-loading-* attributes to element-loading-*. The directive has no size option.

Composition and lifecycle ​

Bind false or true to change visibility. Object bindings provide text, background, spinner, svg, svgViewBox, customClass, and target options. The message and other visual settings follow native update rules. fullscreen, body, and lock determine the scope when the mask is created. Close and recreate the mask to change that scope. On unmount, the hook releases the instance, scroll lock, and target styles. The directive manages each mask without a shared global fullscreen handle.
