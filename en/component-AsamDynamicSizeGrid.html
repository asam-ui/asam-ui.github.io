Dynamic Size Grid ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Render the visible cells of a grid within a bounded viewport.

Contract and composition ​

This virtual grid renders the visible range plus the cache buffer. Supply a fixed height and width and set totalRow and totalColumn. Apply the default slot's style to the actual item root so absolute positioning and dimensions work. The slot receives rowIndex, columnIndex, style, and data.

rowHeight and columnWidth are sizing functions. estimatedRowHeight and estimatedColumnWidth cover rows and columns that have yet to be measured. See the full notes.

Use scrollTo and scrollToItem to navigate the two scroll axes. See the full notes.

The host determines the row and column dimensions, and ASAM tokens provide colors, spacing, and typography. These low-level entries have no table column registration, independent selection model, or four-value control size.

The component preserves the native default for perfMode and native forceUpdate behavior. In the pinned version, reset methods can retain old dimensions in the active style cache with perfMode=true. The example calls the public reset method to show native behavior for the same inputs. To rebuild the viewport and its cache, change the component key while keeping the host data.

Instance, types, and boundaries ​

The public API and complete SFCs on this page use the same component entry point. The TS and JS demos each include all local dependencies. Type constraints appear in the TS versions. The host handles remote requests and application persistence.

Usage and contract notes ​

Contract and composition ​

rowHeight and columnWidth are sizing functions. estimatedRowHeight and estimatedColumnWidth cover rows and columns that have yet to be measured. When the function results change, call the public resetAfter({rowIndex,columnIndex}, true), or reset one axis with resetAfterRowIndex or resetAfterColumnIndex. All three methods and scrollTo / scrollToItem come directly from the native instance. They retain all arguments, this, return values, and live state. The native instance handles the style cache, scroll requests, and unmounting.

Additional props and events ​

Contract and composition ​

Use the public scrollTo({scrollLeft,scrollTop}) or scrollToItem(rowIndex,columnIndex,alignment) methods. See the public type for alignment values start, center, end, auto, and smart. Set direction to ltr or rtl. The grid scrolls on both axes. scrollbarAlwaysOn keeps scrollbars visible, while useIsScrolling controls whether the slot receives scrolling state. When scrolling to a distant item, the pinned 2.14.7 release may set the position before updating the estimated total size. The browser can clamp the position to the old size. The wrapper preserves the native result from that single scroll request.
