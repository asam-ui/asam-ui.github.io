Scrollbar ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Display long content within a bounded region and observe its scroll position.

Contract and composition ​

height provides a fixed viewport; maxHeight preserves the natural height for smaller content. Read the full explanation.

The public ref supports scrollTo, setScrollTop, setScrollLeft, update, handleScroll and wrapRef. Read the full explanation.

In the complete infinite example, the bottom branch of end-reached automatically appends five items; top / left / right only record the direction without appending. Appending increases the actual scrollable content height so the next arrival at the bottom can load more. This composition uses native events and host state.

Additional usage and contract notes ​

Contract and composition ​

height provides a fixed viewport; maxHeight preserves the natural height for smaller content. Content wider than the viewport can scroll horizontally. always keeps scrollbars visible, native switches to browser scrollbars, and noresize is for hosts that trigger update themselves. wrapStyle / wrapClass, viewStyle / viewClass, tag, minSize and tabindex retain this entry’s public contract. scroll receives scrollTop / scrollLeft; end-reached returns top / bottom / left / right according to distance.

Contract and composition ​

The public ref supports scrollTo, setScrollTop, setScrollLeft, update, handleScroll and wrapRef. After content changes, you can await nextTick and then call update. Unmounting releases resize and scroll listeners. Scrollbar sizes and colors use ASAM tokens; set the container height to suit the actual content.
