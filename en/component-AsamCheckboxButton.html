Checkbox Button ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

Related components ​

Bind a checked state directly or place the item in an AsamCheckboxGroup to form a row of connected buttons. To render options automatically, set type="button" on AsamCheckbox.

When to use it ​

Use value to identify the item and the default slot for its content. Place items in the corresponding Group to manage selection together. Use the collection component to render options automatically.

Composition and two-way binding ​

Set the item's selection value with value. Use label for display or an accessible description, and migrate any code that relied on it as the selection value. Disabled items cannot be changed.

Selection limits and standalone state ​

AsamCheckboxGroup uses min and max to limit the number of selections. A standalone CheckboxItem binds to a boolean model. indeterminate indicates partial selection and leaves the bound value unchanged.

This button retains the shared checkbox type’s id, border, and indeterminate compatibility fields. Full details.

Four sizes and context inheritance ​

The four examples set large, big, default, and small explicitly. The example below them omits size and updates with ConfigProvider. An explicit size takes precedence over an inherited size. Components with no public size prop use their surrounding context.

Example: sizes

ASAM extensions and migration ​

ASAM provides four sizes and inherits size from the group context. The default slot controls the item's display. Item, Button, and Group expose no instance methods, including the focus method available on the collection or input components. See the API reference below for events and available props.

Reading the API reference ​

The Props, Events, Slots, and Exposes sections use the current public types and runtime defaults. Props tied to a particular branch apply only to that branch. Use one compatible value mode at a time. “Unknown / Undeclared” marks an unspecified default, which may differ from false or an empty value. Copy or download a standalone Demo.vue in the source panel for either language. The file includes the local helper components, data, and assets.

Base component behavior ​

This component forwards the base control's public behavior and provides ASAM's four sizes and styling. Full details.

Usage and API notes ​

Selection limits and standalone state ​

This button retains the shared checkbox type’s id, border, and indeterminate compatibility fields. id is used to determine the internal control’s identity, though the button template leaves it unbound on the input. The button’s state and styles control its border, and indeterminate has no effect on its appearance. Use AsamCheckboxItem to display partial selection.

Base component behavior ​

This component delegates to version 2.14.7 of its underlying dependency and preserves its public props, defaults, event arguments, and slots. ASAM adds four sizes and its own styling. Use AsamRadio or AsamCheckbox to normalize options or store selection as an object or string. The underlying group handles how first, middle, and last buttons connect, along with selected, disabled, and focus states and keyboard interaction.
