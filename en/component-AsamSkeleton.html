Skeleton ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Show a placeholder that reflects the expected layout while content loads.

Basic usage and states ​

This example uses the component's public API.

Usage guidelines ​

Use loading to switch between the skeleton and the content. Configure the placeholder with animated, rows, count, and throttle. Use the template slot for the skeleton and the default slot for the loaded content. The host handles requests, errors, and recovery.

Rendering a list of data ​

Skeletons often stand in for a list while the application fetches data from a server. Use count to set the number of placeholder items.

Keep count low. Rendering and removing many placeholders adds work in the browser and can affect performance.

Example: cap-rendering-with-data

Preventing flicker ​

A fast response can replace a placeholder almost as soon as it is displayed, causing a flash. Use throttle to control when the skeleton appears or disappears.

Since 2.8.8, throttle accepts a number or an object. A number behaves like { leading: delay } and delays showing the skeleton. Use { trailing: delay } to delay hiding it.
