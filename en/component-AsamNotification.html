Notification ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Show a titled notification in a corner of the page when a result needs a fuller explanation.

Notification position and close handle ​

Create a notification in the bottom-right corner. Dismiss it with its own close button or with the example's close action.

Example: basic

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<div class="actions">
		<AsamButton type="primary" native-type="button" @click="notify">显示通知</AsamButton>
		<AsamButton type="default" native-type="button" @click="closeOwned">
			关闭本例通知
		</AsamButton>
	</div>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamNotificationBasicDemo' });
import { onBeforeUnmount } from 'vue';
import { AsamButton, AsamNotification } from '@asam-ui/ui';
import type { AsamNotificationHandle } from '@asam-ui/ui';
const handles: AsamNotificationHandle[] = [];
const notify = () => {
	handles.push(
		AsamNotification.success({
			title: '处理完成',
			message: '共处理 3 条本地记录。',
			position: 'bottom-right',
			duration: 0,
			showClose: true
		})
	);
};
const closeOwned = () => {
	handles.splice(0).forEach((handle) => handle.close());
};
onBeforeUnmount(closeOwned);
</script>

Usage conventions ​

AsamNotification(options, appContext?) and the success, warning, info, and error shortcuts return a handle with close(). See the usage conventions.

Complete usage examples ​

These examples use the public ASAM UI entry points. Each includes a complete TypeScript and JavaScript SFC. See the API on this page for props, events, slots, and instance types. Close service instances that you create, and pass only trusted strings as HTML.

<template>
	<div class="flex flex-wrap demo-gap">
		<AsamButton type="default" class="!ml-0" @click="open1">自动关闭</AsamButton>
		<AsamButton type="default" class="!ml-0" @click="open2">不自动关闭</AsamButton>
	</div>
</template>

<script lang="ts" setup>
import { AsamButton, AsamNotification, type AsamNotificationHandle } from '@asam-ui/ui';

import { onBeforeUnmount } from 'vue';

import { h } from 'vue';

const open1 = () => {
	trackAsamNotification(
		AsamNotification({
			title: '标题',
			message: h('i', { style: 'color: teal' }, '这是一条提醒。')
		})
	);
};

const open2 = () => {
	trackAsamNotification(
		AsamNotification({
			title: '提示',
			message: '这条消息不会自动关闭。',
			duration: 0
		})
	);
};

const ownedAsamNotification = new Set<AsamNotificationHandle>();
let mountedAsamNotification = true;
const trackAsamNotification = (handle: AsamNotificationHandle) => {
	if (mountedAsamNotification) ownedAsamNotification.add(handle);
	else handle.close();
	return handle;
};
onBeforeUnmount(() => {
	mountedAsamNotification = false;
	for (const handle of ownedAsamNotification) handle.close();
	ownedAsamNotification.clear();
});
</script>

Additional usage and API details ​

Usage conventions ​

AsamNotification(options, appContext?) and the success, warning, info, and error shortcuts return a handle with close(). Use title and message for content, duration and showClose for dismissal, position, offset, and zIndex for placement, and onClick and onClose for interactions. Set duration to 0 to keep the notification visible. closeAll acts globally. ASAM forwards the app context and adds its styling class. The service has no size option. On unmount, close instances you own.

More on options and events ​

Composition and lifecycle ​

Set progress to true to show the countdown bar, or pass an AsamNotificationProgress object to customize settings such as color and strokeWidth. The notification manages percentage, type, duration, indeterminate, and width itself. pauseOnHover pauses the timer and bar by default. Set it to false to keep counting while hovering, or set duration to 0 to prevent automatic dismissal. The shortcuts accept strings or VNodes, and options.message can be a content function. position selects one of four corners, and offset, zIndex, and updateOffsets manage stacking. onClick and onClose remain callbacks. Keep each close handle and dismiss the notifications you own on unmount. customClass accepts Vue class values.
