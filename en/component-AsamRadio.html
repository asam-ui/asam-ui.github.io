Radio ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

Interactive examples, TypeScript and JavaScript source, and the generated API reference are included on this page.

Related controls ​

This entry renders a complete single-choice collection from options. To write choices manually, use Radio group with Radio item or Radio button.

When to use it ​

Render a single choice from normalized options. Use RadioItem for an independent item and RadioGroup for slot composition. This component consumes static options only.

Options and button appearance ​

type selects ordinary or button appearance. The option slot receives a normalized option. Option-level and control-level disabled states apply independently.

Joined buttons and explicit groups ​

Adjacent type="button" options join continuously. Only the first and last retain outer corner radii; middle buttons share a single seam. All four sizes match explicit RadioGroup + RadioButton. Ordinary radios keep density-based spacing. Disabled items retain their position. Tab focuses the current item; arrow keys move between available items. Multiple-selection props min, max and tag are not accepted.

ASAM extensions and migration ​

ASAM separates collections from standalone Item/Group controls. Groups inherit all four sizes. Normalized options must include raw. Do not mix legacy object and string models. The default slot replaces automatic rendering; option customizes one item. The public events are update:modelValue and change; the collection has no public expose. Use Remote/Dict components for data requests.

Renderable default-slot content supplies custom children; an empty slot falls back to options. Dynamic changes preserve the external model's value mode.

Events and instance ​

  • update:modelValue(value) updates the configured model.
  • change(value) reports a user selection after normalization.

Both payloads are AsamValue, AsamChoiceOption<AsamValue, object> or null, according to valueMode. Single choice does not accept multipleValueMode, separator, min, max or tag; removed fields are explicitly rejected at runtime. Raw field mapping through props belongs to AsamRadioGroup. This collection consumes normalized options only. It has no public instance methods. Event tuples come from the actual SFC declarations, with no named Emits type for automatic projection.

Reading the API ​

The reference uses current public types and runtime defaults. Combined props apply by branch; do not mix modes arbitrarily. An unknown or undeclared default does not mean false or empty. Complete standalone Demo.vue files inline local helpers, data and assets. The two events are declared in the SFC, without a named Emits type or expose; payloads follow the modes above.

Collections and base controls ​

This options-plus-Group composition preserves normalized object/value models. Use Item, Group and Button for their native public props, events and slots. Button mode preserves native borders, outer radii, selected and disabled interactions at all four sizes with zero group gap. Ordinary mode uses ASAM spacing. Focus and keyboard navigation remain delegated to the native group and children.
