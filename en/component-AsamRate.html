Rate ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Collect or display a numeric rating. allowHalf enables half-stars. Use texts, colors, and rating thresholds to give each score meaning.

Half-stars, text, and read-only display ​

change carries the committed score. Use disabled to display a read-only rating and showScore with scoreTemplate to show the numeric value.

ASAM extensions and migration ​

ASAM's four sizes adjust the interaction area and icon density. Configure display text and colors through public props. The component has no content slots and exposes focus, setCurrentValue, and resetCurrentValue.

Previewing and restoring the rating ​

setCurrentValue previews a value, and resetCurrentValue restores the committed rating. Previewing leaves v-model unchanged. See the full notes.

Reading the API ​

The generated props, events, slots, and exposed members reflect the current public types and runtime defaults. Use each property combination with its applicable mode. “Unknown / Not declared” means no default is documented by the runtime. The source panel provides a standalone Demo.vue for each language. Its local helpers, data, and assets are included for copying or downloading.

Use ariaLabel (aria-label in templates) to name the rating for assistive technology. The pinned 2.14.7 public props use this name in place of the former label.

Additional usage notes ​

Previewing and restoring the rating ​

setCurrentValue previews the rating without committing v-model, and resetCurrentValue restores the committed rating. The low and high thresholds select the active colors and icons tiers. Configure empty icons, disabled empty icons, and colors independently. allowHalf enables half-stars. clearable resets the rating to zero if you click the same score again. showText displays text and showScore displays the value using scoreTemplate. Disabled ratings still display their actual score. The rating container and icons support theme variables. ASAM adds focus as a keyboard entry point.

More parameters and events ​

Rating theme variables ​

The pinned native component retains --el-rate-void-color, --el-rate-fill-color, --el-rate-disabled-void-color, and --el-rate-text-color. The example uses ASAM tokens. Explicit props such as colors or voidColor override their corresponding theme variables. Read-only ratings keep the text and empty-star colors.
