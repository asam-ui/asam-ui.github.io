Upload ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

Interactive examples, TypeScript and JavaScript source, and the generated API reference are included on this page.

When to use it ​

Default resource mode saves normalized resources after upload. Explicit native mode manages a raw fileList. Each mode has its own model, event and instance-method contracts.

Resource uploads, validation and cancellation ​

The example uses a local asynchronous handler and makes no network request. upload returns a resource containing id, name, url, mimeType and size. Its context supplies cancellation signals and progress reporting. maxSizeBytes / validate check files before upload. The copied source includes the handler.

import type { AsamUploadHandler } from '@asam-ui/ui';
export const localUpload: AsamUploadHandler = async ({ file }, context) => {
	context.reportProgress({ loaded: 0, total: file.size });
	await new Promise<void>((resolve, reject) => {
		const timer = setTimeout(resolve, 250);
		context.signal.addEventListener(
			'abort',
			() => {
				clearTimeout(timer);
				reject(new Error('cancelled'));
			},
			{ once: true }
		);
	});
	if (context.signal.aborted) throw new Error('cancelled');
	context.reportProgress({ loaded: file.size, total: file.size });
	return {
		id: file.name + ':' + file.size,
		name: file.name,
		url: '/local-demo/' + encodeURIComponent(file.name),
		mimeType: file.type || 'application/octet-stream',
		size: file.size
	};
};

Raw file lists and manual submission ​

mode="native" uses v-model:fileList and native httpRequest / hooks. The local request calls onSuccess without a network request. There is no resource modelValue or resource event protocol. abort / clearFiles operate on the native upload instance.

Sizes and inheritance ​

Four examples explicitly use large, big, default and small. Omitted sizes respond to ConfigProvider; explicit sizes override ancestors. A panel without a size contract does not acquire an extra size prop.

Native galleries, thumbnails and controlled ordering ​

Native mode supports text, picture and picture-card list types. onPreview handles previews. beforeUpload can synchronously or asynchronously reject a file, or return a replacement File/Blob. False or Promise rejection prevents upload. beforeRemove can reject removal; onRemove runs after actual removal. onChange receives the current list on selection, success and failure.

The native file slot receives exactly { file, index }; use instance methods handleRemove(file) / abort(file) for removal/cancellation. item, remove and cancel belong only to the resource file slot. Migrate old native usage following the gallery example.

Try limits and hooks.

Native action, method, headers, name, data and withCredentials pass to httpRequest. Try resource requests.

The transform returns a valid id/name/url/mimeType/size resource. Failure, duplicate ids and invalid metadata do not update the model. maxSizeBytes, validate and limit apply before transport. error.kind distinguishes configuration, transport and transform errors. Resource models stay separate from native file lists.

Cancel, clear, scope invalidation and unmount abort the context; late completions cannot write back. Progress, success, error, cancelled and remove events retain their individual payloads. disabled blocks default resource selection, cancellation and removal; callers control custom-slot buttons and external instance calls. abort, clearFiles, handleStart and handleRemove bridge native files; resource operations are submit/cancel/clear. Judge results from the actual model and list.

ASAM extensions and migration ​

ASAM provides resource/native modes and four densities. Resource upload and request are alternatives. Request requires a provider upload transport and transform; do not mix it with native action. Resource methods are submit/cancel/clear. Native methods are abort/submit/clearFiles/handleStart/handleRemove. Empty single resources are null; empty multiple resources are arrays.
