Dynamic Size List ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Render the visible items within a bounded viewport to reduce how many items a long list mounts.

Contract and composition ​

This virtual list renders the visible range plus the cache buffer. Supply a fixed height and width and set total and data. Apply the default slot's style to the actual item root so absolute positioning and dimensions work. The slot receives index, style, data, and isScrolling.

itemSize is a sizing function. estimatedItemSize covers items that have yet to be measured. The list has no public resetAfterIndex method. When the function results change, update the key to rebuild the size cache and use scrollTo to restore the previous offset. The boundary example shows this sequence.

Use the public methods to navigate the list in a horizontal or vertical layout. See the full notes.

The host determines the row and column dimensions, and ASAM tokens provide colors, spacing, and typography. These low-level entries have no table column registration, independent selection model, or four-value control size.

defineOptions({ name: 'AsamDynamicSizeListBoundaryDemo' });
import { nextTick, ref } from 'vue';
import { AsamCheckboxItem, AsamButton, AsamDynamicSizeList } from '@asam-ui/ui';
import type { AsamDynamicSizeListExpose, AsamDynamicSizeListEmits } from '@asam-ui/ui';
const list = ref<AsamDynamicSizeListExpose>();
const items = Array.from({ length: 100 }, (_, index) => '记录 ' + (index + 1));
const horizontal = ref(false);
const rtl = ref(false);
const always = ref(true);
const revision = ref(0);
const eventState = ref('');
const edge = ref('');
const onScroll = (...[direction, offset, requested]: AsamDynamicSizeListEmits['scroll']): void => {
	eventState.value = direction + ':' + offset + ':' + requested;
};
const onRendered = (
	...[start, end, first, last]: AsamDynamicSizeListEmits['itemRendered']
): void => {
	range.value = start + ':' + end + ':' + first + ':' + last;
};
const range = ref('');
const large = ref(false);
const itemSize = (index: number): number => (index % 2 ? 60 : 40) + (large.value ? 30 : 0);
async function resize(): Promise<void> {
	const offset = list.value?.states.scrollOffset ?? 0;
	large.value = !large.value;
	revision.value++;
	await nextTick();
	list.value?.scrollTo(offset);
}
</script>

Instance, types, and boundaries ​

The public API and complete SFCs on this page use the same component entry point. The TS and JS demos each include all local dependencies. Type constraints appear in the TS versions. The host handles remote requests and application persistence.

Additional props and events ​

Contract and composition ​

Use the public scrollTo(offset), scrollToItem(index,alignment), or resetScrollTop() methods. See the public type for alignment values start, center, end, auto, and smart. Set direction to ltr or rtl and layout to vertical or horizontal. scrollbarAlwaysOn keeps scrollbars visible, while useIsScrolling controls whether the slot receives scrolling state. Both ends of the list remain reachable when navigating to the end, changing the item size, or using RTL.
