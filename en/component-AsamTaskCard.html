Task Card ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

AsamTaskCard displays a task's ID, release time, batch size, product model, team, workstations, and status. Actions report their key to the caller, which owns the workflow and any API requests.

Status and actions ​

The example stores the task data in a separate file. When you click an action, the parent uses its action key to update local state and the button label. The reset button recreates the initial data.

Example: basic

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<AsamTaskCard v-bind="task" @action="advance" />
	<p class="example-paragraph">
		<output>最近操作：{{ lastAction || '尚未操作' }}；状态：{{ task.status }}</output>
	</p>
	<AsamButton type="default" @click="reset">恢复任务</AsamButton>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamTaskCardBasicDemo' });
import { ref } from 'vue';
import { AsamButton, AsamTaskCard } from '@asam-ui/ui';
import { createTask } from './task.js';
const task = ref(createTask());
const lastAction = ref('');
function advance(key: string): void {
	lastAction.value = key;
	if (key !== 'advance') return;
	if (task.value.status === 'pending') {
		task.value.status = 'inProgress';
		task.value.actions = [{ key: 'advance', label: '完成任务', variant: 'success' }];
	} else {
		task.value.status = 'completed';
		task.value.stage = 'finish';
		task.value.actions = [];
	}
}
function reset(): void {
	task.value = createTask();
	lastAction.value = '';
}
</script>

export function createTask() {
	return {
		taskNo: 'TASK-001',
		releaseTime: '2026-10-03 08:30:00',
		batchCount: 24,
		productModel: 'A-01',
		teamName: '一班',
		stations: ['装配', '复核'],
		status: 'pending',
		stage: 'mark',
		actions: [{ key: 'advance', label: '开始', variant: 'primary' }]
	};
}

status accepts pending, inProgress, or completed. The optional stage accepts mark or finish. The public API requires the task ID, release time, batch size, model, team, workstation array, and status. The component displays a full YYYY-MM-DD HH:mm:ss release time to the minute and leaves other formats as supplied. It joins workstations with the ideographic comma (、).

Each entry in actions uses key to identify the action and label for the display text. variant uses the semantic variants from AsamButton. Default action buttons use the small size. The event returns only the key. Retrieve the business data from the current task.

icon, title, subTitle, default, and action replace their respective sections. The slot name subTitle is case-sensitive. The action slot replaces the default actions. Bind your own handler there, as slot content does not emit the component's action event automatically. The action area appears only when the card has action entries or an action slot.

The component exposes no instance methods. Fallthrough attributes apply to the outer card. Task status and stage control the visual presentation. The host handles permissions, persistence, and errors.

Usage and API notes ​

Task status, stage, and action ​

status describes pending, inProgress, or completed. stage describes mark or finish independently. The card drops seconds only from timestamps in the full seconds format and joins workstations with the ideographic comma. The action event carries the business key unchanged. The footer renders only when the card has actions or an action slot. The slots example covers all five replaceable regions. Long text is preserved in full in the title and body, with no fields omitted implicitly.
