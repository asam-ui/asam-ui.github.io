Pro virtual table ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

AsamProVirtualTable combines a virtual table view with a data controller.

When to use it ​

Use the virtual table to display large row sets in a windowed view. Configure the data source and server-side queries in the application.

Virtual table viewport ​

Set width and height to define the viewport for the table.

Example: basic

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<div class="pro-example-stack">
		<div ref="host" class="pro-example-width">
			<AsamProVirtualTable
				:rows="rows"
				:columns="columns"
				:width="width"
				:height="280"
				row-key="id"
				label="项目列表"
			/>
		</div>
	</div>
</template>

<script setup lang="ts">
import { AsamProVirtualTable } from '@asam-ui/pro/components';
import { onMounted, onBeforeUnmount, ref } from 'vue';
const host = ref<HTMLElement | null>(null);
const width = ref(320);
let observer: ResizeObserver;
onMounted(() => {
	observer = new ResizeObserver(() => {
		width.value = host.value?.clientWidth || 320;
	});
	observer.observe(host.value!);
});
onBeforeUnmount(() => observer?.disconnect());
const rows = Array.from({ length: 100 }, (_, i) => ({ id: i + 1, name: '项目 ' + (i + 1) }));
const columns = [
	{ key: 'id', label: '编号', width: 100 },
	{ key: 'name', label: '项目名称', width: 200 }
] as const;
</script>
