Application configuration provider ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

AsamApplicationProvider provides application configuration to a subtree.

When to use it ​

Pass a reactive config to update settings for a page or section. Descendants read the resolved configuration as read-only data. Nested providers inherit settings from their nearest enclosing scope and can override settings locally. The default slot receives the resolved config and any configuration errors.

Size within a section ​

Set a size for one subtree to apply it to the controls rendered inside that provider.

Example: size

Nested providers ​

Apply a different configuration in a nested section. The inner section resolves its settings from the closest provider.

Example: nested

Example source ZIPComplete project ZIP
vue
<template>
	<div class="pro-example-stack">
		<AsamApplicationProvider :config="{ size: 'big' }">
			<div class="pro-example-stack">
				<AsamButton type="primary">外层尺寸</AsamButton>
				<AsamApplicationProvider :config="{ size: 'small' }">
					<AsamButton type="primary">内层尺寸</AsamButton>
				</AsamApplicationProvider>
			</div>

	</div>
