Task workbench ​

Bring workspace status, metrics, shortcuts, tasks, and recent activity into one Vue page. The preview loads a local synthetic snapshot so you can try task filters and navigation.

Use the preview controls to switch among the Minimal, Brand, and Tech layouts. Try read-only and disabled modes, a failed refresh, and a change of workspace identity.

Use and API ​

Copy the entire workbench directory and choose MinimalWorkbench.vue, BrandWorkbench.vue, or TechWorkbench.vue. The layouts share the controller and common page sections. Supply a WorkbenchHost with context, a snapshot service, and an allowlist of navigation targets. The host can add explicit task actions when required.

See usage and the host and controller contract. The complete project includes the example host and its matching dependencies, lockfile, and patches.

Reference ​

API and behavior

index.ts is the template source entry. Import a layout from the copied source and pass its WorkbenchPageProps. Workbench.ts manages the page snapshot, while parts/ contains the shared page sections.

Prop Value Purpose
host Required WorkbenchHost Supplies identity, services, permissions, navigation, and optional actions
size Inherits from the provider by default large, big, default, and small correspond to 40, 36, 32, and 28 px
timeZone Defaults to Asia/Shanghai Formats timestamps and reports an invalid time zone explicitly
Snapshots and refresh ​

host.context includes scope, identity, and a string or number revision. Changing any of them or replacing the service clears the previous snapshot and cancels its pending read. Replace service and policy references when their meaning changes. The controller rechecks permissions at the action boundary, and the host enforces service authorization.

service.load({ signal, scope, identity, revision }) returns a complete WorkbenchSnapshot with a version, workspace, metrics, shortcuts, tasks, and activities. IDs must be finite numbers or non-empty strings, unique by type and value within each section. The numeric ID 0 is valid. Supply metric units explicitly. The view displays null or non-finite metric values, and missing or invalid dates, as unknown. A displayed ISO timestamp needs a UTC marker or offset. The workbench clones and freezes the returned snapshot.

Refreshing within the same context keeps the previous snapshot visible and shows its refresh state. A failed refresh offers Retry and marks same-context data as outdated. The latest request wins, including when an earlier service ignores its abort signal. Unmounting releases page-owned listeners and requests. The host disposes borrowed services and navigation.

Navigation and task actions ​

targets maps stable IDs to internal absolute paths or named Vue Router locations. The navigator resolves a real outcome through navigate(location): Promise<boolean>. Blank, duplicate, or unknown targets do not start navigation. The example owns and disposes its navigation controller.

Read-only access allows viewing, filtering, refreshing, and permitted read navigation. Disabled mode retains the readable snapshot and pauses filtering, new reads, navigation, and actions. Permission changes take effect on existing controls.

Optional actions add host-owned task operations. Each receives the task, context, and signal. Visibility, access, and busy state constrain execution. A fulfilled action does not mutate the task snapshot. The host handles authorization, persistence, and concurrency. Changing the context or policy aborts page-owned action handling and prevents a late completion from updating the current view.

Controller and events ​

onEvent synchronously reports load, loaded, navigate, and action, with context and an optional ID. If a callback changes the host or unmounts the page, the workbench rechecks the current state after Vue processes those changes.

createWorkbench(getHost) exposes read-only refs for snapshot, loading, error, feedback, and busy. It has a writable filter, computed tasks, and methods refresh, navigate, runAction, linkReason, actionReason, and dispose. The component exposes controller and releases it on unmount. Call dispose when using the factory directly.

Usage

The workbench is a Vue 3 application with workspace identity and status, four metrics, eight shortcuts, twelve tasks, and eight activity entries. Its local service responds after 100 ms.

Layout Source Arrangement
Minimal MinimalWorkbench.vue Metrics in a row, with a wider task column beside activity
Brand BrandWorkbench.vue Workspace identity in a side panel, two columns of metrics, and a dedicated task area
Tech TechWorkbench.vue A full-width metrics strip, activity on the left, and tasks in the main area

Copy the full template directory and then edit the layout you want. The three layouts share their page sections and controller. Install the versions listed in the project, then run pnpm run dev or pnpm run build. The page consumes the public JavaScript, CSS, and type declarations from @asam-ui/ui and @asam-ui/pro. The included navigation files are editable application source.

Use the preview controls to switch layout, theme, control size, and workspace identity. You can also simulate read-only access, disabled controls, navigation guards, empty and error states, and long text. A production host can provide its own controls and service.

The sample dates are fixed and use the Asia/Shanghai time zone by default. The provider supplies light and dark tokens. Long content wraps within the available columns. Entrance and metric animations leave controls available, and reduced-motion settings remove optional effects.

import type { AsamControlSize } from '@asam-ui/ui';
import type { AsamAvatarItem, AsamTaskStatus, AsamTrendProps } from '@asam-ui/pro';
import type { RouteLocationRaw } from 'vue-router';

export type WorkbenchId = string | number;
export type WorkbenchFamily = 'minimal' | 'brand' | 'tech';
export interface WorkbenchContext {
	readonly scope: string;
	readonly identity: string;
	readonly revision: string | number;
}
export interface WorkbenchMetric {
	readonly id: WorkbenchId;
	readonly label: string;
	readonly value: number | null;
	readonly unit: string;
	readonly precision?: number;
	readonly helper: string;
	readonly trend?: AsamTrendProps;
}
export interface WorkbenchLink {
	readonly id: WorkbenchId;
	readonly label: string;
	readonly description: string;
	readonly target: string;
	readonly permission?: string;
	readonly hidden?: boolean;
}
export interface WorkbenchTask {
	readonly id: WorkbenchId;
	readonly title: string;
	readonly description: string;
	readonly status: AsamTaskStatus;
	readonly assignees: readonly AsamAvatarItem[];
	readonly progress?: number | null;
	/** ISO 8601 with explicit offset, or null. Display uses configured timeZone. */
	readonly dueAt?: string | null;
	readonly target: string;
	readonly permission?: string;
}
export interface WorkbenchActivity {
	readonly id: WorkbenchId;
	readonly text: string;
	readonly at: string | null;
	readonly target: string;
	readonly permission?: string;
}
export interface WorkbenchSnapshot {
	readonly version: string;
	readonly workspace: {
		readonly title: string;
		readonly description: string;
		readonly name: string;
	};
	readonly metrics: readonly WorkbenchMetric[];
	readonly shortcuts: readonly WorkbenchLink[];
	readonly tasks: readonly WorkbenchTask[];
	readonly activities: readonly WorkbenchActivity[];
}
export interface WorkbenchService {
	load(context: WorkbenchContext & { signal: AbortSignal }): Promise<WorkbenchSnapshot>;
}
/** Adapt the public V2-032 navigate contract; ownership remains with the host. */
export interface WorkbenchNavigator {
	navigate(location: RouteLocationRaw): Promise<boolean>;
}
export interface WorkbenchTarget {
	readonly id: string;
	readonly location: RouteLocationRaw;
	readonly permission?: string;
}
export interface WorkbenchAction {
	readonly id: string;
	readonly label: string;
	readonly permission: string;
	readonly disabled?: boolean;
	readonly hidden?: boolean;
	run(input: WorkbenchContext & { task: WorkbenchTask; signal: AbortSignal }): Promise<void>;
}
export interface WorkbenchHost {
	readonly context: WorkbenchContext;
	readonly service: WorkbenchService;
	readonly navigator: WorkbenchNavigator;
	readonly targets: readonly WorkbenchTarget[];
	readonly actions?: readonly WorkbenchAction[];
	readonly disabled?: boolean;
	readonly readonly?: boolean;
	/** Synchronous host authorization. This is presentation policy, not server authorization. */
	readonly allowed: (permission: string) => boolean;
	/** Can synchronously replace/unmount the host. Rechecked before calling services. */
	readonly onEvent?: (event: WorkbenchEvent) => void;
}
export interface WorkbenchEvent {
	readonly type: 'load' | 'loaded' | 'navigate' | 'action';
	readonly context: WorkbenchContext;
	readonly id?: WorkbenchId;
}
export interface WorkbenchPageProps {
	host: WorkbenchHost;
	size?: AsamControlSize;
	timeZone?: string;
}
