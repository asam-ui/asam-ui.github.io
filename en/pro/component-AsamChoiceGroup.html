Choice group ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

AsamChoiceGroup manages single or multiple selection across a set of card or tag options.

When to use it ​

Use each option's label as display text. The model keeps the underlying type of each option's value. Bind a single value for the default single-selection mode and an array when multiple is enabled. Use appearance to choose how the options are displayed.

Single selection with cards ​

Select one card. The model receives the selected option's value. This example uses the default primary type for the clear action.

Example: single

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<div class="pro-example-stack">
		<AsamChoiceGroup v-model="selected" :options="options" label="选择团队" />
	</div>
</template>

<script setup lang="ts">
import { AsamChoiceGroup } from '@asam-ui/pro/components';
import { ref } from 'vue';
const options = [
	{ value: 'design', label: '设计' },
	{ value: 'development', label: '开发' },
	{ value: 'support', label: '支持', disabled: true }
];
const selected = ref('design');
</script>

Two-way binding ​

Bind the selected value or null in single-selection mode and an array of selected values in multiple-selection mode. Selection changes emit update:modelValue.

See the generated API reference for the component's public contract.
