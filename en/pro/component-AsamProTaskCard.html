Pro task card ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

AsamProTaskCard displays a task's status, assignees, progress, and actions in a card. Use AsamCardGroup to arrange multiple cards.

When to use it ​

Map workflow state to a status with a label, optional tone, and completion flag. Pass a percentage to progress to show a progress indicator. Use state for the card's loading, empty, or error state. Use actions and listen for action to run application operations. The application manages the workflow and persists changes.

Show task information and actions ​

The header keeps the title and status on one row. The footer places footer-meta and operation on a row of their own. The default slot supports text, images, or both in the order you provide. The example uses the operation slot to open a task details drawer. Bind its blocked value to custom controls so they follow the card's disabled, read-only, and non-ready states.

vue
<template>
	<AsamCardGroup label="任务卡片列表">
		<AsamProTaskCard
			v-for="card in cards"
			:key="card.title"
			:title="card.title"
			:status="card.status"
			:progress="card.progress"
		>
			<template v-for="block in card.content" :key="block.type">
				<img
					v-if="block.type === 'image'"
					:src="cover"
					alt="蓝色山景项目封面"
					width="160"
					height="60"
				/>
				<p v-else>{{ block.text }}</p>
			</template>
			<template #footer-meta>
				<time datetime="2026-01-01">2026-01-01</time>
			</template>
			<template #operation="{ blocked }">
				<AsamButton
					type="primary"
					plain
					:disabled="blocked"
					:aria-label="'查看详情：' + card.title"
					@click="activeTask = card"
				>
					查看详情
				</AsamButton>
			</template>
		</AsamProTaskCard>
	</AsamCardGroup>
	<AsamDrawer
		:model-value="activeTask !== null"
		:title="activeTask?.title"
		@update:model-value="closeDetails"
	>
		<p v-if="activeTask">{{ activeTask.status.label }}</p>
	</AsamDrawer>
</template>

Show assignees ​

Pass member records to assignees with stable IDs and names. The example displays three collaborators and 100% progress. Assignee images and name fallbacks follow AsamProAvatarGroup (Chinese).
