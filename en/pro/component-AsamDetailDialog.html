Detail dialog ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

AsamDetailDialog displays read-only record details in a modal. The dialog handles the title, close controls, and focus. The detail panel renders the fields.

When to use it ​

Create the detail controller with useAsamDetail and open a selected record through that controller. Configure the title, width, and grouping for a focused read-only view. Use the detail drawer when a side panel fits the page better.

<template>
	<AsamButton type="primary" @click="open">打开详情弹窗</AsamButton>
	<AsamDetailDialog :controller="controller" title="项目资料" :columns="3">
		<template #footer="{ close }">
			<AsamButton type="default" @click="close">关闭详情</AsamButton>
		</template>
	</AsamDetailDialog>
</template>

<script setup lang="ts">
import { AsamDetailDialog, useAsamDetail } from '@asam-ui/pro/components';
import type { AsamFieldDefinition } from '@asam-ui/pro/components';
import { AsamButton, createAsamDataRuntime } from '@asam-ui/ui';

const overview = { detail: { layout: { group: '基本信息' } } };
const schedule = { detail: { layout: { group: '项目进度' } } };
const delivery = { detail: { layout: { group: '交付信息' } } };
const fields: readonly AsamFieldDefinition[] = [
	{ key: 'name', kind: 'text', label: '项目名称', modes: overview },
	{ key: 'reference', kind: 'text', label: '项目编号', modes: overview },
	{ key: 'category', kind: 'text', label: '项目类型', modes: overview },
	{ key: 'status', kind: 'text', label: '当前阶段', modes: schedule },
	{ key: 'startDate', kind: 'text', label: '启动日期', modes: schedule },
	{ key: 'dueDate', kind: 'text', label: '计划验收', modes: schedule },
	{ key: 'owner', kind: 'text', label: '项目负责人', modes: delivery },
	{ key: 'team', kind: 'text', label: '交付团队', modes: delivery },
	{ key: 'updatedAt', kind: 'text', label: '最近更新', modes: delivery },
	{ key: 'note', kind: 'textarea', label: '交付说明', modes: delivery }
];

const controller = useAsamDetail({ fields, runtime: createAsamDataRuntime() });

function open() {
	void controller.open({
		mode: 'direct',
		id: 'PRJ-2026-042',
		status: 'ready',
		data: {
			name: '园区设备巡检',
			reference: 'PRJ-2026-042',
			category: '设备运维',
			status: '试点运行',
			startDate: '2026-10-12',
			dueDate: '2026-11-27',
			owner: '陈晨',
			team: '设施运营组',
			updatedAt: '2026-11-10',
			note: '在一号园区试点移动巡检，覆盖空调机房、配电柜和消防设施。验收时核对巡检记录完整性、异常派单结果和周报导出。'
		}
	});
}
</script>

Open the project details and close the dialog to return to the page. The examples and source viewer are included on this page. Open the interactive example.

Component API ​

Read the full generated API.

Props ​

Supply controller and configure title, width, fieldLabels, emptyText, columns, and appearance. Use closeDisabled, closeOnClickModal, and closeOnPressEscape to control closing.

Events ​

The overlay emits open, opened, close, and closed during its lifecycle.

Slots ​

Customize the overlay with header, content, the default slot, and footer.
