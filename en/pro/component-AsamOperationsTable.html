CRUD table and pagination ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

AsamOperationsTable is the results table used by the CRUD page. It brings together the table, pagination, toolbar, selection and column preferences. The host supplies and owns the list controller and any write services.

When to use it ​

Use the table independently when your page already owns the search layout. To add query fields, connect the search form to the same list controller. Use the controller for reads and pass the selection, operation coordinator, and column preferences to the table.

Cross-page selection stores stable row keys and restores checks from the current successful page. Changing pages, page size, or refreshing the same data set keeps selected keys. Changing query, sort, or data scope clears them. Number 0 and string '0' are different keys. Only use cross-page operations for the explicitly selected keys.

The operation coordinator confirms exact permitted targets and checks version and permission before sending. Reuse the coordinator and operation ID to verify an unknown outcome. Retry only eligible targets from that operation record. Column preferences are saved through the adapter you provide.

<template>
	<div class="pro-example-stack">

	</div>

<script setup lang="ts">
import { onBeforeUnmount } from 'vue';
import { createAsamDataRuntime } from '@asam-ui/ui';
import {
	AsamOperationsTable,
	useAsamColumnPreferences,
	useAsamCrossPageSelection,
	useAsamListController
} from '@asam-ui/pro/components';

type Row = { id: number; name: string; status: string };
const records: Row[] = Array.from({ length: 12 }, (_, index) => ({
	id: index + 1,
	name: '项目 ' + (index + 1),
	status: '进行中'
}));
const runtime = createAsamDataRuntime();
const controller = useAsamListController<Row>({
	runtime,
	rowKey: 'id',
	fields: [],
	initial: {},
	pageSize: 10,
	api: async ({ currentPage, pageSize }) => ({
		list: records.slice((currentPage - 1) * pageSize, currentPage * pageSize),
		total: records.length
	})
});
const columns = [
	{ key: 'id', label: '编号' },
	{ key: 'name', label: '项目名称' },
	{ key: 'status', label: '状态' }
] as const;

const selection = useAsamCrossPageSelection({ controller, dataset: 'projects' });
const preferences = useAsamColumnPreferences<Row>({
	columns,
	scope: { application: 'docs', principal: 'visitor', table: 'projects', version: '1' },
	adapter: { load: async () => null, save: async () => {}, reset: async () => {} }
});
onBeforeUnmount(() => {
	selection.dispose();
	preferences.dispose();
	runtime.invalidate();
});
</script>

Component API ​

Read the full generated API.

Props ​

Props Purpose
controller, selection, coordinator, preferences Connect the application-owned list and capabilities.
operations, operationId, actions, rowActions Define table and row actions and provide operation IDs.
size, tableSize, widthMode, pagination, stripe, border Configure controls, row density, width, pagination, and table appearance.
columnSettings, columnSettingsDisabled, resizable Configure column preferences and resizing.
actionColumnWidth, actionColumnFixed, rowActionSize, rowActionOverflow Configure the row-action column and its controls.

Events ​

row-dblclick handles row double-clicks, expand-change reports table expansion, and update:border updates the border binding.

Slots ​

Use toolbar, tools, and tools-end to extend the toolbar. cell and rowActions customize row content. error, empty, and record customize data and operation states.

Exposed instance ​

clearSelection clears selection and loadPreferences loads current column preferences.
