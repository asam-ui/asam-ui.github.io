Collaboration records and details ​

Filter and sort collaboration records, then open a row's basic details or workflow history. The three editable layouts share a query table and the same records and read-only detail contracts.

Use and API ​

Start the standalone example with mountDetailApplication from Application.ts. To integrate the pages into an existing host, supply its router, runtime, and DetailServices. The list uses the public AsamCrudPage in query-table mode. Basic details render fields through AsamFieldView, and workflow details read their own flow data.

API and behavior

The template's public source types are in Types.ts, the synthetic service contract in Service.ts, and configuration in Config.ts.

Entry Responsibility
mountDetailApplication Mounts the standalone demo on a selector or element and supplies app, context, faults, audit, and router
detailApplicationKey Injects the detail application into its pages and shares the runtime with field views
DetailServices.list Reads an AsamPage using the list request, context, and read identity
DetailServices.detail Reads a typed record and returns ready, missing, or forbidden data through the detail protocol
DetailServices.flow Returns ordered steps, history, and related content through FlowData
DetailServices.dictionary Reads typed values and labels through the options protocol
DetailServices.resolve Resolves resource metadata for stable IDs and accepts an abort signal
beforeAction Notifies the host synchronously and rechecks access before the action continues
useListPage and useDetailPage Bind the layout to its page state and handle reads, refresh, navigation, and disposal of page-owned resources
safeReturn, parseId, and idKey Restrict list return paths and preserve typed record identity
Routes and host lifecycle ​

The Vue Router example uses hash history. Register /{family}/list, /{family}/detail/{number|string}/{id}, and /{family}/flow/{number|string}/{id} for the minimal, brand, and tech layouts. Encode IDs when constructing a route. returnTo accepts one registered list path without a query or hash.

PageAccess combines identity, scope, revision, service reference, and runtime epoch to isolate reads. Keep the scope consistent with the runtime and call runtime.setScope when changing it. A borrowed controller is bound to the original explicit session. When the target or access boundary changes, remount with a new key and matching host-owned controller. The standalone pages create their own controllers. Read-only changes retain existing reads, while disabled or revoked access stops the affected page work.

The pages recheck access after a synchronous host callback and before services or navigation. An obsolete completion cannot update the active target. The host owns the runtime and borrowed instances. Pages release their own context, list scope, and detail controller.

Workflow tabs and sizes ​

FlowSections accepts data, loading, error, tab, and disabled. It emits select(tab) and retry(). The active tab is the keyboard tab stop, with Left, Right, Home, and End navigation. Enter and Space activate a focused tab. An invalid selection or session change restores Overview. The initial read returns all tab content and switching tabs uses that data.

The application provider supplies the large, big, default, and small control sizes at 40, 36, 32, and 28 px. Use typed converters when migrating record IDs, dates, resource values, or other DTO fields.

Usage

Copy the full directory to edit any of the nine pages. Each layout offers a query list, a basic detail page, and a workflow detail page.

Use the matching UI and Pro packages, Vue, Element Plus, and Vue Router from the complete project. Load the Element Plus base stylesheet first, followed by the UI and Pro styles. For a standalone start, import mountDetailApplication from Application.ts and call mountDetailApplication('#app'). An existing host supplies its own router, runtime, and services. See the route and service API.

Query and detail flow ​

The example has 100 local records, 20 records per page, six data columns, and four query fields. Each layout uses the public AsamCrudPage in query-table mode. useAsamReadonlyCrudController wraps the active list session so querying, sorting, pagination, retry, and list return share the same successful source.

Numeric 0 and string '0' are different record IDs. The status dictionary preserves typed values. When a value has no label, the page displays the original value with an explicit cue. Date filters use YYYY-MM-DD and allow either inclusive endpoint to be omitted. Workflow times use UTC ISO timestamps.

Basic details use useAsamDetail, AsamDetailPanel, and field modes to display 12 fields in three groups. The panel slot hosts the field view using a projection that leaves the controller's full field state intact. Refresh clears the previous data and offers retry on failure. Workflow details load a separate flow endpoint with three tabs, five steps, and eight entries in the local example.

Returning to the list restores its last successful typed query, page size, sorting, and page. A new draft or a change of scope invalidates that restoration. Reloading or opening a detail URL directly returns to the current layout's default list. The app accepts only its three registered list paths as return targets.

Preview controls and layout ​

Use the local controls to simulate errors, missing or forbidden records, read-only and disabled access, or a change of identity, scope, revision, or service. Read-only access permits reads and return navigation. Disabled access pauses new reads, tabs, and navigation. The page releases its own requests and controllers. The host releases borrowed resources.

The Minimal and Brand layouts follow the parent theme, and Tech retains its dark surface. Narrow viewports use a single column and local table scrolling. Reduced motion turns off the short entrance transition.

Types.ts · Type source
ts
import type { InjectionKey } from 'vue';
import type { Router } from 'vue-router';
import type { AsamDataRuntime, AsamPage, AsamRequestContext, AsamControlSize } from '@asam-ui/ui';
import type { AsamDetailResult, AsamListIntent, AsamListRequest } from '@asam-ui/pro';

export type RecordId = string | number;
export type Family = 'minimal' | 'brand' | 'tech';
export type PageKind = 'list' | 'detail' | 'flow';
export type FlowTab = 'overview' | 'history' | 'related';
export interface RecordRow {
	readonly id: RecordId;
	readonly title: string;
	readonly owner: string;
	readonly organization: string;
	readonly state: string | number;
	readonly created: string;
}
export interface ReadIdentity {
	readonly identity: string;
	readonly scope: string;
	readonly revision: number;
}
export interface FlowStep {
	readonly id: string;
	readonly name: string;
	readonly state: 'done' | 'current' | 'waiting' | 'unknown';
}
export interface FlowRecord {
	readonly id: string;
	readonly actor: string;
	readonly at: string | null;
	readonly result: string;
	readonly state: string;
}
export interface FlowData {
	readonly stage: string;
	readonly steps: readonly FlowStep[];
	readonly records: readonly FlowRecord[];
	readonly related: readonly {
		readonly id: string;
		readonly title: string;
		readonly note: string;
	}[];
}
export interface DetailServices {
	dictionary(
		context: AsamRequestContext,
		identity: ReadIdentity
	): Promise<readonly { value: string | number; label: string }[]>;
	list(
		request: AsamListRequest,
		context: AsamRequestContext,
		identity: ReadIdentity
	): Promise<AsamPage<RecordRow>>;
	detail(
		id: RecordId,
		context: AsamRequestContext,
		identity: ReadIdentity
	): Promise<AsamDetailResult>;
	flow(id: RecordId, context: AsamRequestContext, identity: ReadIdentity): Promise<FlowData>;
	resolve(
		ids: readonly RecordId[],
		signal: AbortSignal
	): Promise<readonly { id: RecordId; name: string }[]>;
}
export interface PageAccess extends ReadIdentity {
	identity: string;
	scope: string;
	revision: number;
	disabled: boolean;
	readonly: boolean;
	allowed: boolean;
}
export interface ReturnState extends ReadIdentity {
	readonly epoch: number;
	readonly services: DetailServices;
	readonly target: string;
	readonly intent: AsamListIntent;
}
export interface DetailApplication {
	readonly runtime: AsamDataRuntime;
	readonly router: Router;
	readonly access: PageAccess;
	services: DetailServices;
	size: AsamControlSize;
	dark: boolean;
	returnState: ReturnState | null;
	/** 同步宿主通知，回调可能重入并修改身份/权限。回调后必须重新核门禁。 */
	beforeAction?: (action: string) => void;
}
export const detailApplicationKey: InjectionKey<DetailApplication> =
	Symbol('ASAM detail application');
