Editor form ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

AsamEditorForm renders grouped fields and their validation inside a page. It shares the field layout used by the edit dialog and the edit drawer.

When to use it ​

Choose a controller-backed form when an existing editor controller owns loading, validation, save state, and the current edit session. Pass that controller to the form. Its default layout uses two columns and drops to one as the container narrows.

Use fields and v-model if the application owns the draft and save flow. Call the instance's validate() before saving, then use focusField() to direct users to an invalid field. In the controlled example, Reset restores the last saved values and starts a new form session. The application can provide its own action buttons.

Examples ​

The examples and source viewer are included on this page.

<template>
	<div class="pro-example-stack">
		<AsamEditorForm
			ref="form"
			v-model="draft"
			:fields="fields"
			:session="session"
			:disabled="saving"
			@submit="save"
		/>
		<div class="pro-example-row">
			<AsamButton type="default" :disabled="saving" @click="reset">重置</AsamButton>
			<AsamButton type="primary" :disabled="saving" @click="save">保存资料</AsamButton>
		</div>
		<p role="status">{{ message }}</p>
	</div>
</template>

<script setup lang="ts">
import { shallowRef } from 'vue';
import { AsamButton } from '@asam-ui/ui';
import { AsamEditorForm } from '@asam-ui/pro/components';
import type { AsamEditorFormExpose, AsamFieldModel } from '@asam-ui/pro/components';
import { createProject, createProjectFields } from './shared/project.js';

defineOptions({ name: 'ControlledEditorFormExample' });

const fields = createProjectFields();
let saved: AsamFieldModel = createProject();
const draft = shallowRef(structuredClone(saved));
const form = shallowRef<AsamEditorFormExpose>();
const session = shallowRef(0);
const saving = shallowRef(false);
const message = shallowRef('重置会恢复到上次保存的值，首次保存前恢复初始资料。');

function reset() {
	if (saving.value) return;
	draft.value = structuredClone(saved);
	session.value++;
	message.value = '已恢复项目资料。';
}

async function save() {
	if (saving.value || !form.value) return;
	saving.value = true;
	let invalidField: string | undefined;
	try {
		const [issue] = await form.value.validate();
		if (issue) {
			invalidField = issue.key;
			message.value = '请检查表单中标出的字段。';
			return;
		}
		saved = structuredClone(draft.value);
		message.value = '项目资料已保存。';
	} finally {
		saving.value = false;
		if (invalidField) await form.value?.focusField(invalidField);
	}
}
</script>

		{
			key: 'stage',

			kind: 'textarea',

		}
	];

Grouped editing in a page ​

See the controlled draft, custom Save and Reset buttons, and field validation. Open the controlled example.

Example: controller

Example source ZIPComplete project ZIP
vue
<template>
	<div class="pro-example-stack">
		<div v-if="!editor.visible.value" class="pro-example-row">
			<AsamButton type="primary" @click="open">加载项目</AsamButton>
		</div>
		<AsamEditorForm
			v-if="editor.visible.value"
			:controller="editor"
			save-button-type="primary"
			cancel-button-type="secondary"
		>
			<template #append>
				<AsamButton type="secondary" :disabled="!canEdit" @click="reset">重置</AsamButton>
			</template>
		</AsamEditorForm>
		<p role="status">{{ message }}</p>
	</div>
</template>

<script setup lang="ts">
import { computed, onBeforeUnmount, shallowRef } from 'vue';
import { AsamButton, createAsamDataRuntime, AsamMessageBox } from '@asam-ui/ui';
import { AsamEditorForm, useAsamEditor, createAsamWriteCoordinator } from '@asam-ui/pro/components';
import type { AsamFieldModel } from '@asam-ui/pro/components';
import { createProject, createProjectFields } from './shared/project.js';

defineOptions({ name: 'ControllerEditorFormExample' });

const runtime = createAsamDataRuntime();
let saved: AsamFieldModel = createProject();
const message = shallowRef('加载项目后可编辑资料，重置会恢复本次加载的值。');
const editor = useAsamEditor({
	fields: createProjectFields(),
	runtime,
	coordinator: createAsamWriteCoordinator(),
	// 这三个自定义字段的模型分别是日期字符串、数字和布尔值。
	equals: { due: Object.is, teamSize: Object.is, notifyMembers: Object.is },
	load: async () => structuredClone(saved),
	save: async (payload) => {
		saved = structuredClone(payload);
		return { status: 'success' };
	},
	onSaved: () => {
		message.value = '项目资料已保存，重新加载可查看保存结果。';
	},
	confirmDiscard: () =>
		AsamMessageBox.confirm('放弃尚未保存的内容？', '关闭编辑').then(
			() => true,
			() => false
		)
});
const canEdit = computed(() => editor.status.value === 'editing' && editor.writable.value);

let operation = 0;
async function open() {
	await editor.open({ mode: 'edit', id: 1, operationId: 'inline-' + ++operation });
	if (canEdit.value) message.value = '已加载项目资料。';
}
async function reset() {
	if (!canEdit.value) return;
	// 示例的数据源保留当前已保存快照，重新加载会重建草稿和校验状态。
	await editor.reload();
	if (canEdit.value) message.value = '已恢复本次加载的项目资料。';
}

onBeforeUnmount(() => {
	editor.dispose();
	runtime.invalidate();
});
</script>

Two-way binding ​

In controlled mode, bind the model with v-model. The form emits update:modelValue with the draft model.

Read the full generated API.

Props ​

Props Purpose
controller Reuse an existing editor controller.
fields, modelValue, session, issues Provide field definitions and application-owned draft state.
columns, fieldLabels, size, autoFocus Configure the form layout, labels, control size, and initial focus.
readonly, disabled, busy, active Set the form interaction state.
showActions, saveButtonType, cancelButtonType, cancelButtonPlain Configure the built-in actions.

Events ​

update:modelValue carries draft changes. submit is the form's submission event.

Slots ​

error-help and unknown-help customize help for the corresponding states. append adds content to the form.

Exposed instance ​

focusInitial and focusField place focus. validate runs field validation.
