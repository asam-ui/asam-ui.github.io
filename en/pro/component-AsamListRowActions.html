Standalone list row actions ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

AsamListRowActions renders row actions from an existing list controller in a tree table or a custom list.

When to use it ​

Pass the original row from the controller's current successful result together with the original AsamListAction definitions. The actions use the small size by default and stay on one line. When there are more than three actions or the column is too narrow, extra actions move into the More menu.

The component presents actions from the existing list. Permission, confirmation, and detail handling stay with the original list controller and action definitions.

Standalone actions and overflow ​

Use the controller and its public actions to render a single row of controls with overflow. Action availability follows the current list context.

<template>
	<div class="pro-example-stack">
		<p>同一行四个动作，空间足够时显示两项和更多；只传当前成功结果的原行。</p>
		<div v-if="row" style="width: 260px">
			<AsamListRowActions :controller="list" :row="row" :actions="actions" />
		</div>
		<p role="status">{{ message }}</p>
	</div>
</template>
<script setup lang="ts">
import { computed, onBeforeUnmount, ref } from 'vue';
import { createAsamDataRuntime } from '@asam-ui/ui';
import { AsamListRowActions, useAsamListController } from '@asam-ui/pro/components';
import type { AsamListAction } from '@asam-ui/pro/components';
defineOptions({ name: 'ListRowActionsExample' });
type Row = { id: number; name: string };
const runtime = createAsamDataRuntime();
const message = ref('尚未执行动作');
const list = useAsamListController<Row>({
	runtime,
	rowKey: 'id',
	initial: {},
	fields: [],
	api: async () => ({ list: [{ id: 0, name: '合成项目' }], total: 1 })
});
const row = computed(() => list.page.data.value.list[0]);
const actions: readonly AsamListAction<Row>[] = ['详情', '编辑', '授权', '删除'].map(
	(label, index) => ({
		id: `action-${index}`,
		label,
		button: { type: index === 3 ? 'danger' : 'primary', plain: true },
		run: async ({ row }) => {
			message.value = `${label}：${row?.name}`;
		}
	})
);
onBeforeUnmount(() => runtime.invalidate());
void list.submit();
</script>

Resolve the original row in a tree table ​

Use the table’s cell slot to render the action column. Map the displayed tree row to its original row in the controller’s current result. Pass that row to the action component so context checks still apply.

Example: structured

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<div class="pro-example-stack">
		<p>树投影通过 typed key 回到列表原行，保留层级和独立行操作。</p>
		<AsamStructuredTable mode="tree" :controller="tree" :columns="columns">
			<template #cell="{ row, column }">
				<template v-if="column.key === 'actions'">
					<AsamListRowActions
						v-if="canonical.get(row.id)"
						:controller="list"
						:row="canonicalRow(row.id)"
						:actions="actions"
					/>
				</template>
				<span v-else>{{ row.name }}</span>
			</template>
		</AsamStructuredTable>
		<p role="status">{{ message }}</p>
	</div>
</template>
<script setup lang="ts">
import { computed, onBeforeUnmount, ref } from 'vue';
import { createAsamDataRuntime } from '@asam-ui/ui';
import {
	AsamListRowActions,
	AsamStructuredTable,
	useAsamListController,
	useAsamStructuredTable
} from '@asam-ui/pro/components';
import type { AsamListAction, AsamStructuredColumn } from '@asam-ui/pro/components';
type Row = { id: string | number; name: string; parent?: string | number };
defineOptions({ name: 'StructuredRowActionsExample' });
type Node = Row & { children?: Node[]; actions?: never };
const runtime = createAsamDataRuntime();
const message = ref('尚未执行动作');
const list = useAsamListController<Row>({
	runtime,
	rowKey: 'id',
	initial: {},
	fields: [],
	api: async () => ({
		list: [
			{ id: 0, name: '父节点' },
			{ id: '0', parent: 0, name: '子节点（字符串键）' }
		],
		total: 2
	})
});
const canonical = computed(() => new Map(list.page.data.value.list.map((row) => [row.id, row])));
// 模板保留运行表达式；类型断言放在脚本内，使 TS/JS 投影共享同一取行逻辑。
const canonicalRow = (id: Row['id']) => canonical.value.get(id)!;
const nodes = computed<Node[]>(() =>
	list.page.data.value.list
		.filter((row) => row.parent === undefined)
		.map((row) => ({
			...row,
			children: list.page.data.value.list
				.filter((child) => Object.is(child.parent, row.id))
				.map((child) => ({ ...child }))
		}))
);
const tree = useAsamStructuredTable<Node>({
	rows: nodes,
	scope: () => String(list.session.value),
	rowKey: 'id',
	mode: 'tree',
	children: 'children',
	initialExpandedKeys: [0]
});
const columns: readonly AsamStructuredColumn<Node>[] = [
	{ key: 'name', label: '名称' },
	{ key: 'actions', label: '操作', width: 260 }
];
const actions: readonly AsamListAction<Row>[] = ['详情', '编辑', '添加子项', '删除'].map(
	(label, index) => ({
		id: `action-${index}`,
		label,
		button: { type: index === 3 ? 'danger' : 'primary', plain: true },
		run: async ({ row }) => {
			const current = row && canonical.value.get(row.id);
			if (current) message.value = `${label}：${current.name}`;
		}
	})
);
onBeforeUnmount(() => runtime.invalidate());
void list.submit();
</script>
