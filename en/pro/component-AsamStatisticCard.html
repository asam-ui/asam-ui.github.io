Statistic card ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

AsamStatisticCard combines a metric, its unit, a trend, and supporting text in a card.

When to use it ​

Give the metric a label. Pass an application-computed number in value, set its display precision and unit, and add a helper when the number needs context. Use status to reflect loading, empty, or error states. Set animated for a display transition. Calculations stay in the application.

Show a metric with a unit ​

The example displays a revenue figure with a unit and helper text. Select the replay button to run the value animation again. The duration option controls the animation time. The value slot receives the raw value if you need custom rendering.

Example: basic

<template>
	<div class="pro-example-stack">
		<AsamCardGroup label="收入指标卡片">
			<AsamStatisticCard
				:key="playback"
				label="本月收入"
				:value="12345.6"
				:precision="2"
				unit="元"
				helper="按已完成订单统计"
				animated
				:duration="1200"
			/>
		</AsamCardGroup>
		<AsamButton type="primary" plain @click="playback++">重播数值动画</AsamButton>
	</div>
</template>

Add a trend and footer ​

Pass a trend configuration (Chinese) through trend. Specify both the direction of change and its business meaning. The example uses the footer slot to describe the comparison. Use extra for supplemental content in the card header.

Example: trend

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<AsamCardGroup label="趋势指标卡片">
		<AsamStatisticCard
			label="活跃项目"
			:value="128"
			animated
			:duration="1200"
			:trend="{ direction: 'up', tone: 'positive', value: 12.5, suffix: '%', precision: 1 }"
		>
			<template #footer>较上月</template>
		</AsamStatisticCard>
	</AsamCardGroup>
</template>

<script setup lang="ts">
