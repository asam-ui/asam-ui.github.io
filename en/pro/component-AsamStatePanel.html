State panel ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

AsamStatePanel communicates an application state and offers relevant recovery or follow-up actions.

When to use it ​

Provide a title for the result and a description to explain what the user can do. The application supplies actions and their callbacks. A success event means that the callback completed. Confirm the result in the application before reporting a server-side recovery.

Explain a state ​

Use tone to convey information, success, a warning, or an error. The example uses a warning with a short instruction to check the connection.

Offer recovery actions ​

Give each action a stable, unique id, a label, and a run callback. A pending callback disables the built-in actions and emits start, followed by success or failure if its result is still current. Change stateKey when the panel represents a different business object. Calling reset() also invalidates pending results, while callbacks that already started retain responsibility for their side effects. A custom actions slot receives the pending action ID and manages its own controls and feedback.

Example: actions

import { AsamStatePanel } from '@asam-ui/pro/components';

		id: 'reload',
		label: '重新读取',
		run: async () => {
			message.value = '已重新读取';
		}
	}

</script>

Style a primary action ​

Set button: { type: 'primary', plain: false } on an action to display a solid primary button. Omit button for the default outlined appearance. The example uses a solid primary action and a default secondary action, both with the same execution safeguards.

Example: primary-action

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<div class="pro-example-stack">
		<AsamStatePanel
			title="处理完成"
			description="本地演示主操作与默认次操作，业务导航由宿主提供。"
			tone="success"
			:actions="actions"
		/>
		<p role="status">{{ message }}</p>
	</div>
</template>
<script setup lang="ts">
import { ref } from 'vue';
import { AsamStatePanel } from '@asam-ui/pro/components';
import type { AsamStateAction } from '@asam-ui/pro/components';
defineOptions({ name: 'StatePanelPrimaryActionExample' });
const message = ref('');
const actions: readonly AsamStateAction[] = [
	{
		id: 'open',
		label: '查看记录',
		button: { type: 'primary', plain: false },
		run: async () => {
			message.value = '已选择查看记录';
		}
	},
	{
		id: 'back',
		label: '返回列表',
		run: async () => {
			message.value = '已选择返回列表';
		}
	}
];
</script>
