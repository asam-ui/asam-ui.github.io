Edit drawer ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

AsamFormDrawer presents an edit session in a side panel. It uses the same editor controller contract as the edit dialog.

When to use it ​

Use a drawer when users need more room to edit fields while retaining the context of the page that opened it. Mount one editing container per controller. The application owns the edit session and supplies load and save services through that controller.

After an interrupted or unknown save, verify the original operation. Keep the controller and operation record available while verification is pending.

Examples ​

The examples and source viewer are included on this page.

ts
import { onBeforeUnmount } from 'vue';
import { AsamMessageBox, createAsamDataRuntime } from '@asam-ui/ui';
import { createAsamWriteCoordinator, useAsamEditor } from '@asam-ui/pro/components';
import type { AsamFieldModel } from '@asam-ui/pro/components';
import { createProject, createProjectFields } from './project.js';

export function useProjectEditor() {
	const runtime = createAsamDataRuntime();
	let saved: AsamFieldModel = createProject();
	const controller = useAsamEditor({
		fields: createProjectFields(),
		runtime,
		coordinator: createAsamWriteCoordinator(),
		// 日期、人数和通知开关使用标量模型。
		equals: { due: Object.is, teamSize: Object.is, notifyMembers: Object.is },
		load: async () => structuredClone(saved),
		save: async (payload) => {
			saved = structuredClone(payload);
			return { status: 'success' };
		},
		confirmDiscard: () =>
			AsamMessageBox.confirm('放弃尚未保存的内容？', '关闭编辑').then(
				() => true,
				() => false
			)
	});
	let operation = 0;
	const open = () => controller.open({ mode: 'edit', id: 1, operationId: 'edit-' + ++operation });
	onBeforeUnmount(() => {
		controller.dispose();
		runtime.invalidate();
	});
	return { controller, open };
}

Component API ​

Read the full generated API.

Props ​

Pass controller. Set title, columns, fieldLabels, size, and width for the drawer and its fields. Use fallbackFocus to provide a focus target.

Slots ​

error-help, unknown-help, and append customize the editor content.

Exposed instance ​

The drawer instance exposes open, reload, submit, verify, close, and focusField.
