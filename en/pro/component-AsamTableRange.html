Table range ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

AsamTableRange lets users select cell ranges and copy, paste, find, or replace text within the current table projection.

Select and copy a range ​

The example starts with a range selected and displays its coordinates. Drag across cells or use Shift with clicks or arrow keys to extend a selection. Use Ctrl or Command to add another range. Copy through an explicit user action. If clipboard access is unavailable, use the manual text field.

Example: basic

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<div class="pro-example-stack">
		<p role="status">{{ selectionSummary }}</p>
		<AsamTableRange :controller="controller" title="项目数据范围" />
	</div>
</template>

<script setup lang="ts">
import { computed, onBeforeUnmount, ref, watch } from 'vue';
import { AsamTableRange, createAsamFieldModes, useAsamTableRange } from '@asam-ui/pro/components';
import type { AsamFieldDefinition, AsamRangeColumn } from '@asam-ui/pro/components';
interface Row {
	id: number;
	name: string;
	owner: string;
	status: string;
	budget: string;
	startDate: string;
}
const rows = ref<Row[]>(
	Array.from({ length: 16 }, (_, i) => ({
		id: i + 1,
		name: '项目 ' + (i + 1),
		owner: ['陈晨', '林悦', '张远'][i % 3] ?? '陈晨',
		status: i % 3 ? '进行中' : '待启动',
		budget: String(30000 + i * 5000),
		startDate: '2026-05-' + String(i + 1).padStart(2, '0')
	}))
);
const fields: AsamFieldDefinition[] = [
	{ key: 'id', kind: 'text', label: '编号' },
	{ key: 'name', kind: 'text', label: '项目名称' },
	{ key: 'owner', kind: 'text', label: '负责人' },
	{ key: 'status', kind: 'text', label: '状态' },
	{ key: 'budget', kind: 'text', label: '预算（元）' },
	{ key: 'startDate', kind: 'text', label: '开始日期' }
];
const modes = createAsamFieldModes({
	bindings: fields.map((field) => ({ field })),
	submit: fields.map((field) => ({ field: field.key, output: field.key }))
});
const columns: AsamRangeColumn<Row>[] = [
	{ field: 'id', label: '编号', writable: false, read: async (row) => String(row.id) },
	{ field: 'name', label: '项目名称', read: async (row) => row.name },
	{ field: 'owner', label: '负责人', read: async (row) => row.owner },
	{ field: 'status', label: '状态', read: async (row) => row.status },
	{ field: 'budget', label: '预算（元）', read: async (row) => row.budget },
	{ field: 'startDate', label: '开始日期', read: async (row) => row.startDate }
];
const revision = ref(0);
const controller = useAsamTableRange<Row>({
	projection: () => ({ rows: rows.value, columns, revision: revision.value }),
	keyOf: (row) => row.id,
	scope: () => 'projects',
	identity: () => 'visitor',
	modes,
	readonly: () => false,
	operationId: (draft, key) => 'range-' + draft + '-' + key,
	refresh: async () => {
		revision.value++;
	},
	external: {
		prepare: async (operation, context) => async () => {
			if (!context.canCommit()) return { status: 'not-applied', message: '操作已取消' };
			const row = rows.value.find((row) => row.id === operation.row.key);
			if (!row) return { status: 'not-applied', message: '项目不存在' };
			Object.assign(row, operation.row.payload);
			return { status: 'success' };
		}
	}
});
let initialized = false;
watch(
	controller.readable,
	(ready) => {
		if (!ready || initialized) return;
		initialized = true;
		controller.select({ row: 1, column: 1 });
		controller.select({ row: 4, column: 3 }, { extend: true });
	},
	{ immediate: true }
);
const selectionSummary = computed(() =>
	controller.ranges.value.length
		? '已选区域：' +
			controller.ranges.value
				.map(({ start, end }) => {
					const firstRow = Math.min(start.row, end.row) + 1,
						lastRow = Math.max(start.row, end.row) + 1;
					const firstColumn = Math.min(start.column, end.column) + 1,
						lastColumn = Math.max(start.column, end.column) + 1;
					return (
						'第 ' +
						firstRow +
						'–' +
						lastRow +
						' 行，第 ' +
						firstColumn +
						'–' +
						lastColumn +
						' 列（' +
						(lastRow - firstRow + 1) * (lastColumn - firstColumn + 1) +
						' 格）'
					);
				})
				.join('；')
		: '未选择区域'
);
onBeforeUnmount(() => controller.dispose());
</script>

When to use it ​

Create a controller with useAsamTableRange and supply the current rows, columns, and revision as an explicit projection with stable row keys. Change the revision when in-place data or permissions change. The projection supports up to 100 rows and 100 columns, with a maximum of 10,000 cells and 16 selected ranges. Cross-page operations and XLSX import or export are outside this text workflow.

Copy and find use the explicitly exposed column text. Search covers the current projection or the selected ranges. Read-only mode allows selection and reading. Paste and replace preview their changes as a draft, which users can undo or redo before applying it. The host supplies the writer. Keep an operation ID stable for retries or verification of the same draft, and check context.canCommit() after the final asynchronous preparation step and before sending the write.

See the generated API reference for the component's public contract.
