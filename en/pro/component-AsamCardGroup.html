Card group ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

AsamCardGroup arranges slotted cards according to the available width.

When to use it ​

Group related cards and set the required label to give the region an accessible name. Use minWidth to control when cards wrap to the next row, or choose cardSize for the card geometry. The default slot accepts the cards you want to group.

Responsive grouping ​

The example groups AsamDisplayCard (Chinese) instances. The number of cards that fit side by side follows the width of the group.

Minimum card width ​

Set minWidth in pixels to control the minimum card width. With neither minWidth nor cardSize supplied, the minimum is 240 px. Finite values below 120 px are raised to 120 px. An explicit minimum takes precedence over the size preset, while the preset or custom geometry supplies the minimum when minWidth is omitted.

Card geometry and masonry ​

Choose the small, default, big, or large geometry preset, or supply a custom size object. Card geometry is independent of the size of controls inside each card. Use columns to select automatic fitting or a fixed column count, maxWidth to cap card width, and gap to set the spacing. Choose layout="masonry" for cards of varying heights. Automatic columns can shrink to the available width. Layout changes preserve card instances, focus, and data order.

The example switches between grid and masonry, changes the column count and width cap, and adds cards or images to show how the layout responds to changing content.

Example: geometry

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<section class="card-geometry-example">
		<div class="card-geometry-controls">
			<AsamButton
				v-for="preset in presets"
				:key="preset"
				type="primary"
				@click="cardSize = preset"
			>
				{{ preset }}
			</AsamButton>
			<AsamButton type="primary" @click="cardSize = custom">自定义尺寸</AsamButton>
			<AsamButton type="primary" @click="layout = layout === 'grid' ? 'masonry' : 'grid'">
				切换网格与瀑布流
			</AsamButton>
			<AsamButton type="primary" @click="columns = columns === 'auto' ? 3 : 'auto'">
				切换自动与三列
			</AsamButton>
			<AsamButton type="primary" @click="maxWidth = maxWidth ? undefined : 340">
				切换最大宽度
			</AsamButton>
			<AsamButton type="primary" @click="count += 4">追加四项</AsamButton>
			<AsamButton type="primary" @click="media = !media">切换图片</AsamButton>
		</div>
		<p role="status">
			{{ layout }} · {{ columns }} · {{ typeof cardSize === 'string' ? cardSize : '自定义' }}
		</p>
		<AsamCardGroup
			label="卡片几何与瀑布流"
			:card-size="cardSize"
			:columns="columns"
			:layout="layout"
			:max-width="maxWidth"
		>
			<AsamDisplayCard
				v-for="index in count"
				:key="index"
				:title="`项目 ${index} · 随内容自然换行的标题`"
			>
				<img v-if="media && index % 3 === 1" :src="image" alt="蓝色几何示意图" />
				<p v-for="line in (index % 5) + 1" :key="line">
					内容 {{ line }}：卡片使用同一数据顺序，布局切换保留控件和选择。
				</p>
				<template #footer>
					<AsamButton type="primary">查看项目 {{ index }}</AsamButton>
				</template>
			</AsamDisplayCard>
		</AsamCardGroup>
	</section>
</template>
<script setup lang="ts">
import { ref } from 'vue';
import { AsamButton } from '@asam-ui/ui';
import type { AsamCardLayout, AsamCardPreset, AsamCardSize } from '@asam-ui/ui';
import { AsamCardGroup, AsamDisplayCard } from '@asam-ui/pro/components';

defineOptions({ name: 'CardGeometryExample' });

const presets: AsamCardPreset[] = ['small', 'default', 'big', 'large'];
const custom = {
	minWidth: 270,
	minHeight: 120,
	padding: 18,
	titleFontSize: 17,
	bodyFontSize: 14,
	contentGap: 12
};
const cardSize = ref<AsamCardSize>('default');
const layout = ref<AsamCardLayout>('grid');
const columns = ref<'auto' | number>('auto');
const maxWidth = ref<number>();
const count = ref(8);
const media = ref(false);
const image =
	'data:image/svg+xml,' +
	encodeURIComponent(
		'<svg xmlns="http://www.w3.org/2000/svg" width="600" height="320"><rect width="600" height="320" fill="#dce8fb"/><circle cx="300" cy="160" r="96" fill="#2d6bd6"/></svg>'
	);
</script>
<style scoped>
.card-geometry-example {
	min-width: 0;
}

.card-geometry-controls {
	display: flex;
	flex-wrap: wrap;
	gap: 8px;
}

img {
	display: block;
	max-width: 100%;
	height: auto;
}
</style>
