Structured table ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

AsamStructuredTable displays flat data, tree data, or tree data with lazy loading.

When to use it ​

Flat mode supports validated cell merges. Set the summary's data scope explicitly. Pass the structured data controller with controller and the displayed columns with columns. For cell editing, virtual rows, or range operations, use Editable table (Chinese), Pro virtual table (Chinese), or Table range for the relevant workflow.

Flat data ​

Use mode to select the flat layout and supply a stable rowKey for each record.

Example: flat

<template>

<script setup lang="ts">
import { AsamStructuredTable } from '@asam-ui/pro/components';
import { onBeforeUnmount } from 'vue';
import { useAsamStructuredTable } from '@asam-ui/pro/components';
const rows = [
	{ id: 1, name: '设计项目' },
	{ id: 3, name: '开发项目' }
];
const controller = useAsamStructuredTable({ rows, rowKey: 'id', scope: 'projects', mode: 'flat' });
const columns = [{ key: 'name', label: '项目名称' }] as const;
onBeforeUnmount(() => controller.dispose());
</script>

Load child nodes on demand ​

Use mode="lazy-tree" to load children when a parent is expanded. Use the arrow control or the keyboard to expand the row.

Example: lazy

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<div class="pro-example-stack">
		<AsamStructuredTable :controller="controller" :columns="columns" mode="lazy-tree" />
	</div>
</template>

<script setup lang="ts">
import { AsamStructuredTable, useAsamStructuredTable } from '@asam-ui/pro/components';
import { onBeforeUnmount } from 'vue';

type Project = { id: string; name: string; branch?: boolean };
const rows: Project[] = [{ id: 'platform', name: '平台建设', branch: true }];
const columns = [{ key: 'name', label: '项目名称' }] as const;
const controller = useAsamStructuredTable<Project>({
	rows,
	rowKey: 'id',
	scope: 'lazy-projects',
	mode: 'lazy-tree',
	hasChildren: (row) => row.branch === true,
	loader: async (parent, { signal }) => {
		await new Promise<void>((resolve) => setTimeout(resolve, 300));
		signal.throwIfAborted();
		return [{ id: `${parent.id}-review`, name: '平台建设 · 评审' }];
	}
});
onBeforeUnmount(() => controller.dispose());
</script>
