Loading Service ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Call the service to create a loading instance, then keep its handle to update the message or close the mask.

Create, update, and close an instance ​

Limit the mask to the current target. On unmount, release the instances you created.

Example: basic

	<div class="actions">
		<AsamButton type="primary" native-type="button" @click="start">启动加载</AsamButton>

			更新加载文字

		<AsamButton type="default" native-type="button" @click="stop">结束加载</AsamButton>

		<p class="example-paragraph">服务目标区域</p>
	</div>

<script lang="ts" setup>
defineOptions({ name: 'AsamLoadingServiceBasicDemo' });
import { ref, onBeforeUnmount } from 'vue';
import { AsamButton, AsamLoadingService } from '@asam-ui/ui';
import type { AsamLoadingInstance } from '@asam-ui/ui';
const target = ref<HTMLElement>();
let handle: AsamLoadingInstance | undefined;
const stop = () => {
	handle?.close();
	handle = undefined;
};
const start = () => {
	if (!target.value || handle) return;
	handle = AsamLoadingService({ target: target.value, fullscreen: false, text: '正在加载' });
};
onBeforeUnmount(stop);
</script>

Usage conventions ​

The service returns a live instance with setText and close. The options control its visibility and mounting scope. See the usage conventions.

Composition and lifecycle ​

In 2.14.7, $el and vm return null after the instance closes and is destroyed. Save the DOM reference before closing if you need it after removal. See composition and lifecycle.

Host app context and service cleanup ​

This example closes only the instances it creates. The host can provide service content through app.provide('asam-service-label', value) and pass the current AppContext explicitly.

<template>
	<div class="actions">
		<AsamButton native-type="submit" type="primary" @click="open">
			显示带宿主上下文的服务
		</AsamButton>
		<AsamButton native-type="submit" type="default" @click="close">关闭本例服务</AsamButton>

<script lang="ts" setup>
import { defineComponent, getCurrentInstance, h, inject, onBeforeUnmount, ref } from 'vue';
import { AsamButton, AsamLoadingService, AsamMessage, AsamNotification } from '@asam-ui/ui';
import type { AsamLoadingInstance, AsamMessageHandler, AsamNotificationHandle } from '@asam-ui/ui';
const context = getCurrentInstance()?.appContext;
const target = ref<HTMLElement>();
const handles: Array<AsamMessageHandler | AsamNotificationHandle> = [];
let loading: AsamLoadingInstance | undefined;
const Label = defineComponent({
	setup() {
		const label = inject<string>('asam-service-label', '当前宿主的服务内容');
		return () => h('span', label);
	}
});
const close = () => {
	handles.splice(0).forEach((handle) => handle.close());
	loading?.close();
	loading = undefined;
};
const open = () => {
	close();
	handles.push(AsamMessage({ message: h(Label), duration: 0 }, context));
	handles.push(
		AsamNotification(
			{ title: '宿主上下文', message: h(Label), duration: 0, progress: true },
			context
		)
	);
	if (target.value)
		loading = AsamLoadingService(
			{ target: target.value, text: '局部处理', fullscreen: false },
			context
		);
};
onBeforeUnmount(close);
</script>

Fullscreen loading with automatic dismissal ​

Omit target to use fullscreen loading. This example closes its instance after 1.5 seconds and cleans up on unmount.

Example: fullscreen

Example source ZIPComplete project ZIP
vue
<template>
	<AsamButton type="primary" @click="start">显示全屏加载</AsamButton>
	<p class="example-paragraph">锁定页面滚动，1.5 秒后自动结束；卸载时也会清理。</p>
</template>

<script lang="ts" setup>
import { onBeforeUnmount } from 'vue';
import { AsamButton, AsamLoadingService } from '@asam-ui/ui';
let handle: ReturnType<typeof AsamLoadingService> | undefined;
let timer: ReturnType<typeof setTimeout> | undefined;
const stop = () => {
	clearTimeout(timer);
	handle?.close();
	handle = undefined;
};
const start = () => {
	stop();
	handle = AsamLoadingService({ fullscreen: true, lock: true, text: '全屏加载中，稍后自动结束' });
	timer = setTimeout(stop, 1500);
};
onBeforeUnmount(stop);
</script>

Additional usage and API details ​

Composition and lifecycle ​

In 2.14.7, $el and vm return null after the instance closes and is destroyed. Save the DOM reference before closing if you need it after removal. customClass accepts a writable string ref that remains live. ASAM adds its styling class and color variables when creating the instance. Later customClass updates follow native class handling and retain the color variables. Return false from beforeClose to prevent closing. closed runs after the instance closes. Pass an explicit AppContext to use host injections. The caller owns the returned handle.

More on options and events ​

Usage conventions ​

AsamLoadingService(options, appContext?) returns a live instance. Call setText to update the message and close to dismiss the mask. See the API for text, visible, and background refs and the vm and DOM handles. target selects the element. fullscreen, body, and lock determine the scope of the mask and scrolling. beforeClose can prevent closing, and closed reports completion. The default fullscreen service can reuse an instance when target is omitted, so coordinate ownership among callers. ASAM adds its styling class automatically. The service has no size option. Close instances you own on unmount and in the finally block of asynchronous work.
