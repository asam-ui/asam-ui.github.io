Popper ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Provide a shared positioning context for the trigger, content, and arrow.

Composing a trigger, content, and arrow ​

Focus and hover control the public visible prop. The complete SFC combines all four parts.

	<AsamPopper role="tooltip">

		</AsamPopperContent>

</template>

Usage conventions ​

role defines the popup's semantics. Place the trigger and content together in the default slot. The public triggerRef, referenceRef, contentRef, and popperInstanceRef are positioning handles. Use Tooltip or Popover for higher-level application hints. This entry point provides no separate visibility state, control size, or user events.

Composition responsibilities and lifecycle ​

Compose AsamPopperTrigger, AsamPopperContent, and AsamPopperArrow within one AsamPopper instance to share its positioning context. role defines the semantics of the content and the default slot holds the composition. The host manages trigger state, transitions, mounting, and application actions.
