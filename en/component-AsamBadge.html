Badge ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Use a count or a dot to draw attention to the status of an item.

This example uses the component's public API.

Usage guidelines ​

Use value, max, isDot, hidden, showZero, type, color, and offset to configure the badge. Place the item being annotated in the default slot and customize the marker with the public content slot. The host supplies the data and places any clickable control inside the badge.
