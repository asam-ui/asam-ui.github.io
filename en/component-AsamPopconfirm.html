Popconfirm ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Ask for confirmation of a simple action next to the element that triggers it.

Confirm and cancel ​

Confirm to update the state, or cancel to keep the current state.

Example: basic

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<AsamPopconfirm
		title="确认归档这条记录？"
		confirm-button-text="归档"
		cancel-button-text="保留"
		:icon="InfoFilled"
		@confirm="result = '已归档'"
		@cancel="result = '已保留'"
	>
		<template #reference>
			<AsamButton type="default" native-type="button">归档记录</AsamButton>
		</template>
	</AsamPopconfirm>
	<p class="example-paragraph" role="status">{{ result }}</p>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamPopconfirmBasicDemo' });
import { ref } from 'vue';
import { AsamButton, AsamPopconfirm } from '@asam-ui/ui';
import { InfoFilled } from '@asam-ui/icons-vue';
const result = ref('等待操作');
</script>

<style scoped>
p:where(.example-paragraph) {
	margin-block: 16px;
	line-height: 1.8;
	overflow-wrap: anywhere;
}
</style>

Custom confirmation actions ​

The actions slot exposes the existing confirmation and cancellation callbacks.

Example: actions

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<AsamPopconfirm title="清理本地草稿？" @confirm="cleared = true">
		<template #reference>
			<AsamButton type="default" native-type="button">清理草稿</AsamButton>
		</template>
		<template #actions="{ confirm, cancel }">
			<AsamButton type="default" native-type="button" @click="cancel">保留草稿</AsamButton>
			<AsamButton type="default" native-type="button" @click="confirm">确认清理</AsamButton>
		</template>
	</AsamPopconfirm>
	<p class="example-paragraph" role="status">{{ cleared ? '草稿已清理' : '草稿仍保留' }}</p>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamPopconfirmActionsDemo' });

</script>

Additional usage and API details ​

Usage conventions ​

Set title, confirmButtonText, cancelButtonText, icon, and iconColor to configure the prompt. The confirm and cancel events carry their triggering events. Supply the trigger in reference and use the confirm and cancel callbacks exposed by actions for custom buttons. Popup visibility and placement are public props. Popconfirm has no separate control-size prop. Use Message Box for confirmation that needs richer input.

Composition and lifecycle ​

Provide a single trigger through reference. The confirm and cancel events carry the original MouseEvent. Use the callbacks from actions to build custom buttons with the same event behavior. The title, icon, button labels, and button types configure the prompt. Tooltip-related props manage visibility, triggers, mounting, and placement. Use the exposed hide method and popperRef handle to access the popup. Use Dialog for forms that need ongoing validation.
