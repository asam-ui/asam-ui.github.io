Timeline ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Show a history or sequence of events in a defined order.

This example uses the component's public API.

Layout mode (2.13.1) ​

Use mode to set how the content is positioned relative to the timeline.

Since 2.13.1, the underlying timeline sets its own padding. Check the layout if your project overrides padding on ul elements.

Example: cap-mode

Show source
LicenseExample source ZIPComplete project ZIP

	<AsamRadioGroup
		:model-value="mode"
		@update:model-value="
			(value) => {
				if (
					value === 'start' ||
					value === 'end' ||
					value === 'alternate' ||
					value === 'alternate-reverse'
				)
					mode = value;
			}
		"
	>
		<AsamRadioButton label="start" value="start" />
