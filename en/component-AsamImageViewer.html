Image Viewer ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Provide an independent viewer for browsing, zooming, and closing a set of images.

Basic usage and states ​

This example uses the component's public API.

Standalone instance, zoom input, and closing behavior ​

The complete TypeScript and JavaScript examples mount AsamImageViewer directly to demonstrate its public instance method, four events, and four slots. The first two images use local data URLs. The third deliberately fails to load so you can observe error and viewer-error.

Configure the image list, zoom range, and closing behavior before opening the viewer. You can use the instance to control it after it opens. See the full notes.

Call the public setActiveItem(index): void on a ref<AsamImageViewerInstance>() to switch images programmatically. See the full notes.

Pass scale as a prop from the parent. In version 2.14.7, the viewer exposes this as a one-way input and has no scale or update:scale event. See the full notes.

<script lang="ts" setup>
import { AsamFormSection } from '@asam-ui/ui';
import { ref } from 'vue';
import { AsamInputNumber, AsamCheckboxItem, AsamButton, AsamImageViewer } from '@asam-ui/ui';
import type { AsamImageViewerInstance } from '@asam-ui/ui';
defineOptions({ name: 'AsamImageViewerStandaloneDemo' });
const viewer = ref<AsamImageViewerInstance>();
const open = ref(false);
const initialIndex = ref(0);
const infinite = ref(false);
const scale = ref(1);
const zoomRate = ref(1.5);
const minScale = ref(0.5);
const maxScale = ref(2);
const closeOnPressEscape = ref(true);
const hideOnClickModal = ref(false);
const teleported = ref(true);
const zIndex = ref(2100);
const showProgress = ref(true);
const customProgress = ref(true);
const customToolbar = ref(true);
const events = ref<string[]>([]);
const returnType = ref('尚未调用');
const image = (color: string) =>
	'data:image/svg+xml,' +
	encodeURIComponent(
		`<svg xmlns="http://www.w3.org/2000/svg" width="320" height="220"><rect width="320" height="220" fill="${color}"/></svg>`
	);
const urls = [image('royalblue'), image('seagreen'), 'data:image/png;base64,broken'];
function goTo(index: number): void {
	returnType.value = typeof viewer.value?.setActiveItem(index);
}
function onClose(): void {
	events.value.push('close');
	open.value = false;
}
function onError(event: Event): void {
	events.value.push(`error:${event.type}`);
}
function onSwitch(index: number): void {
	events.value.push(`switch:${index}`);
}
function onRotate(degrees: number): void {
	events.value.push(`rotate:${degrees}`);
}
</script>

Events, slots, and component responsibilities ​

Entry Role in the standalone viewer example
close / error / switch / rotate Log the native payloads. close takes no arguments. The remaining events provide the original Event.type, image index, and rotation angle, respectively, as recorded by the example.
default Render the parent's controls and actions that call the public instance ref. The built-in Image preview has its own slot interface.
progress Display progress from { activeIndex, total }. Turn off the custom slot to see how showProgress works on its own.
toolbar Use { actions, prev, next, reset, activeIndex, setActiveItem }. The slot-scoped reset toggles the native original-size and fit modes.
viewer-error Use { activeIndex, src } to render the deliberate load failure for the third image. Use the instance ref to switch back to the first image.

Use AsamImage for image loading and placeholders. Use AsamImageViewer for viewing, zooming, and closing a standalone preview. See the full notes.

Usage guidelines ​

Pass an array of images through urlList and choose the starting image with initialIndex. Use infinite to control looping and zoomRate, minScale, and maxScale to configure zooming. See the full notes.

Standalone instance, zoom input, and closing behavior ​

Pass scale as a one-way prop. In version 2.14.7, the viewer emits neither scale nor update:scale. Change the input to observe the underlying behavior. The viewer dependency handles the limits on initial and dynamic scale and the toolbar zoom step. The close control, Esc, or a permitted overlay click emits close. The host unmounts the viewer in the handler. The separate parent-unmount action changes v-if directly and emits no close event.
