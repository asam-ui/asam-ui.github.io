Button ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Use AsamButton to submit, confirm, go back, or trigger another discrete action. Choose a semantic color with type and an appearance with plain, text, or link.

<script lang="ts" setup>
defineOptions({ name: 'AsamButtonNativeExample' });
import { ref } from 'vue';
import { AsamBaseForm, AsamButton } from '@asam-ui/ui';
import type { AsamButtonExpose } from '@asam-ui/ui';
const button = ref<AsamButtonExpose>();
const submitted = ref(0);
const state = ref('');
function inspect() {
	state.value = button.value
		? [button.value.size, button.value.type, button.value.disabled].join(' / ')
		: '';
}
</script>

The four control sizes are large, big, default, and small. An explicit button size takes precedence over the button group, the form, and the configuration provider. The final fallback is default. Compare the four sizes.

Styling and migration ​

Use block for full-width buttons. pressAnimation controls visual press feedback. Keep the action’s semantic color independent of its shape so it remains recognizable across layouts.

Icon and loading precedence ​

The icon and loading slots take precedence over icon and loadingIcon props, respectively. Use iconSize and iconPosition to control the regular icon. The regular icon returns after loading ends.
