Drawer ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Open a secondary workflow from the edge of the page while keeping the main page in view.

Drawer direction and actions ​

The drawer opens toward the left. Use the footer action to finish and close it. Its title uses an ASAM icon.

Resize from the edge ​

Drag the drawer edge to see the resize callbacks. The narrow-page example uses an explicit CSS size.

Example: resize

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<AsamButton type="primary" native-type="button" @click="open = true">打开可调整抽屉</AsamButton>
	<AsamDrawer
		v-model="open"
		v-bind="{ title: '可调整宽度', size: '60%', resizable: true }"
		@resize="track"
	>
		<p class="example-paragraph" role="status">当前拖动尺寸 {{ size }} px</p>
	</AsamDrawer>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamDrawerResizeDemo' });
import { ref } from 'vue';
import { AsamButton, AsamDrawer } from '@asam-ui/ui';
const open = ref(false);
const size = ref(0);
const track = (_event: MouseEvent, value: number) => {
	size.value = Math.round(value);
};
</script>

Usage conventions ​

v-model controls visibility, and direction chooses the opening direction. size determines the drawer dimensions. Pass default, small, large, or full, a percentage, a CSS length, or a number. See the usage conventions.

Complete usage examples ​

These examples use the public ASAM UI entry points. Each includes a complete TypeScript and JavaScript SFC. See the API on this page for props, events, slots, and instance types. Close service instances that you create, and pass only trusted strings as HTML.

<template>
	<label>
		展开方向
		<AsamSelect :model-value="direction" @change="changeDirection">
			<AsamOption value="ltr" :label="'从左展开'">从左展开</AsamOption>
			<AsamOption value="rtl" :label="'从右展开'">从右展开</AsamOption>
			<AsamOption value="ttb" :label="'从上展开'">从上展开</AsamOption>
			<AsamOption value="btt" :label="'从下展开'">从下展开</AsamOption>
		</AsamSelect>
	</label>

	<AsamButton type="primary" style="margin-left: 16px" @click="drawer = true">打开</AsamButton>
	<AsamButton type="primary" style="margin-left: 16px" @click="drawer2 = true">
		带底部区域
	</AsamButton>

	<AsamDrawer
		v-model="drawer"
		title="标题示例"
		:direction="direction"
		:before-close="handleClose"
	>
		<span>你好！</span>
	</AsamDrawer>
	<AsamDrawer v-model="drawer2" :direction="direction">
		<template #header>
			<h4>通过插槽设置标题</h4>
		</template>
		<template #default>
			<div>
				<AsamRadioItem v-model="radio1" value="Option 1">选项 1</AsamRadioItem>
				<AsamRadioItem v-model="radio1" value="Option 2">选项 2</AsamRadioItem>
			</div>
		</template>
		<template #footer>
			<div style="flex: auto">
				<AsamButton type="default" @click="cancelClick">取消</AsamButton>
				<AsamButton type="primary" @click="confirmClick">确认</AsamButton>
			</div>
		</template>
	</AsamDrawer>
</template>

<script lang="ts" setup>
import {
	AsamSelect,
	AsamOption,
	AsamRadioItem,
	AsamButton,
	AsamDrawer,
	AsamMessageBox,
	type AsamDrawerProps as DrawerProps
} from '@asam-ui/ui';

import { ref } from 'vue';

const drawer = ref(false);
const drawer2 = ref(false);
const direction = ref<DrawerProps['direction']>('rtl');
const radio1 = ref('Option 1');
const handleClose = (done: () => void) => {
	AsamMessageBox.confirm('确定关闭当前窗口吗？')
		.then(() => {
			done();
		})
		.catch(() => {
			// catch error
		});
};
function cancelClick() {
	drawer2.value = false;
}
function confirmClick() {
	AsamMessageBox.confirm(`确认选择${radio1.value === 'Option 1' ? '选项 1' : '选项 2'}吗？`)
		.then(() => {
			drawer2.value = false;
		})
		.catch(() => {
			// catch error
		});
}

const changeDirection = (value: unknown) => {
	if (value === 'ltr' || value === 'rtl' || value === 'ttb' || value === 'btt') {
		direction.value = value;
	}
};
</script>

import {
	AsamBaseForm,

	AsamDrawer,

	AsamOption,
	AsamSelect,
	AsamTable,
	AsamTableColumn
} from '@asam-ui/ui';

import { reactive, ref } from 'vue';

const formLabelWidth = '80px';
let timer: ReturnType<typeof setTimeout> | undefined;

const table = ref(false);
const dialog = ref(false);
const loading = ref(false);

const form = reactive({
	name: '',
	region: '',
	date1: '',
	date2: '',
	delivery: false,
	type: [],
	resource: '',
	desc: ''
});

const gridData = [
	{
		date: '2016-05-02',
		name: 'Peter Parker',
		address: 'Queens, New York City'
	},
	{
		date: '2016-05-04',
		name: 'Peter Parker',
		address: 'Queens, New York City'
	},
	{
		date: '2016-05-01',
		name: 'Peter Parker',
		address: 'Queens, New York City'
	},
	{
		date: '2016-05-03',
		name: 'Peter Parker',
		address: 'Queens, New York City'
	}
];

const onClick = () => {
	loading.value = true;
	setTimeout(() => {
		loading.value = false;
		dialog.value = false;
	}, 400);
};

const handleClose = (done: () => void) => {
	if (loading.value) {
		return;
	}
	AsamMessageBox.confirm('确定提交吗？')
		.then(() => {
			loading.value = true;
			timer = setTimeout(() => {
				done();
				// 动画关闭需要一定的时间
				setTimeout(() => {
					loading.value = false;
				}, 400);
			}, 2000);
		})
		.catch(() => {
			// catch error
		});
};

const cancelForm = () => {
	loading.value = false;
	dialog.value = false;
	clearTimeout(timer);
};
</script>

Native visibility and focus behavior ​

A custom header receives close, titleId, and titleClass. Declare the title element in the slot and assign it titleId once. The default header supplies the ASAM title, icon, and styles.

Local mode confines the backdrop to the example. Global mode uses the default viewport area. The switch shows the current mode. Both modes are interactive, and you can switch after closing the drawer.

Additional usage and API details ​

Usage conventions ​

v-model controls visibility, and direction chooses the opening direction. For the drawer size, pass default, small, large, or full, a percentage, a CSS length, or a number. The supported drawer presets exclude big and mini. ASAM provides a default title icon, and focus restores according to the native behavior. Enable resizable to drag the edge. resize-start, resize, and resize-end provide the original event and size. beforeClose(done) can prevent closing, including when calling the public handleClose() method. See the API below for the complete types. In 2.14.7, afterEnter and afterLeave are internal animation callbacks that were removed from the public instance declaration. Listen to opened and closed for transition completion.

Composition and lifecycle ​

direction accepts ltr, rtl, ttb, and btt. Set size with a CSS dimension or one of the ASAM drawer presets and configure control density separately. resizable enables edge dragging. resize-start, resize, and resize-end carry the original MouseEvent and numeric size. Use header, title, icon, default, and footer for the header, title, icon, body, and actions. handleClose is the public close method and runs beforeClose. Listen for opened and closed to observe transitions. Configure destroyOnClose, appendToBody, appendTo, lockScroll, and closeOnPressEscape to match the host. When changing modelValue externally, the host must validate the action. Unmounting removes the backdrop and the scroll lock, and focus returns to the trigger if it is still mounted.

Defaults for omitted props ​

withHeader, modalFade, closeOnClickModal, closeOnPressEscape, lockScroll, modal, and showClose default to true when omitted. Explicit false or undefined and subsequent removals follow native handling. The API table lists the values used for omitted props.
