Textarea ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Use a multiline input for descriptions, notes, and longer text. rows sets the initial line count, autosize adjusts height to the content, and resize controls the directions in which users can drag to resize.

Multiple lines and character limits ​

Use showWordLimit with maxlength to show the character count. rows sets the initial line count. See the Events API for change and input.

Sizes and inheritance ​

ASAM offers large, big, default, and small. An explicit size overrides inheritance. If omitted, the nearest component, group, form, or ConfigProvider setting applies, with default as the fallback. Change the provider size to see inherited values update.

Example: sizes

				<strong>{{ size }}</strong>
				<AsamTextarea
					:size="size"

ASAM extensions and migration ​

Replace Input with type="textarea" with AsamTextarea. Remove type and keep rows, autosize, resize, and character-limit settings. See the full notes.

Clearing, graphemes, and height ​

clearable and clearIcon add a clear control. With countGraphemes enabled, the component counts graphemes and omits the native minlength and maxlength attributes. See the full notes.

Example: clear-graphemes

Reading the API ​

The API below reflects the current public types and runtime defaults. “Unknown / Not declared” means no default is documented by the runtime. Omit size to inherit the ancestor setting and disabled to inherit the form state. Use validateEvent to control validation events.

Model modifiers and update types ​

The underlying input applies trim, number, and lazy. With number, update:modelValue can emit a number. Text that cannot be converted stays a string. The input and change events retain their own signatures.

Example: modifiers

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<div class="example">
		<AsamTextarea
			v-model.trim.number.lazy="value"
			aria-label="修饰符输入"
			@update:model-value="record"
		/>
		<AsamButton type="default" native-type="button">移出焦点以提交</AsamButton>
		<output>{{ JSON.stringify({ value, type: typeof value, updates }) }}</output>
		<p class="example-paragraph">
			输入数字并失焦后，更新为 number；非数字文本仍为 string。trim 移除两端空白，lazy
			在提交时更新。
		</p>
	</div>
</template>
<script lang="ts" setup>

const value = ref<string | number>('');
const updates = ref<(string | number)[]>([]);

	updates.value.push(value);

Form inheritance and validation across five inputs ​

This complete TS/JS example includes the single-line, password, multiline, autocomplete, and tag inputs. Each leaves disabled unset to inherit the form state. validateEvent controls automatic validation on change and blur per input. Toggling the disabled state preserves the model, and editing still works when automatic validation is off. Each of the five pages contains a self-contained copy of the example.

Formatting and parsing multiline text ​

In the complete TS/JS example, the Textarea's formatter adds a prefix to each displayed line, and its parser removes the prefix from edits. v-model preserves the original text and line breaks. The two-line example action updates the parent model and reformats the display.

import { ref } from 'vue';

const value = ref<string | number>('seed\nline');
function formatter(value: string | number) {
	return String(value)
		.split('\n')
		.map((line) => '> ' + line)
		.join('\n');
}
function parser(value: string) {
	return value
		.split('\n')
		.map((line) => line.replace(/^> ?/, ''))
		.join('\n');
}

Additional usage notes ​

ASAM extensions and migration ​

Replace Input with type="textarea" with AsamTextarea. Remove type and keep rows, autosize, resize, and character-limit settings. The four sizes set type size, line height, and density. Content, rows, and autosize also affect multiline height. See the API for prefix, suffix, prepend, and append types. Use Input for a decorated single-line input.

Clearing, graphemes, and height ​

Use clearable and clearIcon for clearing. countGraphemes enables grapheme counting and omits native minlength and maxlength. minRows and maxRows constrain autosize, and resize controls drag directions. Call resizeTextarea when a hidden container becomes visible. Height repainting in Firefox follows the pinned upstream fix. Verify it in the target Firefox version.
