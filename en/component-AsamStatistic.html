Statistic ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Show an available numeric value and its unit clearly.

Basic usage and states ​

This example uses the component's public API.

Usage guidelines ​

Supply the number through value and format it with precision, decimalSeparator, groupSeparator, or formatter. Use the title, prefix, and suffix props or slots to add context and units. Set valueStyle to style the number. The host supplies any fetched or aggregated data.

Basic usage ​

Highlight statistics, amounts, rankings, or other key figures. Add icons, units, and other context around the number or title. Use VueUse to animate changes to the displayed value.

<script lang="ts" setup>
defineOptions({ name: 'AsamStatisticCapBasicDemo' });
import { AsamRow, AsamCol, AsamStatistic, AsamIcon } from '@asam-ui/ui';

import { ref } from 'vue';
import { onMounted, onBeforeUnmount } from 'vue';
import { ChatLineRound, Male } from '@asam-ui/icons-vue';

const outputValue = ref(0);
let frame = 0;
onMounted(() => {
	const start = performance.now();
	const animate = (now: number) => {
		const progress = Math.min((now - start) / 1500, 1);
		outputValue.value = Math.round(172000 * progress);
		if (progress < 1) frame = requestAnimationFrame(animate);
	};
	frame = requestAnimationFrame(animate);
});
onBeforeUnmount(() => cancelAnimationFrame(frame));
</script>
