Tooltip ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Add a brief hint to a control. Put any required actions in the surrounding interface.

Tooltips on focus and hover ​

The tooltip appears when the button receives focus or the pointer hovers over it. Use the content slot for richer hints.

Example: basic

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<AsamTooltip placement="top" :trigger="['hover', 'focus']" :show-after="100">
		<AsamButton type="default" native-type="button">查看提示</AsamButton>
		<template #content>
			草稿保存在当前设备。
			<br />
			按完成提交。
		</template>
	</AsamTooltip>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamTooltipBasicDemo' });
import { AsamButton, AsamTooltip } from '@asam-ui/ui';
</script>

Controlled tooltips ​

The host toggles visible for both buttons. The example sets trigger and triggerKeys to empty arrays so automatic activation does not run alongside the host's toggle.

Example: controlled

Example source ZIPComplete project ZIP
vue

			切换提示

Usage conventions ​

Supply the hint through the content prop or slot. Use trigger, placement, showAfter, hideAfter, disabled, visible, virtualRef, and the popup positioning props to configure interaction. See the usage conventions.

Complete usage examples ​

These examples use the public ASAM UI entry points. Each includes a complete TypeScript and JavaScript SFC. See the API on this page for props, events, slots, and instance types. Close service instances that you create, and pass only trusted strings as HTML.

Virtual trigger target ​

Example: ep2147-virtual-trigger

Show source
LicenseExample source ZIPComplete project ZIP
vue
<template>
	<AsamTooltip
		:visible="visible"
		content="底部居中"
		placement="bottom"
		effect="light"
		trigger="click"
		virtual-triggering
		:virtual-ref="triggerRef"
	/>
	<AsamButton type="primary" @click="visible = !visible">切换文字提示</AsamButton>
</template>

<script lang="ts" setup>
import { AsamButton, AsamTooltip } from '@asam-ui/ui';

import { onMounted, onUnmounted, ref } from 'vue';

const visible = ref(false);
const position = ref(DOMRect.fromRect({ x: 0, y: 0, width: 0, height: 0 }));

const triggerRef = ref({
	getBoundingClientRect: () => position.value
});

const mousemoveHandler = ({ clientX, clientY }: MouseEvent) => {
	position.value = DOMRect.fromRect({
		x: clientX,
		y: clientY
	});
};

onMounted(() => {
	document.addEventListener('mousemove', mousemoveHandler);
});

onUnmounted(() => {
	document.removeEventListener('mousemove', mousemoveHandler);
});
</script>

Composition and lifecycle ​

Use default for the trigger and the content prop or slot for the hint. See composition and lifecycle.

Local and global mounting ​

The basic example uses default global mounting. The local mounting example shows explicit teleported or appendTo settings. Open the tooltip to see which container holds it. Mounting is independent of the control value and how data is requested.

Additional usage and API details ​

Usage conventions ​

Supply the hint through the content prop or slot. Use trigger, placement, showAfter, hideAfter, disabled, visible, virtualRef, and the popup positioning props to configure interaction. Bind visible for controlled mode, or omit it to let trigger manage visibility. The public hide, onOpen, onClose, and updatePopper methods manage the tooltip. Use Popover for richer interactions. Provide one focusable trigger in the default slot. Tooltip has no control-size prop.

Composition and lifecycle ​

Use default for the trigger and the content prop or slot for the hint. visible provides controlled state. trigger, triggerKeys, showAfter, hideAfter, autoClose, disabled, and enterable control interactions. Enable virtualTriggering with an HTMLElement or a target that implements getBoundingClientRect. When a shared tooltip switches virtualRef, update its position and remove external mouse listeners on unmount. appendTo, teleported, and persistent govern mounting and lifetime. effect, rawContent, transition, popperStyle, and popperClass govern presentation. Supply only trusted HTML. The public popperRef, contentRef, isFocusInsideContent, updatePopper, onOpen, onClose, and hide expose the live tooltip state and actions.
