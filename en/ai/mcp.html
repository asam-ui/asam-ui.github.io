Documentation MCP ​

@asam-ui/mcp is an optional stdio service for base component documentation. It provides the component catalog, public API, TypeScript and JavaScript examples, and integration guides. You can use it separately from the integration Skill.

These examples use the published @asam-ui/mcp@1.0.1, which bundles the UI 1.0.0 documentation snapshot. Make Node.js >=22.19.0 and pnpm available to your host.

Generic JSON configuration ​

Merge this service into the existing mcpServers object.

json
{
	"mcpServers": {
		"asam-ui": {
			"command": "pnpm",
			"args": ["dlx", "@asam-ui/mcp@1.0.1"]
		}
	}
}

If the host cannot resolve pnpm on Windows, set the command to pnpm.cmd.

Codex ​

Add the service to ~/.codex/config.toml or the project's .codex/config.toml, then reload Codex and confirm that the service is available. See the Codex MCP documentation.

toml
[mcp_servers.asam_ui]
command = "pnpm"
args = ["dlx", "@asam-ui/mcp@1.0.1"]
startup_timeout_sec = 60

VS Code ​

Add the service in the project's .vscode/mcp.json and start it from the MCP services list. VS Code uses servers. See the VS Code MCP documentation.

json
{
	"servers": {
		"asam-ui": {
			"type": "stdio",
			"command": "pnpm",
			"args": ["dlx", "@asam-ui/mcp@1.0.1"]
		}
	}
}

Verify a query ​

  1. Use list_components to find Button and confirm its public name.
  2. Call get_component_api with component AsamButton, section props, and member size.
  3. Call get_component_example with component AsamButton, demo basic, and language ts.

The service should report component version 1.0.0. API results can paginate. Omitting the demo lists the available examples. A selected demo returns the complete files and applicable notices. Use get_guide with installation, provider, theme, or skill for longer guidance.

Versions and scope ​

The installed service reads a fixed documentation snapshot. The snapshot describes base components and does not update when this website changes. Use Pro resources for Pro workflows or component references to browse the documentation without MCP.

Public inputs ​

The five inputs were captured from the component API, component index, component examples, content manifest, and source notices. The structured references take you to the corresponding live resources. The catalog hash is calculated on the original catalog.json.gz bytes.

The service reads documentation and has no project write tools. Verify a query in the intended host and test types, build, and rendering in the consuming application. See the license and source usage appendix (Chinese).
