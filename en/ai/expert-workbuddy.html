WorkBuddy Development Expert ​

ASAM UI runs as a local custom expert in WorkBuddy. It uses the expert and documentation tools registered for the current account.

Use the current installation guide for commands and matched versions.

1. Install the expert for your account ​

Start WorkBuddy and sign in once. Exit completely, including the system tray. Run the installer and choose WorkBuddy and Install. If the installer finds multiple accounts, choose the account you plan to use. Then reopen WorkBuddy.

2. Open the expert in My Experts ​

Open Experts, Skills, and Connectors → Experts → My Experts. Under Created by me, open the ASAM UI Development Expert and select Invoke. In MCP service management, expand asam-ui to check whether the service and tools such as agent_discover and agent_read are enabled.

In Installed skills, check that asam-ui-development is enabled. Open its details to see the skills the plugin provides.

3. Run your first query ​

Choose the target Vue project in the expert conversation. You can also type /asam in the task field and select asam-ui-development. If WorkBuddy asks to connect to asam-ui, check the source and follow its prompt.

Send this read-only request, then check the tool activity for the discovery and read calls.
