Form Grid ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

AsamFormGrid lays out form fields in responsive columns and can be nested in AsamFormSection. The caller or form component manages field values, validation, and submission.

Responsive field layout ​

The example puts a reusable field in a separate SFC and stores its input value in the parent. Resize the browser to compare three columns on desktop, two on tablet, and one on mobile. Use the reset button to restore the example data.

vue
<template>
	<div class="demo-root-layout">
		<AsamCheckboxItem v-model="invalid">无效列数回退</AsamCheckboxItem>
		<AsamFormGrid
			:columns="invalid ? 0 : 3"
			:tablet-columns="invalid ? -1 : 2"
			:mobile-columns="invalid ? 1.5 : 1"
			gap="var(--asam-space-lg)"
		>
			<Field v-model="form.name" label="任务名称" />
			<Field v-model="form.model" label="产品型号" />
			<Field v-model="form.team" label="班组" />
		</AsamFormGrid>
		<AsamButton type="default" class="demo-reset" @click="reset">恢复默认值</AsamButton>
		<output>{{ form.name }} / {{ form.model }} / {{ form.team }}</output>
	</div>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamFormGridBasicExample' });
import { reactive, ref } from 'vue';
import { AsamCheckboxItem, AsamButton, AsamFormGrid } from '@asam-ui/ui';
import Field from './Field.vue';
const invalid = ref(false);
const form = reactive({ name: '装配任务', model: 'A-01', team: '一班' });
function reset(): void {
	Object.assign(form, { name: '装配任务', model: 'A-01', team: '一班' });
}
</script>

<style scoped>
.demo-reset {
	margin: var(--asam-space-lg);
}
</style>

	gap: var(--asam-space-md);
	justify-items: start;
}
.demo-root-layout > :is(p, pre, output) {
	margin-block: 0;
}
</style>

		/>

The styles use tabletColumns below 1024px, mobileColumns below 640px, and columns at wider viewport sizes. Their defaults are 2, 2, and 1 for columns, tabletColumns, and mobileColumns, respectively. Invalid column counts fall back to 1. Breakpoints use the viewport width, regardless of the local container width.

Layout and form responsibilities ​

gap accepts a CSS length string and defaults to the field spacing token. The grid provides only a default slot. Field registration, validation, submission, and reset belong to the form. Put the field components in the slot and call validation and reset on the form instance.

Set the four input sizes on the controls or in the theme. The grid handles only column count and spacing and has no size prop.
