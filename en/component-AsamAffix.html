Affix ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Keep a compact set of controls fixed at a chosen position as the page scrolls.

Basic usage and state ​

The following examples use the public API of this entry.

Example: basic

vue
<template>
	<div ref="scroll" class="affix-scroll">
		<div class="doc010-affix-region">
			<AsamAffix target=".doc010-affix-region" :offset="offset" @change="fixed = $event">
				<AsamButton type="default" native-type="button">固定操作</AsamButton>
			</AsamAffix>
			<p class="example-paragraph">滚动查看固定范围</p>
		</div>
	</div>
	<p class="example-paragraph" role="status">
		{{ fixed ? '操作已固定' : '向下滚动本区域以固定操作' }}
	</p>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamAffixBasicDemo' });
import { AsamButton, AsamAffix } from '@asam-ui/ui';
import { onBeforeUnmount, onMounted, ref } from 'vue';
const scroll = ref<HTMLElement>();
const offset = ref(0);
const fixed = ref(false);
const updateOffset = () => {
	offset.value = (scroll.value?.getBoundingClientRect().top ?? 0) + 8;
};
onMounted(() => {
	updateOffset();
	window.addEventListener('resize', updateOffset);
	window.addEventListener('scroll', updateOffset, { passive: true });
});
onBeforeUnmount(() => {
	window.removeEventListener('resize', updateOffset);
	window.removeEventListener('scroll', updateOffset);
});
</script>

Local and global mounting ​

Scroll down until the content becomes fixed, then toggle the public teleported prop to see where it mounts. The prop changes where the element mounts in the DOM while keeping the boundaries set by target. The switch shows the active mode and works in both modes. You can toggle it again after switching it off.

Additional usage and contract notes ​

Usage conventions ​

Use position and offset to select the fixed edge and viewport offset, target to set the active bounds, and zIndex to control stacking. The example syncs offset with the top of the scroll area in the viewport, updates it on scroll and resize, and removes the listeners on unmount. The change and scroll events report the pinned and scroll states. The instance exposes methods to recalculate placement. Keep pinned content compact. Its layout determines the width and height, with no four-level density setting.
