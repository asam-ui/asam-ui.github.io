Avatar ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Represent a person with an icon, text, or an image. Provide fallback content when an image fails to load.

Basic usage and states ​

This example uses the component's public API.

Usage guidelines ​

Set src, srcSet, shape, size, fit, and icon through the public props. size sets the graphic size and accepts the aliases and numeric values in its type. Use the default slot for text or fallback content. The error event reports a failed image load. Import icons from the ASAM icon package.
