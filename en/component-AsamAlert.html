Alert ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Show status, advice, or a dismissible notice inline. Use an alert for information that should stay visible on the page.

Status and dismissal ​

Try the four statuses in this example. After dismissing the alert, use the reset button to display it again.

Example: basic

	<div class="demo">

		/>

	</div>
</template>

Usage conventions ​

Choose the status with type and the light or dark appearance with effect. Use title, description, center, showIcon, closable, and closeText to configure the notice. The close event reports dismissal, and the host can remount the alert to display it again. Customize the content with the title, default, or icon slots. Alert has no control-size prop.

Complete usage scenarios ​

The alert stays inline and remains visible until dismissed or removed.

Set type to choose one of five statuses. It defaults to info. The primary type was added in 2.9.11.

Additional usage and API details ​

Custom close button ​

Use the Boolean closable prop to control whether users can dismiss the alert. It defaults to true. To replace the icon on the right, pass a string to close-text. The alert emits close when dismissed.
