Usage guidelines ​

Set active to the current step index. Use direction, space, alignCenter, simple, processStatus, and finishStatus to configure the display. Put AsamStep components in the default slot. The host advances the process, validates input, and makes requests.

Complete examples ​

Basic usage ​

Show a sequence of steps and highlight the active one.

Set active to a zero-based numeric index. For fixed spacing, set space to a number of pixels. If omitted, the steps adapt to the available space. Set finish-status to change how completed steps appear.

Example: cap-basic

Show source
LicenseExample source ZIPComplete project ZIP
vue
<template>
	<AsamSteps style="max-width: 600px" :active="active" finish-status="success">
		<AsamStep title="步骤 1" />
		<AsamStep title="步骤 2" />
		<AsamStep title="步骤 3" />
	</AsamSteps>

	<AsamButton type="primary" style="margin-top: 12px" @click="next">下一步</AsamButton>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamStepsCapBasicDemo' });
import { AsamSteps, AsamStep, AsamButton } from '@asam-ui/ui';

import { ref } from 'vue';

const active = ref(0);

const next = () => {
	if (active.value++ > 2) active.value = 0;
};
</script>
