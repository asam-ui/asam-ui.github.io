Dictionary Virtualized Select ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

Use dictionary options in a virtualized select with reload and cancellation.

Basic usage ​

The example reads a dictionary from a local provider and demonstrates model updates, pausing, and reloading. Requests run entirely within the demo.

Click the current-label control to read the instance's read-only selectedLabel. An empty single model returns an empty string. A selection returns the current label. See the full notes.

Local creation and canonical dictionary options ​

With allow-create and filterable enabled, createOption(text) synchronously returns a complete AsamOption<V, I>, including its label, correctly typed value, and actual raw record. The default creates a string value. Use a type-matched synchronous factory for numeric or boolean values or custom raw data.

	AsamCreateOption,

import { ref } from 'vue';
import type { AsamDataProvider, AsamDictEntry } from '@asam-ui/ui';
export interface Member extends AsamDictEntry {
	readonly id: string;
	readonly value: string;
}
export function createDemoState() {
	return { tenant: ref('a'), failure: ref(false), canonical: ref(false) };
}
export type DemoState = ReturnType<typeof createDemoState>;
export function createDemoProvider(state: DemoState): AsamDataProvider {
	return {
		dict: {
			async refresh(context) {
				context.signal.throwIfAborted();
			},
			async get(type, context) {
				await new Promise<void>((done) => setTimeout(done, 150));
				context.signal.throwIfAborted();
				if (state.failure.value) throw new Error('演示字典失败');
				if (!['a', 'b'].includes(type)) throw new Error('未知演示字典');
				const items: Member[] = [{ id: 'server', label: 'Server', value: 'server' }];
				if (state.canonical.value)
					items.push({ id: 'saved', label: 'Server Omega', value: 'Omega' });
				return items;
			}
		}
	};
}

Locally created options stay in the current component. The dictionary provider, cache, and success contain source options. Options of the same type and value are deduplicated, with the canonical dictionary record taking precedence. Refreshing preserves the object already assigned to the parent model. clearCreatedOptions() clears the local collection and the base select's text memo and retains v-model.

Searching the same source, refreshing the dictionary, and retrying errors retain local options. Changes in actual dictType, dictValueType, dataSource, or provider or scope clear them. Update v-model separately to clear the model.

Data sources and overrides ​

Choose dictType or dataSource. Create a dataSource with defineAsamDictSource and configure the value type there. See the full notes.

Single selection uses a scalar or null in value mode and a normalized AsamOption in object mode. For multiple selections, combine multiple, valueMode, and multipleValueMode to choose an array or a delimited string. Object mode requires an array. Update the model type when changing the value strategy.

The source manages options, loading, and remote queries. This data component uses ASAM value and object modes. Apply the base component features that fit the selected data mode.

Lifecycle, events, and instance methods ​

active=false pauses requests and retains the last successful data. Use reload({ force: true }) for fresh data and cancel() to cancel the current request. See the full notes.

immediate controls the initial request, and active controls whether requests are enabled. See the generated API for the defaults and their sources.

Slots and base features ​

prefix, header, footer, empty, loading, tag, and label keep their base scopes. selectedLabel is read-only, and focus() and blur() control input focus. The virtual select's default slot uses the base virtual option scope.

Native compatibility with dynamic option heights ​

estimatedOptionHeight is public. Element Plus 2.14.7 calculates item heights. See the full notes.

The published compatibility observation covers the native fixture below. The cause and the corresponding advanced dynamic-height case remain unverified.

Related base components ​

  • Virtualized Select provides the applicable display, interaction, and public API.

Use this page's rules for data sources, models, events, and exposed members, and refer to the linked base components for the features available here. Sizes follow the ASAM base components. Examples use default.

Dictionary refresh and the example provider ​

A forced reload calls provider.dict.refresh before reading the dictionary again. The example supplies both get and refresh and checks the request cancellation signal. It uses fixed local data. Implement cache updates in the host provider's refresh.

Complete option and tag presentation ​

The full example uses two independent instances to show virtual option templates, prefix, header, footer, loading, empty, label, and removable tags. See the full notes.

The presentation example records update:modelValue and change for a raw number in single mode and a raw array in multiple mode, plus success with the full normalized options. Trigger a refresh failure to inspect error.kind and error.message and see the previous selection retained, then recover. Cancelling a held request emits no additional success. Each log entry stores a separate payload snapshot.

The optional error slot runs only when the current request has an error. It receives a read-only { error, stale, retry } scope. See the full notes.

Call retry() without arguments. It returns the forced reload Promise and follows the same cancellation and unmount behavior. See the full notes.

Providing the slot replaces the default local error region, including when the slot renders empty content. With the slot omitted, the component displays its error message, stale-data hint, and retry button. The slot requires a current error. empty, loading, and other base slots keep their original scopes.

In the complete TypeScript and JavaScript example, trigger a failure and await the slot's retry() result. After a success, trigger a refresh failure to see the existing result and model retained. Each mount creates an isolated child app with a local provider.

Local and global poppers ​

Additional usage notes ​

Basic usage ​

Click the current-label control to read the instance's read-only selectedLabel. An empty single model returns an empty string, and a selection returns its label. Call focus() and blur() without arguments to control input focus independently of the model. The blur button prevents its mouse-down action from taking focus so you can observe blur() itself. Enable multiple selection to use an independent array model. The label result is an empty array when nothing is selected and a label array after selection. The focus methods leave both models untouched.

Data sources and overrides ​

Choose dictType or a dataSource created with defineAsamDictSource. Configure the source's value type in its factory. With the shorthand dictType source, dictValueType converts dictionary values to string, number, or boolean. The app injects dict.get through provideAsamData. The demo uses a local dictionary in a separate child app and unmounts it on a language change or navigation away.

Lifecycle, events, and instance methods ​

active=false pauses requests and retains the last successful data. Use reload({ force: true }) for fresh data and cancel() to cancel the current request. success emits a normalized option array. error emits an AsamDataError. A failed refresh marks the last successful data stale. Handle the reload result by its status of success, error, or cancelled.

Native compatibility with dynamic option heights ​

estimatedOptionHeight is public, and Element Plus 2.14.7 calculates item heights. In a direct native ElSelectV2 fixture with 500 flat options, an empty single model of null, filterable=true, height=120, itemHeight=34, and estimatedOptionHeight=34, mounting and nextTick() did not complete within the 10-second observation period. Omitting estimatedOptionHeight with the same other inputs let the control mount, scroll to the bottom and top, and select numeric 0.

Complete option and tag presentation ​

The full example uses two independent instances for virtual option templates, prefix, header, footer, loading, empty, label, and removable tags. Data sources return flat normalized records. Use the base Virtualized Select's native mode for nested native option groups. Multiple selection uses a raw number array and preserves collapsed-tag tooltips, maxCollapseTags, multipleLimit, and disabled. Custom tags use native deleteTag, which emits remove-tag. Complete the local held request to observe the loading and empty slots. Unmounting the isolated child app cancels its request. fitInputWidth=320 sets the virtualized select's popper width.

Complete option and tag presentation ​

Toggle collapseTags and collapseTagsTooltip, switch maxCollapseTags between 1 and 3, and adjust multipleLimit between 3 and 0. With the limit removed, select a fourth item. The caller first resets the model to [1, 3, 4] and then restores the limit. Collapsing tags and changing tooltips preserve the model and reuse the current source result. Native deleteTag and remove-tag retain numeric payloads.

Local request error slot ​

The optional error slot runs only while the current request has an error. It receives a read-only { error, stale, retry } scope. The error is the same AsamDataError emitted by that instance, including cause, kind, message, and notified. Rendering the slot leaves the provider's notification state unchanged. stale indicates that the retained data is outdated.

Additional props and events ​

Local request error slot ​

Call retry() with no arguments. It returns the Promise from reload({ force: true }) with the success, error, or cancelled branch of AsamReloadResult<readonly AsamOption<V, I>[]>. Retrying follows active, the current source, cancellation, and unmount, and preserves the model. A forced dictionary refresh runs refresh before get. Omitting refresh produces the existing configuration error.
