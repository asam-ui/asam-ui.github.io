When to use it ​

Display text with consistent theme styles, sizes, and truncation.

This example uses the component's public API.

Usage guidelines ​

Use type and tag to set the visual meaning and HTML element. Use truncated or lineClamp to shorten the text. Place the text in the default slot and give it a constrained width or line count when truncating. Provide access to the full text where needed. ASAM's size accepts large, big, default, and small.

Ellipsis ​

Enable truncated to show an ellipsis when text exceeds the available width or the configured maximum width. Use line-clamp to limit the number of lines. Since 2.14.6, the public isTruncated property indicates whether the text is truncated, so you can show a tooltip only when needed.

Reactive truncation state ​

The instance exposes isTruncated as a boolean because Vue unwraps the underlying reactive ref. The component measures again when the content, width, truncated, or lineClamp changes. The instance ref is empty before mounting. Omitting title allows the component to generate a title when the text is truncated. Pass an explicit empty string to disable the automatic title.

Example: behavior

Show source
Example source ZIPComplete project ZIP
vue
<template>
	<div class="demo-root-layout">
		<div class="controls">
			<AsamButton
				type="default"
				native-type="button"
				@click="content = content === '短文' ? longText : '短文'"
			>
				切换内容
			</AsamButton>
			<AsamButton
				type="default"
				native-type="button"
				@click="width = width === 120 ? 1000 : 120"
			>
				切换宽度
			</AsamButton>
			<AsamButton type="default" native-type="button" @click="truncated = !truncated">
				切换截断
			</AsamButton>
		</div>
		<AsamText
			ref="text"
			:truncated="truncated"
			:style="{ width: width + 'px', display: 'inline-block' }"
		>
			{{ content }}
		</AsamText>
		<output v-bind="domDataAttrs('data-state', 'single')">{{ text?.isTruncated }}</output>
		<!-- prettier-ignore -->
		<AsamText
		ref="multi"
		:line-clamp="2"
		style="width: 120px"
		v-bind="domTitleAttrs('')"
	>
		{{ content }}
	</AsamText>
		<output v-bind="domDataAttrs('data-state', 'multi')">{{ multi?.isTruncated }}</output>
	</div>
</template>
<script lang="ts" setup>
import type { HTMLAttributes } from 'vue';
defineOptions({ name: 'AsamTextBehaviorDemo' });
import { ref } from 'vue';
import { AsamButton, AsamText } from '@asam-ui/ui';
import type { AsamTextExpose } from '@asam-ui/ui';
const longText = '这是一段超过容器宽度的文字，用于观察内容与宽度变化后真实截断状态是否更新。';
const content = ref(longText);
const width = ref(120);
const truncated = ref(true);
const text = ref<AsamTextExpose>();
const multi = ref<AsamTextExpose>();

type DemoDataAttributes = Record<`data-${string}`, string | number | boolean | null | undefined>;
const domDataAttrs = (
	name: `data-${string}`,
	value: string | number | boolean | null | undefined = ''
): Pick<HTMLAttributes, 'class'> & DemoDataAttributes => ({
	class: 'ui032-data-marker',
	[name]: value
});

const domTitleAttrs = (
	title: NonNullable<HTMLAttributes['title']>
): Pick<HTMLAttributes, 'class' | 'title'> => ({ class: 'ui032-text-title', title });
</script>
