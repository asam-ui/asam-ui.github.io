Mention ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Mention people with @ or topics with # in comments and messages. The model stores the complete input. See the full notes.

Triggers and selection ​

Type @ to show suggestions. select reports the option and trigger character. search reports the query fragment and trigger character.

Example: basic

Sizes and inheritance ​

ASAM offers large, big, default, and small. An explicit size overrides inheritance. If omitted, the nearest component, group, form, or ConfigProvider setting applies, with default as the fallback. Change the provider size to see inherited values update.

ASAM extensions and migration ​

Mention inherits ASAM's four sizes. Use whole and checkIsWhole to control whole-token deletion on Backspace, filterOption to customize searches, and props to map option fields. The application drives the loading state and can customize the loading slot. See Password for passwords, Input for plain single-line text, and Textarea for plain multiline text.

Option mapping and asynchronous loading ​

props maps the value, label, and disabled fields. select returns the original option. The application owns options and loading. The default filter matches the label or value. Set filterOption to false to disable filtering. Discard stale remote results and use the loading slot to show progress.

<script lang="ts" setup>
defineOptions({ name: 'AsamMentionLoadingExample' });
import { ref } from 'vue';
import { AsamMention } from '@asam-ui/ui';
const value = ref('');
const options = ref<{ id: string; name: string; inactive?: boolean }[]>([]);
const loading = ref(false);
let request = 0;
async function search(pattern: string) {
	const current = ++request;
	loading.value = true;
	await new Promise((resolve) => setTimeout(resolve, 400));
	if (current !== request) return;
	options.value = [
		{ id: pattern || 'alice', name: 'Alice ' + pattern },
		{ id: 'disabled', name: '不可选', inactive: true }
	];
	loading.value = false;
}
</script>

Text composition and the input event ​

input carries a string. The actual input or textarea supplies native CompositionEvent payloads for compositionstart, compositionupdate, and compositionend. Wait until composition is complete before submitting the text. Use this example to check the input method on the target OS.

Example: composition

		<AsamMention
			v-model="value"
			:options="options"
			aria-label="组合输入提及"
			@input="input = $event"
			@compositionstart="record"
			@compositionupdate="record"
			@compositionend="record"
		/>

Additional usage notes ​

When to use it ​

The complete text includes markers such as @people and #topics. The modelValue prop follows the native string model in MentionProps. The update:modelValue event retains string | number because Vue's number modifier can send a number to listeners. Options describe value, label, and disabled, with custom fields retained through the generic type.

Inherited input options ​

The underlying input receives min, max, step, formatter, parser, modelModifiers, and textarea props. Native handling applies to trim, number, lazy, whole-token deletion, and change/blur validation. The native input also owns drafts, model conversion, and commit timing. Writing a numeric result from v-model.number directly into the string prop can produce the same type warning as the native control. Keep the model as text, including with type="number", and handle numeric business values in the application or data layer. Update listeners still need to handle numeric values.

Single-line slots and nested input instance ​

Call focus, blur, select, clear, and resizeTextarea through mention.input. The example displays the actual input, textarea, and refs plus textareaStyle, autosize, passwordVisible, and isComposing to show the nested InputInstance contract. For tooltip and dropdownVisible, see the public types and the multiline and event examples.

Native delegation and event logging ​

The complete TS/JS example logs model updates and event order and lets you toggle disabled, read-only, and automatic validation states. Omitted base props use the native defaults. Explicit undefined, null, and false pass through when allowed by the API. ASAM supplies four visual sizes. Password fixes type to password and enables the visibility toggle when showPassword is omitted.

More parameters and events ​

Inherited input events ​

Mention provides search, select, and whole-remove. The input or textarea supplies update:modelValue as string | number, input as a string, change as a string plus an optional native Event, and clear with an optional MouseEvent. focus and blur carry FocusEvent, while mouseenter and mouseleave carry MouseEvent. keydown can carry KeyboardEvent or an Event from browser autofill. The composition events carry CompositionEvent. An explicit public listener receives each native occurrence once, through the actual input.
