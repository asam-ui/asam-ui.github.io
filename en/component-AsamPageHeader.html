Page Header ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Place a back action and supporting information beside the page title.

Basic usage and state ​

This example uses the public Page Header API.

Usage conventions ​

Use title, content and icon or their matching slots, along with the extra and default slots, to compose the header. The back event signals the user’s intent to go back. The host controls routing and browser history. This example keeps a local count of back actions.
