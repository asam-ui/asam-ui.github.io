Virtualized Tree ​

Example data, control text, messages and source comments may be in Chinese. Viewer controls and API headings use English. Untranslated API descriptions are marked.

When to use it ​

Display a large hierarchy in a viewport with a numeric height.

Basic usage and states ​

The following example uses the public features of this component.

Usage conventions ​

Use height and itemSize for viewport and row height. Use data and props to map your actual fields. Each node key corresponds to props.value. See the full notes.

Native usage and API ​

These examples use the pinned 2.14.7 release. Cascader and TreeSelect examples set value-mode="native" explicitly. Their native values, paths, field mappings, and callbacks apply to that mode. The API tables show native defaults. See the ASAM overrides and four size values in the usage notes.

Virtualization keeps the number of rendered rows bounded when working with large hierarchies.

Basic usage ​

Display a basic tree structure.

Example: native-basic

Show source
LicenseExample source ZIPComplete project ZIP
vue
<template>
	<AsamTreeV2 style="max-width: 600px" :data="data" :props="props" :height="200" />
</template>

<script lang="ts" setup>


import { AsamTreeV2 } from '@asam-ui/ui';
// Adapted from the fixed upstream MIT example: tree-v2/basic.vue

interface Tree {
	id: string;
	label: string;
	children?: Tree[];
}

const getKey = (prefix: string, id: number) => {
	return `${prefix}-${id}`;
};

const createData = (
	maxDeep: number,
	maxChildren: number,
	minNodesNumber: number,
	deep = 1,
	key = 'node'
): Tree[] => {
	let id = 0;
	return Array.from({ length: minNodesNumber })
		.fill(deep)
		.map(() => {
			const childrenNumber = deep === maxDeep ? 0 : Math.round(Math.random() * maxChildren);
			const nodeKey = getKey(key, ++id);
			return {
				id: nodeKey,
				label: nodeKey.replace(/^node/, '节点'),
				children: childrenNumber
					? createData(maxDeep, maxChildren, childrenNumber, deep + 1, nodeKey)
					: undefined
			};
		});
};

const props = {
	value: 'id',
	label: 'label',
	children: 'children'
};
const data = createData(4, 30, 40);
</script>

You can expand or check nodes when the tree initializes.

Set default-expanded-keys and default-checked-keys to control which nodes expand and which are checked by default.

Usage and contract notes ​

Usage conventions ​

Use height and itemSize for viewport and row height. Use data and props to map your actual fields. Each node key corresponds to props.value. Use showCheckbox, checkStrictly, defaultExpandedKeys, defaultCheckedKeys, filterMethod, and node events according to this entry point's contract. The default slot provides node and data, and the empty slot handles empty data. See the public expose API for filtering, checking, expansion, and scrolling. Supply data from the host before rendering. Tree V2 has no Tree-style lazy or load props. itemSize defines row height independently of the four control densities.
