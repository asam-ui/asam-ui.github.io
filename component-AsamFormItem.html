选择与表单

表单项 AsamFormItem

连接表单字段、标签、错误提示与帮助内容。

使用场景 ​

连接表单字段、标签、错误提示与帮助内容。prop 指向表单 model 字段，独立 help 提供不参与校验的说明。

帮助、标签与错误插槽 ​

help 插槽覆盖 help 属性。label 插槽收到 label，error 插槽收到实际错误文本；自定义内容保留错误语义。

帮助、标签与错误插槽

展开源码
vue
<template>
	<div class="example">
		<AsamBaseForm
			ref="form"
			v-bind="{ ...{ 'label-position': 'top' }, model: model, rules: rules }"
		>
			<AsamFormItem ref="item" v-bind="{ label: '项目名称', prop: 'name', help: '名称必填' }">
				<template #label="{ label }"> {{ label }} * </template>
				<AsamInput v-model="model.name" />
				<template #help> 用于团队列表展示 </template>
				<template #error="{ error }">
					<span role="alert">
						{{ error }}
					</span>
				</template>
			</AsamFormItem>
		</AsamBaseForm>
		<AsamButton type="default" @click="submit"> 校验 </AsamButton>
		<output>{{ result }}</output>
	</div>
</template>

defineOptions({ name: 'AsamFormItemBasicExample' });

import type { AsamBaseFormExpose, AsamBaseFormProps } from '@asam-ui/ui';
const form = ref<AsamBaseFormExpose>();
const model = reactive({ name: '', team: '' });
const rules: AsamBaseFormProps['rules'] = {
	name: [{ required: true, message: '请输入名称', trigger: 'blur' }],
	team: [{ required: true, message: '请选择团队', trigger: 'change' }]
};
const result = ref('尚未提交');
async function submit() {
	try {
		await form.value?.validate();
		result.value = '校验通过';
	} catch {
		result.value = '请检查必填项';
	}
}
import type { AsamFormItemExpose } from '@asam-ui/ui';
const item = ref<AsamFormItemExpose>();
</script>

单项清除与重置 ​

clearValidate 只清除单项提示，resetField 恢复单项初始值。validateState/validateMessage 是实时公开状态。

四档尺寸与上下文继承 ​

四个实例分别显式使用 large、big、default、small。下面省略 size 的实例随 ConfigProvider 响应切换；显式 size 覆盖祖先。面板本身没有 size 契约的入口不附加虚构尺寸属性。

四档尺寸与上下文继承
