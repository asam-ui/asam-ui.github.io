分页 AsamPagination

展示页码并让宿主管理当前页和每页数量。

使用场景 ​

展示页码并让宿主管理当前页和每页数量。

基础用法与状态 ​

下列示例只使用本入口的实际公开能力。

基础用法与状态

展开源码
vue
<template>
	<AsamPagination
		v-bind="{
			total: 95,
			pageSizes: [10, 20, 50],
			layout: 'total, sizes, prev, pager, next',
			size
		}"
		v-model:current-page="page"
		v-model:page-size="pageSize"
	/>
	<label>
		<span>密度</span>
		<AsamSelect v-model="size">
			<AsamOption v-for="value in sizes" :key="value" :label="value" :value="value">{{
				value
			}}</AsamOption>
		</AsamSelect>
	</label>
	<p role="status">第 {{ page }} 页，每页 {{ pageSize }} 条</p>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamPaginationBasicDemo' });
import { ref } from 'vue';
import { AsamSelect, AsamOption, AsamPagination } from '@asam-ui/ui';
import type { AsamControlSize } from '@asam-ui/ui';
const sizes: AsamControlSize[] = ['large', 'big', 'default', 'small'];
const size = ref<AsamControlSize>('default');
const page = ref(1);
const pageSize = ref(10);
</script>

使用约定 ​

v-model:current-page 与 v-model:page-size 管理状态，total/pageCount、pageSizes、layout、disabled/background 控制显示。基础 current-change/size-change/change 和 ASAM page-change/page-size-change 按公开事件使用。size 接受 large/big/default/small 并继承上下文；不要同时给模型配置互相冲突的静态值。它只改变分页状态，实际数据请求由宿主处理。

完整使用场景 ​

基础用法 ​

设置layout，表示需要显示的内容，用逗号分隔，布局元素会依次显示。分页元素包括：prev（跳转到上一页的按钮）、next（跳转到下一页的按钮）、pager（页码列表）、jumper（跳转输入框）、total（总条目数）、sizes（用于设置每页条数的选择器）以及 ->（该符号之后的所有元素将被靠右对齐）。

	<div>
		<AsamSwitch
			:model-value="value"
