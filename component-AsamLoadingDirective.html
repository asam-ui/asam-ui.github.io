加载指令 AsamLoadingDirective

将加载遮罩绑定到元素，在状态变化或元素卸载时关闭。

使用场景 ​

将加载遮罩绑定到元素，在状态变化或元素卸载时关闭。

状态、动态文字与卸载 ​

切换遮罩、修改提示文字，并卸载目标检查清理。

状态、动态文字与卸载

展开源码
vue
<template>
	<div class="actions">
		<AsamButton type="default" native-type="button" @click="loading = !loading"
			>切换加载</AsamButton
		>
		<label>
			<span>提示文字</span>
			<AsamInput v-model="text" />
		</label>
		<AsamButton type="default" native-type="button" @click="mounted = !mounted"
			>卸载/恢复区域</AsamButton
		>
	</div>
	<div
		v-if="mounted"
		v-asam-loading="loading"
		v-bind="{ 'element-loading-text': text, class: 'loading-target' }"
	>
		<p class="example-paragraph">局部内容区域</p>
	</div>
	<p class="example-paragraph" role="status">{{ loading ? '加载中' : '加载已结束' }}</p>
</template>

const mounted = ref(true);
</script>

使用约定 ​

绑定值可以是 boolean 或加载选项对象。 完整说明。

组合职责与生命周期 ​

绑定 false 或 true 控制显隐；对象值直接提供 text/background/spinner/svg/svgViewBox/customClass 和目标选项，绑定对象的文字等视觉字段按原生规则更新。 完整说明。

宿主卸载由 原生组件 原生 unmounted 钩子处理，不另建状态、关闭守卫或清理算法。

全屏指令与自动结束 ​

fullscreen 与 lock 修饰符选择视口范围并锁定滚动；绑定 false 或宿主卸载时由指令关闭。

全屏指令与自动结束

展开源码
vue
<template>
	<AsamButton v-asam-loading.fullscreen.lock="loading" type="default" @click="start"
		>显示全屏指令加载</AsamButton
	>
	<p class="example-paragraph">指令绑定状态决定显隐，1.5 秒后自动结束。</p>
</template>

<script lang="ts" setup>
import { ref, onBeforeUnmount } from 'vue';
import { AsamButton, vAsamLoading } from '@asam-ui/ui';
const loading = ref(false);
let timer: ReturnType<typeof setTimeout> | undefined;
const start = () => {
	clearTimeout(timer);
	loading.value = true;
	timer = setTimeout(() => {
		loading.value = false;
	}, 1500);
};
onBeforeUnmount(() => clearTimeout(timer));
</script>

<style scoped>
p:where(.example-paragraph) {
	margin-block: 16px;
	line-height: 1.8;
	overflow-wrap: anywhere;
}
</style>

用法与契约补充说明 ​

使用约定 ​

绑定值可以是 boolean 或加载选项对象。fullscreen/body/lock 修饰符分别选择全屏、挂到 body 和锁定滚动。对象选项和 element-loading-text 等原生属性提供文本与外观，文字按原生 updated 规则更新。绑定 false 和宿主卸载直接交由原生指令关闭；beforeClose/closed 是加载服务选项，不属于原生指令处理的协议。旧 asam-loading-* 属性迁移为 element-loading-*。没有控件 size；服务参数和返回实例参见 LoadingService。

组合职责与生命周期 ​

绑定 false 或 true 控制显隐；对象值直接提供 text/background/spinner/svg/svgViewBox/customClass 和目标选项，绑定对象的文字等视觉字段按原生规则更新。fullscreen、body 与 lock 修饰符在创建时确定遮罩范围，改变拓扑需先关闭再重建。卸载钩子释放实例、锁屏和目标样式。与服务不同，不自行持有全局共享全屏句柄。
