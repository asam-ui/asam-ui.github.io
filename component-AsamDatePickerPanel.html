日期面板 AsamDatePickerPanel

在页面中常驻编辑日期。

使用场景 ​

在页面中常驻编辑日期。 未设置 valueFormat 时保留 Date 模型；format 控制展示，valueFormat 控制模型文本或时间戳。

原生默认模型 ​

未设置行为属性时由原生控件解析默认值。以下完整 SFC 对照显式 undefined、null 和空字符串；输出保留原始模型类型，不把清空值统一为 null。固定原生版本的非法输入诊断与兼容限制仍按原生处理。

原生默认模型

展开源码
vue
<template>
	<section class="native-values-example">
		<p class="example-paragraph">使用原生模型和默认值；日期/时间未传 valueFormat，选择后保持 Date。</p>
		<AsamDatePickerPanel v-model="value" @update:model-value="updates++" />
		<AsamButton type="default" native-type="button" @click="value = undefined"
			>显式 undefined</AsamButton
		>
		<AsamButton type="default" native-type="button" @click="value = null">显式 null</AsamButton>
		<AsamButton type="default" native-type="button" @click="value = ''"
			>显式空字符串</AsamButton
		>
		<output>{{ summary }}；更新次数 {{ updates }}</output>
	</section>
</template>

<script lang="ts" setup>
import { computed, ref } from 'vue';
import { AsamButton, AsamDatePickerPanel } from '@asam-ui/ui';
import type { AsamDatePickerPanelValue } from '@asam-ui/ui';
defineOptions({ name: 'AsamDatePickerPanelNativeValuesExample' });
const value = ref<AsamDatePickerPanelValue>();
const updates = ref(0);
const summary = computed(() =>
	value.value === undefined
		? 'undefined'
		: value.value instanceof Date
			? 'Date ' + value.value.toISOString()
			: JSON.stringify(value.value)
);
</script>

用法与契约补充说明 ​

ASAM 扩展与迁移 ​

常驻 Panel 同样支持 quarter、quarters、quarterrange 与原生范围的 singlePanel（含 datetimerange）；输入弹层的 teleported 不属于此入口。border 控制面板边框，disabled 禁用选择，切换 type 时调用方应重置不兼容的模型。showFooter 和 showConfirm 默认为 false，需要多选确认流程时显式打开。

ASAM 扩展与迁移 ​

ASAM 四档 size 与表单、ConfigProvider 继承一致。null、undefined 和空字符串直接交给原生 Panel，不进行边界转换；遇到原生对某种输入的警告或异常时由调用方选择原生支持的模型。未指定模型时保留原生默认值，展示 format 不改变存储；日期字符大小写按 valueFormat 规则配置。 常驻面板不提供输入聚焦或打开方法，当前 expose 为空。 单点日期时间使用 DatePicker type=datetime；两个独立日期时间端点使用 DateTimeRangePicker。

本地化与高级配置 ​

日期语言和控件文字是两份配置：本例的 locale.ts / locale.js 同时注册 Day.js 的 zh-cn 日期 locale，中文每周从周一开始，英文从周日开始。应用需显式安装 dayjs，并保证组件与应用消费同一实例；只切换 Provider 字典不会改变周首日。日期 locale 注册不切换应用的全局默认语言。

原生默认值与适配说明 ​

type 默认为 date，modelValue 默认空字符串，valueFormat 未设置时为 Date；border 默认为 true，showFooter/showConfirm 默认为 false。 其余行为默认值交由固定版本原生组件解析；显式 undefined、null、false 原样输入，不以包装层默认值覆盖。size 仅负责 ASAM large/big/default/small 四档密度及品牌样式。DatePicker/TimePicker/TimeSelect 的 focus/blur（日期和时间另有 handleOpen/handleClose）直接使用原生公开实例的接收者和返回值；Panel 没有这些输入实例方法。
