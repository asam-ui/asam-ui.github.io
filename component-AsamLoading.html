加载组合入口 AsamLoading

统一访问加载服务与指令，并可用于应用级注册。

使用场景 ​

统一访问加载服务与指令，并可用于应用级注册。

通过组合入口使用指令 ​

SFC 局部注册不要求应用全量安装。

通过组合入口使用指令

展开源码
vue
<template>
	<div class="actions">
		<AsamButton type="default" native-type="button" @click="loading = !loading"
			>切换加载</AsamButton
		>
		<label>
			<span>提示文字</span>
			<AsamInput v-model="text" />
		</label>
		<AsamButton type="default" native-type="button" @click="mounted = !mounted"
			>卸载/恢复区域</AsamButton
		>
	</div>
	<div
		v-if="mounted"
		v-asam-loading="loading"
		v-bind="{ 'element-loading-text': text, class: 'loading-target' }"
	>
		<p>局部内容区域</p>
	</div>
	<p role="status">{{ loading ? '加载中' : '加载已结束' }}</p>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamLoadingBasicDemo' });
import { ref } from 'vue';
import { AsamInput, AsamButton, AsamLoading } from '@asam-ui/ui';
const vAsamLoading = AsamLoading.directive;
const loading = ref(false);
const text = ref('正在加载');
const mounted = ref(true);
</script>

使用约定 ​

AsamLoading.service 指向 加载服务，AsamLoading.directive 指向 加载指令。app.use(AsamLoading) 注册 asam-loading 指令和 $asamLoading；它是组合对象，不是 Vue 标签组件。

选择局部或全屏用法 ​

  • 局部加载与实例更新、全屏加载服务：函数调用，创建方持有和关闭句柄。
  • 局部指令与动态文字、全屏加载指令：用绑定状态控制显隐，宿主卸载时清理。

服务参数与返回实例见加载服务页面；指令绑定值、修饰符和生命周期见加载指令页面。组合入口只说明 service、directive、install 的关系。

API

服务 AsamLoading

名称说明类型必填默认值
service创建加载实例；完整参数与返回实例见加载服务页面。（ASAM 声明）typeof AsamLoadingService是未知 / 未声明
directive加载指令；绑定值、修饰符与生命周期见加载指令页面。（ASAM 声明）typeof AsamLoadingDirective是未知 / 未声明
install通过 app.use(AsamLoading) 注册指令和应用加载服务。（ASAM 声明）(app: App) => void是未知 / 未声明
公开类型视图
ts
const AsamLoading: {
 service: typeof AsamLoadingService;
 directive: typeof AsamLoadingDirective;
 install(app: App): void;
}
