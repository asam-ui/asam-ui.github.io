时间选项选择器 AsamTimeSelect

从固定起止区间按步长生成时间选项，用于预约和排班。

使用场景 ​

从固定起止区间按步长生成时间选项，用于预约和排班。正常选择提交格式化时间文本，清空时直接输出原生 valueOnClear 结果。

原生默认模型 ​

未设置行为属性时由原生控件解析默认值。以下完整 SFC 对照显式 undefined、null 和空字符串；输出保留原始模型类型，不把清空值统一为 null。固定原生版本的非法输入诊断与兼容限制仍按原生处理。

原生默认模型

展开源码
vue
<template>
	<section class="native-values-example">
		<p>使用原生模型和默认值，选择提交格式化时间文本，清空输出原生配置值。</p>
		<AsamTimeSelect v-model="value" clearable @update:model-value="updates++" />
		<button type="button" @click="value = undefined">显式 undefined</button>
		<button type="button" @click="value = null">显式 null</button>
		<button type="button" @click="value = ''">显式空字符串</button>
		<output>{{ summary }}；更新次数 {{ updates }}</output>
	</section>
</template>

<script lang="ts" setup>
import { computed, ref } from 'vue';
import { AsamTimeSelect } from '@asam-ui/ui';
import type { AsamTimeSelectValue } from '@asam-ui/ui';
defineOptions({ name: 'AsamTimeSelectNativeValuesExample' });
const value = ref<AsamTimeSelectValue>();
const updates = ref(0);
const summary = computed(() =>
	value.value === undefined
		? 'undefined'
		: value.value instanceof Date
			? 'Date ' + value.value.toISOString()
			: JSON.stringify(value.value)
);
</script>

}

ASAM 扩展与迁移 ​

固定 2.14.7 对无法解析或负数的 start/end，以及无法解析、负数或零步长 step 给出诊断，并分别回退到 09:00、18:00、00:30，避免无穷生成选项。原生没有附加 24 小时或 60 分钟上限：25:70 的解析和内部格式仍为 25:70；推进零步长得到 26:10，推进 00:30 得到 26:40（组件中的零步长先回退，不能用工具函数零步长代替组件行为）。默认 HH:mm 下对应选项显示 02:10 和 02:40，选择时模型也是这个显示格式值；跨午夜的 24:15 同样显示并提交 00:15。需要限制钟表范围时，由调用方验证输入。

start 大于 end 且 includeEndTime=false 时没有选项；includeEndTime=true 时仍追加 end。minTime/maxTime 使用原始时间比较，等于 min/max 的选项也禁用，包括被追加的 end。format 同时决定选项显示和选择提交的文本；不自动清除调用方已有的越界模型，联动更新由调用方决定。teleported 和 validateEvent 由内部 Select 承接。

ASAM 四档 size 与表单、ConfigProvider 继承一致。step 是时间文本，不是分钟数。 validateEvent 控制表单校验触发；teleported 决定弹层挂载位置。 单点日期时间使用 DatePicker type=datetime；两个独立日期时间端点使用 DateTimeRangePicker。

API 阅读方式 ​

下方 Props、Events、Slots、Exposes 按当前实际公开类型与运行默认值生成。组合属性按分支生效，不能任意混搭值模式。标为“未知 / 未声明”的默认值不代表 false 或空值。所有示例的 TS 与 JS 版本和支持文件同源；复制多文件示例时保留目录及相对导入。

原生清空配置与迁移 ​

基础入口仅委托原生公开 props、事件、slots、模型与 expose。未传属性与显式 undefined、null、false 均保持原生语义；不补入空值，不替换清空工厂，不将输出统一为 null。合法 0、false、undefined 或数组工厂输出及原生的事件顺序完整保留，工厂调用受原生校验与计算规则约束。

固定 2.14.7 对某些清空哨兵与格式组合可能产生空显示、格式化异常或诊断；这些属于原生兼容限制，基础包装不接管处理。需要 nullable 业务模型的调用方应在自己的高级数据适配层处理；双端 DateTimeRangePicker/DateTimePicker 保留明确的完整范围/null 组合协议。原依赖默认字符串模型的用法需显式传入 valueFormat（日期 YYYY-MM-DD，时间 HH:mm:ss）。
