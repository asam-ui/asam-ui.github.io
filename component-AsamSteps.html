使用约定 ​

active 表示当前步骤索引，direction、space、alignCenter、simple、processStatus/finishStatus 控制呈现。default 插槽放 Step；它展示流程状态，推进、校验和请求由宿主处理。

完整使用场景 ​

基础用法 ​

简洁风格的步骤条

设置 active 属性，接受一个 Number，表明步骤的 index，从 0 开始。需要定宽的步骤条时，设置 space 属性即可，它接受 Number，单位为 px，如果不设置，则为自适应。设置 finish-status 属性可以改变已经完成的步骤的状态。

基础用法

展开源码
许可
vue
<template>
	<AsamSteps style="max-width: 600px" :active="active" finish-status="success">
		<AsamStep title="步骤 1" />
		<AsamStep title="步骤 2" />
		<AsamStep title="步骤 3" />
	</AsamSteps>

	<AsamButton type="default" style="margin-top: 12px" @click="next">下一步</AsamButton>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamStepsCapBasicDemo' });
import { AsamSteps, AsamStep, AsamButton } from '@asam-ui/ui';

import { ref } from 'vue';

const active = ref(0);

const next = () => {
	if (active.value++ > 2) active.value = 0;
};
</script>
