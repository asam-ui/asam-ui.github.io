虚拟树 AsamTreeV2

在数值高度的视窗内展示较多层级节点。

使用场景 ​

在数值高度的视窗内展示较多层级节点。

基础用法与状态 ​

下列示例只使用本入口的实际公开能力。

基础用法与状态

展开源码
vue
<template>
	<AsamTreeV2
		v-bind="{
			data,
			height: 180,
			itemSize: 32,
			showCheckbox: true,
			defaultExpandedKeys: ['root'],
			props: { value: 'id', label: 'label', children: 'children', disabled: 'disabled' }
		}"
		@node-click="selected = $event.label"
	>
		<template #default="{ data: item }">
			<span>{{ item.label }}</span>
		</template>
	</AsamTreeV2>
	<p role="status">当前节点：{{ selected }}</p>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamTreeV2BasicDemo' });
import { ref } from 'vue';
import { AsamTreeV2 } from '@asam-ui/ui';
const data = [
	{
		id: 'root',
		label: '本地记录',
		children: [
			{ id: 'draft', label: '草稿' },
			{ id: 'locked', label: '锁定记录', disabled: true }
		]
	}
];
const selected = ref('');
</script>

使用约定 ​

height/itemSize 指定视窗与行高，data 与 props 映射实际字段，节点 key 对应 props.value。showCheckbox、checkStrictly、defaultExpandedKeys/defaultCheckedKeys、filterMethod 及节点事件按本入口契约使用。default 插槽提供 node/data，empty 处理空数据；实例过滤、勾选、展开、滚动等能力以公开 Expose 为准。它没有 Tree 的 lazy/load 契约，宿主先准备数据。行高不属于四档控件密度。

原生协议完整用法与 API ​

以下用法对应固定 2.14.7。Cascader 与 TreeSelect 的示例显式使用 value-mode="native"；其原生值、路径、字段映射和回调不能直接套到标准化模式。API 表保留原生默认值，ASAM 覆盖值与四档尺寸以下列约定为准。

不论你的数据量多大，虚拟树都能毫无压力地处理。
