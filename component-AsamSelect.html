选择器 AsamSelect

用于单选、多选与筛选静态选项。

使用场景 ​

用于单选、多选与筛选静态选项。 options 使用包含 label、value、raw 的规范化选项；本组件不发起数据请求。远程与字典数据见本站对应数据组件。

单选、筛选与事件 ​

change 反映用户提交，clear 反映清空。禁用选项不能选择；disabled 禁用整个选择器并保留已选回显。实例 focus / blur 访问实际输入。

单选、筛选与事件

展开源码
vue
<template>
	<div class="example">
		<AsamSelect
			ref="control"
			v-bind="{ clearable: true, filterable: true, 'aria-label': '团队' }"
			v-model="value"
			:options="options"
			@change="event = 'change: ' + String($event)"
			@clear="event = 'clear'"
		/>
		<div class="row">
			<AsamButton type="default" @click="control?.focus()"> 聚焦 </AsamButton>
			<AsamButton type="default" @click="control?.blur()"> 失焦 </AsamButton>
		</div>
		<output>值：{{ value }}；{{ event }}</output>
		<AsamSelect :model-value="value" :options="options" disabled aria-label="禁用选择" />
	</div>
</template>

对象、数组与字符串存储 ​

valueMode="object" 返回完整规范化选项。multiple 配合 array 返回数组，配合 string 与 separator 保存分隔文本；对象模式不能与字符串存储组合。数值与布尔值的字符串还原依赖选项，避免同名字符串碰撞。

multipleLimit 限制实际选中数量，删除标签后可以重新选择。示例同时展示默认折叠标签、对象清空为 null、数组和分隔字符串的实际模型。

对象、数组与字符串存储

展开源码
vue
<template>
	<div class="example">
		<AsamSelect
			v-model="objectValue"
			:options="options"
			v-bind="{ 'value-mode': 'object', clearable: true, 'aria-label': '对象选择' }"
		/>
		<AsamSelect
			v-model="arrayValue"
			:options="options"
			v-bind="{
				multiple: true,
				'collapse-tags': true,
				'collapse-tags-tooltip': true,
				'aria-label': '数组选择'
			}"
		/>
		<AsamSelect
			v-model="stringValue"
			:options="options"
			v-bind="{
				multiple: true,
				'multiple-value-mode': 'string',
				separator: '|',
				'aria-label': '字符串选择'
			}"
		/>
		<AsamSelect
			v-model="limitedValue"
			:options="options"
			multiple
			:multiple-limit="1"
			aria-label="最多一项"
		/>
		<output data-object>{{ JSON.stringify(objectValue) }}</output>
		<output data-array>{{ JSON.stringify(arrayValue) }}</output>
		<output data-string>{{ stringValue }}</output>
		<output data-limited>{{ JSON.stringify(limitedValue) }}</output>
	</div>
</template>

分组、原始值与插槽 ​

valueMode="native" 使用 Option/OptionGroup 和原始值，不经过规范化存储。header/footer、prefix、label 与 empty 用于展示层。

分组、原始值与插槽

展开源码
vue
<template>
	<div class="example">
		<AsamSelect
			v-model="value"
			v-bind="{
				'value-mode': 'native',
				filterable: true,
				clearable: true,
				'aria-label': '分组选择'
			}"
		>
			<AsamOptionGroup label="团队">
				<AsamOption label="设计" value="design" />
				<AsamOption label="开发" value="dev" />

			<template #footer> 本地选项 </template>
			<template #label="{ label }"> 已选 {{ label }} </template>
			<template #empty> 无匹配项 </template>
		</AsamSelect>
		<output>值：{{ value }}</output>
	</div>
</template>

用法与契约补充说明 ​

ASAM 扩展与迁移 ​

ASAM 扩展为四档密度、规范化 options、valueMode、multipleValueMode 与 separator。原始对象值必须显式 native 并配置 valueKey；object 模式保存规范化 option，raw 保留业务原件。空单选为 null，空多选为 [] 或空字符串。未解析值不会自动发起请求。loading、remote、remoteMethod 只是调用方控制的检索入口，异步生命周期使用本站 Remote 组件。

对象选项创建 ​

filterable + allowCreate 允许输入新选项。普通记录的 valueMode="object" 返回完整 { value, label, raw }，单选清空为 null，多选清空为 []。自定义 value/raw 必须传同步 createOption(text)；它必须返回真实实体，不能返回字符串、Promise 或缺少 raw 的对象。多选按实际值类型去重，数字 7 与字符串 '7' 保持区别；同值已有规范项优先。回填完整对象不需要先请求远端。

滚动末端与浮层插槽 ​

end-reached(direction) 来自列表真正到达末端，方向为 top/bottom/left/right；popup-scroll 仅提供滚动位置，两者不能替代。默认插槽可组合 Option/OptionGroup；header/footer/loading/empty/prefix/tag/label 分别承接列表内容、状态与选中展示。valueMode="native" 保留原始对象、字段映射与原生分组，不参与 ASAM 对象创建归一化。

自定义标签、加载与清空策略 ​

多选 tag 插槽接收 data、selectDisabled、deleteTag；调用 deleteTag 保留原生禁用和 remove-tag 事件。label 插槽接收 index、label、value；index 为 number，label/value 沿用原生公开槽的开放类型，具体操作须与实际选项值匹配。collapseTags、maxCollapseTags 与 collapseTagsTooltip 控制默认折叠标签；自定义 tag 时由插槽自己决定布局。 tagTooltip 显式字段优先，随后继承同名浮层配置，最后使用底层 Tooltip 默认。 emptyValues 决定空值集合，valueOnClear 决定清空返回值；object 模式仍输出完整选项或 null。 loading / empty 插槽分别展示加载和无结果；multipleLimit 限制已选数量。

异步查询回调 ​

filterable + remote 将输入交给 remoteMethod。基础入口本身不请求数据，示例由调用方 异步筛选本地模拟记录，并用 generation 防止迟到响应覆盖较新查询。debounce 控制输入 回调延迟，reserveKeyword 决定多选选中后保留搜索词；完整请求和字典生命周期使用本站 RemoteSelect / DictSelect。filterMethod 可在非 remote 模式使用自定义过滤策略。

空字符串、清空与默认折叠标签 ​

空字符串可以是有效选项；native 模式的 emptyValues 明确排除空字符串，valueOnClear 明确返回 null。默认 tag 渲染下，显式 tagTooltip 配置优先于继承的 popperClass/effect；maxCollapseTags 控制保留的可见标签数。自定义 tag 插槽会接管默认标签布局，因此另用这个完整示例验证默认折叠浮层。

API 阅读方式 ​

高级 value/object 模式默认 placeholder 为“请选择”；valueMode="native" 保留原生省略值、显式 undefined/null/false 和默认值，可显式覆盖；显式 popperClass 保留并追加当前密度类。固定 2.14.7 已移除 suffixTransition，箭头内容使用 suffixIcon，样式由当前组件 CSS 控制。

原生委托边界 ​

valueMode="native" 直接使用依赖中的原生选择器；options、props 字段映射、默认值、全部事件参数和命名插槽原样交给原生。focus / blur 保留原生调用返回值，selectedLabel 每次读取原生公开值。高级 value/object 和 array/string 路径单独承接 ASAM 数据协议；createOption 不生成虚假业务实体。创建首项、选项缓存与查询宽度若有原生限制，ASAM 不修改私有 options/hover 状态或 DOM 尺寸算法。

对象选项创建 ​

固定依赖 2.14.7 / Vue 3.5.34 下，已核验的单选输入为 options=[]、显式传入初始 modelValue=undefined 或 modelValue=null 的两组独立输入，allowCreate / filterable / defaultFirstOption 为 true，reserveKeyword / teleported 为 false。输入 Created 并等待 500 ms 后，直接按 Enter（未先按 ArrowDown），可见的 Created 项没有被选中，且没有 update:modelValue / change 事件；原生选择器与 ASAM native / value / object 路径结果一致。点击同一项的正控制能够选择，ASAM object 返回完整 value/label/raw。该 Enter 结果只限定此具体输入；多选、非空 options、其他初始值及其他键盘流程按各自核验结果判断，ASAM 不接管私有选项或导航算法。
