卡片列表 AsamCardList

组合卡片的自动宽度、固定列数与间距布局。

卡片列表 ​

AsamCardList 为默认插槽中的卡片提供网格布局。数据加载、分页和选择状态由使用方维护，卡片内容可使用 AsamCard 或 AsamTaskCard。

自动宽度与固定列 ​

示例包含独立的卡片子组件和数据文件。切换布局可比较自动宽度与三列网格，切换等高开关可观察不同长度内容。

columns 为正整数时固定列数；省略、传入 null 或无效列数时自动排列。自动模式通过 minCardWidth 和 maxCardWidth 控制卡片宽度，并将单卡宽度限制在容器内；固定列模式按剩余宽度等分。

间距与对齐 ​

宽度和间距接受数字或 CSS 长度字符串，数字按 px 处理。省略时使用卡片布局 tokens，rowGap 省略时沿用 gap。align 接受 start、center、stretch，equalHeight 默认开启。

自动模式中，数字或 px 字符串表示的最小宽度大于最大宽度时，最大宽度按最小宽度处理。其他 CSS 单位不会作跨单位比较，使用方应提供一致且有效的范围。狭窄容器需要避免强制过多固定列。

使用边界 ​

组件仅提供默认插槽，不提供列表事件或实例方法。容器间距和卡片宽度不是控件尺寸；不要将 size 或数据表格的分页参数传给它。

用法与契约补充说明 ​

固定列、自动宽度与异常范围 ​

正整数 columns 使用固定列；null、0、负数和非整数回到自动布局。minCardWidth 大于 maxCardWidth 且二者可比较为 px 时，最大宽度钳制到最小宽度。gap 数字转 px，rowGap 省略继承 gap，空白字符串使用 token 默认值。align 控制水平方向对齐；equalHeight 默认开启，在每个网格行内将卡片拉伸到该行最高卡片的高度。关闭时使用纵向起始对齐，各卡片保持自然内容高度及自身最小高度。二者独立；自动模式变为单列时，每行只有一张卡片，不会将不同行强制拉成同高。
