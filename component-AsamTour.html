浮层

漫游导览 AsamTour

围绕页面目标组织多步骤引导。

使用场景 ​

围绕页面目标组织多步骤引导。

目标步骤与无目标步骤 ​

目标来自当前 SFC 的元素 ref，避免依赖页面全局 ID。

目标步骤与无目标步骤

展开源码
vue
<template>
	<button type="button" @click="open = true">开始导览</button>
	<button ref="target" type="button">导览目标</button>
	<AsamTour v-model="open" v-model:current="current" @finish="finished++">
		<AsamTourStep :target="target" title="第一步" description="这里展示目标说明。" />
		<AsamTourStep title="完成导览">
			<template #header>下一步操作</template>
			<p>没有目标的步骤使用居中展示。</p>
		</AsamTourStep>
		<template #indicators="{ current: index, total }">{{ index + 1 }} / {{ total }}</template>
	</AsamTour>
	<p role="status">当前步骤 {{ current + 1 }}；完成 {{ finished }} 次</p>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamTourBasicDemo' });
import { ref } from 'vue';
import { AsamTour, AsamTourStep } from '@asam-ui/ui';
const open = ref(false);
const current = ref(0);
const finished = ref(0);
const target = ref<HTMLElement>();
</script>

使用约定 ​

modelValue 与 current 分别控制显隐和当前步骤，change/finish/close 通知进度。mask、gap、placement、showArrow、scrollIntoViewOptions 和 targetAreaClickable 配置目标遮罩及定位。每个步骤使用 AsamTourStep；步骤枚举沿用原生能力，不能把任意包装组件当作步骤。indicators 插槽可自定义进度；无四档密度 size。

完整用法 ​

以下用法使用本库公开入口。每个示例提供完整 TS/JS SFC，参数、事件、插槽和实例类型见本页 API。服务实例由创建方负责关闭；HTML 内容仅用于调用方已知的可信字符串。

组合职责与生命周期 ​

default 中可直接放置 AsamTourStep，或使用原生可识别的 Fragment 组织步骤。无 props、无 slots 的纯函数组件可返回这些步骤；函数不应依赖组件实例或 setup 状态。用 defineComponent 或 SFC 创建的有状态包装组件即使渲染 AsamTourStep，也不会因此参与步骤枚举。不要依靠包装组件的 render 结果增加步骤，组件不为此递归渲染或改写 VNode。

current 为零起始索引，change 通知切换，finish 只在最后一步完成时发出，close 包含当前索引。target 可为选择器、HTMLElement 或返回元素的函数，动态目标需保证当前 DOM 已挂载。scrollIntoViewOptions 接受布尔值或原生滚动选项对象，步骤可覆盖父配置。mask/gap/targetAreaClickable 控制遮罩与可点击区域；无目标步骤居中。indicators 接收 current/total；导航按钮配置由各步骤承担，关闭和卸载释放焦点、遮罩及监听。

步骤组合与原生限制 ​

下面的 Fragment 和无 props 纯函数示例各有两步。有状态包装示例中，包装后的步骤不计入 total，只剩直接声明的一步；第一次完成便结束导览。这是原生组合限制。需要有状态内容时，将 AsamTourStep 直接放在导览插槽中，把内容组件放进步骤内部。

	<div>
		<button type="button" @click="begin('fragment')">查看 Fragment 两步</button>
		<button type="button" @click="begin('functional')">查看纯函数两步</button>

<script lang="ts" setup>
import { defineComponent, h, ref } from 'vue';
import { AsamTour, AsamTourStep } from '@asam-ui/ui';

defineOptions({ name: 'AsamTourStepCompositionDemo' });
type Mode = 'fragment' | 'functional' | 'stateful';
const mode = ref<Mode>('fragment');
const open = ref(false);
const finished = ref(0);

// 纯函数没有 props、slots 或组件实例依赖，只返回公开步骤。
const FunctionalSteps = () => [
	h(AsamTourStep, { title: '纯函数第一步', description: '无 props 的纯函数返回步骤。' }),
	h(AsamTourStep, { title: '纯函数第二步', description: '两步都会计入 total。' })
];

// 反例：有状态包装返回步骤，但不会被原生枚举为一个步骤。
const StatefulStep = defineComponent({
	name: 'TourStatefulStep',
	setup: () => () => h(AsamTourStep, { title: '不会被枚举的包装步骤' })
});

function begin(nextMode: Mode) {
	mode.value = nextMode;
	finished.value = 0;
	open.value = true;
}
</script>
