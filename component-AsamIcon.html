图标容器 AsamIcon

为一个图形内容提供统一的颜色与尺寸容器。

使用场景 ​

为一个图形内容提供统一的颜色与尺寸容器。

基础用法与状态 ​

下列示例只使用本入口的实际公开能力。

使用约定 ​

本入口是容器；实际图形从独立 @asam-ui/icons-vue 包导入。size 是图形尺寸，可使用数值或 CSS 尺寸，不能把控件密度 big 当成图形尺寸。color 可消费主题变量，default 插槽放一个 ASAM 图标。独立图标组件也可直接使用；两者职责不同。

完整容器用法 ​

容器与直接图标 ​

容器的 size 与 color 为内部 SVG 提供尺寸和颜色，更新后实时生效；独立 SVG 使用自己的字体尺寸和颜色。Menu 图标用 MenuIcon 导入别名，避免与 HTML 的 menu 标签重名。下例通过具名 import 即可运行，无需全局注册。

容器样式与旋转 ​

is-loading 使用每两秒一圈的持续旋转动画；可在使用方覆盖动画。no-inherit 作为附加类名与显式 color 一起使用，实际颜色由 color 决定，尺寸仍来自 size 或继承字体；本版本没有该类名的额外容器行为。图标可放入按钮并设置垂直对齐。
