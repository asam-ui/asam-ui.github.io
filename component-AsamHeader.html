布局页头 AsamHeader

在页面中组织页头、侧栏、主内容与页脚。

使用场景 ​

在页面中组织页头、侧栏、主内容与页脚。

使用约定 ​

height 是 CSS 高度，default 插槽放页头内容。它作为 Container 的直接子节点时参与纵向布局识别。 布局宽高不属于四档控件密度；这些入口没有业务事件。

组合用法 ​

在 AsamContainer 的完整场景中使用本入口；包含 layout-hm、layout-hmf、layout-am、layout-ham、layout-hamf、layout-ahm、layout-ahmf、example。
