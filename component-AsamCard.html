卡片 AsamCard

将标题、摘要、正文和操作组织为一个独立内容单元。

使用场景 ​

将标题、摘要、正文和操作组织为一个独立内容单元。

基础用法与状态 ​

下列示例只使用本入口的实际公开能力。

基础用法与状态

展开源码
vue
<template>
	<AsamCard
		v-bind="{
			title: '本地草稿',
			subtitle: '保存后可继续编辑',
			bordered: true,
			hoverable: true,
			shadow: 'hover'
		}"
	>
		<template #extra>
			<button type="button" @click="count++">保存</button>
		</template>
		<p>卡片正文由 default 插槽提供。</p>
		<template #footer>
			<span role="status">已保存 {{ count }} 次</span>
		</template>
	</AsamCard>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamCardBasicDemo' });
import { ref } from 'vue';
import { AsamCard } from '@asam-ui/ui';
const count = ref(0);
</script>

使用约定 ​

ASAM title/subtitle、extra 插槽、bordered/hoverable 和 bodyClass 提供卡片扩展。基础 header/footer、headerClass/footerClass/bodyStyle 与 shadow 保留公开契约。header 插槽可替代默认标题区域，footer 支持正文或插槽；卡片没有控件密度 size。事件由实际内部操作控件提供，不制造卡片业务事件。

完整使用场景 ​

Basic usage ​

Card includes title, content and operations.

Card is made up of header, body and footer. header and footer are optional, and its content distribution depends on a named slot.

You can define when to show the card shadows

The shadow attribute determines when the card shadows are displayed. It can be always, hover or never.
