消息确认服务 AsamMessageBox

以 Promise 驱动提示、确认和文本输入流程。

使用场景 ​

以 Promise 驱动提示、确认和文本输入流程。

提示、确认和输入验证 ​

每个 Promise 均处理取消；输入框通过 inputPattern 校验，成功展示返回值。

提示、确认和输入验证

展开源码
vue
<template>
	<div class="actions">
		<AsamButton type="default" :disabled="active" native-type="button" @click="alert"
			>提示</AsamButton
		>
		<AsamButton type="default" :disabled="active" native-type="button" @click="confirm"
			>确认归档</AsamButton
		>
		<AsamButton type="default" :disabled="active" native-type="button" @click="prompt"
			>输入名称</AsamButton
		>
	</div>
	<p role="status">{{ result }}</p>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamMessageBoxBasicDemo' });
import { ref, onBeforeUnmount } from 'vue';
import { AsamButton, AsamMessageBox } from '@asam-ui/ui';
const result = ref('等待操作');
const active = ref(false);
const alert = async () => {
	active.value = true;
	try {
		await AsamMessageBox.alert('本地草稿已保存', '提示', { buttonSize: 'big' });
		result.value = '已阅读';
	} catch {
		result.value = '提示关闭';
	} finally {
		active.value = false;
	}
};
const confirm = async () => {
	active.value = true;
	try {
		await AsamMessageBox.confirm('确认归档这条记录？', '归档确认', {
			distinguishCancelAndClose: true,
			buttonSize: 'small'
		});
		result.value = '已确认归档';
	} catch (action) {
		result.value = String(action);
	} finally {
		active.value = false;
	}
};
const prompt = async () => {
	active.value = true;
	try {
		const data = await AsamMessageBox.prompt('请输入至少两个字的名称', '命名', {
			inputPattern: /^.{2,}$/,
			inputErrorMessage: '名称至少两个字',
			buttonSize: 'large'
		});
		result.value = data.value;
	} catch {
		result.value = '输入已取消';
	} finally {
		active.value = false;
	}
};
onBeforeUnmount(() => {
	if (active.value) AsamMessageBox.close();
});
</script>

使用约定 ​

消息框提供通用调用与 alert、confirm、prompt 快捷入口，并返回 Promise。 完整说明。

宿主 AppContext 与简写重载 ​

三个快捷方法均支持 (message, options?, appContext?) 和 (message, title, options?, appContext?)。 完整说明。

宿主应用可在挂载前完成配置：

js
import { createApp } from 'vue';
import { AsamMessageBox } from '@asam-ui/ui';
import App from './App.vue';

const app = createApp(App);
app.provide('asam-message-box-context', '当前应用提供的内容');
app.use(AsamMessageBox);
app.mount('#app');

以下完整 TS/JS 示例可切换 alert、confirm、prompt 与两种重载。取消和卸载只调用本例 message 动作的 cancel，使本例 Promise 结算；不全局关闭其他业务的弹层。

宿主 AppContext 与简写重载

展开源码
vue
<template>
	<div class="actions">
		<label>
			<span>服务类型</span>
			<AsamSelect v-model="method" :disabled="active">
				<AsamOption value="alert" :label="'alert'">alert</AsamOption>
				<AsamOption value="confirm" :label="'确认'">确认</AsamOption>
				<AsamOption value="prompt" :label="'prompt'">prompt</AsamOption>
			</AsamSelect>
		</label>
		<label>
			<span>上下文</span>
			<AsamSelect v-model="contextMode" :disabled="active">
				<AsamOption value="explicit" :label="'显式当前 AppContext'"
					>显式当前 AppContext</AsamOption
				>
				<AsamOption value="installed" :label="'安装服务的默认上下文'"
					>安装服务的默认上下文</AsamOption
				>
				<AsamOption value="null" :label="'显式 null'">显式 null</AsamOption>
			</AsamSelect>
		</label>
		<AsamButton native-type="submit" type="default" :disabled="active" @click="open(false)"
			>使用 options 简写</AsamButton
		>
		<AsamButton native-type="submit" type="default" :disabled="active" @click="open(true)"
			>使用 title 重载</AsamButton
		>
	</div>
	<p role="status">{{ result }}</p>
</template>
<script lang="ts" setup>
defineOptions({ name: 'AsamMessageBoxServiceContextDemo' });
import { defineComponent, getCurrentInstance, h, inject, onBeforeUnmount, ref } from 'vue';
import { AsamSelect, AsamOption, AsamButton, AsamMessageBox } from '@asam-ui/ui';
import type { AsamMessageBoxActionHandlers, AsamMessageBoxOptions } from '@asam-ui/ui';

const context = getCurrentInstance()?.appContext;
const method = ref<'alert' | 'confirm' | 'prompt'>('alert');
const contextMode = ref<'explicit' | 'installed' | 'null'>('explicit');
const active = ref(false);
const result = ref('等待操作');
let cancelOwned: (() => void) | undefined;
const Content = defineComponent({
	setup() {
		const label = inject<string>('asam-message-box-context', '未设置宿主 provide');
		return () => h('span', { 'data-context-label': '' }, label);
	}
});
const cancel = () => cancelOwned?.();
const open = async (withTitle: boolean) => {
	if (active.value) return;
	active.value = true;
	result.value = '等待确认';
	const message = ({ cancel }: AsamMessageBoxActionHandlers) => {
		cancelOwned = cancel;
		return h('div', [
			h(Content),
			h(
				AsamButton,
				{ type: 'default', nativeType: 'button', onClick: cancel },
				'取消本例弹层'
			)
		]);
	};
	const options: AsamMessageBoxOptions = {
		buttonSize: 'default',
		inputPlaceholder: '输入本次确认值',
		distinguishCancelAndClose: true
	};
	const appContext =
		contextMode.value === 'installed'
			? undefined
			: contextMode.value === 'null'
				? null
				: context;
	try {
		const value = withTitle
			? await AsamMessageBox[method.value](message, '宿主上下文', options, appContext)
			: await AsamMessageBox[method.value](message, options, appContext);
		result.value =
			method.value === 'prompt' ? `confirmed: ${value.value}` : `resolved: ${value}`;
	} catch (action) {
		result.value = `rejected: ${String(action)}`;
	} finally {
		cancelOwned = undefined;
		active.value = false;
	}
};
onBeforeUnmount(cancel);
</script>

		cancelOwned = undefined;
		active.value = false;

用法与契约补充说明 ​

宿主 AppContext 与简写重载 ​

三个快捷方法均支持 (message, options?, appContext?) 和 (message, title, options?, appContext?)。省略 options 时可用 (message, undefined, appContext)；省略 title 而保留 options 时用 (message, undefined, options, appContext)。显式 AppContext 使 VNode 内容能读取对应应用的 provide；省略或传 undefined 使用 app.use(AsamMessageBox) 安装时记录的默认上下文。显式 null 直接交给底层服务，不使用 ASAM 安装默认值；宿主另行配置的底层服务默认回退仍保留。

更多参数与事件说明 ​

使用约定 ​

AsamMessageBox(options, appContext?) 或 alert/confirm/prompt(message, titleOrOptions?, optionsOrContext?, appContext?) 返回 Promise。确认 resolve；取消或关闭 reject，distinguishCancelAndClose 可区分 cancel/close。prompt 成功数据包含 value 与 action；必须处理取消分支。beforeClose(action, instance, done) 可异步拦截提交，callback 是回调模式。buttonSize 使用 ASAM large/big/default/small 控件密度，弹层本身不使用这组 size。close 是全局关闭 API，本例仅在自己发起的弹层存活时清理。

组合职责与生命周期 ​

message 函数可接收 AsamMessageBoxActionHandlers 的 confirm/cancel/close，在 VNode 内提供业务按钮，三种动作仍经过 beforeClose 并驱动同一个 Promise。distinguishCancelAndClose=true 时分别拒绝 cancel 和 close；confirm 解析确认结果，prompt 返回 action/value。beforeClose 使用 done 完成异步确认，不调用则保持打开；callback 是回调模式。inputValidator/inputPattern/inputErrorMessage 负责输入校验。close 为全局清理，原生语义不保证结算所有存活 Promise，因此不能用它替代业务 cancel，也不要在共存示例卸载时无条件调用。
