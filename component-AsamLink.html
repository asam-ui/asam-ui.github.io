使用约定 ​

href/target 设置真实目标，type、underline、disabled、icon 与 default/icon 插槽控制呈现。click 提供 MouseEvent；阻止默认行为需由宿主明确处理。ASAM size 支持 large/big/default/small，区别于图标的图形尺寸。

链接目标校验 ​

href 会直接传给原生 <a>，组件没有自动过滤 URL。来自外部输入的目标应由宿主在传入前校验，避免执行 javascript: 等协议或跳转到不允许的目标。以下函数允许 HTTP、HTTPS 及按当前页面 origin 解析的相对路径；解析失败或协议不在白名单时返回 #。传给 AsamLink 的是 sanitizeUrl(rawUrl) 的返回值。

完整 TypeScript 版本：

ts
function sanitizeUrl(url: string): string {
	const allowedProtocols = ['http:', 'https:'];
	try {
		const parsed = new URL(url, window.location.origin);
		return allowedProtocols.includes(parsed.protocol) ? parsed.href : '#';
	} catch {
		return '#';
	}
}

完整 JavaScript 版本：

js
function sanitizeUrl(url) {
	const allowedProtocols = ['http:', 'https:'];
	try {
		const parsed = new URL(url, window.location.origin);
		return allowedProtocols.includes(parsed.protocol) ? parsed.href : '#';
	} catch {
		return '#';
	}
}

这两个函数用于浏览器环境，只演示协议校验；HTTP/HTTPS 域名、跳转目标及授权仍须满足业务规则，不能仅凭协议白名单认定目标可信。

下划线 ​

控制下划线是否出现

属性 boolean 值 将在 3.0.0 版本中被移除，请考虑切换至新的 API。

从 2.9.9 开始，你可以使用 'always' | 'hover' | 'never' 来控制是否显示下划线。文档中的示例将都使用这些值。如果您使用的版本 低于 2.9.9，请参考：

vue
<template>
	<!-- works before 2.9.9, use 'hover' after, removed in 3.0.0 -->
	<el-link underline>link</el-link>
	<!-- works before 2.9.9, use 'never' after, removed in 3.0.0 -->
	<el-link :underline="false">link</el-link>
</template>
