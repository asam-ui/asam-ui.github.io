远端级联选择器 AsamRemoteCascader

在级联选择器上管理异步选项、重载和请求取消。

远端级联选择器 ​

在级联选择器上管理异步选项、重载和请求取消。

基础用法 ​

示例通过本地 Promise 函数加载选项，支持模型更新、暂停与重载。所有请求都留在演示内部。

本地数据与生命周期

展开源码
vue
<template>
	<section class="data-demo">
		<!-- prettier-ignore -->
		<AsamCheckboxItem v-model="active">启用请求</AsamCheckboxItem>
		<AsamRemoteCascader
			ref="control"
			v-model="value"
			:data-source="dataSource"
			:active="active"
			size="default"
			placeholder="请选择或输入"
			@error="error = $event.message"
			@success="error = ''"
		>
			<template #default="{ option, data }">{{ option?.label ?? data.label }}</template>
		</AsamRemoteCascader>
		<AsamButton type="primary" native-type="button" :disabled="!active" @click="reload"
			>强制重载</AsamButton
		>
		<AsamButton type="primary" native-type="button" @click="control?.cancel()"
			>取消请求</AsamButton
		>
		<p role="status">{{ result }} {{ error }}</p>
		<pre>{{ value }}</pre>
	</section>
</template>

<script lang="ts" setup>
import { ref } from 'vue';
import { AsamCheckboxItem, AsamButton, AsamRemoteCascader, defineAsamOptions } from '@asam-ui/ui';
import type { AsamRemoteCascaderExpose, AsamApiRequest } from '@asam-ui/ui';

defineOptions({ name: 'AsamRemoteCascaderBasicDemoExample' });
interface Item {
	label: string;
	value: string;
	children?: readonly Item[];
}
interface Query {
	text: string;
}
const value = ref<string | null>(null);
const active = ref(true);
const control = ref<AsamRemoteCascaderExpose<string, Item>>();
const error = ref('');
const result = ref('');
const items: readonly Item[] = [
	{ label: '准备', value: 'ready', children: [{ label: '就绪', value: 'available' }] },
	{ label: '进行', value: 'running' }
];
const api: AsamApiRequest<Query, readonly Item[]> = async (params, context) => {
	context.signal.throwIfAborted();
	return items.filter((item) => item.label.includes(params.text));
};
const factory = defineAsamOptions<string, Item>();
const dataSource = factory.api({
	api,
	params: { text: '' },
	transform: (response) => response,
	fieldNames: { label: 'label', value: 'value', children: 'children' }
});
async function reload() {
	const response = await control.value?.reload({ force: true });
	result.value = response?.status ?? 'cancelled';
}
</script>

数据来源与覆盖 ​

dataSource、api + params、request 三种来源只选一种。dataSource 必须由 defineAsamOptions 创建，使用该来源时映射、转换和缓存配置写在工厂内，不再重复传短来源属性。自定义字段映射同时提供同步 transform；API 返回 Promise，并检查 context.signal。

单选值模式使用标量或 null；对象模式使用规范化 AsamOption。多选的数组与分隔字符串模式由 multiple、valueMode、multipleValueMode 联合约束；对象模式不能使用字符串存储。切换值策略时同时调整模型类型。

省略顶层 multiple 时使用公开配置 props.multiple；显式顶层 false 或 true 优先。 动态改变多选配置时同时更新模型，来源校验与显示控件采用同一有效策略。

对象单选清空统一发布 null；合法原生 valueOnClear 为 false 或 0、且 emptyValues 包含该值时，也保留 update:modelValue、change 与 clear 事件。多选清空发布空数组。 合法清空回调返回 [] 或 [null]、且 emptyValues 包含对应数组时，对象单选同样 发布 null；原生清空数组不会进入公开的单对象模型。 实际值为 0 或 false 的业务节点仍保存完整 AsamOption 和 raw，不当成清空值； 原生实例的节点键分别为 number:0、boolean:false，与原生清空返回值区分。

层级来源一次返回完整树；children 通过字段映射规范化。数据层不开放 lazy/load 或 props.lazy/props.lazyLoad，不能从基础页的节点懒加载示例推导本组件支持。值模型保留 ASAM 标量/对象策略，不开放 native 值模式。

生命周期、事件与实例 ​

active=false 暂停请求并保留上次成功数据；reload({ force: true }) 请求新数据，cancel() 取消当前请求。success 返回规范化选项数组，error 返回 AsamDataError；旧成功数据更新失败时组件显示过期状态。reload 的 status 为 success、error 或 cancelled；不能把取消当作成功。

immediate 控制初始化是否请求，active 控制请求是否启用。初始化和默认值以本页自动 API 的原始来源为准。

插槽与基础能力 ​

default 插槽保留对应级联或树节点的 data/node 与可选 option；tag、label 等以对应基础入口和本页公开 slots 为准。

本站继承关系 ​

  • 级联选择器：适用的基础展示、交互与公开 API。

本页数据来源、模型、事件和实例的覆盖规则优先；本站链接不扩大本组件公开契约。尺寸使用基础组件的 ASAM 尺寸规则，示例使用 default。

完整树与对象多选 ​

示例一次返回完整组织树，使用 multiple 与 valueMode=object 保存规范化对象及 raw 成员；禁用成员不能勾选。展示节点、header/footer、过滤、清空、原生 getCheckedNodes、刷新失败的旧数据保留与取消慢请求。读取节点时只保存数量，避免序列化级联节点的循环引用。API 在演示内部运行，传递 AbortSignal 并检查取消。 不包含节点懒加载。

示例逐次保存 update:modelValue、change、success 和 error 的载荷快照：模型与成功结果保留规范化对象及原始 raw 树；失败记录错误种类和消息。default 读取规范化 option.raw 与原生 data.label，header/footer 直接展示内容。取消请求不会伪造一次成功事件，失败刷新不清空调用方模型。

<template>
	<section class="data-demo">
		<!-- prettier-ignore -->
		<AsamCheckboxItem v-model="active">启用请求</AsamCheckboxItem>
		<!-- prettier-ignore -->
		<AsamCheckboxItem v-model="failure">模拟接口失败</AsamCheckboxItem>
		<AsamRemoteCascader
			ref="control"
			v-model="value"
			:data-source="dataSource"
			multiple
			value-mode="object"
			:active="active"
			clearable
			filterable
			:teleported="false"
			:props="{ expandTrigger: 'click' }"
			placeholder="选择成员"
			size="default"
			@update:model-value="onModelUpdate"
			@change="onModelChange"
			@success="onSuccess"
			@error="onError"
		>
			<template #default="{ option, data }">
				<span :data-member="option?.raw.id">{{ data.label }}</span>
			</template>
			<template #header><p data-testid="hierarchy-header">完整组织树</p></template>
			<template #footer><p data-testid="hierarchy-footer">冻结成员不能勾选</p></template>
		</AsamRemoteCascader>
		<AsamButton type="primary" native-type="button" :disabled="!active" @click="reload"
			>强制重载</AsamButton
		>
		<AsamButton type="primary" native-type="button" @click="cancelSlow">取消慢请求</AsamButton>
		<AsamButton type="primary" native-type="button" @click="inspect">读取勾选节点</AsamButton>
		<AsamButton type="primary" native-type="button" @click="value = []">清空模型</AsamButton>
		<p role="status">结果：{{ result }}；成功次数：{{ successes }}；{{ error }}</p>
		<pre data-testid="tree-model">{{ JSON.stringify(value) }}</pre>
		<pre data-testid="checked-count">{{ checkedCount }}</pre>
		<pre data-testid="hierarchy-data-events">{{ JSON.stringify(events) }}</pre>
	</section>
</template>
<script lang="ts" setup>
defineOptions({ name: 'AsamRemoteCascaderCompleteTreeDemo' });
import { ref } from 'vue';
import { AsamCheckboxItem, AsamButton, AsamRemoteCascader, defineAsamOptions } from '@asam-ui/ui';
import type {
	AsamCascaderDataEmits,
	AsamValue,
	AsamDataError,
	AsamRemoteCascaderExpose,
	AsamOption,
	AsamApiRequest
} from '@asam-ui/ui';
import type { Member } from './provider.js';
import { members } from './provider.js';
const active = ref(true);
const failure = ref(false);
const slow = ref(false);
const api: AsamApiRequest<undefined, readonly Member[]> = async (_params, context) => {
	await new Promise<void>((done) => setTimeout(done, slow.value ? 500 : 100));
	context.signal.throwIfAborted();
	if (failure.value) throw new Error('演示完整树请求失败');
	return members;
};
const dataSource = defineAsamOptions<string, Member>().api({
	api,
	params: undefined,
	transform: (response) => response,
	fieldNames: { label: 'label', value: 'value', children: 'children', disabled: 'disabled' }
});
const value = ref<readonly AsamOption<string, Member>[]>([]);
const control = ref<AsamRemoteCascaderExpose<string, Member>>();
const result = ref('');
const successes = ref(0);
const error = ref('');
const checkedCount = ref(0);
type DataEmits = AsamCascaderDataEmits<AsamValue, object>;
const events = ref<readonly { readonly name: string; readonly payload: unknown }[]>([]);
function recordEvent(name: string, payload: unknown) {
	const snapshot: unknown = JSON.parse(JSON.stringify(payload));
	events.value = [...events.value, { name, payload: snapshot }];
}
function onModelUpdate(payload: DataEmits['update:modelValue'][0]) {
	recordEvent('update:modelValue', payload);
}
function onModelChange(payload: DataEmits['change'][0]) {
	recordEvent('change', payload);
}
function onSuccess(payload: DataEmits['success'][0]) {
	recordEvent('success', payload);
	successes.value++;
	error.value = '';
}
function onError(payload: AsamDataError) {
	recordEvent('error', { kind: payload.kind, message: payload.message });
	error.value = payload.message;
}
async function reload() {
	result.value = (await control.value?.reload({ force: true }))?.status ?? 'cancelled';
}
async function cancelSlow() {
	slow.value = true;
	const pending = control.value?.reload({ force: true });
	setTimeout(() => control.value?.cancel(), 30);
	result.value = (await pending)?.status ?? 'cancelled';
	slow.value = false;
}
function inspect() {
	checkedCount.value = control.value?.getCheckedNodes(false)?.length ?? 0;
}
</script>

局部请求错误插槽 ​

可选 error 插槽仅在当前请求错误存在时调用，接收只读 { error, stale, retry }。 error 与本实例 error 事件中的 AsamDataError 为同一对象，保留 cause、kind、 message 与 notified；渲染插槽不会再次通知 provider。stale 表示保留的数据已过期。

retry() 不接收参数，直接返回现有 reload({ force: true }) 的 Promise，结果为 AsamReloadResult<readonly AsamOption<V, I>[]> 的 success、error 或 cancelled 分支。 重试遵守 active、当前来源、取消和卸载规则，不改写模型。

提供该插槽时，自有内容替换整个默认局部错误区；返回空内容也表示主动替换。 未提供时继续显示原错误文字、过期提示和默认重试按钮。无 error 的单独 stale 状态 不调用此插槽；empty、loading 和其他基础插槽继续使用原作用域。

以下完整 TS/JS 示例先制造失败，再等待插槽 retry 的返回结果；成功后可再次制造 更新失败，观察旧结果与模型保留。每次挂载使用独立子 app 和本地 provider。

		busy.value = false;
	}
