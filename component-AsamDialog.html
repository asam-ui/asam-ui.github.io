浮层

对话框 AsamDialog

在独立浮层中完成短流程或确认操作，以 v-model 控制显隐。

使用场景 ​

在独立浮层中完成短流程或确认操作，以 v-model 控制显隐。

受控显隐与标题图标 ​

点击打开，使用底部完成按钮或关闭按钮关闭；焦点返回打开按钮。

受控显隐与标题图标

关闭确认与公开方法 ​

存在未保存内容时，关闭按钮进入确认步骤；确认后调用保存的 done。取消确认继续编辑。

关闭确认与公开方法

展开源码
vue
<template>
	<AsamButton type="default" native-type="button" @click="open = true">打开待保存内容</AsamButton>
	<AsamDialog
		ref="dialog"
		v-model="open"
		title="未保存内容"
		width="min(90vw, 500px)"
		:before-close="guard"
	>
		<p>确认丢弃后才关闭。</p>
		<div v-if="pending" class="actions">
			<AsamButton type="default" native-type="button" @click="approve">确认丢弃</AsamButton>
			<AsamButton type="default" native-type="button" @click="pending = null"
				>继续编辑</AsamButton
			>
		</div>
		<template #footer>
			<AsamButton type="default" native-type="button" @click="dialog?.handleClose()"
				>请求关闭</AsamButton
			>
		</template>
	</AsamDialog>
</template>

使用约定 ​

header、icon、default、footer 插槽分别承载标题、标识、正文和操作。ASAM 提供默认标题 icon 与独立尺寸 default/small/mini/large；焦点恢复沿用原生行为，width 可明确覆盖尺寸宽度。这组尺寸是浮层宽度，不是控件四档密度。beforeClose(done) 可拦截关闭按钮/遮罩；自定义底部按钮自行决定何时关闭。open/opened 与 close/closed 分别对应开始和动画完成。公开 handleClose 可走关闭流程，resetPosition 可重置拖动位置；不要写入内部 refs。

组合职责与生命周期 ​

modelValue 控制显隐，open/opened 与 close/closed 分别观察开始和过渡完成。beforeClose 只拦截组件的关闭入口；业务直接修改 modelValue 时自己执行校验。header 可获得 close/titleId/titleClass，footer 承担业务操作，title 与 icon 为 ASAM 扩展。handleClose 经过关闭守卫；visible/dialogContentRef 为实时句柄，resetPosition 用于拖动后复位。嵌套层使用独立状态，并按 appendToBody/appendTo 决定挂载容器；destroyOnClose 销毁内容，重新打开会创建新的内容节点。fullscreen、alignCenter、modalPenetrable 与 transition 可独立组合。size 的 default/small/mini/large 是弹层宽度别名，width 显式值优先，和四档控件密度分别配置。

原生显隐与焦点 ​

省略 appendToBody 等交互参数使用 原生公开组件 默认值；显式 undefined、null、false 原样传递。打开、关闭、自动聚焦及过渡事件使用原生顺序，关闭守卫、Esc 和焦点回退交由原生处理。ASAM 仅保留标题、图标与尺寸外观，公开实例方法保留原生 this、返回值及实时引用。

自定义 header 直接接收原生 close/titleId/titleClass，并由调用方声明标题节点；组件不额外包裹 heading 或重复设置 titleId。未提供 header 时，默认标题保留 ASAM 的标题、图标与外观。

参数省略时的默认值 ​

closeOnClickModal、closeOnPressEscape、lockScroll、modal、showClose 省略时均由原生组件采用 true。显式提供 false、undefined 或后续移除参数仍按原生契约透传；API 表的默认值描述省略参数，不是包装层的内部布尔转换结果。
