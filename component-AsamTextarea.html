基础输入与操作

多行文本 AsamTextarea

多行输入、字数限制、自适应高度与原生编辑操作。

使用场景 ​

用于说明、备注、长文本，固定多行职责。通过 rows 配置初始行数，通过 autosize 配置内容自适应高度；resize 控制用户拖动方向。

多行与字数限制 ​

showWordLimit 与 maxlength 配合显示字数；rows 控制初始行数。change 与 input 行为见事件 API。

多行与字数限制

展开源码
vue
<template>
	<div class="example">
		<AsamTextarea
			v-model="value"
			v-bind="{ class: 'field', 'aria-label': '任务说明' }"
			placeholder="请输入任务说明"
			:rows="3"
			:maxlength="120"
			show-word-limit
			word-limit-position="outside"
		/>
		<output>当前说明：{{ value }}</output>
	</div>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamTextareaBasicExample' });

import { AsamTextarea } from '@asam-ui/ui';
const value = ref('第一行说明\n第二行说明');
</script>

autosize 可使用布尔值或包含 minRows、maxRows 的对象；只读与禁用状态保留内容展示。

四档密度与继承 ​

large / big / default / small 分别为四档密度。显式 size 覆盖继承；省略 size 时按组件、组、表单、ConfigProvider 到 default 解析。通过切换 provider 验证继承响应。

四档密度与继承

展开源码
vue
<template>
	<div class="example">
		<div class="row">
			<AsamTextarea
				size="large"
				v-bind="{ class: 'field', 'aria-label': 'large尺寸' }"
				model-value="ASAM"
			/>
			<AsamTextarea
				size="big"
				v-bind="{ class: 'field', 'aria-label': 'big尺寸' }"
				model-value="ASAM"
			/>
			<AsamTextarea
				size="default"
				v-bind="{ class: 'field', 'aria-label': 'default尺寸' }"
				model-value="ASAM"
			/>
			<AsamTextarea
				size="small"
				v-bind="{ class: 'field', 'aria-label': 'small尺寸' }"
				model-value="ASAM"
			/>
		</div>
		<AsamConfigProvider :size="density">
			<div class="example">
				<AsamTextarea
					v-bind="{ class: 'field', 'aria-label': '继承尺寸' }"
					model-value="ASAM"
				/>
				<div class="row">
					<AsamButton type="default" @click="density = 'small'"> 继承 small </AsamButton>
					<AsamButton type="default" @click="density = 'big'"> 继承 big </AsamButton>
				</div>
			</div>
		</AsamConfigProvider>
		<output>配置提供器：{{ density }}</output>
	</div>
</template>

用法与契约补充说明 ​

ASAM 扩展与迁移 ​

原 Input 的 type="textarea" 改为 AsamTextarea，移除 type，保留 rows、autosize、resize 与字数配置。四档尺寸控制字体、行高和密度；多行高度还由内容、行数和 autosize 决定。prefix/suffix/prepend/append 类型见 API；装饰型单行组合请使用 Input。

清空、字素与浏览器高度 ​

clearable 和 clearIcon 提供多行清空，countGraphemes 承接字素计数；开启后不设置原生 minlength/maxlength。autosize 的 minRows/maxRows 限制自动高度，resize 控制用户拖动方向。隐藏容器重新显示时可调用 resizeTextarea；Firefox 的高度重绘依照固定上游修复，仍须在目标 Firefox 实际验证。
