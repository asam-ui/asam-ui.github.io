日期时间范围 AsamDateTimeRangePicker

以两个独立 datetime 输入编辑开始与结束时间。

使用场景 ​

以两个独立 datetime 输入编辑开始与结束时间。 模型只在两端完整时提交 [start, end]，空值为 null；部分选择保留在内部。

两个端点与完整模型 ​

startPlaceholder/endPlaceholder 分别设置端点提示。clear 清除范围，change 提交完整范围；valueFormat 决定两个端点的存储形式。

端点实例与插槽 ​

focus/blur/handleOpen/handleClose 接收 start 或 end，默认 start。default 单元格插槽额外携带 endpoint；visible-change 同时给出可见性和端点。

ASAM 扩展与迁移 ​

本入口有两个独立 datetime 弹层。singlePanel 和 isRange 不属于此组合的公开契约；需要真正的单面板日期时间范围，使用 AsamDatePicker type="datetimerange" single-panel。teleported 同时控制两个端点；name 和 id 的双元素数组分别传给开始/结束输入，字符串 id 的结束端附加 -end。输入和弹层 attrs（例如 tabindex、data 属性）传给两个端点，class/style 留在组合容器。清空一个端点将模型置为 null，并发出一次 clear 和一次 change(null)；首次只选一个非空端点不发出部分范围。

ASAM 扩展为双端点输入、端点实例、端点事件参数与四档密度。单点日期时间请使用 DatePicker type=datetime。旧 DateTimePicker 是同一范围契约的兼容名称；迁移只更换组件导入和标签，保留 DateTimeRangeValue。不要为本入口传入 type 或单个日期模型。

下方 Props、Events、Slots、Exposes 按当前实际公开类型与运行默认值生成。组合属性按分支生效，不能任意混搭值模式。标为“未知 / 未声明”的默认值不代表 false 或空值。源码区域提供对应语言的独立 Demo.vue，可直接复制或下载；本地辅助组件、数据和素材已内联到当前文件。
