走马灯 AsamCarousel

在同一范围内切换几组相关内容。

使用场景 ​

在同一范围内切换几组相关内容。

基础用法与状态 ​

下列示例只使用本入口的实际公开能力。

基础用法与状态

展开源码
vue
<template>
	<AsamCarousel
		v-bind="{ height: '180px', autoplay: false, trigger: 'click', arrow: 'always' }"
		@change="index = $event"
	>
		<AsamCarouselItem v-for="item in 3" :key="item" :name="String(item)">
			<div class="slide">本地内容 {{ item }}</div>
		</AsamCarouselItem>
	</AsamCarousel>
	<p class="example-paragraph" role="status">当前索引：{{ index }}</p>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamCarouselBasicDemo' });
import { ref } from 'vue';
import { AsamCarousel, AsamCarouselItem } from '@asam-ui/ui';
const index = ref(0);
</script>

<style scoped>
.slide {
	height: 100%;
	display: grid;
	place-items: center;
	background: var(--asam-color-surface);
}
</style>

<style scoped>
p:where(.example-paragraph) {
	margin-block: 16px;
	line-height: 1.8;
	overflow-wrap: anywhere;
}
</style>

使用约定 ​

height、initialIndex、trigger、autoplay/interval、loop、direction、type 和 indicatorPosition/arrow 控制展示；change 提供当前和上一个索引。实例可切换、前进或后退。示例关闭自动播放，用户通过箭头与指示器选择。

指示器 ​

可以将指示器的显示位置设置在容器外部

indicator-position 属性定义了指示器的位置。默认情况下，它会显示在走马灯内部，设置为 outside 则会显示在外部；设置为 none 则不会显示指示器。

基础用法 ​

结合使用 el-carousel 和 el-carousel-item 标签就得到了一个走马灯。每一个页面的内容是完全可定制的，把你想要展示的内容放在 el-carousel-item 标签内。默认情况下，在鼠标 hover 底部的指示器时就会触发切换。通过设置 trigger 属性为 click，可以达到点击触发的效果。
