基础输入与操作

数字输入 AsamInputNumber

数字步进、范围、精度、清空值与数字事件。

使用场景 ​

用于数量和有限精度的数值输入。v-model 为 number、null 或 undefined；change 同时提供新值与之前的值。需要格式化文本展示时见 Input。

范围与步进 ​

min/max 控制范围，step 控制步长；stepStrictly 约束为步长倍数。

省略 min/max 时保留固定原生的 Number.MIN_SAFE_INTEGER / Number.MAX_SAFE_INTEGER 默认边界，提交不安全整数会裁剪到该范围。应用需要其他范围时显式配置边界。

四档密度与继承 ​

large / big / default / small 分别为四档密度。显式 size 覆盖继承；省略 size 时按组件、组、表单、ConfigProvider 到 default 解析。通过切换 provider 验证继承响应。

用法与契约补充说明 ​

空值、非法格式与恢复 ​

省略 valueOnClear 时默认清空为 null，显式配置可使用数字、null、min 或 max。 非法格式编辑可能产生 null；重新键入有效数字即可恢复。模型及 update:modelValue、 input、change 的新旧值类型均为 number | null | undefined，不能把 null 当作字符串 或从事件协议中删除。

完整输入边界 ​

stepStrictly 保证步长倍数，precision 限定小数位且不能小于 step 的小数位数。min/max 在提交时限定范围；valueOnClear 指定清空后的值。disabled、readonly、controls、controlsPosition 分别控制禁用、只读、按钮显示和按钮位置。disabledScientific 禁止键盘 e/E，业务仍应校验数据。

动态表单状态与无障碍范围 ​

disabled、min/max 的更新委托 底层输入。2.14.7 原生在挂载时初始化部分 ARIA 属性，后续动态更新可能仍显示旧的 aria-disabled/aria-valuemin/aria-valuemax。ASAM 保留这一兼容限制，不使用 MutationObserver 改写属性，也不以重挂载恢复选区。

原生委托与事件记录 ​

下方完整 TS/JS 示例记录模型及事件顺序，并可切换禁用、只读和自动校验状态。省略的基础参数使用原生 defaults；显式 undefined/null/false 原样传入，合法值范围见 API。四档 size 是 ASAM 的视觉桥接；Password 额外固定 type=password，并在省略 showPassword 时启用显隐入口。
