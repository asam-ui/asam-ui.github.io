页头导航 AsamPageHeader

在页面标题旁放置返回操作和补充信息。

使用场景 ​

在页面标题旁放置返回操作和补充信息。

基础用法与状态 ​

下列示例只使用本入口的实际公开能力。

基础用法与状态

展开源码
vue
<template>
	<AsamPageHeader title="返回" content="本地说明" @back="count++">
		<template #extra>
			<span>草稿</span>
		</template>
	</AsamPageHeader>
	<p role="status">返回意图：{{ count }} 次</p>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamPageHeaderBasicDemo' });
import { ref } from 'vue';
import { AsamPageHeader } from '@asam-ui/ui';
const count = ref(0);
</script>

使用约定 ​

title/content/icon 及同名插槽、extra/default 插槽按公开契约组织。back 只通知返回意图，宿主决定路由或历史操作；本例记录本地次数，不修改浏览历史。
