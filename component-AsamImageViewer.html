独立实例、缩放输入与关闭策略 ​

下面的完整 TS/JS SFC 直接挂载 AsamImageViewer，展示全部公开实例、四个事件和四个插槽。前两张图片为本地 data URL，第三张故意加载失败，供观察 error 与 viewer-error。

打开前可设置 urlList、initialIndex、teleported、zIndex、infinite、zoomRate、scale、minScale、maxScale、closeOnPressEscape、hideOnClickModal、showProgress；本例还透传原生 crossorigin。打开后，default 插槽中的控制区可以动态修改 scale、关闭开关和循环策略。

ref<AsamImageViewerInstance>() 的公开 setActiveItem(index): void 用于手动切换。示例中的“ref：第二张”调用真实 Viewer ref 并显示返回类型；它与 toolbar scope 的 setActiveItem 分别展示。原生上一张/下一张在 infinite=false 时保留首尾边界，infinite=true 时按原生规则循环。

scale 是父级输入，不是 v-model；2.14.7 没有 scale 或 update:scale 事件。改动输入值观察原生显示；初始/动态 scale 的限制及 toolbar 的缩放步长均由依赖处理，ASAM 不新增缩放算法。关闭事件由原生 close、Esc 或允许的遮罩点击触发，宿主在 close handler 中卸载；“父级卸载 Viewer”直接改变 v-if，不伪造 close 事件。

<script lang="ts" setup>
import { ref } from 'vue';
import { AsamImageViewer } from '@asam-ui/ui';
import type { AsamImageViewerInstance } from '@asam-ui/ui';
defineOptions({ name: 'AsamImageViewerStandaloneDemo' });
const viewer = ref<AsamImageViewerInstance>();
const open = ref(false);
const initialIndex = ref(0);
const infinite = ref(false);
const scale = ref(1);
const zoomRate = ref(1.5);
const minScale = ref(0.5);
const maxScale = ref(2);
const closeOnPressEscape = ref(true);
const hideOnClickModal = ref(false);
const teleported = ref(true);
const zIndex = ref(2100);
const showProgress = ref(true);
const customProgress = ref(true);
const customToolbar = ref(true);
const events = ref<string[]>([]);
const returnType = ref('尚未调用');
const image = (color: string) =>
	'data:image/svg+xml,' +
	encodeURIComponent(
		`<svg xmlns="http://www.w3.org/2000/svg" width="320" height="220"><rect width="320" height="220" fill="${color}"/></svg>`
	);
const urls = [image('royalblue'), image('seagreen'), 'data:image/png;base64,broken'];
function goTo(index: number): void {
	returnType.value = typeof viewer.value?.setActiveItem(index);
}
function onClose(): void {
	events.value.push('close');
	open.value = false;
}
function onError(event: Event): void {
	events.value.push(`error:${event.type}`);
}
function onSwitch(index: number): void {
	events.value.push(`switch:${index}`);
}
function onRotate(degrees: number): void {
	events.value.push(`rotate:${degrees}`);
}
</script>

事件、插槽与职责拆分 ​

入口 独立 Viewer 示例中的用途
close / error / switch / rotate 记录无参数 close、原始 Event.type、图片索引和旋转角度，原生载荷不改写。
default 放置父级参数控制区与公开 ref 操作；Image 的内置预览不承接此插槽。
progress 使用 { activeIndex, total } 显示进度；关闭此插槽后可以独立观察 showProgress。
toolbar 使用 { actions, prev, next, reset, activeIndex, setActiveItem }；reset 按原生切换原始尺寸/适应模式，不是公开 ref 方法。
viewer-error 使用 { activeIndex, src } 展示故意失败的第三张图片，并用 ref 返回第一张。

图片本身的 load、lazy、placeholder、error 和 showPreview 属于 AsamImage；其 cap-image-preview、cap-custom-toolbar、cap-custom-progress、cap-load-failed 示例展示从图片打开预览的路径。本页 standalone 独立承接 Viewer 的 ref、scale、关闭策略以及 default/progress/toolbar/viewer-error，不能用 Image 的 toolbar slot 方法替代 Viewer ref 的证明。

使用约定 ​

urlList 提供图片数组，initialIndex 设置起始图片，infinite 控制循环，zoomRate/minScale/maxScale 控制缩放范围。close/switch/rotate 等事件反馈交互；插槽名称及参数以公开 Slots 为准。宿主用 v-if 管理预览器存在状态并处理 close。teleported 决定挂载位置，zIndex 决定层级。本入口没有控件密度 size。

缩放边界、键盘、切换和关闭遵循组件的公开行为。公开实例方法及其返回值以本页 API 为准。
