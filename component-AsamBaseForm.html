基础表单 AsamBaseForm

为输入控件提供模型、规则、校验状态和表单尺寸上下文。

使用场景 ​

为输入控件提供模型、规则、校验状态和表单尺寸上下文。model 必须是调用方维护的响应式对象，FormItem.prop 绑定对应字段。

校验、原生提交与重置 ​

以真实 form 提交触发校验；FormActions 使用 submitNativeType=submit 时无需同时监听 save 再次提交。resetFields 将有 prop 的字段恢复初始值。

校验、原生提交与重置

展开源码
vue
<template>
	<div class="example">
		<AsamBaseForm
			ref="form"
			v-bind="{ ...{ 'label-position': 'top' }, ...{ model: model, rules: rules } }"
			@submit.prevent="submit"
		>
			<AsamFormItem label="项目名称" prop="name" help="使用团队易于辨认的名称">
				<AsamInput v-model="model.name" aria-label="项目名称" />
			</AsamFormItem>
			<AsamFormItem label="团队" prop="team">
				<AsamSelect v-model="model.team" :options="options" />
			</AsamFormItem>
			<AsamFormActions submit-native-type="submit" @cancel="form?.resetFields()" />
		</AsamBaseForm>
		<output>{{ result }}；{{ model }}</output>
	</div>
</template>

defineOptions({ name: 'AsamBaseFormBasicExample' });

const model = reactive({ name: '', team: '' });
const rules: AsamBaseFormProps['rules'] = {
	name: [{ required: true, message: '请输入名称', trigger: 'blur' }],
	team: [{ required: true, message: '请选择团队', trigger: 'change' }]
};

	try {

	} catch {
		result.value = '请检查必填项';
	}
}

	{ label: '设计', value: 'design', raw: { code: 'design' } },
	{ label: '开发', value: 'dev', raw: { code: 'dev' } },
	{ label: '停用', value: 'off', disabled: true, raw: { code: 'off' } }
];
</script>

字段校验与动态禁用 ​

validateField 校验指定字段，clearValidate 清除提示，scrollToField 定位字段。表单 disabled 传递到控件；显式设置 disabled=false 的子控件保持启用。不能用关闭校验代替禁用。

用法与契约补充说明 ​

异步规则、行内布局与字段实例 ​

inline 控制行内排列；labelPosition 可为 left/right/top，FormItem 的位置覆盖表单继承值。left/right 通常配合 labelWidth；数值 0 保持零宽度，不转换为 auto。labelSuffix、required 星号位置、hideRequiredAsterisk、statusIcon、showMessage、inlineMessage 分别控制标签与提示。disabled 是控件的继承默认值，子控件显式的 disabled 配置优先。

异步规则、行内布局与字段实例 ​

下面的异步 validator 返回 Promise，确认账号规则读取同一响应式 model。提交时 await validate，结束后在 finally 恢复 saving；callback 风格的 validator 必须调用 callback。规则依赖的其他字段改变后，使用 validateField 重新检查相关字段；validateOnRuleChange 只处理规则本身的变化。scrollToError 和 scrollIntoViewOptions 用于失败定位。

异步规则、行内布局与字段实例 ​

validate、validateField 支持 callback 和 Promise；验证失败应处理 rejection。validate 事件传出字段路径、布尔结果和消息。fields 是已注册字段的实时列表，getField 返回上下文或 undefined；不要把布局分区误当注册字段。clearValidate 清提示而不改模型，resetFields 可指定路径；setInitialValues 设置后续 resetFields 的基线，并不等于立即改写当前 model。scrollToField 可显式定位。

标签提示、规则变化与 callback ​

下面可以切换 auto/0/固定 labelWidth、必填星号隐藏与左右位置、showMessage 与 inlineMessage，并观察 validateOnRuleChange 对规则替换的处理。validate/validateField 的 callback 接收 valid 和错误字段；提供 callback 后仍可 await 返回的 Promise，但无需将 callback 的 false 结果当未处理异常。FormItem 的外部 error、validateStatus 展示服务端消息和显式校验状态。

嵌套与动态字段、数字和辅助标签 ​

prop 支持 contact.email 字符串路径或 ['rows', '0', 'value'] 数组路径。动态列表使用稳定 key；新增、删除或 prop 路径改变时，表单项注册与初始值跟随真实字段。resetFields 重置字段值，不恢复使用方已删除的列表条目。数字规则要求数字模型，原生 input 使用 .number；空值、范围和 required 仍由规则决定。

嵌套与动态字段、数字和辅助标签 ​

嵌套 FormItem 的标签宽度默认归零，可单独指定 labelWidth。一个控件的 label 自动关联；多个控件组成 group 时，应逐个提供辅助名称，见 AsamFormItem。BaseForm 负责模型、规则和表单实例；动态字段 schema、异步选项和数据 provider 的组合由 AsamForm 承接。使用方维护的 v-for 字段列表与 schema 驱动表单各有用途。
