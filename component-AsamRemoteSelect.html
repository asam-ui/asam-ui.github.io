远端选择器 AsamRemoteSelect

在选择器上管理异步选项、重载和请求取消。

远端选择器 ​

在选择器上管理异步选项、重载和请求取消。

基础用法 ​

示例通过本地 Promise 函数加载选项，支持模型更新、暂停与重载。所有请求都留在演示内部。

点击“读取当前标签”读取实例的只读 selectedLabel：空模型返回空字符串，选择后返回当前标签。focus() 与 blur() 为无参数方法，仅控制输入焦点，不改写模型；失焦按钮阻止鼠标按下时抢走焦点，以便观察 blur() 的实际作用。勾选“启用多选”切换到独立数组模型；空选择读取空数组，选择多个选项后返回标签数组，输入焦点方法仍不改写模型。

<template>
	<section class="data-demo">
		<!-- prettier-ignore -->
		<label><input v-model="active" type="checkbox">启用请求</label>
		<!-- prettier-ignore -->
		<label><input v-model="multipleMode" type="checkbox">启用多选</label>
		<AsamRemoteSelect
			v-if="!multipleMode"
			ref="control"
			v-model="value"
			:data-source="dataSource"
			:active="active"
			size="default"
			placeholder="请选择或输入"
			@error="error = $event.message"
			@success="error = ''"
		>
			<template #prefix><span aria-hidden="true">状态</span></template>
		</AsamRemoteSelect>
		<AsamRemoteSelect
			v-else
			ref="control"
			v-model="multipleValue"
			multiple
			:data-source="dataSource"
			:active="active"
			size="default"
			placeholder="请选择或输入"
			@error="error = $event.message"
			@success="error = ''"
		>
			<template #prefix><span aria-hidden="true">状态</span></template>
		</AsamRemoteSelect>
		<button type="button" :disabled="!active" @click="reload">强制重载</button>
		<button type="button" @click="control?.cancel()">取消请求</button>
		<button type="button" @click="readSelectedLabel">读取当前标签</button>
		<button type="button" @click="control?.focus()">聚焦选择器</button>
		<button type="button" @mousedown.prevent @click="control?.blur()">失焦选择器</button>
		<p role="status">{{ result }} {{ error }}</p>
		<pre>{{ multipleMode ? multipleValue : value }}</pre>
		<pre data-testid="selected-label">{{ selectedLabel }}</pre>
	</section>
</template>

<script lang="ts" setup>
import { ref } from 'vue';

defineOptions({ name: 'AsamRemoteSelectBasicExample' });
import { AsamRemoteSelect, defineAsamOptions } from '@asam-ui/ui';
import type { AsamAsyncSelectExpose, AsamApiRequest } from '@asam-ui/ui';
interface Item {
	label: string;
	value: string;
	children?: readonly Item[];
}
interface Query {
	text: string;
}
const value = ref<string | null>(null);
const active = ref(true);
const multipleMode = ref(false);
const multipleValue = ref<string[]>([]);
const control = ref<AsamAsyncSelectExpose<string, Item>>();
const selectedLabel = ref<string | string[]>('');
function readSelectedLabel() {
	selectedLabel.value = control.value?.selectedLabel ?? '';
}
const error = ref('');
const result = ref('');
const items: readonly Item[] = [
	{ label: '准备', value: 'ready' },
	{ label: '进行', value: 'running' }
];
const api: AsamApiRequest<Query, readonly Item[]> = async (params, context) => {
	context.signal.throwIfAborted();
	return items.filter((item) => item.label.includes(params.text));
};
const factory = defineAsamOptions<string, Item>();
const dataSource = factory.api({
	api,
	params: { text: '' },
	transform: (response) => response,
	fieldNames: { label: 'label', value: 'value' }
});
async function reload() {
	const response = await control.value?.reload({ force: true });
	result.value = response?.status ?? 'cancelled';
}
</script>

本地创建与完整实体 ​

allow-create 与 filterable 开启后，createOption(text) 同步返回完整的 AsamOption<V, I>：label、正确类型的 value 和真实 raw。默认记录使用字符串 value； 数字、布尔值或自定义 raw 必须提供类型一致的工厂，不能返回 Promise 或仅有标量。

<template>
	<section class="data-demo">
		<div class="actions">

<script lang="ts" setup>
import { nextTick, ref } from 'vue';
import { AsamRemoteSelect } from '@asam-ui/ui';
import type {
	AsamOption,
	AsamCreateOption,
	AsamValue,
	AsamAsyncSelectExpose,
	AsamApiRequest
} from '@asam-ui/ui';
interface Member {
	id: string;
	label: string;
	value: string;
}
interface Query {
	tenant: string;
	text: string;
}
const tenant = ref('a');
const failure = ref(false);
const canonical = ref(false);
defineOptions({ name: 'AsamRemoteSelectLocalCreationDemo' });
const value = ref<AsamOption<string, Member> | null>(null);
const control = ref<AsamAsyncSelectExpose<string, Member>>();
const createdTexts = ref<string[]>([]);
const providerValues = ref<AsamValue[]>([]);
const message = ref('');
const result = ref('');
const createOption: AsamCreateOption<string, Member> = (text) => {
	createdTexts.value.push(text);
	return { label: text, value: text, raw: { id: 'local-' + text, label: text, value: text } };
};
const transform = (items: readonly Member[]) => items;
const api: AsamApiRequest<Query, readonly Member[]> = async (query, context) => {
	await new Promise<void>((done) => setTimeout(done, 150));
	context.signal.throwIfAborted();
	if (failure.value) throw new Error('演示请求失败');
	const items: Member[] = [{ id: 'server', label: 'Server', value: 'server' }];
	if (canonical.value) items.push({ id: 'saved', label: 'Server Omega', value: 'Omega' });
	return items.filter((item) => item.label.toLowerCase().includes(query.text.toLowerCase()));
};
const search = {
	debounceMs: 100,
	buildParams: (params: Query, text: string) => ({ ...params, text })
};
async function reload() {
	await nextTick();
	result.value = (await control.value?.reload({ force: true }))?.status ?? 'cancelled';
	if (result.value === 'success') message.value = '';
}
</script>

import { reactive } from 'vue';
import type { AsamDataProvider } from '@asam-ui/ui';

export interface ProviderCall {
	readonly text: string;
	readonly scope: string;
	readonly epoch: number;
	readonly requestId: number;
}
export interface ProviderState {
	failure: boolean;
	slow: boolean;
	calls: ProviderCall[];
	aborts: number;
}

/** Local transport only: no server URL is contacted by this example. */
export function createProvider() {
	const state = reactive<ProviderState>({ failure: false, slow: false, calls: [], aborts: 0 });
	let release: () => void = () => undefined;
	const provider: AsamDataProvider = {
		async request(config, context) {
			if (config.url !== '/demo/members' || config.method !== 'get')
				throw new Error('Unknown local route');
			const text = config.params?.text;
			if (typeof text !== 'string') throw new Error('text must be a string');
			context.signal.throwIfAborted();
			state.calls.push({
				text,
				scope: context.scope,
				epoch: context.epoch,
				requestId: context.requestId
			});
			if (state.slow) {
				await new Promise<void>((resolve, reject) => {
					const abort = () => {
						state.aborts++;
						context.signal.removeEventListener('abort', abort);
						reject(context.signal.reason);
					};
					context.signal.addEventListener('abort', abort, { once: true });
					release = () => {
						context.signal.removeEventListener('abort', abort);
						resolve();
					};
				});
			}
			context.signal.throwIfAborted();
			if (state.failure) throw new Error('Local provider failure');
			return [
				{ id: 1, name: '第一成员' },
				{ id: 2, name: '第二成员' }
			].filter((item) => item.name.includes(text));
		}
	};
	return { provider, state, release: () => release() };
}

export function createProvider() {
	const state = reactive({ failure: false, slow: false, calls: [], aborts: 0 });
	let release = () => undefined;
	const provider = {
		async request(config, context) {
			if (config.url !== '/demo/members' || config.method !== 'get')
				throw new Error('Unknown local route');
			const text = config.params?.text;
			if (typeof text !== 'string') throw new Error('text must be a string');
			context.signal.throwIfAborted();
			state.calls.push({
				text,
				scope: context.scope,
				epoch: context.epoch,
				requestId: context.requestId
			});
			if (state.slow) {
				await new Promise((resolve, reject) => {
					const abort = () => {
						state.aborts++;
						context.signal.removeEventListener('abort', abort);
						reject(context.signal.reason);
					};
					context.signal.addEventListener('abort', abort, { once: true });
					release = () => {
						context.signal.removeEventListener('abort', abort);
						resolve();
					};
				});
			}
			context.signal.throwIfAborted();
			if (state.failure) throw new Error('Local provider failure');
			return [
				{ id: 1, name: '第一成员' },
				{ id: 2, name: '第二成员' }
			].filter((item) => item.name.includes(text));
		}
	};

export function createDemoState() {
	const held = ref(false),
		empty = ref(false),
		failure = ref(false),
		calls = ref(0);
	const pending = new Set<() => void>();
	async function read(signal: AbortSignal, text: string) {
		signal.throwIfAborted();
		calls.value++;
		if (held.value)
			await new Promise<void>((done, reject) => {
				const finish = () => {
					pending.delete(finish);
					signal.removeEventListener('abort', abort);
					done();
				};
				const abort = () => {
					pending.delete(finish);
					signal.removeEventListener('abort', abort);
					reject(signal.reason);
				};
				pending.add(finish);
				signal.addEventListener('abort', abort, { once: true });
				if (signal.aborted) abort();
			});
		signal.throwIfAborted();
		if (failure.value) throw new Error('演示选择器请求失败');
		return empty.value
			? []
			: rows.filter((item) => item.label.toLowerCase().includes(text.toLowerCase()));
	}
	function release() {
		held.value = false;
		for (const finish of [...pending]) finish();
	}
	return { held, empty, failure, calls, read, release };
}

				if (type !== 'presentation') throw new Error('Unknown local dictionary');

	async function read(signal, text) {
		signal.throwIfAborted();
		calls.value++;

			await new Promise((done, reject) => {
				const finish = () => {
					pending.delete(finish);
					signal.removeEventListener('abort', abort);
					done();
				};
				const abort = () => {
					pending.delete(finish);
					signal.removeEventListener('abort', abort);
					reject(signal.reason);
				};
				pending.add(finish);
				signal.addEventListener('abort', abort, { once: true });
				if (signal.aborted) abort();
			});

		held.value = false;

公开 runtime 注入键 ​

asamDataRuntimeKey 是包根公开的 InjectionKey<AsamDataRuntime>，用于 Vue setup 内通过 inject 取得当前应用关联的 runtime；返回值可能为 undefined，调用方应先处理未提供的情况。getAsamDataRuntime(app) 与 provideAsamData(app, provider) 使用同一个键提供 runtime，同一应用重复获取保持对象身份，不同应用各自持有 runtime 与 provider。符号按身份匹配；重新创建同描述的 Symbol 或字符串 “AsamDataRuntime” 都不能代替公开键。

provider-lifetime 的完整 TS/JS 示例增加独立检查按钮，实际挂载两个应用并通过公开键注入，核对各自 scope 与 provider、重复符号和字符串缺失、一个应用切换 scope 后另一个应用保持原 scope，以及组件卸载时释放其自建请求 context。直接使用公开键注入只提供 runtime 对象；自建 context 的释放由创建它的组件负责。这里不把普通 runtime.scope getter 描述成可自动驱动模板更新的 Vue ref。

创建回调的公开类型 ​

AsamCreateOption<V, I> 接收一个必填字符串，直接返回 AsamOption<V, I>。不指定泛型时，V 为 string、number、boolean 的联合，I 为只读、未知字段值的 AsamRecord；数据选择器未提供工厂时采用的默认记录才使用字符串 value。自定义数字或布尔 value、业务 raw 和递归 children 应在工厂中完整构造，children 保持父选项的 V/I 类型。返回对象的公开属性只读，类型不保证 raw 的嵌套对象深冻结。

类型检查会拒绝异步工厂、标量返回、缺少 raw、错误 label/value/raw、不同泛型的 children，以及非字符串输入。number 类型本身允许 NaN 和 Infinity；实际本地选项校验另行要求有限数值、对象 raw、布尔 disabled 和无循环的完整 children，Promise/thenable 也会被同步回调检查拒绝。校验失败发生在本地集合写入前，不创建远端实体。这里的校验不能替业务 raw 的领域校验。

本页 local-creation 完整 TS/JS 示例通过真实输入和选项选择调用工厂，并观察同一文本的 memo、刷新与失败保留、逻辑来源切换、服务端同值项优先、清空本地集合后再次调用工厂。这些操作保持来源返回值与父组件模型的各自归属；工厂调用本身不向后台提交创建请求。

AsamValuePolicy 的三条分支描述单选、值多选、对象多选；单选分支里的 valueMode 可为 value 或 object，值多选里的 multipleValueMode 可为 array 或 string，对象多选只使用 array。AsamSelection<V, I, M> 是根据策略 M 推导模型的条件类型，不是运行时转换函数，也不自动关联组件 props 与模型。

内部来源描述边界 ​

应用使用 defineAsamOptions、defineAsamDictSource 和 resolveAsamOptions 创建及消费来源。describeAsamOptionsSource 的函数声明通过根入口的 export type * 留在类型查询中，可以在 import type 配合 typeof 时描述函数形状；根入口不提供可调用的运行值。内部描述对象由真实工厂登记，不能靠复制 { kind } 伪造来源。应用无需调用描述读取器，也不能从未开放的包内深路径导入它。

局部请求错误插槽 ​

可选 error 插槽仅在当前请求错误存在时调用，接收只读 { error, stale, retry }。 error 与本实例 error 事件中的 AsamDataError 为同一对象，保留 cause、kind、 message 与 notified；渲染插槽不会再次通知 provider。stale 表示保留的数据已过期。

retry() 不接收参数，直接返回现有 reload({ force: true }) 的 Promise，结果为 AsamReloadResult<readonly AsamOption<V, I>[]> 的 success、error 或 cancelled 分支。 重试遵守 active、当前来源、取消和卸载规则，不改写模型。

提供该插槽时，自有内容替换整个默认局部错误区；返回空内容也表示主动替换。 未提供时继续显示原错误文字、过期提示和默认重试按钮。无 error 的单独 stale 状态 不调用此插槽；empty、loading 和其他基础插槽继续使用原作用域。
