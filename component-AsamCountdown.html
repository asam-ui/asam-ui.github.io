倒计时 AsamCountdown

展示到一个明确目标时刻的剩余时间。

使用场景 ​

展示到一个明确目标时刻的剩余时间。

基础用法与状态 ​

下列示例只使用本入口的实际公开能力。

基础用法与状态

展开源码
vue
<template>
	<div class="demo-root-layout">
		<AsamButton type="default" native-type="button" @click="restart">重新倒计时</AsamButton>
		<AsamCountdown :value="target" title="本地倒计时" @finish="finished = true" />
		<p class="example-paragraph" role="status">{{ finished ? '已结束' : '进行中' }}</p>
	</div>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamCountdownBasicDemo' });
import { ref } from 'vue';
import { AsamButton, AsamCountdown } from '@asam-ui/ui';
const target = ref(Date.now() + 90000);
const finished = ref(false);
const restart = () => {
	target.value = Date.now() + 90000;
	finished.value = false;
};
</script>

使用约定 ​

value 是目标时刻而非持续秒数，公开类型接受毫秒时间戳 number 或 Dayjs 实例。 完整说明。

Dayjs 目标时刻 ​

直接传入 Dayjs 实例，无需先转换成时间戳。示例从 dayjs 包导入，初始目标为30秒后，重置按钮将目标更新为60秒后；change 通知剩余毫秒数，finish 更新本地结束状态。源码提供完整 TS 和 JS 两种版本。

用法与契约补充说明 ​

使用约定 ​

value 是目标时刻而非持续秒数，公开类型接受毫秒时间戳 number 或 Dayjs 实例。原生 Date 对象不属于公开 TypeScript 输入契约；已有 Date 可显式调用 getTime() 后传入时间戳。format、title/prefix/suffix 和 valueStyle 控制显示；change/finish 通知剩余时间与结束。示例重新设置本地目标，不代表业务会话或服务器截止时间。

关联组件

统计值 AsamStatistic
参数与事件补充说明

公开绑定参数，包含具备类型的事件监听器；默认值由运行时定义提供。

参数与事件说明

format

必填：否；声明来源：上游声明。

默认值与来源
"HH:mm:ss"（已安装运行时；已安装组件）
