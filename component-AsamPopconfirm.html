气泡确认 AsamPopconfirm

在触发位置附近确认一个简单操作。

使用场景 ​

在触发位置附近确认一个简单操作。

确认与取消 ​

选择确认更新状态；取消保留原状态。

确认与取消

展开源码
vue
<!-- 此演示还使用 @asam-ui/icons-vue，请按官网对应指南配置这些公开依赖。 -->
<template>
	<AsamPopconfirm
		title="确认归档这条记录？"
		confirm-button-text="归档"
		cancel-button-text="保留"
		:icon="InfoFilled"
		@confirm="result = '已归档'"
		@cancel="result = '已保留'"
	>
		<template #reference>
			<AsamButton type="default" native-type="button">归档记录</AsamButton>
		</template>
	</AsamPopconfirm>
	<p role="status">{{ result }}</p>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamPopconfirmBasicDemo' });
import { ref } from 'vue';
import { AsamButton, AsamPopconfirm } from '@asam-ui/ui';
import { InfoFilled } from '@asam-ui/icons-vue';
const result = ref('等待操作');
</script>

自定义确认操作 ​

actions 插槽保留确认/取消回调语义。

自定义确认操作

展开源码
vue
<template>
	<AsamPopconfirm title="清理本地草稿？" @confirm="cleared = true">
		<template #reference>
			<AsamButton type="default" native-type="button">清理草稿</AsamButton>
		</template>
		<template #actions="{ confirm, cancel }">
			<AsamButton type="default" native-type="button" @click="cancel">保留草稿</AsamButton>
			<AsamButton type="default" native-type="button" @click="confirm">确认清理</AsamButton>
		</template>
	</AsamPopconfirm>
	<p role="status">{{ cleared ? '草稿已清理' : '草稿仍保留' }}</p>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamPopconfirmActionsDemo' });
import { ref } from 'vue';
import { AsamButton, AsamPopconfirm } from '@asam-ui/ui';
const cleared = ref(false);
</script>

用法与契约补充说明 ​

使用约定 ​

title、confirmButtonText、cancelButtonText 和 icon/iconColor 配置确认内容。confirm/cancel 事件分别接收触发事件；reference 插槽提供触发控件，actions 插槽可通过 confirm/cancel 回调提供自定义操作。浮层显隐与定位参数属于本入口公开 Props，无独立四档 size；复杂输入确认用 MessageBox。

组合职责与生命周期 ​

reference 提供单个触发元素，confirm/cancel 发出原 MouseEvent；actions 插槽接收 confirm/cancel，可自定义操作按钮而保持同一事件语义。title、图标、按钮文字与按钮类型负责确认呈现，tooltip 相关属性管理显隐、触发、挂载和定位。hide 与 popperRef 为实例入口。它承载确认动作，不承担持久表单校验；复杂表单使用 Dialog。
