加载服务 AsamLoadingService

用函数创建加载实例，持有返回值以更新提示和结束遮罩。

使用场景 ​

用函数创建加载实例，持有返回值以更新提示和结束遮罩。

创建、更新和关闭实例 ​

将遮罩限制在当前目标内，卸载也释放自己创建的实例。

创建、更新和关闭实例

展开源码
vue
<template>
	<div class="actions">
		<AsamButton type="default" native-type="button" @click="start">启动加载</AsamButton>
		<AsamButton type="default" native-type="button" @click="handle?.setText('即将完成')"
			>更新加载文字</AsamButton
		>
		<AsamButton type="default" native-type="button" @click="stop">结束加载</AsamButton>
	</div>
	<div ref="target" class="loading-target">
		<p class="example-paragraph">服务目标区域</p>
	</div>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamLoadingServiceBasicDemo' });
import { ref, onBeforeUnmount } from 'vue';
import { AsamButton, AsamLoadingService } from '@asam-ui/ui';
import type { AsamLoadingInstance } from '@asam-ui/ui';
const target = ref<HTMLElement>();
let handle: AsamLoadingInstance | undefined;
const stop = () => {
	handle?.close();
	handle = undefined;
};
const start = () => {
	if (!target.value || handle) return;
	handle = AsamLoadingService({ target: target.value, fullscreen: false, text: '正在加载' });
};
onBeforeUnmount(stop);
</script>

宿主上下文与所属服务清理 ​

本例仅关闭自己持有的句柄。宿主可通过 app.provide('asam-service-label', value) 提供服务内容；显式传入当前 AppContext。

宿主上下文与所属服务清理

展开源码
vue
<template>
	<div class="actions">
		<AsamButton native-type="submit" type="default" @click="open"
			>显示带宿主上下文的服务</AsamButton
		><AsamButton native-type="submit" type="default" @click="close">关闭本例服务</AsamButton>
	</div>
	<div ref="target" class="panel">局部加载目标</div>
</template>
<script lang="ts" setup>
import { defineComponent, getCurrentInstance, h, inject, onBeforeUnmount, ref } from 'vue';
import { AsamButton, AsamLoadingService, AsamMessage, AsamNotification } from '@asam-ui/ui';
import type { AsamLoadingInstance, AsamMessageHandler, AsamNotificationHandle } from '@asam-ui/ui';
const context = getCurrentInstance()?.appContext;
const target = ref<HTMLElement>();
const handles: Array<AsamMessageHandler | AsamNotificationHandle> = [];
let loading: AsamLoadingInstance | undefined;
const Label = defineComponent({
	setup() {
		const label = inject<string>('asam-service-label', '当前宿主的服务内容');
		return () => h('span', label);
	}
});
const close = () => {
	handles.splice(0).forEach((handle) => handle.close());
	loading?.close();
	loading = undefined;
};
const open = () => {
	close();
	handles.push(AsamMessage({ message: h(Label), duration: 0 }, context));
	handles.push(
		AsamNotification(
			{ title: '宿主上下文', message: h(Label), duration: 0, progress: true },
			context
		)
	);
	if (target.value)
		loading = AsamLoadingService(
			{ target: target.value, text: '局部处理', fullscreen: false },
			context
		);
};
onBeforeUnmount(close);
</script>

全屏加载与自动结束 ​

不指定 target 时使用全屏服务；示例在 1.5 秒后关闭自己持有的实例，并在卸载时清理。

全屏加载与自动结束

展开源码
vue
<template>
	<AsamButton type="default" @click="start">显示全屏加载</AsamButton>
	<p class="example-paragraph">锁定页面滚动，1.5 秒后自动结束；卸载时也会清理。</p>
</template>

<script lang="ts" setup>
import { onBeforeUnmount } from 'vue';
import { AsamButton, AsamLoadingService } from '@asam-ui/ui';
let handle: ReturnType<typeof AsamLoadingService> | undefined;
let timer: ReturnType<typeof setTimeout> | undefined;
const stop = () => {
	clearTimeout(timer);
	handle?.close();
	handle = undefined;
};
const start = () => {
	stop();
	handle = AsamLoadingService({ fullscreen: true, lock: true, text: '全屏加载中，稍后自动结束' });
	timer = setTimeout(stop, 1500);
};
onBeforeUnmount(stop);
</script>

<style scoped>
p:where(.example-paragraph) {
	margin-block: 16px;
	line-height: 1.8;
	overflow-wrap: anywhere;
}
</style>
