虚拟列表选择器 AsamSelectV2

以虚拟列表处理较多选项，height 与 itemHeight 控制列表视口。

使用场景 ​

以虚拟列表处理较多选项，height 与 itemHeight 控制列表视口。 options 使用包含 label、value、raw 的规范化选项；本组件不发起数据请求。远程与字典数据见本站对应数据组件。

单选、筛选与事件 ​

change 反映用户提交，clear 反映清空。禁用选项不能选择；disabled 禁用整个选择器并保留已选回显。实例 focus / blur 访问实际输入。

对象、数组与字符串存储 ​

valueMode="object" 返回完整规范化选项。multiple 配合 array 返回数组，配合 string 与 separator 保存分隔文本；对象模式不能与字符串存储组合。数值与布尔值的字符串还原依赖选项，避免同名字符串碰撞。

multipleLimit 限制实际选中数量，删除标签后可以重新选择。示例同时展示默认折叠标签、对象清空为 null、数组和分隔字符串的实际模型。

用法与契约补充说明 ​

虚拟选项与列表插槽 ​

在固定依赖 2.14.7 / Vue 3.5.34 的已核验输入中，首次挂载未提供 default 插槽，随后向同一实例动态新增该插槽时，新内容未显示；原生虚拟选择器与 ASAM native 路径结果一致。首次挂载即提供 default 的新实例对照能够显示内容。因此这项“初始缺省 → 动态新增”表现属于原生兼容限制，不保证新增内容可见。内容替换、删除和其他插槽按各自独立核验结果判断。

ASAM 扩展与迁移 ​

ASAM 扩展为四档密度、规范化 options、valueMode、multipleValueMode 与 separator。原始对象值必须显式 native 并配置 valueKey；object 模式保存规范化 option，raw 保留业务原件。空单选为 null，空多选为 [] 或空字符串。未解析值不会自动发起请求。loading、remote、remoteMethod 只是调用方控制的检索入口，异步生命周期使用本站 Remote 组件。

来源接管本地创建项 ​

对象创建先返回工厂提供的完整选项。来源随后提供同 value 的规范项时，清空模型并重新选择原创建文本会返回来源的 label/value/raw；可见选中标签与实例 selectedLabel 使用规范标签，即使工厂或来源标签不包含输入文本也成立。清空模型保留创建集合，clearCreatedOptions() 保留当前模型。这里用宿主更新静态 options 演示接管；真实远程生命周期由 Remote/Dict 组件承接。

大列表过滤、末端事件和对象创建 ​

虚拟列表只渲染视口附近的行，height 控制视口、itemHeight 控制行高。过滤后最后一项仍可选，已选标签在列表关闭及再次过滤时保留。end-reached(direction) 是原生虚拟列表的真实末端事件；没有把普通滚动回调改名。默认插槽接收规范化 item/index/disabled，native 模式可用 props 映射自定义字段及分组。

大列表过滤、末端事件和对象创建 ​

对象创建与 Select 共用 createOption 契约：普通记录自动构造完整 label/value/raw，自定义实体必须传同步工厂；清空返回 null/数组空值，按实际 value 类型去重。clearCreatedOptions() 仅重置本地创建集合，逻辑 source/scope 改变才调用，搜索/刷新/错误不清理。

原始字段映射与分组 ​

valueMode="native" 使用原始 options，props.options 映射组的子项字段，value/label/disabled 分别映射单项身份、文字和禁用标记。分组标题与禁用项仍属于虚拟列表的真实行。native 原始对象模式配合 valueKey；规范化 ASAM object 模式不混用原始字段映射。

异步查询回调 ​

filterable + remote + remoteMethod 将输入交给调用方；基础 V2 不执行 provider 请求。 示例在本地模拟异步过滤，使用 generation 拒绝迟到结果。debounce 控制回调延迟， remoteShowSuffix 保留后缀。完整请求与来源生命周期使用本站 RemoteSelectV2。

原始对象的稳定身份 ​

native 模式可以直接保存业务对象，以 valueKey 指定对象身份字段。回填同 id 的新对象时， 标签由对应来源选项显示；选中后返回原始 value 对象，不额外套 ASAM option / raw。 单选清空与多选空数组遵循原生模式，disabled 选项不能选取，multipleLimit 约束多选数量。

空字符串、清空与默认折叠标签 ​

空字符串可以是有效选项；native 模式的 emptyValues 明确排除空字符串，valueOnClear 明确返回 null。默认 tag 渲染下，显式 tagTooltip 配置优先于继承的 popperClass/effect；maxCollapseTags 控制保留的可见标签数。自定义 tag 插槽会接管默认标签布局，因此另用这个完整示例验证默认折叠浮层。

动态行高与内容更新的兼容限制 ​

estimatedOptionHeight、itemHeight 和列表插槽直接交给固定依赖 2.14.7 的原生虚拟列表。示例提供不同内容高度并允许更新内容；实际测量、缓存和滚动遵循原生限制，ASAM 不添加测量器、VNode 高度修补或重置缓存。未设置 estimatedOptionHeight 时使用原生固定行高分支。

API 阅读方式 ​

高级 value/object 模式默认 placeholder 为“请选择”；valueMode="native" 保留原生省略值、显式 undefined/null/false 和默认值，可显式覆盖；显式 popperClass 保留并追加当前密度类。旧 popperAppendToBody 已移除，使用 teleported 决定是否传送浮层，再用 appendTo 指定传送目标。

原生委托与高级对象标签 ​

native 的 tag scope 使用固定依赖公开的 Option[]；value、label、disabled 及自定义字段遵循原生 options/props 映射。deleteTag 接收 MouseEvent 与该原生项。此类型和经典 Select 的 OptionBasic 分开，不把原生项降为 unknown。

原生委托与高级对象标签 ​

valueMode="native" 直接使用依赖中的原生虚拟选择器，过滤、创建、IME、键盘、虚拟滚动与原生一致。高级 object 模式将 createOption 返回的完整选项存入本地集合；通过公开 label 插槽显示规范化标签，不修改原生 selectedLabel 或内部 states。实例 selectedLabel 在 native 模式直接读取原生值，在 object 模式读取规范化选项标签；自定义 label 插槽仍优先。原生键盘创建或动态行高问题按同输入原生实例记录，不能由包装层接管。
