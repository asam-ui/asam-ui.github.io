选择与表单

选择项 AsamOption

为 Select 的默认插槽提供原始值选项。

使用场景 ​

为 Select 的默认插槽提供原始值选项。value 是选择身份，label 是输入框回显，default 插槽可显示更丰富内容。

分组与显示内容 ​

Select 使用 valueMode=native 消费原始 Option。默认插槽内容负责菜单展示，label 保持简洁的选中回显。

分组与显示内容

展开源码
vue
<template>
	<div class="example">
		<AsamSelect
			v-model="value"
			v-bind="{
				'value-mode': 'native',
				clearable: true,
				filterable: true,
				'aria-label': '团队'
			}"
		>
			<AsamOptionGroup label="可用团队">
				<AsamOption label="设计" value="design">
					<span> 设计团队 · 视觉 </span>
				</AsamOption>
				<AsamOption label="开发" value="dev">
					<span> 开发团队 · 工程 </span>
				</AsamOption>
			</AsamOptionGroup>
			<AsamOptionGroup label="停用团队" disabled>
				<AsamOption label="停用" value="off" />
			</AsamOptionGroup>
		</AsamSelect>
		<output>原始值：{{ value }}</output>
	</div>
</template>

四档尺寸与上下文继承 ​

ASAM 扩展与迁移 ​

Option/OptionGroup 没有独立 size 属性，菜单密度由外层 Select 的四档 size 与弹层上下文决定。当前仅有 default 插槽，没有独立事件或实例方法；选择变化监听 Select.change。

API 阅读方式 ​

下方 Props、Events、Slots、Exposes 按当前实际公开类型与运行默认值生成。组合属性按分支生效，不能任意混搭值模式。标为“未知 / 未声明”的默认值不代表 false 或空值。源码区域提供对应语言的独立 Demo.vue，可直接复制或下载；本地辅助组件、数据和素材已内联到当前文件。
