使用约定 ​

mode、collapse、defaultActive/defaultOpeneds、uniqueOpened、router 和触发策略以公开 Props 配置；select/open/close 反馈实际选择和展开。router 模式需要宿主路由，实例公开打开、关闭和更新方法。 示例维护本地选择值，选择后的跳转由宿主处理；菜单项宽高由布局决定。

水平菜单高度 ​

mode 为 horizontal 时，可通过原生 CSS 变量 --el-menu-horizontal-height 覆盖默认菜单高度。给 AsamMenu 添加自己的 class，再在使用方局部样式中设置该变量，例如：

css
.menu-with-height.el-menu--horizontal {
	--el-menu-horizontal-height: 100px;
}

将 class="menu-with-height" 传给对应 AsamMenu 即可；数值是宿主布局设置，不是新增的 height prop，也不代表四档控件密度。此处只覆盖指定菜单，不修改共享样式。

完整使用场景 ​

Top bar ​

Top bar Menu can be used in a variety of scenarios.

By default Menu is vertical, but you can change it to horizontal by setting the mode prop to 'horizontal'. In addition, you can use the sub-menu component to create a second level menu. Menu provides background-color, text-color and active-text-color to customize the colors.
