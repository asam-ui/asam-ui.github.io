基础输入与操作

单行输入 AsamInput

单行文本、清空、格式化与输入装饰。

使用场景 ​

适合名称、邮箱、搜索词等单行输入。密码使用 AsamPassword，多行文本使用 AsamTextarea，数字步进使用 AsamInputNumber。普通 v-model 更新为字符串；number 修饰符可更新为数字。

type 支持 text、number、email、search、tel、url。单选、多选、日期及上传等场景使用对应的独立组件。

双向绑定与输入状态 ​

input 随输入触发，change 在值提交或失焦后触发；clearable 提供清空操作，readonly 和 disabled 表达不同的交互状态。

双向绑定与输入状态

	<div class="example">
		<AsamInput
			v-model="value"

			clearable
			:maxlength="20"

			@change="event = 'change: ' + $event"

		/>

	</div>
</template>

模型与事件补充说明 ​

模型修饰符与提交规则 ​

trim、number、lazy 按原生模型修饰协议承接。启用 number 时 update:modelValue 可能为数字；无法转换的文本仍为字符串。input/change 保留各自事件签名，不能从更新类型中删去合法数字。

lazy 依赖实际的原生 change 提交模型，失焦本身不额外提交。未提交的编辑草稿没有独立保存：切换 type 后，后续渲染会按父级已提交的 modelValue 恢复输入显示，草稿可能因此丢失；这也可能发生在同一输入节点仍保持焦点时。需要保留该次编辑值时，先完成提交并确认父级接受，再切换类型。

用法与契约补充说明 ​

ASAM 扩展与迁移 ​

四档 size 是 ASAM 密度扩展。旧 type="password" 和 showPassword 从单行输入迁至专用 Password；旧 type="textarea"、rows、autosize、resize 迁至专用 Textarea。ariaLabel、name、autocomplete、inputmode 按实际输入场景配置；validateEvent 控制表单校验触发。
