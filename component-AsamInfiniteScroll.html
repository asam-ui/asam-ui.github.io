指令

无限滚动指令 AsamInfiniteScroll

在滚动容器接近末尾时请求追加内容。

使用场景 ​

在滚动容器接近末尾时请求追加内容。

契约与组合 ​

这是 v-asam-infinite-scroll 指令；在 script setup 中导入 AsamInfiniteScroll as vAsamInfiniteScroll，或通过插件注册使用。 完整说明。

滚动容器可以是指令元素或最近的可滚动父元素。 完整说明。

卸载由原生清理 scroll 监听和不足一屏观察器；原生已排队节流、以及 mounted 等待 nextTick 期间发生卸载的行为均保持上游实现，ASAM 不增加异步清理或禁止迟到回调的保证。 完整说明。

基础用法与状态 ​

基础用法与状态

展开源码
vue
<template>
	<AsamCheckboxItem v-model="paused"> 暂停追加</AsamCheckboxItem>
	<ul
		v-asam-infinite-scroll="load"
		:infinite-scroll-disabled="disabled"
		:infinite-scroll-distance="16"
		:infinite-scroll-immediate="false"
		class="scroll-list"
	>
		<li v-for="item in count" :key="item">记录 {{ item }}</li>
	</ul>
	<p class="example-paragraph" role="status">{{ loading ? '正在追加' : count >= 30 ? '已经到底' : '可继续滚动' }}</p>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamInfiniteScrollBasicDemo' });
import { ref, computed, onBeforeUnmount } from 'vue';
import { AsamCheckboxItem, AsamInfiniteScroll as vAsamInfiniteScroll } from '@asam-ui/ui';
const count = ref(12);
const paused = ref(false);
const loading = ref(false);
const disabled = computed(() => paused.value || loading.value || count.value >= 30);
let timer: ReturnType<typeof setTimeout> | undefined;
const load = () => {
	if (disabled.value) return;
	loading.value = true;
	timer = setTimeout(() => {
		count.value = Math.min(count.value + 6, 30);
		loading.value = false;
	}, 250);
};
onBeforeUnmount(() => clearTimeout(timer));
</script>

}
</style>

}
</style>

立即填充与嵌套滚动容器 ​

立即填充与嵌套滚动容器

展开源码
vue
<template>
	<div class="demo-root-layout">
		<AsamCheckboxItem v-model="paused">暂停加载</AsamCheckboxItem>
		<AsamButton native-type="submit" type="default" @click="reset">清空后重新填充</AsamButton>
		<AsamButton native-type="submit" type="default" @click="secondary = !secondary"
			>切换宿主加载分派</AsamButton
		>
		<div class="scroll-parent">
			<ul
				:key="generation"
				v-asam-infinite-scroll="loadCallback"
				:infinite-scroll-delay="80"
				:infinite-scroll-distance="24"
				:infinite-scroll-disabled="disabled"
				:infinite-scroll-immediate="true"
			>
				<li v-for="id in count" :key="id">记录 {{ id }}</li>
			</ul>
		</div>
		<p class="example-paragraph" role="status">
			{{ loading ? '正在加载' : '可加载' }}；{{ count }} 条；调用 {{ calls }} 次
		</p>
		<p class="example-paragraph">
			当前函数 {{ secondary ? '第二加载函数' : '第一加载函数' }}；最近调用 {{ lastCallback }}
		</p>
	</div>
</template>
<script lang="ts" setup>
defineOptions({ name: 'AsamInfiniteScrollImmediateDemo' });
import { computed, onBeforeUnmount, ref } from 'vue';
import {
	AsamCheckboxItem,
	AsamButton,
	AsamInfiniteScroll as vAsamInfiniteScroll
} from '@asam-ui/ui';
const count = ref(0);
const calls = ref(0);
const paused = ref(false);
const loading = ref(false);
const secondary = ref(false);
const lastCallback = ref('尚未调用');

const disabled = computed(() => paused.value || loading.value || count.value >= 50);
let timer: ReturnType<typeof setTimeout> | undefined;
const generation = ref(0);
function loadCallback(): void {
	load(secondary.value ? '第二加载函数' : '第一加载函数');
}
function load(source: string): void {
	if (disabled.value) return;
	lastCallback.value = source;
	loading.value = true;
	calls.value++;
	const revision = generation.value;
	timer = setTimeout(() => {
		if (revision !== generation.value) return;
		count.value = Math.min(50, count.value + 5);
		loading.value = false;
	}, 100);
}
function reset(): void {
	generation.value++;
	clearTimeout(timer);
	count.value = 0;
	loading.value = false;
}
onBeforeUnmount(() => {
	generation.value++;
	clearTimeout(timer);
});
</script>

用法与契约补充说明 ​

契约与组合 ​

这是 v-asam-infinite-scroll 指令；在 script setup 中导入 AsamInfiniteScroll as vAsamInfiniteScroll，或通过插件注册使用。指令绑定为加载函数；infinite-scroll-delay 设置节流间隔，infinite-scroll-distance 设置触发距离，infinite-scroll-disabled 在加载中、暂停或到达末页时禁止追加。infinite-scroll-immediate=true 会在内容不足一屏时继续填充；false 等待实际滚动。

契约与组合 ​

滚动容器可以是指令元素或最近的可滚动父元素。mounted / updated / unmounted 生命周期直接使用 底层 2.14.7 的指令函数，回调和 this 原样传入。固定版本捕获挂载时的加载函数，updated 不替换该函数；需要动态分派时，宿主绑定一个稳定函数并在函数体读取当前状态，或以 key 重挂指令。完整示例采用稳定函数，展示加载中、末页、暂停/恢复、空列表立即填充和嵌套滚动父容器。

契约与组合 ​

卸载由原生清理 scroll 监听和不足一屏观察器；原生已排队节流、以及 mounted 等待 nextTick 期间发生卸载的行为均保持上游实现，ASAM 不增加异步清理或禁止迟到回调的保证。宿主需要避免重复请求，在卸载时取消自有请求或定时器，并可用自己的挂载标记拒绝失效业务请求。清空重新填充时，以 key 重挂指令恢复初始不足一屏观察器，并取消旧请求计时器；immediate 只保证初始填充，不自动重建已经释放的原生观察器。该指令在 2.14.7 已有原生弃用提示；本入口保留公开委托，替代组合见 AsamScrollbar。
