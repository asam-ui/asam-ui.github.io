固钉 AsamAffix

在滚动时把一小段操作固定到指定位置。

使用场景 ​

在滚动时把一小段操作固定到指定位置。

基础用法与状态 ​

下列示例只使用本入口的实际公开能力。

基础用法与状态

展开源码
vue
<template>
	<div ref="scroll" class="affix-scroll">
		<div class="doc010-affix-region">
			<AsamAffix target=".doc010-affix-region" :offset="offset" @change="fixed = $event">
				<AsamButton type="default" native-type="button">固定操作</AsamButton>
			</AsamAffix>
			<p>滚动查看固定范围</p>
		</div>
	</div>
	<p role="status">{{ fixed ? '操作已固定' : '向下滚动本区域以固定操作' }}</p>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamAffixBasicDemo' });
import { AsamButton, AsamAffix } from '@asam-ui/ui';
import { onBeforeUnmount, onMounted, ref } from 'vue';
const scroll = ref<HTMLElement>();
const offset = ref(0);
const fixed = ref(false);
const updateOffset = () => {
	offset.value = (scroll.value?.getBoundingClientRect().top ?? 0) + 8;
};
onMounted(() => {
	updateOffset();
	window.addEventListener('resize', updateOffset);
	window.addEventListener('scroll', updateOffset, { passive: true });
});
onBeforeUnmount(() => {
	window.removeEventListener('resize', updateOffset);
	window.removeEventListener('scroll', updateOffset);
});
</script>

<style scoped>
.affix-scroll {
	height: 200px;
	overflow: auto;
}

.doc010-affix-region {
	height: 500px;
	padding: var(--asam-space-md);
}
</style>

使用约定 ​

position 与 offset 设置固定方向和视窗偏移，target 限定有效目标范围，zIndex 管理层级。示例把 offset 同步到滚动区域在视窗中的顶部，随页面滚动与窗口大小更新，并在卸载时清理监听。change/scroll 反馈固定和滚动状态，实例提供更新计算方法。固定内容应保持短小；宽高由内容布局决定，没有四档密度。
