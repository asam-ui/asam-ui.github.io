指令

滚轮指令 AsamMousewheel

将滚轮原始事件与归一化位移提供给宿主。

使用场景 ​

将滚轮原始事件与归一化位移提供给宿主。

读取归一化滚轮位移 ​

在框内滚动查看累计像素；本例不阻止页面的默认滚动。

读取归一化滚轮位移

展开源码
vue
<template>
	<div v-asam-mousewheel="track" class="panel">
		<p class="example-paragraph">在这里滚动滚轮</p>
		<p class="example-paragraph" role="status">累计垂直位移 {{ pixels }} px</p>
	</div>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamMousewheelBasicDemo' });
import { ref } from 'vue';
import { AsamMousewheel as vAsamMousewheel } from '@asam-ui/ui';
import type { AsamMousewheelBinding } from '@asam-ui/ui';
const pixels = ref(0);
const track: AsamMousewheelBinding = (_event, normalized) => {
	pixels.value += normalized.pixelY;
};
</script>

使用约定 ​

绑定回调接收 WheelEvent 与 spinX/spinY/pixelX/pixelY。可按需调用 event.preventDefault，但要让页面其他区域继续正常滚动。卸载移除监听；本入口没有组件 Props 或 size。

组合职责与生命周期 ​

SFC 命名 vAsamMousewheel 后接收原 WheelEvent 与归一化滚轮数据。业务选择是否阻止默认滚动，卸载会移除宿主监听；它不提供滚动容器或无限加载状态。
