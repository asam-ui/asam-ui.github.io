反馈

警告提示 AsamAlert

在页面内展示状态、操作建议和可关闭的提示。适用于持续可见的信息。

使用场景 ​

在页面内展示状态、操作建议和可关闭的提示。适用于持续可见的信息。

状态与关闭 ​

切换四种状态；关闭后使用重置按钮重新显示。

状态与关闭

展开源码
vue
<template>
	<div class="actions">
		<label>
			<span>状态</span>
			<AsamSelect v-model="kind">
				<AsamOption :label="'success'" :value="'success'">success</AsamOption>
				<AsamOption :label="'info'" :value="'info'">info</AsamOption>
				<AsamOption :label="'warning'" :value="'warning'">warning</AsamOption>
				<AsamOption :label="'error'" :value="'error'">error</AsamOption>
			</AsamSelect>
		</label>
		<AsamButton type="default" native-type="button" @click="shown = true">重置提示</AsamButton>
	</div>
	<AsamAlert
		v-if="shown"
		title="数据导入结果"
		:type="kind"
		description="请确认导入内容后继续。"
		show-icon
		@close="shown = false"
	/>
	<p role="status">{{ shown ? '提示显示中' : '提示已关闭' }}</p>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamAlertBasicDemo' });
import { ref } from 'vue';
import { AsamSelect, AsamOption, AsamButton, AsamAlert } from '@asam-ui/ui';
const kind = ref<'success' | 'info' | 'warning' | 'error'>('info');
const shown = ref(true);
</script>

	display: flex;
	flex-wrap: wrap;
	gap: var(--asam-space-md);
	align-items: center;
}

.panel {
	padding: var(--asam-space-lg);
	border: 1px solid var(--asam-color-border);

使用约定 ​

通过 type 与 effect 选择语义和明暗效果；title、description、center、showIcon、closable 和 closeText 用于信息层次。close 事件只表示用户关闭，恢复提示由宿主重新挂载。title/default/icon 插槽可定制内容。本入口没有控件密度 size。

基础用法 ​

Alert 组件不属于浮层元素，不会自动消失或关闭。

Alert 组件提供5种类型，由 type 属性指定，默认值为 info。 primary 已被添加到2.9.11。

自定义关闭按钮 ​

你可以自定义关闭按钮为文字或其他符号。

你可以设置 Alert 组件是否为可关闭状态，关闭按钮的内容以及关闭时的回调函数同样可以定制。 closable 属性决定 Alert 组件是否可关闭，该属性接受一个 Boolean，默认为 false。你可以设置 close-text 属性来代替右侧的关闭图标，需要注意的是 close-text 必须是一个字符串。当 Alert 组件被关闭时会触发 close 事件。
