警告提示 AsamAlert

在页面内展示状态、操作建议和可关闭的提示。适用于持续可见的信息。

使用场景 ​

在页面内展示状态、操作建议和可关闭的提示。适用于持续可见的信息。

状态与关闭 ​

切换四种状态；关闭后使用重置按钮重新显示。

状态与关闭

展开源码
vue
<template>
	<div class="actions">
		<label>
			<span>状态</span>
			<select v-model="kind">
				<option>success</option>
				<option>info</option>
				<option>warning</option>
				<option>error</option>
			</select>
		</label>
		<button type="button" @click="shown = true">重置提示</button>
	</div>
	<AsamAlert
		v-if="shown"
		title="数据导入结果"
		:type="kind"
		description="请确认导入内容后继续。"
		show-icon
		@close="shown = false"
	/>
	<p role="status">{{ shown ? '提示显示中' : '提示已关闭' }}</p>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamAlertBasicDemo' });
import { ref } from 'vue';
import { AsamAlert } from '@asam-ui/ui';
const kind = ref<'success' | 'info' | 'warning' | 'error'>('info');
const shown = ref(true);
</script>

<style scoped>
.actions {
	display: flex;
	flex-wrap: wrap;
	gap: var(--asam-space-md);
	align-items: center;
}

.panel {
	padding: var(--asam-space-lg);
	border: 1px solid var(--asam-color-border);
	border-radius: var(--asam-radius-control);
}
</style>

图标来自独立 ASAM 图标包，暗色状态与自定义标题分别演示。

使用约定 ​

通过 type 与 effect 选择语义和明暗效果；title、description、center、showIcon、closable 和 closeText 用于信息层次。close 事件只表示用户关闭，恢复提示由宿主重新挂载。title/default/icon 插槽可定制内容。本入口没有控件密度 size。

Customizable Close Button ​

Customize the close button as texts or other symbols.

Alert allows you to configure if it's closable. The close button text and closing callbacks are also customizable. closable attribute decides if the component can be closed or not. It accepts boolean, and the default is true. You can set close-text attribute to replace the default cross symbol as the close button. Be careful that close-text must be a string. close event fires when the component is closed.

close button
