标签页 AsamTabs

在相关视图之间切换，或使用 ASAM 数据项展示标签和计数。

使用场景 ​

在相关视图之间切换，或使用 ASAM 数据项展示标签和计数。

基础用法与状态 ​

下列示例只使用本入口的实际公开能力。

基础用法与状态

展开源码
vue
<template>
	<AsamTabs
		:model-value="active"
		:items="items"
		@update:model-value="
			(value) => {
				if (typeof value === 'string') active = value;
			}
		"
		@change="changes++"
	>
		<template #label="{ item }">{{ item.label }}（{{ item.count ?? 0 }}）</template>
	</AsamTabs>
	<p role="status">当前 {{ active }}；变更 {{ changes }} 次</p>
	<AsamTabs
		:model-value="pane"
		@update:model-value="
			(value) => {
				if (typeof value === 'string') pane = value;
			}
		"
	>
		<AsamTabPane label="概览" name="overview">
			<p>概览内容</p>
		</AsamTabPane>
		<AsamTabPane label="明细" name="detail" lazy>
			<p>延迟挂载的明细</p>
		</AsamTabPane>
		<AsamTabPane label="暂不可用" name="disabled" disabled />
	</AsamTabs>
</template>

<script lang="ts" setup>
defineOptions({ name: 'AsamTabsBasicDemo' });
import { ref } from 'vue';
import { AsamTabs, AsamTabPane } from '@asam-ui/ui';
import type { AsamTabItem } from '@asam-ui/ui';
const active = ref('all');
const pane = ref('overview');
const changes = ref(0);
const items: AsamTabItem[] = [
	{ label: '全部', value: 'all', count: 3 },
	{ label: '草稿', value: 'draft', count: 1 },
	{ label: '锁定', value: 'locked', disabled: true }
];
</script>

使用约定 ​

items 的 label/value/disabled/count 为 ASAM 扩展；label 插槽接收 item。default 插槽放 AsamTabPane 以承载内容；两种方式可以分别使用，不应重复声明同一个 name。v-model 支持字符串或数值，change 带数据项；tabClick/tabChange/edit/tabAdd/tabRemove 保留基础事件。type、tabPosition、editable/closable、beforeLeave 等以公开参数为准。禁用项阻止选择并退出键盘序列；不声称当前实现添加了额外 aria-disabled。

完整使用场景 ​

基础用法 ​

基础的、简洁的标签页。

使用 v-model 或 model-value 控制当前选中的面板 name；default-value 设置未受控时的初始面板。原生默认 name 为首项序号 "0"，使用自定义 name 时应明确设置初始值。value 不是选择面板的公开 prop。
