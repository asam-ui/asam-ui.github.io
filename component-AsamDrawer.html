		v-model="open"

const track = (_event: MouseEvent, value: number) => {
	size.value = Math.round(value);
};
</script>

使用约定 ​

v-model 控制显隐，direction 决定展开方向，size 是本入口的浮层尺寸；支持 default/small/large/full 别名，也可传百分比、CSS 长度或数值。它与控件密度 size 不同，不传入 big/mini 冒充支持。ASAM 提供默认标题 icon，焦点恢复沿用原生行为。resizable 允许边缘拖动，resize-start/resize/resize-end 提供原始事件及尺寸；beforeClose(done) 可拦截关闭。公开 handleClose() 通过同一关闭守卫，完整类型见下方 API。2.14.7 的 afterEnter/afterLeave 是内部动画回调，已移除旧实例声明；调用方通过 opened/closed 事件观察动画结束，不直接触发内部过渡。

	}
};

组合职责与生命周期 ​

direction 支持 ltr/rtl/ttb/btt；size 接受实际 CSS 尺寸或 ASAM default/small/large/full 宽度别名，与控件密度分别配置。resizable 开启边缘拖动，resize-start/resize/resize-end 保留 MouseEvent 和数字尺寸。header、title、icon、default、footer 分别承载标题与内容。handleClose 是唯一公开关闭方法，经过 beforeClose；过渡完成分别订阅 opened/closed。destroyOnClose、appendToBody、appendTo、lockScroll 和 closeOnPressEscape 按宿主需求组合。外部直接修改 modelValue 由业务负责校验。卸载时释放遮罩和锁屏，原触发器仍连接时恢复焦点。

原生显隐与焦点 ​

省略 appendToBody 等交互参数使用 原生公开组件 默认值；显式 undefined、null、false 原样传递。打开、关闭、自动聚焦及过渡事件使用原生顺序，关闭守卫、Esc 和焦点回退交由原生处理。ASAM 仅保留标题、图标与尺寸外观，公开实例方法保留原生 this、返回值及实时引用。

自定义 header 直接接收原生 close/titleId/titleClass，并由调用方声明标题节点；组件不额外包裹 heading 或重复设置 titleId。未提供 header 时，默认标题保留 ASAM 的标题、图标与外观。

参数省略时的默认值 ​

withHeader、modalFade、closeOnClickModal、closeOnPressEscape、lockScroll、modal、showClose 省略时均由原生组件采用 true。显式提供 false、undefined 或后续移除参数仍按原生契约透传；API 表的默认值描述省略参数，不是包装层的内部布尔转换结果。
